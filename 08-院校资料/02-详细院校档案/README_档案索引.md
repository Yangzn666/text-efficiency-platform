## 💡 使用建议

### 快速筛选三步法

**第一步：确定专业类型**
- 想读学硕？→ 关注081200、083500
- 想读专硕？→ 关注085400、085404、085405
- 对AI感兴趣？→ 关注085410人工智能专硕（7所院校）

**第二步：确定目标院校范围**
- 冲刺型：C9 + 华科、电子科大等A+级
- 稳健型：北航、同济、武大等A/A-级
- 保底型：湖大、重大、山大等B+级

**第三步：查看改考信息**
- 2026改考408的院校可能有抄底机会
- 但竞争也会加剧，需谨慎评估
