# 11408考研院校资料库

## 📋 项目说明

本项目用于系统性地收集和分析所有开设**11408（计算机学科专业基础）**科目的考研院校信息，为27考研择校提供数据支持。

### 目标用户
- 准备参加27考研（2026年12月考试）的考生
- 专业课科目为11408的计算机相关专业考生
- 需要全面了解院校信息进行科学择校的同学

### 数据覆盖范围
- **院校类型**：所有开设11408科目的院校（预计80-120所）
- **数据类型**：招生数据、师资就业、院校环境三大维度
- **时间跨度**：重点收集2022-2026年近5年数据

## 🎯 数据收集计划

### 第一阶段：建立院校清单（1-2天）
✅ 访问研招网查询所有11408院校  
✅ 创建基础院校清单CSV表格  
✅ 按地区和层次分类整理  

### 第二阶段：批量收集招生数据（1-2周）
📊 收集近5年复试分数线  
📊 收集报录比和推免比例  
📊 收集招生人数和调剂信息  

### 第三阶段：深度调研重点院校（2-3周）
🔍 筛选20-30所目标院校  
🔍 联系在读学长学姐  
🔍 收集真题和考试特点  
🔍 调研导师和就业情况  

### 第四阶段：数据分析与决策（1周）
📈 难度评估和性价比分析  
📈 生成推荐院校清单  
📈 确定梯度志愿方案

## 📊 数据收集内容框架

### 1️⃣ 招生数据（核心）
- 历年分数线（2022-2026）
- 报录比（报名人数/录取人数）
- 推免比例（保研学生占比）
- 招生人数（统考名额）
- 调剂政策

### 2️⃣ 师资与就业
- 学科评估等级（A+/A/A-等）
- 导师研究方向和课题组
- 重点实验室和科研项目
- 就业率和薪资水平
- 主要就业去向

### 3️⃣ 院校环境
- 地理位置和城市级别
- 生活成本（学费/住宿/日常）
- 住宿条件和设施
- 学术氛围和竞争压力
- 实习和就业机会

## ⚠️ 注意事项

### 数据准确性
1. **交叉验证**：重要数据从2-3个来源确认
2. **标注来源**：每个数据点都要记录来源和采集日期
3. **区分学硕/专硕**：两者分数线和招生政策可能不同
4. **注意校区差异**：如哈工大（哈尔滨/深圳/威海）分数线差异大

### 时效性管理
1. **优先近2年数据**：老数据仅作参考趋势
2. **关注政策变化**：某校可能突然改考408或退出408联盟
3. **定期更新**：每年9月招生简章发布后更新最新数据

### 常见陷阱
- ❌ 不要只看分数线，要结合报录比综合判断
- ❌ 不要忽视推免比例对统考名额的影响
- ❌ 不要盲目追求名校，要考虑个人实力匹配度
- ❌ 不要忽略地理位置对就业的影响

## 🛠️ 使用建议

### 对于数据收集者
1. 按照阶段计划逐步推进，不要急于求成
2. 使用统一的模板记录数据，便于后续分析
3. 重要页面及时截图保存到`04-原始数据来源/`
4. 定期备份数据，避免丢失

### 对于择校决策者
1. 先广泛收集数据，再逐步缩小范围
2. 结合自身优势（数学强/专业课强/英语弱等）选择
3. 建立梯度志愿：冲刺（1-2所）+ 稳妥（2-3所）+ 保底（1-2所）
4. 记录决策逻辑，方便后续复盘和调整
