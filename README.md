## 📐 01-数学一/

**用途**: 数学一科目的学习资料整理

### 子目录结构
```
01-数学一/
├── 01-知识点整理/           # 按章节整理的知识点
│   ├── 高等数学/            # 高数知识点、公式、定理
│   ├── 线性代数/            # 线代知识点、矩阵、向量
│   └── 概率论/              # 概率统计知识点
│
├── 02-真题与习题/           # 历年真题和练习题
│   ├── 历年真题/            # 2000-2025年真题及解析
│   ├── 专项练习/            # 按题型分类的练习
│   └── 错题集/              # 个人错题整理
│
├── 03-个人笔记/             # 个人学习笔记和总结
│   ├── 公式汇总/            # 重要公式整理
│   ── 解题技巧/            # 各类题型的解题方法
│
└── 04-备考指南/             # 备考策略和规划
    └── 复习计划/            # 基础、强化、冲刺阶段计划
```

### 使用建议
- **知识点整理**: 每学完一章,立即整理到对应文件夹
- **真题与习题**: 按年份保存真题,按题型分类专项练习
- **个人笔记**: 记录自己的理解和易错点
- **备考指南**: 根据经验贴制定个性化复习计划

## 📋 使用说明

### 1. 添加新的知识点
在对应科目的 `01-知识点整理/` 目录下创建新的Markdown文件或文件夹

### 2. 记录学习笔记
在对应科目的 `03-个人笔记/` 目录下记录个人理解和总结

### 3. 整理真题
将做过的真题和错题整理到对应科目的 `02-真题与习题/` 目录

### 4. 更新学习进度
在 `06-学习进度跟踪/` 目录下定期更新学习进度

### 5. 收集经验贴
在 `05-经验贴整理/` 目录下收集和整理高质量经验贴

---

## 🔧 维护建议

1. **每日整理**: 每天学习结束后,花10分钟整理当天的学习资料
2. **每周总结**: 每周日花30分钟总结本周进度,调整下周计划
3. **及时备份**: 重要资料建议定期备份到云盘(OneDrive/百度网盘)
4. **保持简洁**: 避免在根目录放置过多文件,保持根目录整洁
5. **统一命名**: 文件命名建议使用 `日期_主题.扩展名` 格式
