## 5.1 CPU的功能和基本构造

## 5.1 CPU的功能和基本构造 \u2b50\u2b50

### 一、CPU的功能 \u2b50\u2b50
CPU是计算机的核心部件，负责解释和执行指令。主要功能包括：

#### 1. 指令控制 \u2b50
- **取指**：从内存中取出指令
- **译码**：分析指令的操作码和地址码
- **顺序控制**：控制指令的执行顺序（PC自动递增或跳转）

#### 2. 操作控制 \u2b50
- 产生各种**控制信号**，协调各部件工作
- 例如：读/写信号、ALU运算控制信号、寄存器使能信号等
- 控制信号的来源：**控制器（CU）**根据指令译码结果产生

#### 3. 时间控制 \u2b50
- 对各种操作实施**定时控制**
- 确保数据在正确的时间出现在正确的位置
- 通过**时钟信号**同步各部件的工作节奏
- 时序信号：节拍脉冲、机器周期、指令周期

#### 4. 数据加工 \u2b50
- **算术运算**：加、减、乘、除等
- **逻辑运算**：与、或、非、异或等
- 由**运算器（ALU）**完成

---

### 二、CPU的基本结构 \u2b50\u2b50

#### 1. 运算器（ALU, Arithmetic Logic Unit）\u2b50
**功能**：执行所有的算术和逻辑运算
**组成**：
- **算术逻辑单元（ALU）**：核心部件，执行加减乘除、逻辑运算
- **累加器（ACC, Accumulator）**：暂存操作数和运算结果
- **状态寄存器（PSW, Program Status Word）**：存放运算结果的状态标志
  - CF（Carry Flag）：进位标志
  - ZF（Zero Flag）：零标志
  - SF（Sign Flag）：符号标志
  - OF（Overflow Flag）：溢出标志

#### 2. 控制器（CU, Control Unit）\u2b50\u2b50
**功能**：指挥整个计算机系统协调工作
**组成**：
- **程序计数器（PC, Program Counter）**：存放下一条指令的地址 \ud83d\udd22
- **指令寄存器（IR, Instruction Register）**：存放当前正在执行的指令 \ud83d\udcdd
- **指令译码器（ID, Instruction Decoder）**：对指令操作码进行译码 \ud83d\udd0d
- **时序产生器**：产生各种时序信号 \u23f1️
- **操作控制器**：产生各种控制信号 \ud83c\udfaf

#### 3. 寄存器组 \u2b50\u2b50\u2b50 必考重点
CPU内部的高速存储单元，用于暂存数据和地址。

**专用寄存器**（每个都有特定用途）：
- **PC（Program Counter）程序计数器** \u2b50\u2b50
  - 功能：存放**下一条**要执行的指令地址
  - 特点：具有自动递增功能（PC ← PC + 1）
  - 大小：取决于地址总线宽度（如32位系统PC为32位）
  - 注意：PC指向的是下一条指令，不是当前指令！

- **IR（Instruction Register）指令寄存器** \u2b50\u2b50
  - 功能：存放**当前**正在执行的指令
  - 内容：从内存取出的完整指令（操作码 + 地址码）
  - 大小：取决于指令字长（如32位指令IR为32位）

- **MAR（Memory Address Register）存储器地址寄存器** \u2b50\u2b50
  - 功能：存放欲访问的**内存单元地址**
  - 特点：单向输出（只向地址总线发送地址）
  - 大小：等于地址总线宽度

- **MDR（Memory Data Register）存储器数据寄存器** \u2b50\u2b50
  - 功能：存放从内存读出或写入内存的**数据**
  - 特点：双向传输（既可以从内存读，也可以向内存写）
  - 大小：等于数据总线宽度

- **ACC（Accumulator）累加器** \u2b50
  - 功能：暂存操作数和运算结果
  - 特点：ALU的一个输入端通常固定连接到ACC

**通用寄存器**：
- 程序员可以直接使用的寄存器
- 用于存放操作数、中间结果、地址等
- 数量：RISC架构较多（如MIPS有32个），CISC架构较少（如x86有8~16个）

---

### 三、寄存器的作用总结 \u2b50\u2b50\u2b50 必背表格
| 寄存器 | 全称 | 功能 | 位数 | 方向 |
|--------|------|------|------|------|
| **PC** | Program Counter | 存放下条指令地址 | 地址总线宽度 | 输出 |
| **IR** | Instruction Register | 存放当前指令 | 指令字长 | 输入 |
| **MAR** | Memory Address Register | 存放内存地址 | 地址总线宽度 | 输出 |
| **MDR** | Memory Data Register | 存放内存数据 | 数据总线宽度 | 双向 |
| **ACC** | Accumulator | 暂存操作数/结果 | 数据总线宽度 | 双向 |

**记忆口诀**：
- "**P**C指向**下**一条，**I**R存放**当**前令"
- "**M**AR送**地**址，**M**DR传**数**据"
- "**A**CC累加器，运算好帮手"

## 5.3 数据通路

## 5.3 数据通路 \u2b50\u2b50

### 一、数据通路的概念 \u2b50
**定义**：数据在CPU各部件之间传输的路径
**组成**：
- **寄存器**：PC、IR、MAR、MDR、ACC、通用寄存器等
- **ALU**：算术逻辑单元
- **内部总线**：连接各部件的数据通道
- **控制信号**：控制数据的流向和操作

**作用**：
- 实现指令执行过程中的数据传输
- 协调各部件的工作时序
- 确保数据在正确的时间到达正确的位置

---

### 二、总线结构 \u2b50\u2b50

#### 1. 单总线结构 \u2b50
**特点**：所有部件都连接到一条公共总线上
**优点**：
- 结构简单，成本低
- 易于扩展新部件
**缺点**：
- **同一时刻只能有一个部件发送数据**（总线冲突）
- 速度慢（串行传输）
- 总线成为性能瓶颈

## 5.4 控制器设计

## 5.4 控制器设计 \u2b50\u2b50\u2b50 重点难点

### 一、控制器的功能 \u2b50\u2b50
**核心任务**：根据指令译码结果，产生各种控制信号，协调各部件工作。

**控制信号示例**：
- **寄存器使能信号**：RegWrite（寄存器写使能）、PCWrite（PC写使能）
- **ALU控制信号**：ALUOp（选择运算类型）、ALUSrc（选择ALU输入源）
- **存储器控制信号**：MemRead（内存读）、MemWrite（内存写）
- **总线控制信号**：BusEnable（总线使能）

---

### 二、硬布线控制器 \u2b50\u2b50

#### 1. 基本原理 \u2b50
**定义**：通过**组合逻辑电路**直接产生控制信号
**特点**：
- 控制逻辑由硬件电路实现（与门、或门、非门等）
- 速度快（硬件并行执行）⚡⚡⚡
- 设计复杂（需要手工设计大量逻辑电路）
- 不易修改（修改功能需要重新设计电路）

#### 2. 工作原理 \u2b50\u2b50
**输入**：
- 指令操作码（来自IR）
- 时序信号（时钟脉冲、节拍信号）
- 状态标志（来自PSW）

**输出**：
- 各种控制信号（RegWrite、MemRead、ALUOp等）

## 5.5 流水线技术

## 5.5 流水线技术 \u2b50\u2b50\u2b50 超级重点（必考大题）

### 一、流水线的基本概念 \u2b50\u2b50

#### 1. 什么是流水线？ \u2b50
**类比**：工厂装配线
- **非流水线**：一个工人完成整个产品的所有工序（慢）
- **流水线**：多个工人分工合作，每人负责一道工序，产品依次通过各工序（快）

**CPU流水线**：
- 将指令执行过程分解为多个**阶段（Stage）**
- 多条指令在不同阶段**并行执行**
- 每个时钟周期都有一条新指令进入流水线

---

#### 2. 经典的5级流水线 \u2b50\u2b50\u2b50
MIPS处理器的经典5级流水线：

| 阶段 | 名称 | 功能 | 英文 |
|------|------|------|------|
| **IF** | 取指 | 从内存取出指令 | Instruction Fetch |
| **ID** | 译码 | 译码指令，读取寄存器 | Instruction Decode |
| **EX** | 执行 | ALU执行运算 | Execute |
| **MEM** | 访存 | 访问内存（LOAD/STORE） | Memory Access |
| **WB** | 写回 | 将结果写回寄存器 | Write Back |
