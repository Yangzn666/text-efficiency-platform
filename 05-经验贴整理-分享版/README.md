## 💡 核心精华提炼

### 数学一 Top 5 建议
1. ⭐ **平时积累 > 冲刺突击** - 真正决定考场发挥的是平时积累
2. ⭐ **选填专项训练** - 考前16套选填练习,目标95%正确率
3. ⭐ **名师组合策略** - 武忠祥前六章 + 方浩无穷级数 + 张宇补充
4. ⭐ **一本保本,两本血赚** - 吃透一两本习题集就够了
5. ⭐ **真题至少刷2遍** - 真题是最宝贵的资源

### 英语一 Top 5 建议
1. ⭐ **阅读不是翻译,是找逻辑** - 掌握唐迟阅读逻辑
2. ⭐ **细节服从主旨** - 所有细节都服务于主旨
3. ⭐ **真题至少刷三遍** - 精读+归类+突破
4. ⭐ **作文一定要自己写** - 参考句式,自己写几十篇
5. ⭐ **单词反复背** - 直到考前一天都要背单词

### 政治 Top 5 建议
1. ⭐ **得选择题者得天下** - 选择题占50分,是关键
2. ⭐ **1000题三遍法** - 全面刷→错题重做→重点突破
3. ⭐ **肖四必背** - 12月拿到肖四立即背,至少3遍
4. ⭐ **10月启动** - 政治10月启动完全来得及
5. ⭐ **跟着肖秀荣没有错** - 肖秀荣是考研政治一生推

### 408 Top 5 建议
1. ⭐ **王道四本是核心** - 吃透王道就够了,不要贪多
2. ⭐ **真题至少刷3遍** - 真题是最宝贵的资源
3. ⭐ **LeetCode算法训练** - 1000题+模板总结
4. ⭐ **艾宾浩斯遗忘表** - 科学记忆,定期复习
5. ⭐ **早期启动** - 408内容多,需要早期启动

## 🎓 不同背景考生必读

### 科班考生
- 优势: 有专业基础,理解能力强
- 注意: 不要眼高手低,认真复习408
- 必读: [科班考生备考策略汇总](./分析与总结/按背景分类/科班考生备考策略汇总.md)

### 跨考考生
- 优势: 学习动力强,目标明确
- 注意: 提前1-2年规划,补足专业基础
- 必读: [跨考考生备考策略汇总](./分析与总结/按背景分类/跨考考生备考策略汇总.md)

### 在职考生
- 优势: 有工作经验,自律性强
- 注意: 找轻松工作,利用碎片时间
- 必读: [11408综合/202X_370_在职二战_工作学习平衡.md](./原始经验贴/11408综合/202X_370_在职二战_工作学习平衡.md)

- 优势: 有备考经验,知道问题所在
- 注意: 翻烂一战错题本,精准复仇
