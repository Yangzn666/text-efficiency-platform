## 🔧 API接口说明

### GET /api/study-data
获取学习记录数据

**请求：**
```
GET http://localhost:3001/api/study-data
```

**响应：**
```json
{
  "success": true,
  "data": {
    "studyRecords": [...],
    "subjectProgress": {...}
  }
}
```

### POST /api/study-data
保存学习记录数据

**请求：**
```
POST http://localhost:3001/api/study-data
Content-Type: application/json

{
  "studyRecords": [...],
  "subjectProgress": {...}
}
```

**响应：**
```json
{
  "success": true,
  "message": "数据保存成功"
}
```
