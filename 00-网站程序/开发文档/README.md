# 个人考研效率平台

一个专注于提升考研学习效率的个人专用平台，整合心理学方法帮助克服拖延问题。

## 项目特点

- **个人专用**：去社交化设计，专注个人学习
- **轻量化**：简洁高效的架构设计
- **心理学支撑**：基于认知、行为、情感三个维度的干预机制
- **高效实用**：针对性解决考研学习中的实际问题

## 技术栈

### 前端
- Vue 3 + TypeScript
- Vite 构建工具
- Element Plus UI 组件库
- Pinia 状态管理
- Vue Router 路由管理

### 后端
- Node.js + Express
- SQLite 数据库
- JWT 身份验证
- LowDB 本地数据存储

## 开发计划

按照五个阶段逐步实施：
1. 基础架构搭建
2. 核心功能开发
3. 学科专项功能
4. 功能完善优化
5. 测试与使用

## 使用说明

本平台专为个人考研备考设计，帮助用户：
- 管理注意力，克服短视频成瘾
- 制定个性化学习路径
- 应用心理学方法改善学习习惯
- 跟踪各科目学习进度
- 提升整体学习效率

## 部署方式

支持本地部署，数据完全私有化存储，确保个人隐私安全。
