# 408费曼强化方案（AI协作版）

> 2026-07-20 制定 | 适用阶段：408强化轮（7月底 ~ 10月中）

---

## 一、方案总览

**目标**：用费曼学习法 + AI陪练，把408四门课从"看过"变成"讲得出来、做得对题"。

**核心逻辑**：
- 基础轮已完成 → 强化轮不是重看一遍，而是**检测理解深度 + 补漏洞**
- 费曼讲解 = 最诚实的漏洞检测器（讲不出来 = 没真懂）
- AI = 随叫随到的陪练（追问、挑错、出题、记录漏洞）

**时间预算**：每章净增15-20分钟（讲解+补漏），不额外挤占刷题时间。

---

## 二、每章执行流程（四步闭环）

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│ ① 听课  │ →  │ ② 讲解  │ →  │ ③ 刷题  │ →  │ ④ 补讲  │
│ 正常流程 │    │ 10-15min │    │ 大题+错题│    │ 错题重讲 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
                     ↓                              ↓
              卡点 → 记录漏洞清单            错题 → 讲清错因
```

| 步骤 | 做什么 | 标准 |
|------|--------|------|
| ① 听课 | 看强化视频 + 教材对应章节 | 正常速度，不暂停抄笔记 |
| ② 费曼讲解 | 合上书，用大白话讲本章核心机制 | 外行能听懂、能答"为什么" |
| ③ 刷题 | 王道书大题（综合应用题）+ 基础轮错题重刷 | 大题必须动手写，记录正确率 |
| ④ 补讲 | 错题对应的知识点重新讲一遍 | 能讲清"我错在哪、正确逻辑是什么" |

**刷题来源说明**（王道没有单独的强化题集）：
1. **王道书大题**：每章的综合应用题，基础轮可能跳过的，强化轮必须动手写
2. **错题重刷**：小程序里基础轮正确率<70%章节的选择题
3. **真题按章练**：9月开始，用历年真题对应章节的大题检测强化效果

## 三、AI协作三种模式

### 模式A：我讲AI挑刺（每章必做）

**开场白**：
> 「我刚学完[科目]的[章节名]，我来给你讲一遍。你扮演完全不懂的人，我讲不清楚的地方你就追问，讲错了直接指出。最后给我打分（流畅度/准确度/通俗度）。」

**AI行为**：
- 追问含糊处："你说的'映射'具体是什么意思？能举个例子吗？"
- 纠正错误："这里不对，写回法和写直达法你搞反了"
- 最后输出：评分 + 漏洞清单（章节+卡点描述）

**耗时**：10分钟/章

---

### 模式B：AI故意讲错，我找茬（周末复习用）

**开场白**：
> 「你把[章节名]的核心内容讲一遍，但故意埋2-3处错误，我来找茬并纠正。」

**规则**：
- 错误要"看起来合理"（概念混淆、因果颠倒、数值记错）
- 我找出错误后，AI确认并追问"为什么这里是错的"
- 找不出 = 这块还有漏洞 → 加入漏洞清单

**耗时**：15分钟/次，每周1-2次

---

### 模式C：苏格拉底式追问（错题≥3道时触发）

**开场白**：
> 「用苏格拉底提问法帮我复习[知识点]，一次只问一个问题，我答完你再问下一个，答不上来给提示。最后汇总我的漏洞。」

**适用场景**：某章刷题正确率 < 70% 时

**耗时**：5-8分钟

## 四、四科强化大纲 & 费曼讲解要点

### 数据结构（约3周）

| 章节 | 费曼讲解核心问题 |
|------|-----------------|
| 线性表 | 数组和链表各自的痛点是什么？为什么有了链表还要数组？ |
| 栈和队列 | 为什么"限制操作"反而有用？举两个生活中的栈/队列 |
| 树与二叉树 | 为什么树比链表查找快？BST退化怎么办？AVL/红黑树怎么救？ |
| 图 | 为什么需要图？BFS和DFS分别在"找什么"？最短路径算法各自的适用场景？ |
| 查找 | 哈希为什么O(1)？冲突了怎么办？B+树为什么适合磁盘？ |
| 排序 | 每种排序的"核心思想"一句话？稳定性为什么重要？ |

**讲解模板**：「XX结构是为了解决XX问题而发明的 → 它的核心操作是XX → 代价/局限是XX → 所以有了改进版XX」

## 五、进度追踪指标（网站同步显示）

每章记录4个状态：

| 指标 | 状态值 | 说明 |
|------|--------|------|
| 听课 | ⬜未开始 / 🔄进行中 / ✅完成 | 视频+教材 |
| 费曼讲解 | ⬜待讲 / ⚠️有卡点 / ✅通过 | 核心指标 |
| 刷题 | 正确率% | <70%标红 |
| 错题补讲 | ⬜待补 / ✅已补 | 错题对应知识点重讲 |

**章节完成定义**：听课✅ + 讲解✅ + 正确率≥70% + 错题已补讲

**漏洞清单**：所有"⚠️有卡点"的章节汇总，冲刺阶段重点回炉。

## 七、验收标准（强化结束时自测）

1. 随机抽一章，能在3分钟内用大白话讲清核心机制，不看任何资料
2. 王道大题能独立写出完整解题过程，各章选择题重刷正确率 ≥ 75%
3. 漏洞清单清零（所有卡点已补讲通过）
4. 能画出四门课之间的关联图（如：虚拟内存 ↔ 页表 ↔ Cache ↔ 磁盘调度）
