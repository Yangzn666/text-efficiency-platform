## 🎯 核心特色

### 1. 精确追踪听课:做题比例

- **目标**: 1:3 (听课1小时,做题3小时)
- **监控**: 总体比例 + 单个知识点比例
- **预警**: 超出1:2到1:4范围显示红色
- **建议**: 系统自动调整今日任务

### 2. 智能复习(艾宾浩斯遗忘曲线)

- **复习间隔**:
  - 掌握≥90%: 30天
  - 掌握≥70%: 14天
  - 掌握≥50%: 7天
  - 掌握<50%: 3天
- **自动提醒**: 仪表盘显示今日需复习内容
- **到期标记**: 知识点和错题分别追踪

### 3. 讲义例题多刷机制

- **标记**: 添加知识点时勾选"是否为讲义例题"
- **追踪**: 记录复习轮数(1/2/3刷)
- **建议**: 
  - 第1刷: 跟老师思路
  - 第2刷: 独立重做
  - 第3刷: 只看错题

### 4. 错题深度分析

- **错误原因**: 5种类型多选(概念/方法/计算/思路/粗心)
- **详细分析**: 文字描述错误原因
- **正确解法**: 完整记录解题步骤
- **关键技巧**: 总结核心技巧
- **其他解法**: 记录多种解法
- **标签系统**: 便于检索和统计

### 5. 专题突破支持

- **智能推荐**: 基于薄弱知识点自动推荐
- **默认专题**: 6个高频考点
  - 微分中值定理
  - 积分不等式
  - 无穷级数综合题
  - 曲线曲面积分
  - 特征值特征向量
  - 多维随机变量
- **进度追踪**: 视频观看+习题完成

## 💡 设计理念

### 1. 以题型为核心

不是按章节组织,而是按**题型**组织知识点:
- 求极限
- 证明中值定理
- 计算三重积分
- ...

这样更符合强化阶段的实际需求。

### 2. 量化学习过程

所有学习行为都可量化:
- 听课时长(分钟)
- 做题时长(分钟)
- 做题数量(道)
- 正确率(%)
- 复习次数(次)

数据驱动决策,不再凭感觉学习。

### 3. 智能而非手动

- 自动生成今日任务
- 自动计算复习日期
- 自动监控听课:做题比例
- 自动推荐薄弱专题

减少手动操作,专注学习内容。

### 4. 深度而非广度

- 错题深度分析(不只是记录)
- 知识点多维掌握(概念/方法/速度/综合)
- 专题集中突破(不只是泛泛而学)

追求真正掌握,而不是走过场。

## 📝 注意事项

### 数据存储

- 所有数据保存在浏览器localStorage
- 清除浏览器缓存会丢失数据
- 建议定期手动备份
- 不同浏览器数据不互通

### 兼容性

- 推荐使用Chrome/Edge浏览器
- 需要启用JavaScript
- 需要启用localStorage
- 建议使用桌面端(手机端体验不佳)

### 性能

- 大数据量时(>1000个知识点)可能变慢
- 建议定期清理已掌握的错题
- 避免一次性添加过多知识点
