**数据结构** (+26行):
```typescript
interface ReviewSchedule { ... }      // 复习计划
```

**状态管理** (+6行):
```typescript
const reviewSchedules = ref<ReviewSchedule[]>([])

```

**核心方法** (+210行):

1. **艾宾浩斯遗忘曲线系统**:
   - `generateReviewDates()` - 生成6次复习日期
   - `calculateRetentionRate()` - 计算记忆保持率
   - `createReviewSchedule()` - 创建复习计划
   - `completeReview()` - 完成复习
   - `getTodayReviews()` - 获取今日复习
   - `getPendingReviews()` - 获取待复习列表

2. **掌握度追踪系统**:
   - `updateMasteryRecord()` - 更新掌握度
   - `getSubjectMasteryStats()` - 科目统计
   - `getWeakKnowledgePoints()` - 薄弱点识别

3. **数据持久化**:
   - `saveReviewData()` - 保存复习数据
   - `saveMasteryData()` - 保存掌握度数据
   - 更新`initializeLearningPathData()`加载新数据
