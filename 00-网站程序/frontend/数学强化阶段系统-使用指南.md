## 🚀 快速开始

### 第一步: 数据迁移(可选)

如果你之前使用过旧的数学模块,可以迁移数据:

1. 打开浏览器控制台 (F12)
2. 输入以下命令:
```javascript
window.migrateMathData()
```
3. 等待迁移完成提示

### 第二步: 添加知识点

1. 进入 [知识点强化管理](http://localhost:5173/math/reinforcement/topics)
2. 点击"添加知识点"按钮
3. 填写信息:
   - 所属科目: 高等数学/线性代数/概率论
   - 章节: 如"第1讲 函数、极限、连续"
   - 知识点名称: 如"函数间断点判定"
   - 是否为讲义例题: 如果是武忠祥/张宇讲义上的例题,勾选
   - 需要专题突破: 如果这个知识点比较难,勾选

**建议批量添加**:
- 高等数学: 求极限、求导数、求积分、中值定理、无穷级数...
- 线性代数: 行列式、矩阵运算、特征值、二次型...
- 概率论: 概率计算、分布函数、参数估计...

### 第三步: 记录学习

每次学习后,记录你的学习情况:

1. 在知识点卡片上点击"记录学习"
2. 选择学习类型:
   - 📺 听课: 看视频课
   - ✍️ 做题: 做习题
   - 🔄 复习: 复习旧知识
   - 🎯 专题: 进行专题突破
3. 输入时长(分钟)
4. 如果做题,填写做题数量和正确率
5. 可选: 写学习笔记

**重要**: 保证听课:做题 = 1:3 的比例!

### 第四步: 添加错题

遇到错题时,立即记录:

1. 进入 [智能错题本](http://localhost:5173/math/reinforcement/wrong-book)
2. 点击"添加错题"
3. 填写信息:
   - 题目来源: 880题/660题/严选题/讲义例题/真题/模拟卷
   - 题型分类: 如"求极限"、"证明中值定理"
   - 难度: 基础/中等/困难
   - 错误原因: 多选(概念不清/方法不会/计算错误/思路错误/粗心大意)
   - 错误分析: 详细描述为什么错了
   - 正确解法: 记录正确的解题步骤
   - 关键技巧: 总结解题技巧
   - 其他解法: 如果有多种解法,记录下来
   - 标签: 如"中值定理,积分不等式"
   - 优先级: 高/中/低

### 第五步: 查看今日计划

每天开始前,查看 [强化学习仪表盘](http://localhost:5173/math/reinforcement):

1. 查看今日任务列表
2. 系统会自动推荐:
   - 需要复习的知识点
   - 需要复习的错题
   - 新课学习(保证1:3比例)
3. 点击"开始"按钮,进入对应页面学习
4. 完成后打勾,系统自动统计

## 💡 核心功能说明

### 1. 强化学习仪表盘

**功能**:
- 三门科目进度概览(高数/线代/概率)
- 今日学习任务(自动生成)
- 智能提醒(复习到期、错题待复习、专题建议)
- 学习统计(总时间、听课:做题比例)
- 快速操作入口

**使用技巧**:
- 每天早上第一件事: 查看仪表盘,了解今日任务
- 关注听课:做题比例,确保在1:2到1:4之间
- 及时处理智能提醒,不要积压

### 2. 知识点强化管理

**功能**:
- 按科目浏览所有知识点
- 筛选器(掌握程度、复习状态、专题需求)
- 每个知识点显示:
  - 掌握程度进度条
  - 听课时长 vs 做题时长
  - 听课:做题比例(绿色表示合理)
  - 下次复习日期
- 学习记录时间轴
- 掌握详情雷达图(概念/方法/速度/综合)

**使用技巧**:
- 定期筛选"需复习"的知识点,及时复习
- 关注比例异常的知识点(红色),调整学习方法
- 标记需要专题突破的知识点,集中攻克

### 3. 智能错题本

**功能**:
- 错题统计分析(错误类型分布饼图)
- 多维度筛选(科目、优先级、状态)
- 智能复习提醒(基于遗忘曲线)
- 复习模式(隐藏答案,先自己做)
- 错题掌握追踪(复习3次且正确自动标记掌握)

**使用技巧**:
- 遇到错题立即记录,不要拖延
- 详细分析错误原因,这是提升的关键
- 定期复习错题,直到标记为"已掌握"
- 关注高频错误类型,针对性改进

### 4. 专题突破中心

**功能**:
- 智能推荐(基于薄弱知识点)
- 专题列表(微分中值定理、积分不等式等)
- 学习进度追踪
- B站视频链接
- 配套习题记录

**使用技巧**:
- 优先学习智能推荐的专题
- 每看完一个视频,更新进度
- 做完配套习题,更新题数
- 进度达到100%自动标记完成

## 📊 学习流程示例

### 典型的一天

**上午 8:30-11:30**:

1. **8:30-9:00** 复习到期知识点
   - 打开仪表盘,查看"今日任务"
   - 点击"复习: XXX"任务
   - 回顾知识点,做几道题检验

2. **9:00-9:50** 复习错题
   - 进入智能错题本
   - 复习到期的错题(5-10道)
   - 先自己做,再看答案
   - 标记是否掌握

3. **10:00-11:00** 听课
   - 看武忠祥强化班视频1讲
   - 在知识点管理中记录"听课60分钟"

**下午 14:00-17:00**:

4. **14:00-15:30** 做题
   - 做880题对应章节
   - 目标: 15道题
   - 在知识点管理中记录"做题90分钟,15道,正确率80%"

5. **15:30-16:15** 专题突破(可选)
   - 如果某个知识点薄弱

**晚上 19:00-21:00**:

7. **20:00-21:00** 复盘总结
   - 查看仪表盘,确认今日任务完成
   - 检查听课:做题比例是否合理
   - 规划明天任务

## 🎯 强化阶段学习要点

### 1. 听课:做题 = 1:3

**为什么重要**:
- 听懂≠会做
- 只有通过大量练习才能掌握
- 考试考的是解题能力,不是听课能力

**如何保证**:
- 系统会自动监控比例
- 仪表盘显示总体比例
- 知识点卡片显示单个知识点比例
- 绿色表示合理(1:2到1:4)
- 红色表示需要调整

### 2. 讲义例题2-3刷

**第一刷**: 跟老师思路,理解方法
**第二刷**: 独立重做,检验掌握
**第三刷**: 只看错题,巩固薄弱

**如何操作**:
- 添加知识点时,勾选"是否为讲义例题"
- 在知识点详情中,可以看到复习轮数
- 每刷一次,更新复习轮数

### 3. 智能复习(基于遗忘曲线)

**复习间隔**:
- 掌握度≥90%: 30天后复习
- 掌握度≥70%: 14天后复习
- 掌握度≥50%: 7天后复习
- 掌握度<50%: 3天后复习

**如何使用**:
- 系统自动计算下次复习日期
- 仪表盘显示"今日需复习"
- 按时复习,不要拖延

### 4. 错题深度分析

**错误原因分类**:
- 概念不清: 基础知识没掌握
- 方法不会: 解题方法不知道
- 计算错误: 思路对但算错
- 思路错误: 方向就错了
- 粗心大意: 看错题、抄错数

**分析要点**:
- 诚实面对自己的错误
- 找到根本原因,不只是表面
- 记录关键技巧,避免再犯

### 5. 专题突破

**何时需要专题**:
- 某知识点错题超过5道
- 掌握度低于50%
- 历年真题高频考点

**常见专题**:
- 微分中值定理
- 积分不等式
- 无穷级数综合题
- 曲线曲面积分
- 特征值特征向量
- 多维随机变量

## 🔧 常见问题

### Q1: 如何批量添加知识点?

目前需要逐个添加。建议:
1. 先列出所有需要的知识点清单
2. 分批添加(每次10-20个)
3. 可以利用Excel整理后,手动录入

未来可以开发批量导入功能。

### Q2: 数据保存在哪里?

所有数据保存在浏览器本地存储(localStorage)中:
- `mathReinforcement_topics`: 知识点数据
- `mathReinforcement_wrongProblems`: 错题数据
- `mathReinforcement_specialTraining`: 专题数据
- `mathReinforcement_dailyPlans`: 每日计划

**注意**: 
- 清除浏览器缓存会丢失数据
- 建议定期导出备份(功能开发中)
- 不同浏览器数据不互通

### Q3: 如何备份数据?

目前可以手动备份:

1. 打开浏览器控制台
2. 输入:
```javascript
JSON.stringify(localStorage.getItem('mathReinforcement_topics'))
```
3. 复制输出内容,保存到文本文件

未来会开发一键导出/导入功能。

### Q4: 可以在手机上使用吗?

理论上可以,但:
- 界面是为桌面端优化的
- 手机端体验可能不佳
- 建议在电脑或平板上使用

### Q5: 如何修改已添加的知识点?

目前在知识点详情对话框中可以:
- 更新掌握程度
- 记录学习时间
- 标记是否需要专题突破

如需修改其他字段,需要删除后重新添加(功能待优化)。
