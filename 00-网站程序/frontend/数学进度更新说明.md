## 🔄 如何更新学习记录到系统

由于学习记录存储在浏览器的 localStorage 中，你需要在浏览器控制台运行以下代码：

### 方法一：使用提供的脚本文件

1. 打开考研效率平台网站
2. 按 `F12` 打开浏览器开发者工具
3. 切换到 **Console（控制台）** 标签
4. 复制 `update-math-progress.js` 文件的全部内容
5. 粘贴到控制台中并按回车执行

### 方法二：直接运行以下代码

```javascript
// 在浏览器控制台中直接运行
(async function updateMathProgress() {
  const studyRecords = JSON.parse(localStorage.getItem('studyRecords') || '[]');
  const today = new Date().toISOString().split('T')[0];
  const timestamp = Date.now();
  
  const newRecords = [{
    id: `record_${timestamp}_math_update`,
    date: today,
    subject: '数学',
    duration: 180,
    content: '基础阶段进度更新：基础三十讲概率论剩3讲，1000题高数1-17讲完成、线代完成、概率论剩3讲',
    type: 'study',
    createdAt: new Date().toISOString()
  }];
  
  localStorage.setItem('studyRecords', JSON.stringify([...studyRecords, ...newRecords]));
  console.log('✅ 学习记录已更新！请刷新页面查看最新进度');
})();
```

## 💡 后续更新建议

每次完成新的学习内容后，你可以：

1. **快速更新**：在控制台运行简短代码添加学习记录
2. **详细记录**：记录具体学习的章节、时长和内容
3. **自动同步**：进度组件会自动计算并显示完成情况

示例代码（每次学习后运行）：
```javascript
// 添加一条学习记录
const records = JSON.parse(localStorage.getItem('studyRecords') || '[]');
records.push({
  id: `record_${Date.now()}`,
  date: new Date().toISOString().split('T')[0],
  subject: '数学',
  duration: 120,  // 学习时长（分钟）
  content: '学习了XXX内容',  // 具体学习内容
  type: 'study',
  createdAt: new Date().toISOString()
});
localStorage.setItem('studyRecords', JSON.stringify(records));
console.log('✅ 学习记录已添加');
```
