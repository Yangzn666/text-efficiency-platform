## 💡 技术要点

### 1. 卡片触发机制
```typescript
// CSLearning.vue中已注册
onMounted(() => {
  ;(window as any).showKnowledgeCard = (cardId: string) => {
    knowledgeCardRef.value?.show(cardId)
  }
})

// composition.ts中使用
onclick="showKnowledgeCard('ieee754')"
```

### 2. Markdown中的HTML链接
- ❌ 不能用: `[text](url)` (不支持@click)
- ✅ 必须用: `<a onclick="...">text</a>`

### 3. 数据结构设计
每个卡片的数据数组应放在script部分,例如:
```typescript
const singlePrecisionData = [
  { field: '符号位 S', bits: '1位', description: '0正1负' },
  // ...
]
```
