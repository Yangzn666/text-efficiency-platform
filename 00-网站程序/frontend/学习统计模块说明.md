# 学习数据统计模块 - 全新设计

## 📊 功能特性

### 1. 今日学习概览
- **实时显示**今日学习时长（分钟）
- **学习次数**统计
- **学习科目**数量
- **各科进度条**直观展示各科学习时间占比

### 2. 最近学习记录
- 显示**准确时间**（精确到分钟）
- 支持**展开/收起**查看全部记录
- 每条记录包含：
  - 学习日期和时间
  - 科目标签（带颜色区分）
  - 学习时长
  - 学习内容详情
  - 学习类型（学习/练习/复习）

### 3. 本周学习趋势
- **柱状图**展示7天学习情况
- 高亮显示**今天**
- 统计信息：
  - 本周总时长
  - 日均时长
  - 学习天数

### 4. 学习热力图
- **30天学习热力图**（类似GitHub贡献图）
- 5个等级颜色区分学习强度：
  - 灰色：0分钟
  - 浅绿：< 60分钟
  - 中绿：60-120分钟
  - 深绿：120-180分钟
  - 最深绿：> 180分钟
- 鼠标悬停显示具体数据

### 5. 学习成就系统
6个成就徽章，激励持续学习：
- 🥇 **初试锋芒**：完成第一次学习记录
- ⏱️ **小时达人**：累计学习60分钟
- 🌟 **半日苦读**：单日学习超过240分钟
- 🔥 **周学习战士**：本周学习超过600分钟
- 💪 **坚持不懈**：连续学习7天
- 🏆 **学习马拉松**：累计学习1000分钟

## 📝 使用方法

### 添加学习记录

#### 方法1：快速录入工具
双击打开：`d:\学习\效率\00-网站程序\frontend\add-study-record.html`

#### 方法2：控制台直接添加
```javascript
const request = indexedDB.open('localforage');
request.onsuccess = function(e) {
  const db = e.target.result;
  const tx = db.transaction('keyvaluepairs', 'readwrite');
  const store = tx.objectStore('keyvaluepairs');
  
  store.get('studyRecords').onsuccess = function(ev) {
    const records = ev.target.result || [];
    records.push({
      id: 'record_' + Date.now(),
      date: '2026-05-06',  // 改成实际日期
      subject: '科目名称',
      duration: 25,  // 分钟
      content: '学习内容描述',
      type: 'study',  // study/practice/review
      createdAt: new Date().toISOString()
    });
    store.put(records, 'studyRecords').onsuccess = function() {
      localStorage.setItem('studyRecords', JSON.stringify(records));
      console.log('✅ 添加成功！');
      location.reload();
    };
  };
};
```
