# 1000题A组错题批量导入指南

## 📋 准备工作

### 1. 数据格式要求

系统支持 **JSON** 和 **CSV** 两种格式的错题数据导入。

#### JSON格式（推荐）

```json
[
  {
    "questionType": "选择题",
    "problemSource": "1000题A组",
    "subject": "高等数学",
    "chapter": "第一章 函数 极限 连续",
    "title": "第1题 - 函数定义域",
    "content": "已知 $f(x+1)$ 的定义域为 $[0,a]$，求 $f(x)$ 的定义域",
    "mistakeType": ["概念不清"],
    "mistakeAnalysis": "错误原因分析...",
    "correctSolution": "正确解法...",
    "keyTechnique": "关键技巧总结...",
    "difficulty": "基础",
    "priority": "medium"
  }
]
```

#### CSV格式

```csv
questionType,problemSource,subject,chapter,title,content,mistakeType,mistakeAnalysis,correctSolution,keyTechnique,difficulty,priority
选择题,1000题A组,高等数学,第一章 函数 极限 连续,第1题,"已知$f(x+1)$的定义域","[""概念不清""]","错误分析","正确解法","关键技巧",基础,medium
```

### 2. 字段说明

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| questionType | String | ✅ | 题型 | 选择题/填空题/解答题 |
| problemSource | String | ✅ | 题目来源 | 1000题A组 |
| subject | String | ✅ | 科目 | 高等数学/线性代数/概率论 |
| chapter | String | ❌ | 章节 | 第一章 函数 极限 连续 |
| title | String | ✅ | 题目标题 | 第1题 - 函数定义域 |
| content | String | ❌ | 题目内容（支持LaTeX） | 已知 $f(x+1)$... |
| mistakeType | Array/String | ✅ | 错误类型 | ["概念不清","计算错误"] |
| mistakeAnalysis | String | ❌ | 错误分析 | 详细描述错误原因 |
| correctSolution | String | ❌ | 正确解法 | 完整的解题步骤 |
| keyTechnique | String | ❌ | 关键技巧 | 解题技巧和要点 |
| difficulty | String | ❌ | 难度 | 基础/中等/困难 |
| priority | String | ❌ | 优先级 | high/medium/low |

### 3. 错误类型选项

- **概念不清**：对基本概念理解不透彻
- **方法不会**：不知道用什么方法解题
- **计算错误**：思路正确但计算出错
- **思路错误**：解题方向完全错误
- **粗心大意**：看错题目、抄错数字等

## 🚀 导入步骤

### 第一步：准备数据文件

1. 参考模板文件：`public/1000题A组错题导入模板.json`
2. 按照你的实际错题情况填写数据
3. 保存为 `.json` 或 `.csv` 文件

### 第二步：打开智能错题本

1. 访问网站
2. 进入"数学强化阶段" → "智能错题本"

### 第三步：批量导入

1. 点击顶部的 **"📥 批量导入"** 按钮
2. 在弹出的对话框中：
   - 查看导入说明和数据格式要求
   - 拖拽文件或点击上传你的错题数据文件
3. 系统会自动解析并显示预览（前5条）
4. 确认无误后，点击 **"确认导入"**

### 第四步：验证导入结果

1. 导入成功后会显示成功消息
2. 在错题列表中查看新导入的错题
3. 可以使用筛选功能按科目、优先级等查看

## 💡 使用技巧

### 1. 分批导入
如果错题数量较多（>100道），建议分批次导入，便于检查和管理。

### 2. 优先级设置
- **high（高）**：经常错的、重要的知识点
- **medium（中）**：一般难度的错题
- **low（低）**：简单但粗心的错误

### 3. LaTeX公式
题目内容和解答中可以使用LaTeX公式，用 `$...$` 包裹行内公式，用 `$$...$$` 包裹块级公式。

### 4. 数据备份
导入前建议备份原始数据文件，以防需要重新导入。

## ⚠️ 注意事项

1. **JSON格式要求**：
   - 确保JSON语法正确（可以用在线JSON验证工具检查）
   - 数组最后一项后面不要加逗号
   - 字符串中的双引号需要转义：`\"`

2. **mistakeType字段**：
   - JSON中应该是数组格式：`["概念不清", "计算错误"]`
   - 如果是字符串，系统会自动转换为单元素数组

3. **特殊字符**：
   - LaTeX中的反斜杠需要双写：`\\frac`、`\\sqrt`
   - 换行符使用 `\n`

4. **文件大小**：
   - 单次导入建议不超过500条记录
   - 文件太大可能导致浏览器卡顿

## 🔧 常见问题

### Q: 导入后看不到数据？
A: 刷新页面，或者检查浏览器的控制台是否有错误信息。

### Q: 提示"文件格式错误"？
A: 检查JSON语法是否正确，可以使用 https://jsonlint.com/ 验证。

### Q: 可以修改已导入的错题吗？
A: 目前不支持直接编辑，可以先删除再重新导入修正后的版本。

### Q: 如何导出错题数据？
A: 在错题列表页面，点击"导出错题"按钮即可。
