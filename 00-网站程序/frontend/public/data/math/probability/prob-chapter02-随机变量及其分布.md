# 第二章 随机变量及其分布

- 掌握离散型随机变量的分布律与连续型随机变量的概率密度
- 掌握八大常见分布（0-1、二项、泊松、几何、超几何、均匀、指数、正态）
- 会求随机变量函数的分布

---

## 🎯 核心知识点

### 一、分布函数

**定义**：$F(x)=P\{X\le x\}$，$x\in\mathbb{R}$。

**性质**：

- 单调不减
- $F(-\infty)=0$，$F(+\infty)=1$
- 右连续：$F(x+0)=F(x)$

**用分布函数求概率**：

- $P\{a<X\le b\}=F(b)-F(a)$
- $P\{X=a\}=F(a)-F(a-0)$（连续型此值为 $0$）
- $P\{X>a\}=1-F(a)$

### 二、离散型随机变量

**分布律**：$P\{X=x_k\}=p_k$，满足 $p_k\ge 0$，$\sum p_k=1$。

**分布函数**：$F(x)=\sum_{x_k\le x}p_k$（阶梯函数）。

#### 常见离散分布

- **0-1 分布** $B(1,p)$：$P\{X=k\}=p^k(1-p)^{1-k}$，$k=0,1$
- **二项分布** $X\sim B(n,p)$：$P\{X=k\}=C_n^k p^k(1-p)^{n-k}$，$k=0,1,\cdots,n$
- **泊松分布** $X\sim P(\lambda)$：$P\{X=k\}=\dfrac{\lambda^k}{k!}e^{-\lambda}$，$k=0,1,2,\cdots$
- **几何分布**：$P\{X=k\}=p(1-p)^{k-1}$，$k=1,2,\cdots$
- **超几何分布**：$P\{X=k\}=\dfrac{C_M^k C_{N-M}^{n-k}}{C_N^n}$

**泊松定理**：$n$ 大 $p$ 小、$np=\lambda$ 适中时，二项分布近似泊松分布。

### 三、连续型随机变量

**概率密度** $f(x)$：$F(x)=\int_{-\infty}^x f(t)\,dt$，满足 $f(x)\ge 0$，$\int_{-\infty}^{+\infty}f(x)\,dx=1$。

**性质**：

- $P\{a<X\le b\}=\int_a^b f(x)\,dx$
- 在 $f(x)$ 连续点 $F'(x)=f(x)$
- 单点概率 $P\{X=a\}=0$

#### 常见连续分布

- **均匀分布** $X\sim U(a,b)$：$f(x)=\dfrac{1}{b-a}\ (a<x<b)$
- **指数分布** $X\sim E(\lambda)$：$f(x)=\lambda e^{-\lambda x}\ (x>0)$，具**无记忆性**
- **正态分布** $X\sim N(\mu,\sigma^2)$：$f(x)=\dfrac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

**标准正态** $N(0,1)$：密度 $\varphi(x)=\dfrac{1}{\sqrt{2\pi}}e^{-x^2/2}$，分布函数 $\Phi(x)$。

**正态分布性质**：

- $\Phi(-x)=1-\Phi(x)$
- 标准化：$X\sim N(\mu,\sigma^2)\Rightarrow \dfrac{X-\mu}{\sigma}\sim N(0,1)$
- $P\{|X-\mu|<k\sigma\}$：$1\sigma\to0.6826$，$2\sigma\to0.9544$，$3\sigma\to0.9974$

### 四、随机变量函数的分布

**离散型**：列出 $Y=g(X)$ 的取值，合并相同取值的概率。

**连续型（一维）**：

- **分布函数法**：先求 $F_Y(y)=P\{g(X)\le y\}$，再求导得 $f_Y(y)$
- **公式法**（$g$ 单调可导）：$f_Y(y)=f_X[h(y)]|h'(y)|$，其中 $h=g^{-1}$

## ✏️ 经典题型

:::fold 题型一 利用分布函数/密度性质求参数（★年年考）
**例**：设 $X$ 的分布函数 $F(x) = \begin{cases} A + Be^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases}$（$\lambda > 0$），求 $A$、$B$。

**解**：

1. $F(+\infty) = 1$：$x \to +\infty$ 时 $F \to A = 1$
2. 右连续 $F(0+) = F(0) = 0$：$A + B = 0$ → $B = -1$

**要点**：分布函数用三大性质（单调、$F(\pm\infty)$、右连续）列方程；密度则用 $\int_{-\infty}^{+\infty} f(x)dx = 1$。
:::

:::fold 题型二 常见分布的概率计算（高频）
**例（泊松）**：$X \sim P(2)$，求 $P\{X \ge 1\}$。

**解**：$P\{X \ge 1\} = 1 - P\{X = 0\} = 1 - e^{-2} \approx 0.865$

---

**例（指数）**：$X \sim E(0.1)$（寿命，单位千小时），求 $P\{5 < X < 10\}$。

**解**：$P = e^{-0.5} - e^{-1} \approx 0.607 - 0.368 = 0.239$

**要点**：指数分布 $P\{X > x\} = e^{-\lambda x}$（无记忆性）；二项分布用 $C_n^k p^k(1-p)^{n-k}$。
:::

:::fold 题型三 正态分布标准化计算（★年年考）
**例**：$X \sim N(3, 4)$，求 $P\{2 < X < 5\}$（$\Phi(0.5) = 0.6915$，$\Phi(1) = 0.8413$）。

**解**：标准化 $Z = \frac{X - 3}{2}$：

1. $P\{2 < X < 5\} = \Phi(\frac{5 - 3}{2}) - \Phi(\frac{2 - 3}{2}) = \Phi(1) - \Phi(-0.5)$
2. $= \Phi(1) - [1 - \Phi(0.5)] = 0.8413 - 0.3085 = 0.5328$

**要点**：$X \sim N(\mu, \sigma^2) \Rightarrow \frac{X - \mu}{\sigma} \sim N(0,1)$；$\Phi(-x) = 1 - \Phi(x)$。
:::

:::fold 题型四 一维随机变量函数的分布（★年年考·大题）
**例**：$X$ 的密度 $f_X(x) = \begin{cases} \frac{x}{8}, & 0 < x < 4 \\ 0, & \text{其他} \end{cases}$，求 $Y = 2X + 8$ 的密度。

**解**（分布函数法）：

1. $F_Y(y) = P\{2X + 8 \le y\} = P\{X \le \frac{y - 8}{2}\} = F_X(\frac{y - 8}{2})$
2. 求导：$f_Y(y) = f_X(\frac{y - 8}{2}) \cdot \frac{1}{2} = \frac{y - 8}{32}$（$8 < y < 16$）

**公式法**（$g$ 单调可导）：$f_Y(y) = f_X[h(y)]|h'(y)|$，其中 $h = g^{-1}$。

**要点**：先写 $F_Y(y) = P\{g(X) \le y\}$，化为 $X$ 的不等式，用 $F_X$ 表示后求导。
:::

## ⭐ 重点提示

- ★ 分布函数 $F(x)$ 是统一描述各类随机变量的核心工具
- ★ 八大分布的形式、参数、取值范围必须熟记
- ★ 正态分布的标准化是计算概率的关键步骤
- ★ 求随机变量函数的分布（分布函数法）是必考大题
- ★ 指数分布无记忆性、泊松定理是常考选择题
