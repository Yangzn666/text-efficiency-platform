# 第五章 大数定律与中心极限定理

- 理解棣莫弗—拉普拉斯定理、列维—林德伯格中心极限定理
- 会用中心极限定理近似计算概率

---

## 🎯 核心知识点

### 一、依概率收敛

设 $\{Y_n\}$ 为随机变量序列，若对任意 $\varepsilon>0$，

$$\lim_{n\to\infty}P\{|Y_n-Y|<\varepsilon\}=1$$

则称 $Y_n$ **依概率收敛**于 $Y$，记为 $Y_n\xrightarrow{P}Y$。

### 二、大数定律

**切比雪夫大数定律**：设 $X_1,\cdots,X_n$ 两两不相关，方差有共同上界 $C$，则

$$\frac{1}{n}\sum_{k=1}^n X_k - \frac{1}{n}\sum_{k=1}^n E(X_k) \xrightarrow{P} 0$$

**伯努利大数定律**：$n_A$ 为 $n$ 重伯努利试验中事件 $A$ 发生的次数，$p=P(A)$，则

$$\frac{n_A}{n}\xrightarrow{P}p$$

即频率依概率收敛于概率（频率稳定性的理论依据）。

**辛钦大数定律**：设 $X_1,\cdots,X_n$ 独立同分布，期望 $\mu$ 存在，则

$$\frac{1}{n}\sum_{k=1}^n X_k \xrightarrow{P} \mu$$

即样本均值依概率收敛于总体均值。

### 三、中心极限定理

**列维—林德伯格定理（独立同分布）**：设 $X_1,\cdots,X_n$ 独立同分布，$E(X_k)=\mu$，$D(X_k)=\sigma^2>0$，则当 $n$ 充分大时，

$$\frac{\sum\limits_{k=1}^n X_k - n\mu}{\sqrt{n}\sigma} \overset{\text{近似}}{\sim} N(0,1)$$

即 $\sum X_k$ 近似服从 $N(n\mu,n\sigma^2)$。

**棣莫弗—拉普拉斯定理（二项分布）**：$X\sim B(n,p)$，当 $n$ 充分大时，

$$\frac{X-np}{\sqrt{np(1-p)}} \overset{\text{近似}}{\sim} N(0,1)$$

即二项分布近似正态分布，是上者的特例。

### 四、应用步骤

用中心极限定理近似计算概率的一般步骤：

1. 确认 $X$ 为大量独立随机变量之和（或二项分布）
2. 计算总和的期望 $n\mu$ 与方差 $n\sigma^2$
3. 标准化为 $N(0,1)$：$Z=\dfrac{X-n\mu}{\sqrt{n}\sigma}$
4. 查标准正态分布表 $\Phi$ 求概率

## ✏️ 经典题型

:::fold 题型一 中心极限定理近似计算（中频·大题）
**例**：每袋水泥重量 $X_i$ 独立同分布，$E(X_i) = 50$ kg，$D(X_i) = 25$。求 $100$ 袋总重量超过 $5075$ kg 的概率（$\Phi(1.5) = 0.9332$）。

**解**：总重 $S = \sum_{i=1}^{100} X_i$：

1. $E(S) = 100 \times 50 = 5000$，$D(S) = 100 \times 25 = 2500$，$\sigma_S = 50$
2. 由中心极限定理，$S$ 近似 $N(5000, 2500)$
3. $P\{S > 5075\} = 1 - \Phi(\frac{5075 - 5000}{50}) = 1 - \Phi(1.5) = 0.0668$

**步骤**：求总和的期望方差 → 标准化为 $N(0,1)$ → 查 $\Phi$ 表。
:::

:::fold 题型二 二项分布的正态近似（中频）
**例**：$X \sim B(100, 0.2)$，用正态近似求 $P\{X \le 25\}$（$\Phi(1.25) = 0.8944$）。

**解**：$np = 20$，$np(1-p) = 16$，$\sigma = 4$

1. 标准化：$P\{X \le 25\} \approx \Phi(\frac{25 - 20}{4}) = \Phi(1.25)$
2. $= 0.8944$

**要点**：棣莫弗—拉普拉斯定理，$X \sim B(n,p)$ 当 $n$ 大时近似 $N(np, np(1-p))$。
:::

:::fold 题型三 切比雪夫不等式（低频）
**例**：设 $E(X) = 2$，$D(X) = 1$，用切比雪夫不等式估计 $P\{|X - 2| < 4\}$。

**解**：$P\{|X - 2| < 4\} \ge 1 - \frac{D(X)}{4^2} = 1 - \frac{1}{16} = \frac{15}{16}$

**大数定律辨析（选择题考点）**：

1. 辛钦：独立同分布 + 期望存在（不要求方差）
2. 切比雪夫：两两不相关 + 方差有共同上界
3. 伯努利：频率依概率收敛于概率
:::

## ⭐ 重点提示

- ★ 三大数定律的条件与结论辨析是经典选择题
- ★ 辛钦大数定律（独立同分布、只需期望存在）最常用
- ★ 中心极限定理的标准化计算是高频大题
- ★ 棣莫弗—拉普拉斯定理用于二项分布的正态近似
- ★ 理解"频率→概率""样本均值→总体均值"的统计思想
