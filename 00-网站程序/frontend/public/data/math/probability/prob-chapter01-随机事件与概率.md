# 第一章 随机事件与概率

## 📖 考纲要求

- 理解样本空间、随机事件的概念，掌握事件的运算（并、交、差、对立、互斥）
- 理解概率的公理化定义与基本性质
- 掌握古典概型与几何概型
- 理解条件概率，掌握乘法公式、全概率公式、贝叶斯公式
- 理解事件独立性的概念，会用独立性计算概率

---

## 🎯 核心知识点

### 一、事件及其运算

- **样本空间** $\Omega$：随机试验所有可能结果的全体
- **事件**：样本空间的子集，用 $A,B,C$ 表示
- **必然事件** $\Omega$，**不可能事件** $\varnothing$

**事件运算**：

- 并（和）$A\cup B$：$A$ 与 $B$ 至少一个发生
- 交（积）$A\cap B$ 或 $AB$：$A$ 与 $B$ 同时发生
- 差 $A-B=A\bar{B}$：$A$ 发生而 $B$ 不发生
- 对立 $\bar{A}=\Omega-A$：$A$ 不发生
- **互斥（互不相容）**：$AB=\varnothing$
- **对立必互斥，互斥未必对立**

**运算律**：交换律、结合律、分配律 $A(B\cup C)=AB\cup AC$，德摩根律 $\overline{A\cup B}=\bar{A}\bar{B}$，$\overline{AB}=\bar{A}\cup\bar{B}$。

### 二、概率的定义与性质

**公理化定义**（柯尔莫哥洛夫）：$P(A)$ 满足非负性、规范性 $P(\Omega)=1$、可列可加性。

**基本性质**：

- $P(\bar{A})=1-P(A)$
- $P(A-B)=P(A)-P(AB)$，若 $B\subset A$ 则 $P(A-B)=P(A)-P(B)$
- **加法公式**：$P(A\cup B)=P(A)+P(B)-P(AB)$
- 三事件：$P(A\cup B\cup C)=P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$

### 三、古典概型与几何概型

**古典概型**（有限等可能）：

$$P(A)=\frac{A\text{ 包含的样本点数}}{\text{样本点总数}}=\frac{m}{n}$$

常用计数：排列 $A_n^k$、组合 $C_n^k$。

**几何概型**（无限等可能）：

$$P(A)=\frac{A\text{ 的几何度量（长度/面积/体积）}}{\Omega\text{ 的几何度量}}$$

### 四、条件概率与三大公式

**条件概率**：$P(A\mid B)=\dfrac{P(AB)}{P(B)}\ (P(B)>0)$。

**乘法公式**：$P(AB)=P(B)P(A\mid B)=P(A)P(B\mid A)$。

**全概率公式**（$B_1,\cdots,B_n$ 为完备事件组，两两互斥且并为 $\Omega$）：

$$P(A)=\sum_{i=1}^{n}P(B_i)P(A\mid B_i)$$

**贝叶斯公式**（逆概率）：

$$P(B_k\mid A)=\frac{P(B_k)P(A\mid B_k)}{\sum\limits_{i=1}^{n}P(B_i)P(A\mid B_i)}$$

### 五、事件的独立性

**定义**：$A$ 与 $B$ 独立 $\Leftrightarrow P(AB)=P(A)P(B)$。

**重要结论**：

- $A$ 与 $B$ 独立 $\Rightarrow$ $A$ 与 $\bar{B}$、$\bar{A}$ 与 $B$、$\bar{A}$ 与 $\bar{B}$ 均独立
- 独立 $\ne$ 互斥（除非概率为 $0$）
- 多事件独立需满足任意有限个的交的概率等于概率之积

**独立试验（伯努利概型）**：$n$ 重伯努利试验中事件 $A$ 恰好发生 $k$ 次的概率

$$P_n(k)=C_n^k p^k(1-p)^{n-k}$$

## ✏️ 经典题型

:::fold 题型一 事件关系运算求概率（中频）
**例**：设 $P(A) = 0.5$，$P(B) = 0.6$，$P(B|A) = 0.8$，求 $P(AB)$ 与 $P(A \cup \bar{B})$。

**解**：

1. $P(AB) = P(A)P(B|A) = 0.5 \times 0.8 = 0.4$
2. $P(\bar{A}B) = P(B) - P(AB) = 0.6 - 0.4 = 0.2$
3. $P(A \cup \bar{B}) = 1 - P(\bar{A}B) = 1 - 0.2 = 0.8$

**要点**：先翻译事件（德摩根律 $\overline{A \cup \bar{B}} = \bar{A}B$），再用加法公式/条件概率。
:::

:::fold 题型二 全概率公式与贝叶斯公式（高频·大题）
**例**：某厂三台机器生产同一产品，产量占 $25\%$、$35\%$、$40\%$，次品率分别 $5\%$、$4\%$、$2\%$。任取一件是次品，求是第二台机器生产的概率。

**解**：设 $B_i$ = 第 $i$ 台生产，$A$ = 取到次品。

1. 全概率：$P(A) = 0.25 \times 0.05 + 0.35 \times 0.04 + 0.40 \times 0.02 = 0.0345$
2. 贝叶斯：$P(B_2|A) = \frac{0.35 \times 0.04}{0.0345} \approx 0.406$

**套路**：找完备事件组（分原因）→ 全概率求总概率 → 贝叶斯求逆概率。
:::

:::fold 题型三 独立性与伯努利试验（高频）
**例（独立 vs 互斥）**：$A$、$B$ 独立，$P(A) = 0.4$，$P(A \cup B) = 0.7$，求 $P(B)$。

**解**：独立时 $P(A \cup B) = P(A) + P(B) - P(A)P(B)$

$0.7 = 0.4 + 0.6P(B)$ → $P(B) = 0.5$

---

**例（伯努利）**：射击命中率 $0.6$，独立射击 $4$ 次，恰好命中 $2$ 次的概率：

$P = C_4^2 (0.6)^2 (0.4)^2 = 6 \times 0.36 \times 0.16 = 0.3456$

**辨析**：独立是"互不影响"（$P(AB) = P(A)P(B)$），互斥是"不能同时发生"（$AB = \varnothing$）。
:::

## ⭐ 重点提示

- ★ 事件运算与德摩根律是分析复杂事件的基础
- ★ 全概率公式与贝叶斯公式是必考大题，关键是找完备事件组
- ★ 独立性与互斥性的辨析是经典选择题
- ★ 加法公式、条件概率公式需灵活变形
- ★ 伯努利概型（二项概率）是高频计算题
