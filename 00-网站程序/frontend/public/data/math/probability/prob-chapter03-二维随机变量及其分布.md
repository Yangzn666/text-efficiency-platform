# 第三章 二维随机变量及其分布

## 📖 考纲要求

- 理解二维随机变量的联合分布函数、联合分布律、联合概率密度
- 掌握边缘分布与条件分布的求法
- 理解随机变量相互独立的判定
- 掌握二维连续型随机变量的计算
- 会求两个随机变量函数的分布（和、最大、最小）

---

## 🎯 核心知识点

### 一、联合分布函数

**定义**：$F(x,y)=P\{X\le x,Y\le y\}$。

**性质**：对每个变量单调、右连续，$F(-\infty,y)=F(x,-\infty)=0$，$F(+\infty,+\infty)=1$。

**求矩形区域概率**：

$$P\{x_1<X\le x_2,\ y_1<Y\le y_2\}=F(x_2,y_2)-F(x_2,y_1)-F(x_1,y_2)+F(x_1,y_1)$$

### 二、二维离散型

**联合分布律**：$p_{ij}=P\{X=x_i,Y=y_j\}$，$\sum_i\sum_j p_{ij}=1$。

**边缘分布律**：

- $P\{X=x_i\}=\sum_j p_{ij}$（对 $j$ 求和）
- $P\{Y=y_j\}=\sum_i p_{ij}$（对 $i$ 求和）

**条件分布律**：$P\{X=x_i\mid Y=y_j\}=\dfrac{p_{ij}}{P\{Y=y_j\}}$。

### 三、二维连续型

**联合概率密度** $f(x,y)$：

$$F(x,y)=\int_{-\infty}^x\int_{-\infty}^y f(u,v)\,dv\,du$$

满足 $f\ge 0$，$\iint_{\mathbb{R}^2}f(x,y)\,dx\,dy=1$。

**区域概率**：$P\{(X,Y)\in D\}=\iint_D f(x,y)\,dx\,dy$。

**边缘密度**：

- $f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy$
- $f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx$

**条件密度**：$f_{X\mid Y}(x\mid y)=\dfrac{f(x,y)}{f_Y(y)}$（$f_Y(y)>0$）。

### 四、独立性

**判定**：$X$ 与 $Y$ 独立 $\Leftrightarrow$ 对一切 $x,y$，$F(x,y)=F_X(x)F_Y(y)$。

- 离散型：$p_{ij}=p_{i\cdot}\,p_{\cdot j}$（一切 $i,j$）
- 连续型：$f(x,y)=f_X(x)f_Y(y)$（几乎处处）

**实用判据**：联合密度可分离为 $f(x,y)=g(x)h(y)$ 且区域为矩形，则独立。

### 五、两个随机变量函数的分布

**和的分布** $Z=X+Y$：

- 一般公式：$f_Z(z)=\int_{-\infty}^{+\infty}f(x,z-x)\,dx$
- **卷积公式**（独立时）：$f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\,dx$

**最大与最小**（独立时）：

- $M=\max(X,Y)$：$F_M(z)=F_X(z)F_Y(z)$
- $N=\min(X,Y)$：$F_N(z)=1-[1-F_X(z)][1-F_Y(z)]$

推广到 $n$ 个独立随机变量同理。

**重要结论**：

- 独立正态之和仍正态：$X\sim N(\mu_1,\sigma_1^2),Y\sim N(\mu_2,\sigma_2^2)$ 独立 $\Rightarrow X+Y\sim N(\mu_1+\mu_2,\sigma_1^2+\sigma_2^2)$
- 独立泊松之和：$P(\lambda_1)+P(\lambda_2)\sim P(\lambda_1+\lambda_2)$

## ✏️ 经典题型

:::fold 题型一 求边缘密度与条件密度（★年年考·大题）
**例**：$(X, Y)$ 的联合密度 $f(x, y) = \begin{cases} 6xy^2, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$，求 $f_X(x)$、$f_Y(y)$ 与条件密度 $f_{X|Y}(x|y)$。

**解**：

1. $f_X(x) = \int_0^1 6xy^2 dy = 2x$（$0 < x < 1$）
2. $f_Y(y) = \int_0^1 6xy^2 dx = 3y^2$（$0 < y < 1$）
3. $f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)} = \frac{6xy^2}{3y^2} = 2x$（$0 < x < 1$）

**要点**：边缘密度 = 积分掉另一个变量（注意积分范围由联合密度的支撑域决定）；条件密度 = 联合 ÷ 边缘。
:::

:::fold 题型二 联合分布与区域概率（★年年考）
**例**：$(X, Y)$ 在 $D$: $0 < y < x < 1$ 上均匀分布，求 $P\{X + Y < 1\}$。

**解**：$D$ 的面积 $= \frac{1}{2}$，故密度 $f(x, y) = 2$

1. $D \cap \{x + y < 1\}$ 是顶点为 $(0,0)$、$(1,0)$、$(\frac{1}{2}, \frac{1}{2})$ 的三角形
2. 其面积 $= \frac{1}{2} \times 1 \times \frac{1}{2} = \frac{1}{4}$
3. $P = 2 \times \frac{1}{4} = \frac{1}{2}$

**要点**：均匀分布的概率 = 面积之比；先画图确定积分区域与上下限。
:::

:::fold 题型三 二维随机变量函数的分布（★年年考·大题）
**例（卷积）**：$X$、$Y$ 独立且都服从 $N(0, 1)$，求 $Z = X + Y$ 的密度。

**解**：由卷积公式：

1. $f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)f_Y(z - x)dx = \frac{1}{2\pi}\int e^{-\frac{x^2 + (z - x)^2}{2}}dx$
2. 配方：$x^2 + (z - x)^2 = 2(x - \frac{z}{2})^2 + \frac{z^2}{2}$
3. $f_Z(z) = \frac{1}{\sqrt{4\pi}}e^{-\frac{z^2}{4}}$ → $Z \sim N(0, 2)$

---

**例（最小值）**：$X$、$Y$ 独立且都服从 $E(1)$，求 $N = \min(X, Y)$ 的分布函数。

**解**：$F_N(z) = 1 - [1 - F_X(z)][1 - F_Y(z)] = 1 - e^{-2z}$（$z > 0$），即 $N \sim E(2)$

**要点**：和用卷积公式；最大最小用分布函数法；独立正态之和仍正态（均值、方差相加）。
:::

:::fold 题型四 独立性判定（高频）
**例**：$(X, Y)$ 的联合密度 $f(x, y) = \begin{cases} e^{-(x + y)}, & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$，问 $X$ 与 $Y$ 是否独立？

**解**：

1. $f(x, y) = e^{-x} \cdot e^{-y} = g(x)h(y)$，可分离
2. 区域 $x > 0, y > 0$ 为矩形
3. 故 $X$、$Y$ 独立，且 $X \sim E(1)$，$Y \sim E(1)$

**反例**：若区域改为 $0 < y < x < 1$（非矩形），即使密度可分离也不独立。

**判据**：独立 $\Leftrightarrow$ 密度可分离 + 区域为矩形（两条件缺一不可）。
:::

## ⭐ 重点提示

- ★ 由联合密度求边缘密度（积分掉另一变量）是核心计算
- ★ 求区域概率时正确确定积分上下限是关键，常需画图
- ★ 独立性判定（密度可分离 + 矩形区域）是高频考点
- ★ 卷积公式求和的分布、最大最小分布是经典大题
- ★ 条件分布与条件密度是连接第四章数字特征的桥梁
