# 第八章 假设检验

## 📖 考纲要求

- 理解假设检验的基本思想、原假设与备择假设
- 理解两类错误（弃真、取伪）与显著性水平
- 掌握单个正态总体均值与方差的假设检验
- 掌握两个正态总体均值差与方差比的假设检验

---

## 🎯 核心知识点

### 一、基本概念

- **原假设** $H_0$：待检验的假设（通常含等号）
- **备择假设** $H_1$：与 $H_0$ 对立的假设
- **显著性水平** $\alpha$：允许犯弃真错误的最大概率（常取 $0.05$、$0.01$）
- **检验统计量**：用于决策的样本函数
- **拒绝域**：使拒绝 $H_0$ 的统计量取值范围
- **$p$ 值**：在原假设成立下，出现当前或更极端结果的概率；$p<\alpha$ 则拒绝 $H_0$

### 二、两类错误

- **第一类错误（弃真）**：$H_0$ 为真却拒绝了它，概率 $\alpha=P\{\text{拒绝}H_0\mid H_0\text{真}\}$
- **第二类错误（取伪）**：$H_0$ 为假却接受了它，概率 $\beta=P\{\text{接受}H_0\mid H_0\text{假}\}$

显著性检验只控制第一类错误概率不超过 $\alpha$。

### 三、假设检验的一般步骤

1. 根据问题提出 $H_0$ 与 $H_1$
2. 选取合适的检验统计量及其在 $H_0$ 下的分布
3. 由显著性水平 $\alpha$ 确定拒绝域
4. 由样本计算统计量的观测值
5. 判断是否落入拒绝域，作出结论

### 四、单个正态总体 $N(\mu,\sigma^2)$ 的检验

**均值 $\mu$ 的检验**：

- $\sigma^2$ 已知（$Z$ 检验）：统计量 $Z=\dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}\sim N(0,1)$
- $\sigma^2$ 未知（$t$ 检验）：统计量 $T=\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}\sim t(n-1)$

**双边检验** $H_0:\mu=\mu_0$ 拒绝域 $|Z|>u_{\alpha/2}$（或 $|T|>t_{\alpha/2}(n-1)$）。

**方差 $\sigma^2$ 的检验**（$\chi^2$ 检验）：统计量 $\chi^2=\dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$。

### 五、两个正态总体的检验

**均值差 $\mu_1-\mu_2$ 的检验**：

- $\sigma_1^2,\sigma_2^2$ 已知（$Z$ 检验）：$Z=\dfrac{\bar{X}-\bar{Y}}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}$
- $\sigma_1^2=\sigma_2^2$ 未知（$t$ 检验）：$T=\dfrac{\bar{X}-\bar{Y}}{S_w\sqrt{1/n_1+1/n_2}}\sim t(n_1+n_2-2)$

**方差比 $\sigma_1^2/\sigma_2^2$ 的检验**（$F$ 检验）：统计量 $F=\dfrac{S_1^2}{S_2^2}\sim F(n_1-1,n_2-1)$（$H_0:\sigma_1^2=\sigma_2^2$ 下）。

### 六、检验类型对照

- 双边检验 $H_1:\theta\ne\theta_0$：拒绝域在两侧，临界值用 $\alpha/2$
- 单边检验 $H_1:\theta>\theta_0$ 或 $\theta<\theta_0$：拒绝域在一侧，临界值用 $\alpha$

---

## ✏️ 经典题型

:::fold 题型一 单个正态总体均值的假设检验（中频）
**例**：某厂灯泡寿命 $X \sim N(\mu, \sigma^2)$，$\sigma = 80$ 小时，长期均值 $1500$ 小时。现用新工艺，抽 $n = 25$ 只测得 $\bar{x} = 1540$ 小时。问平均寿命是否显著提高？（$\alpha = 0.05$，$u_{0.05} = 1.645$）

**解**：$\sigma^2$ 已知，用 $Z$ 检验。

1. 设假设：$H_0: \mu = 1500$，$H_1: \mu > 1500$（单边）
2. 统计量：$Z = \frac{\bar{X} - 1500}{80/\sqrt{25}} = \frac{1540 - 1500}{16} = 2.5$
3. 拒绝域：$Z > u_{0.05} = 1.645$
4. $2.5 > 1.645$ → 拒绝 $H_0$，认为平均寿命显著提高

**要点**：方差已知用 $Z$，未知用 $t$；单边检验用 $u_\alpha$，双边用 $u_{\alpha/2}$。
:::

:::fold 题型二 单个正态总体方差的假设检验（低频）
**例**：某零件直径 $X \sim N(\mu, \sigma^2)$，规格要求 $\sigma \le 0.16$。现抽 $n = 10$ 个，测得 $s = 0.24$。问直径的波动是否显著增大？（$\alpha = 0.05$，$\chi^2_{0.05}(9) = 16.919$）

**解**：用 $\chi^2$ 检验。

1. 设假设：$H_0: \sigma^2 = 0.16^2$，$H_1: \sigma^2 > 0.16^2$
2. 统计量：$\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} = \frac{9 \times 0.24^2}{0.16^2} = 20.25$
3. 拒绝域：$\chi^2 > \chi^2_{0.05}(9) = 16.919$
4. $20.25 > 16.919$ → 拒绝 $H_0$，认为波动显著增大

**要点**：方差检验用 $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$；拒绝域方向与 $H_1$ 一致。
:::

:::fold 题型三 两类错误与基本概念（低频选择题）
**要点**：

1. 第一类错误（弃真）：$H_0$ 真却拒绝，概率为 $\alpha$（显著性水平）
2. 第二类错误（取伪）：$H_0$ 假却接受，概率为 $\beta$
3. 显著性检验只控制第一类错误概率不超过 $\alpha$
4. $p$ 值 $< \alpha$ → 拒绝 $H_0$；$p$ 值越小，反对 $H_0$ 的证据越强

**关系**：$\alpha$ 减小则 $\beta$ 增大（样本量固定时）；增大样本量可同时减小两类错误。
:::

## ⭐ 重点提示

- ★ 正确设立 $H_0$ 与 $H_1$（等号放 $H_0$）是第一步
- ★ 区分 $Z$/$t$/$\chi^2$/$F$ 四种检验的适用条件是核心
- ★ 双边与单边检验的拒绝域、临界值不同，最易混淆
- ★ 两类错误的概念常以选择题考查
- ★ 假设检验与区间估计互为对偶，思想相通
