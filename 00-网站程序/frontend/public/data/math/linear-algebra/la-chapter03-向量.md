# 第三章 向量

## 📖 考纲要求

- 理解 $n$ 维向量、向量的线性组合与线性表示的概念
- 理解向量组线性相关、线性无关的概念，掌握向量组线性相关、线性无关的有关性质及判别法
- 理解向量组的极大线性无关组和向量组的秩的概念，会求向量组的极大线性无关组及秩
- 理解向量组等价的概念，理解矩阵的秩与其行（列）向量组的秩的关系
- 了解内积的概念，掌握线性无关向量组正交规范化的施密特方法
- （数一）了解向量空间、子空间、基、维数、坐标等概念，会求过渡矩阵及坐标变换公式

向量是连接矩阵与方程组的桥梁。本章核心只有一件事：**把"线性表示/相关/无关"翻译成秩的语言**。

## 🎯 核心知识点

### 3.1 线性组合与线性表示

**线性组合**：给定向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 和数 $k_1, k_2, \cdots, k_s$，称 $k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$ 为该向量组的一个线性组合。

**线性表示**：若 $\beta = k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$，则称 $\beta$ 可由向量组 $\alpha_1,\cdots,\alpha_s$ 线性表示。

**矩阵语言（核心翻译）**：记 $A = (\alpha_1, \alpha_2, \cdots, \alpha_s)$，则

$$\beta \text{ 可由 } \alpha_1,\cdots,\alpha_s \text{ 线性表示} \Leftrightarrow Ax = \beta \text{ 有解} \Leftrightarrow r(A) = r(A \mid \beta)$$

表示法唯一 $\Leftrightarrow r(A) = r(A\mid\beta) = s$（向量个数）。

### 3.2 线性相关与线性无关

**定义**：向量组 $\alpha_1,\cdots,\alpha_s$ 线性相关 $\Leftrightarrow$ 存在**不全为零**的 $k_1,\cdots,k_s$ 使 $k_1\alpha_1 + \cdots + k_s\alpha_s = 0$；若只有全零解则线性无关。

**矩阵语言**：

$$\alpha_1,\cdots,\alpha_s \text{ 线性相关} \Leftrightarrow Ax = 0 \text{ 有非零解} \Leftrightarrow r(A) < s$$

$$\alpha_1,\cdots,\alpha_s \text{ 线性无关} \Leftrightarrow Ax = 0 \text{ 只有零解} \Leftrightarrow r(A) = s$$

**基本性质与结论**：

- 含零向量的向量组必线性相关；单个向量 $\alpha$：相关 $\Leftrightarrow \alpha = 0$
- 向量个数 > 维数必相关：$s > n$ 时 $n$ 维向量组 $\alpha_1,\cdots,\alpha_s$ 必线性相关
- **部分相关则整体相关；整体无关则部分无关**
- 原组无关，延伸组（每个向量增加分量）也无关；缩短组相关则原组相关
- 向量组 $I$ 无关，且可由向量组 $II$ 线性表示，则 $|I| \le |II|$（无关组被表示，个数不超）
- **替换定理**：无关组中的向量逐个被表示它的向量替换，无关性保持

**线性相关的直观理解**：组中至少有一个向量能被其余向量线性表示（"有多余的"）；线性无关 = 每个向量都不可替代。

### 3.3 向量组的等价

**定义**：两个向量组能**相互**线性表示，则称两向量组等价。

**判定**：向量组 $I$ 与 $II$ 等价 $\Leftrightarrow r(I) = r(II) = r(I, II)$（合并组的秩等于各自的秩）。

**性质**：等价向量组有相同的秩，可以相互替换（替换后生成的向量组不变）；但等价向量组的向量个数可以不同。

**注意区分**：向量组等价 $\ne$ 矩阵等价 $\ne$ 矩阵相似/合同（后续章节）。

### 3.4 矩阵乘法与向量组的重要关系（真题重点）

设 $A$ 为 $m\times n$ 矩阵，$B$ 为 $n\times s$ 矩阵，$C = AB$：

- **列视角**：$C$ 的每一列都是 $A$ 的列向量组的线性组合 $\Rightarrow$ $C$ 的列向量组可由 $A$ 的列向量组线性表示
- **行视角**：$C$ 的每一行都是 $B$ 的行向量组的线性组合 $\Rightarrow$ $C$ 的行向量组可由 $B$ 的行向量组线性表示
- 核心不等式：$r(AB) \le \min(r(A), r(B))$
- $AB = O \Leftrightarrow B$ 的每一列都是 $Ax = 0$ 的解

**广义初等变换**：对分块矩阵 $(A \mid B)$ 做行变换相当于左乘可逆阵，不改变行向量组的线性关系；做列变换不改变列向量组的线性关系。这是"求极大无关组"和"用已知表示求未知表示"的工具。

### 3.5 向量组的秩与极大线性无关组

**极大线性无关组**：向量组 $T$ 的部分组 $\alpha_{i_1},\cdots,\alpha_{i_r}$ 满足①线性无关；②$T$ 中任一向量都可由其线性表示，则称其为 $T$ 的一个极大无关组。

**向量组的秩**：极大无关组所含向量的个数，记 $r(\alpha_1,\cdots,\alpha_s)$。

**关键定理**：

- 矩阵的秩 = 其行向量组的秩 = 其列向量组的秩
- 极大无关组不唯一，但所含向量个数唯一；任意两个极大无关组等价
- 向量组线性无关 $\Leftrightarrow$ 秩 = 向量个数

**求极大无关组的方法**：把向量按**列**排成矩阵 $A$，对 $A$ 做初等**行**变换化为行阶梯形（或行最简形），每个非零行首元所在的列对应的原向量即构成一个极大无关组。其余向量的表示系数由行最简形读出。

### 3.6 施密特（Schmidt）正交化

把线性无关向量组 $\alpha_1, \alpha_2, \alpha_3$ 化为正交向量组 $\beta_1, \beta_2, \beta_3$：

$$\beta_1 = \alpha_1$$

$$\beta_2 = \alpha_2 - \frac{[\beta_1, \alpha_2]}{[\beta_1, \beta_1]}\beta_1$$

$$\beta_3 = \alpha_3 - \frac{[\beta_1, \alpha_3]}{[\beta_1, \beta_1]}\beta_1 - \frac{[\beta_2, \alpha_3]}{[\beta_2, \beta_2]}\beta_2$$

其中 $[\alpha, \beta] = \alpha^T\beta = \sum a_i b_i$ 为内积。再单位化 $\eta_i = \frac{\beta_i}{|\beta_i|}$ 得标准正交组。

**要点**：正交化必须**按顺序逐个进行**，$\beta_k$ 减去它在前面所有 $\beta_1,\cdots,\beta_{k-1}$ 上的投影；正交化前后两向量组等价（相互可线性表示）。

### 3.7 向量空间（数一）

**向量空间**：对加法和数乘封闭的向量集合。$\mathbb{R}^n$ 的子空间必过原点。

**基与维数**：向量空间 $V$ 的极大无关组称为 $V$ 的一组基，基中向量个数称为维数 $\dim V$。

**坐标**：向量 $\alpha$ 在基 $\varepsilon_1,\cdots,\varepsilon_n$ 下的坐标 $(x_1,\cdots,x_n)$ 满足 $\alpha = x_1\varepsilon_1 + \cdots + x_n\varepsilon_n$。

**过渡矩阵与坐标变换**：设两组基 $(\varepsilon_1,\cdots,\varepsilon_n)$ 与 $(\eta_1,\cdots,\eta_n)$ 满足

$$(\eta_1, \eta_2, \cdots, \eta_n) = (\varepsilon_1, \varepsilon_2, \cdots, \varepsilon_n)P$$

则 $P$ 为由基 $\varepsilon$ 到基 $\eta$ 的**过渡矩阵**（可逆）。同一向量在两组基下的坐标 $x, y$ 满足：

$$x = Py \quad (\text{基变换右乘}P,\ \text{坐标变换左乘}P^{-1}\text{的逆关系})$$

**求过渡矩阵**：$(\varepsilon \mid \eta) \xrightarrow{行变换} (E \mid P)$，即 $P = \varepsilon^{-1}\eta$。

**子空间的交与和**（数一了解）：$\dim(V_1 + V_2) = \dim V_1 + \dim V_2 - \dim(V_1 \cap V_2)$（维数公式）。

### 3.8 向量相关/无关的几何意义（数一）

- 2维：两个向量相关 $\Leftrightarrow$ 共线（平行）
- 3维：三个向量相关 $\Leftrightarrow$ 共面
- 混合积 $(\alpha \times \beta)\cdot \gamma = 0 \Leftrightarrow$ 三向量共面

## ⭐ 重点提示

- 本章所有问题最终都翻译成**秩的比较**：表示看 $r(A)$ 与 $r(A\mid\beta)$，相关无关看 $r(A)$ 与 $s$，等价看三个秩相等
- "向量个数 > 维数必相关"和"$s$ 个 $n$ 维向量无关则 $s \le n$"是最快的判断
- 极大无关组按列排阵、只做行变换——列对应关系在行变换下保持不变
- 抽象相关/无关证明题：从定义出发设 $k_1\alpha_1+\cdots=0$，左乘矩阵或利用已知无关性推出 $k_i$ 全为零
- 做抽象选择题的心态：不必想"原理本质"，用特例（单位向量、对角阵）验证选项，"配得上得5分"
