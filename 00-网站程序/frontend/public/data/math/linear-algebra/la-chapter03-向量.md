# 第三章 向量

## 📖 考纲要求与考情

- 理解向量线性组合与线性表示的概念，理解线性相关/无关的定义与性质
- 会判定向量组的线性相关性，理解极大无关组与向量组的秩
- 掌握施密特正交化方法
- 了解向量空间、基变换与过渡矩阵（数一要求）

**考情**：线性相关性的判定与证明是线代解答题的**必考题型**，几乎年年出现证明题。向量组的秩与矩阵秩的关系是核心工具。本章概念抽象，是线代"分水岭"。

## 🎯 核心知识体系

### 3.1 线性组合与线性表示

**线性组合**：$k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$（一组向量的加权求和）

**线性表示**：$\beta$ 能由 $\alpha_1, \cdots, \alpha_s$ 线性表示 $\Leftrightarrow$ 存在 $k_i$ 使 $\beta = \sum k_i\alpha_i$

**矩阵语言（核心翻译）**：

$$\beta可由\alpha_1,\cdots,\alpha_s表示 \Leftrightarrow Ax = \beta 有解 \Leftrightarrow r(A) = r(A|\beta)$$

其中 $A = (\alpha_1, \alpha_2, \cdots, \alpha_s)$。

**等价向量组**：两个向量组能互相线性表示。等价向量组秩相同（反之不然）。

### 3.2 线性相关与线性无关（★核心中的核心）

**定义**：存在**不全为零**的 $k_1, \cdots, k_s$ 使 $k_1\alpha_1 + \cdots + k_s\alpha_s = 0$，则向量组线性相关；否则（仅 $k_i$ 全为零才行）线性无关。

**矩阵语言**：

$$\alpha_1,\cdots,\alpha_s 线性相关 \Leftrightarrow Ax=0有非零解 \Leftrightarrow r(A) < s$$

$$\alpha_1,\cdots,\alpha_s 线性无关 \Leftrightarrow Ax=0仅零解 \Leftrightarrow r(A) = s$$

**关键结论（必背）**：

- $n$ 个 $n$ 维向量线性无关 $\Leftrightarrow |A| \ne 0$
- 向量个数 $s >$ 维数 $n$ 时必线性相关（$r(A) \le n < s$）
- 部分组相关 → 整体相关；整体无关 → 部分组无关
- 原组无关，延伸组（加高维）也无关；缩短组相关 → 原组相关
- $\alpha_1,\cdots,\alpha_s$ 无关，加入 $\beta$ 后相关 → $\beta$ 可由 $\alpha_1,\cdots,\alpha_s$ **唯一**表示

**线性相关的等价表述**：组中至少有一个向量可由其余向量线性表示。

### 3.3 极大无关组与向量组的秩

**极大线性无关组**：组中一个线性无关的部分组，且组中任一向量都可由它线性表示。

**向量组的秩**：极大无关组所含向量的个数，记 $r(\alpha_1, \cdots, \alpha_s)$。

**核心定理**：

$$r(\alpha_1, \cdots, \alpha_s) = r(A) \quad (A = (\alpha_1, \cdots, \alpha_s)为矩阵)$$

即**向量组的秩 = 矩阵的秩 = 行秩 = 列秩**。

**找极大无关组的操作**：对 $A$ 做行变换化为行阶梯形，非零行的首个非零元所在**列**对应的原列向量即为极大无关组。

**重要推论**：
- 向量组可由另一组线性表示 $\Rightarrow$ 秩不超过对方：$r(I) \le r(II)$
- 等价的向量组秩相同
- 秩相同的向量组不一定等价（反例：$(1,0)$ 与 $(0,1)$ 秩同为1但不等价... 需同维数组间构造）

### 3.4 施密特正交化

**目标**：把线性无关组 $\alpha_1, \alpha_2, \alpha_3$ 化为正交（规范正交）组。

**步骤**：

$$\beta_1 = \alpha_1$$

$$\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1$$

$$\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2$$

最后单位化：$\eta_i = \frac{\beta_i}{|\beta_i|}$。

**注意**：正交化过程中 $\beta_i$ 只与 $\alpha_1, \cdots, \alpha_i$ 有关（逐步投影），且 $(\alpha_1,\cdots,\alpha_s)$ 与 $(\beta_1,\cdots,\beta_s)$ 等价。

### 3.5 向量空间（数一专属）

**基与维数**：$n$ 维向量空间中 $n$ 个线性无关的向量构成一组基。

**坐标**：向量在基下的表示系数。

**基变换与过渡矩阵**：$(\beta_1,\cdots,\beta_n) = (\alpha_1,\cdots,\alpha_n)C$，$C$ 为从基 $\alpha$ 到基 $\beta$ 的过渡矩阵（$C$ 必可逆）。

**坐标变换公式**：同一向量在新旧基下坐标 $x, y$ 的关系：$x = Cy$（★坐标变换与基变换方向相反）。

## 📐 核心公式速查

$$\alpha_1,\cdots,\alpha_s无关 \Leftrightarrow r(\alpha_1,\cdots,\alpha_s) = s \Leftrightarrow Ax=0仅零解$$

$$\beta可由\alpha组表示 \Leftrightarrow r(A) = r(A|\beta)$$

$$向量组I可由II表示 \Rightarrow r(I) \le r(II)$$

$$n+1个n维向量必线性相关$$

## ✏️ 经典题型

:::fold 题型一 判定向量组的线性相关性
**方法**：构造矩阵 $A = (\alpha_1, \cdots, \alpha_s)$，求秩（行变换化阶梯形）。

- $r(A) = s$ → 线性无关
- $r(A) < s$ → 线性相关

**例**：判断 $\alpha_1 = (1,2,3)^T$，$\alpha_2 = (1,0,-1)^T$，$\alpha_3 = (2,4,6)^T$ 的相关性。

**解**：$\alpha_3 = 2\alpha_1$，故线性相关。（观察法：成比例即相关）

**例2**：设 $\alpha_1, \alpha_2, \alpha_3$ 线性无关，证明 $\alpha_1 + \alpha_2, \alpha_2 + \alpha_3, \alpha_3 + \alpha_1$ 线性无关。

**证**：设 $k_1(\alpha_1+\alpha_2) + k_2(\alpha_2+\alpha_3) + k_3(\alpha_3+\alpha_1) = 0$

整理得 $(k_1+k_3)\alpha_1 + (k_1+k_2)\alpha_2 + (k_2+k_3)\alpha_3 = 0$

由 $\alpha_1,\alpha_2,\alpha_3$ 无关得齐次方程组 $\begin{cases} k_1+k_3 = 0 \\ k_1+k_2 = 0 \\ k_2+k_3 = 0 \end{cases}$

系数行列式 $\begin{vmatrix} 1&0&1\\1&1&0\\0&1&1 \end{vmatrix} = 2 \ne 0$，仅零解，故新组线性无关。
:::

:::fold 题型二 线性表示问题
**方法**：转化为方程组 $Ax = \beta$ 的求解。

**例**：设 $\alpha_1 = (1,0,2)^T$，$\alpha_2 = (1,1,3)^T$，$\alpha_3 = (0,1,1)^T$，$\beta = (1,2,a)^T$。问 $a$ 为何值时 $\beta$ 可由 $\alpha_1, \alpha_2, \alpha_3$ 线性表示？

**解**：对 $(A|\beta) = \begin{pmatrix} 1 & 1 & 0 & | & 1 \\ 0 & 1 & 1 & | & 2 \\ 2 & 3 & 1 & | & a \end{pmatrix}$ 做行变换。

$r_3 - 2r_1$：$(0, 1, 1 | a-2)$，与 $r_2$ 相同 → 需 $a - 2 = 2$，即 $a = 4$ 时 $r(A) = r(A|\beta) = 2$，可表示。

$a = 4$ 时有无穷多表示（因 $r(A) = 2 < 3$）。
:::

:::fold 题型三 线性相关性的证明（★年年考）
**证明策略**：

1. **定义法**：设 $k_1\alpha_1 + \cdots + k_s\alpha_s = 0$，利用已知条件推出 $k_i$ 全为零
2. **秩法**：证明 $r(A) = s$（利用秩的不等式）
3. **反证法**：假设相关，推出与已知矛盾

**例（经典真题型）**：设 $\alpha_1, \cdots, \alpha_s$ 线性无关，$\beta_i = \alpha_i + \alpha_{i+1}$（$i = 1,\cdots,s$，$\alpha_{s+1} = \alpha_1$），讨论 $\beta_1, \cdots, \beta_s$ 的线性相关性。

**解**：设 $\sum k_i\beta_i = 0$，展开整理得：

$(k_1 + k_s)\alpha_1 + (k_1 + k_2)\alpha_2 + \cdots + (k_{s-1} + k_s)\alpha_s = 0$

由无关性得方程组：$k_1 + k_s = 0, k_1 + k_2 = 0, \cdots, k_{s-1} + k_s = 0$

系数行列式为循环结构，$s$ 为奇数时行列式 $= 2 \ne 0$（仅零解，无关）；$s$ 为偶数时行列式 $= 0$（有非零解，相关）。

**结论**：$s$ 为奇数时 $\beta$ 组无关，$s$ 为偶数时相关。
:::

:::fold 题型四 求极大无关组与秩
**标准操作**：

1. 以向量为列构造矩阵 $A$
2. 行变换化为行阶梯形
3. 阶梯形中每行首个非零元所在列 → 对应原矩阵的列向量即为极大无关组
4. 非零行数 = 秩

**例**：求 $\alpha_1 = (1,2,1,3)^T$，$\alpha_2 = (1,0,1,1)^T$，$\alpha_3 = (2,2,2,4)^T$，$\alpha_4 = (0,2,0,2)^T$ 的秩和一个极大无关组。

**解**：观察 $\alpha_3 = \alpha_1 + \alpha_2$，$\alpha_4 = \alpha_1 - \alpha_2$，故 $r = 2$，$\{\alpha_1, \alpha_2\}$ 为一个极大无关组。

$\alpha_3 = \alpha_1 + \alpha_2$，$\alpha_4 = \alpha_1 - \alpha_2$（用行变换验证并读出表示系数）。
:::

:::fold 题型五 施密特正交化计算
**例**：将 $\alpha_1 = (1,1,0)^T$，$\alpha_2 = (1,0,1)^T$ 正交化并单位化。

**解**：

$\beta_1 = \alpha_1 = (1,1,0)^T$

$\beta_2 = \alpha_2 - \frac{(\alpha_2,\beta_1)}{(\beta_1,\beta_1)}\beta_1 = (1,0,1)^T - \frac{1}{2}(1,1,0)^T = (\frac{1}{2}, -\frac{1}{2}, 1)^T$

取 $\beta_2 = (1,-1,2)^T$（乘2化简，正交性不变）

单位化：$\eta_1 = \frac{1}{\sqrt{2}}(1,1,0)^T$，$\eta_2 = \frac{1}{\sqrt{6}}(1,-1,2)^T$

**应用场景**：实对称矩阵对角化时，同一特征值的多个特征向量需正交化（第五章）。
:::

## ⭐ 重点提示

- **翻译能力是本章灵魂**：看到"线性相关"立即翻译为 $Ax = 0$ 有非零解 / $r(A) < s$
- 证明题两大套路：定义法（设组合为零推系数）和秩法（不等式夹逼）
- "无关组 + 添入向量变相关 → 唯一表示"是选择题高频结论
- 正交化本身计算不难，但常与第五章实对称矩阵对角化联动出大题
