# 第五章 特征值与特征向量

## 📖 考纲要求

- 理解矩阵的特征值和特征向量的概念及性质，会计算矩阵的特征值和特征向量
- 理解矩阵相似的概念，掌握矩阵相似对角化的条件及方法
- 理解实对称矩阵的特征值和特征向量的性质，掌握实对称矩阵正交相似对角化的方法

本章是线性代数的"升华"——把矩阵运算转化为对角阵的运算。核心主线：**特征值问题 = 解 $(\lambda E - A)x = 0$**。

## 🎯 核心知识点

### 5.1 特征值与特征向量的定义

设 $A$ 为 $n$ 阶方阵，若存在数 $\lambda$ 和非零向量 $\alpha$ 使

$$A\alpha = \lambda\alpha$$

则称 $\lambda$ 是 $A$ 的特征值，$\alpha$ 是 $A$ 属于 $\lambda$ 的特征向量。

**要点**：

- 特征向量必须**非零**；特征值可以是 0
- $\alpha$ 是属于 $\lambda$ 的特征向量 $\Rightarrow$ $k\alpha\ (k\ne0)$ 也是；但属于不同特征值的特征向量的线性组合一般不再是特征向量
- 一个特征向量只能属于一个特征值（若 $A\alpha = \lambda_1\alpha = \lambda_2\alpha$ 且 $\alpha\ne0$，则 $\lambda_1 = \lambda_2$）

### 5.2 求具体矩阵的特征值与特征向量

**步骤**：

1. 解特征方程 $|\lambda E - A| = 0$，求出全部特征值 $\lambda_1, \lambda_2, \cdots$
2. 对每个 $\lambda_i$，解齐次方程组 $(\lambda_i E - A)x = 0$，其基础解系张成的空间（去掉零向量）就是属于 $\lambda_i$ 的全部特征向量

**注意**：$|\lambda E - A| = |A - \lambda E|$ 仅当 $n$ 为偶数时直接相等，一般 $|A-\lambda E| = (-1)^n|\lambda E - A|$，但零点相同，用哪个都行。

### 5.3 特征值与特征向量的性质（必背）

设 $A$ 为 $n$ 阶方阵，特征值为 $\lambda_1, \lambda_2, \cdots, \lambda_n$（按重数计）：

**两大基本关系**：

$$\lambda_1 + \lambda_2 + \cdots + \lambda_n = \mathrm{tr}(A) = a_{11} + a_{22} + \cdots + a_{nn}$$

$$\lambda_1 \lambda_2 \cdots \lambda_n = |A|$$

**特征值的变换规律**（若 $\lambda$ 是 $A$ 的特征值，$\alpha$ 是对应特征向量）：

- $A^k$ 的特征值是 $\lambda^k$，特征向量仍是 $\alpha$
- $A$ 可逆时，$A^{-1}$ 的特征值是 $\lambda^{-1}$（$\lambda \ne 0$）
- $A^*$ 的特征值是 $\dfrac{|A|}{\lambda}$
- $kA + lE$ 的特征值是 $k\lambda + l$
- $P^{-1}AP$ 的特征值是 $\lambda$（相似矩阵特征值相同）
- $A$ 与 $A^T$ 特征值相同（特征向量一般不同）
- 多项式 $f(A)$ 的特征值是 $f(\lambda)$（如 $A^2 - 3A + E$ 的特征值是 $\lambda^2 - 3\lambda + 1$）

**特征向量的性质**：

- 属于不同特征值的特征向量**线性无关**
- 属于同一特征值的特征向量的非零线性组合仍是该特征值的特征向量
- $\lambda_i$ 的线性无关特征向量恰有 $n - r(\lambda_i E - A)$ 个（几何重数），且不超过其代数重数

**哈密顿-凯莱定理**：矩阵满足自己的特征方程。若 $f(\lambda) = |\lambda E - A|$，则 $f(A) = O$。可用于化简 $A$ 的高次多项式。

### 5.4 相似矩阵

**定义**：存在可逆矩阵 $P$ 使 $P^{-1}AP = B$，则称 $A$ 与 $B$ 相似，记 $A \sim B$。

**相似的必要条件**（判断"不相似"的快捷工具）：$A \sim B \Rightarrow$

- $A, B$ 有相同的特征值（从而 $|A| = |B|$、$\mathrm{tr}(A) = \mathrm{tr}(B)$）
- $r(A) = r(B)$
- $|\lambda E - A| = |\lambda E - B|$（特征多项式相同）
- $A, B$ 有相同的初等因子（充要条件，了解）

**相似的性质**：$A \sim B \Rightarrow A^k \sim B^k$，$A^{-1} \sim B^{-1}$（可逆时），$A^T \sim B^T$，$f(A) \sim f(B)$。

### 5.5 矩阵的相似对角化（☆必考）

**定义**：$A$ 与对角阵 $\Lambda$ 相似（$P^{-1}AP = \Lambda$），称 $A$ 可相似对角化。

**充要条件**：$A$ 有 $n$ 个线性无关的特征向量 $\Leftrightarrow$ 对每个 $k$ 重特征值 $\lambda_i$，有 $n - r(\lambda_i E - A) = k$（几何重数 = 代数重数）。

**充分条件**：

- $A$ 有 $n$ 个互不相同的特征值 $\Rightarrow$ 必可对角化
- $A$ 是实对称矩阵 $\Rightarrow$ 必可对角化（且可正交对角化）

**必要条件**：$A$ 可对角化 $\Rightarrow$ 每个特征值的几何重数等于代数重数。

**对角化的步骤**：

1. 求 $A$ 的全部特征值 $\lambda_1, \lambda_2, \cdots$
2. 对每个 $\lambda_i$ 求 $(\lambda_i E - A)x = 0$ 的基础解系，得特征向量 $\alpha_1, \alpha_2, \cdots, \alpha_n$
3. 令 $P = (\alpha_1, \alpha_2, \cdots, \alpha_n)$，则 $P^{-1}AP = \Lambda = \mathrm{diag}(\lambda_1, \lambda_2, \cdots, \lambda_n)$

**注意**：$P$ 的列向量排列顺序必须与 $\Lambda$ 对角线上特征值的顺序**一一对应**。

**对角化的应用**：

- 求 $A^n$：$A^n = P\Lambda^n P^{-1}$
- 求 $f(A)$：$f(A) = Pf(\Lambda)P^{-1}$
- 解矩阵方程/递推关系

### 5.6 实对称矩阵的正交对角化

**实对称矩阵的性质（极其重要）**：

- 特征值全为实数
- 属于不同特征值的特征向量**正交**
- 必可正交相似对角化：存在正交矩阵 $Q$ 使 $Q^{-1}AQ = Q^TAQ = \Lambda$

**正交对角化的步骤**：

1. 求特征值
2. 对每个特征值求特征向量
3. 同一特征值的多个特征向量之间做施密特正交化（不同特征值的已自动正交）
4. 全部单位化，按列排成正交矩阵 $Q$

**二级结论（矩阵可同时对角化）**：$A, B$ 都可对角化，且 $AB = BA$（可交换）$\Leftrightarrow$ $A, B$ 可同时相似对角化（存在同一个 $P$ 使 $P^{-1}AP$、$P^{-1}BP$ 都是对角阵）。

### 5.7 不可对角化矩阵的处理

**题型：求可逆 $P$ 使 $P^{-1}AP = B$（$B$ 非对角阵）**

方法：不玩特征值了！设 $P = (x_{ij})$ 为未知矩阵，由 $AP = PB$ 展开为线性方程组，解出 $P$ 并要求 $|P| \ne 0$。

**题型：已知 $A$ 的特征值特征向量求 $A$**

- 可对角化时：$A = P\Lambda P^{-1}$
- 实对称阵反求：利用"不同特征值的特征向量正交"补齐缺失的特征向量，再 $A = Q\Lambda Q^T$

### 5.8 判断两矩阵是否相似

**证不相似**（先试这个，简单）：比较特征值、迹、行列式、秩，有一个不同就不相似。

**证相似**：

- 都可对角化且有相同特征值（含重数）$\Rightarrow$ 相似（都相似于同一个 $\Lambda$）
- 直接构造 $P$ 使 $P^{-1}AP = B$（解 $AP = PB$）

## ⭐ 重点提示

- 特征值问题的计算核心就是解 $|\lambda E - A| = 0$ 和 $(\lambda E - A)x = 0$，前者是行列式，后者是方程组——前两章功底决定本章速度
- 抽象矩阵特征值题：用定义 $A\alpha = \lambda\alpha$ 左乘/右乘变形，或用变换规律（$A^{-1}, A^*, f(A)$ 的特征值）
- 对角化题先验证条件：$n$ 个无关特征向量；实对称阵无条件可对角化且用正交阵
- 实对称阵"不同特征值对应特征向量正交"是反求矩阵、补特征向量的钥匙
- 相似必要条件是排除法利器：特征值/迹/行列式/秩，四连查
