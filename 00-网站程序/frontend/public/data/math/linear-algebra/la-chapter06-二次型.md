# 第六章 二次型

## 📖 考纲要求

- 掌握二次型及其矩阵表示，了解二次型秩的概念，了解合同变换与合同矩阵的概念，了解二次型的标准形和规范形
- 会用正交变换和配方法化二次型为标准形
- 理解惯性定理，理解二次型的正定性概念，掌握正定二次型的判别法
- （数一）了解二次曲面方程与标准形

二次型是特征值理论的"应用场"。核心主线：**二次型 $f = x^TAx$ 的一切性质都由实对称阵 $A$ 的特征值决定**。

## 🎯 核心知识点

### 6.1 二次型的概念

**定义**：$n$ 个变量的二次齐次多项式

$$f(x_1, x_2, \cdots, x_n) = \sum_{i=1}^{n}\sum_{j=1}^{n} a_{ij}x_i x_j$$

称为二次型。$a_{ij}$ 全为实数时称为实二次型。

**矩阵表示**：$f = x^T A x$，其中 $A = (a_{ij})$ 为**实对称矩阵**（$a_{ij} = a_{ji}$ 取 $x_ix_j$ 系数的一半），$A$ 称为二次型的矩阵。

**要点**：

- 二次型与实对称矩阵一一对应：$x_i^2$ 的系数是 $a_{ii}$，$x_ix_j\ (i\ne j)$ 的系数是 $2a_{ij}$
- 二次型的秩 = 其矩阵 $A$ 的秩 = 标准形中非零项个数
- 写矩阵时交叉项系数要**平分**到对称位置（最常见错误！）

### 6.2 标准形与规范形

**标准形**：只含平方项的二次型 $f = d_1 y_1^2 + d_2 y_2^2 + \cdots + d_n y_n^2$（系数可为任意实数）。

**规范形**：系数只为 $1, -1, 0$ 的标准形 $f = z_1^2 + \cdots + z_p^2 - z_{p+1}^2 - \cdots - z_r^2$。

**可逆线性变换**：令 $x = Cy$（$C$ 可逆），则 $f = x^TAx = y^T(C^TAC)y$，新二次型的矩阵为 $C^TAC$。

**合同**：$B = C^TAC$（$C$ 可逆）时称 $A$ 与 $B$ 合同。可逆线性变换不改变二次型的秩和正定性。

### 6.3 化二次型为标准形

**方法一：正交变换法（最常用）**

步骤：

1. 写出二次型矩阵 $A$
2. 求 $A$ 的特征值 $\lambda_1, \lambda_2, \cdots, \lambda_n$
3. 求各特征值对应的特征向量，同特征值内部正交化，再全部单位化
4. 排成正交矩阵 $Q$，令 $x = Qy$，则 $f = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \cdots + \lambda_n y_n^2$

**特点**：正交变换保持几何形状不变（旋转/反射），标准形系数恰为特征值。正交变换下的标准形唯一（特征值唯一）。

**方法二：配方法**

- 含 $x_1^2$ 项：把含 $x_1$ 的项集中配方，再对剩余变量继续配
- 不含平方项但有 $x_ix_j$ 交叉项：先做可逆变换 $x_i = y_i + y_j,\ x_j = y_i - y_j$ 制造平方项，再配方

配方法得到的变换矩阵 $C$ 要确保**可逆**（写出 $x = Cy$ 验证 $|C|\ne0$）。

**二级结论**：设 $A$ 可逆，则二次型 $f = x^TAx$ 经可逆线性变换必可化为标准形 $f = \lambda_1 y_1^2 + \cdots$，即任一实对称阵合同于对角阵。

### 6.4 惯性指数与惯性定理

**正惯性指数 $p$**：标准形中正平方项的个数；**负惯性指数 $q$**：负平方项的个数。$p + q = r$（秩）。

**惯性定理（Sylvester）**：二次型经任意可逆线性变换化为规范形，正、负惯性指数不变。即规范形唯一。

**二级结论**：若存在非零向量 $\alpha$ 使 $\alpha^T A\alpha > 0$，不能断定 $A$ 正定（正定要求对**一切**非零向量成立）；但可断定 $p \ge 1$。

**合同与惯性指数的关系**：两个实对称矩阵合同 $\Leftrightarrow$ 正负惯性指数相同 $\Leftrightarrow$ 规范形相同。

### 6.5 等价、相似、合同的关系

**三者对比**（设 $A, B$ 为 $n$ 阶实对称矩阵）：

- **等价**：$B = PAQ$（$P, Q$ 可逆）$\Leftrightarrow$ $r(A) = r(B)$
- **相似**：$B = P^{-1}AP$（$P$ 可逆）$\Rightarrow$ 特征值相同
- **合同**：$B = C^TAC$（$C$ 可逆）$\Leftrightarrow$ 正负惯性指数相同

**实对称阵的重要结论**：

- 实对称阵 $A \sim B \Rightarrow A$ 与 $B$ 合同（特征值相同 $\Rightarrow$ 正负惯性指数相同）；反之不然
- 实对称阵必合同于对角阵
- 合同的必要条件：$r(A) = r(B)$，且 $|A|$ 与 $|B|$ 同号（正负惯性指数相同推出）
- 正交变换既是相似变换又是合同变换（$Q^{-1} = Q^T$）

### 6.6 正定二次型与正定矩阵

**定义**：对任意非零向量 $x$，恒有 $x^T A x > 0$，则称 $f = x^TAx$ 为正定二次型，$A$ 为正定矩阵。

**常见误区**：正定要求对**所有**非零 $x$ 成立，仅对某个或某些 $x$ 成立不算。

**正定的充要条件（等价命题群，必背）**：

- $A$ 的特征值全大于 0
- $A$ 的各阶顺序主子式全大于 0
- $A$ 的正惯性指数 $p = n$
- $A$ 合同于单位阵 $E$，即存在可逆矩阵 $C$ 使 $A = C^T C$

**正定的必要条件**（不满足则必不正定）：

- $a_{ii} > 0$（对角线元素全正）
- $|A| > 0$
- $a_{ij}$ 满足 $|a_{ij}| < \sqrt{a_{ii}a_{jj}}$

**负定**：$-A$ 正定 $\Leftrightarrow$ $A$ 负定 $\Leftrightarrow$ 奇数阶顺序主子式为负、偶数阶为正（交替变号）$\Leftrightarrow$ 特征值全小于 0。

**正定矩阵的运算性质**：

- $A$ 正定 $\Rightarrow$ $A^{-1}$、$A^*$、$kA\ (k>0)$、$A^T$ 正定
- $A, B$ 正定 $\Rightarrow$ $A + B$ 正定（注意：$AB$ 未必正定，甚至未必对称）
- $A, B$ 正定，则 $AB$ 正定 $\Leftrightarrow$ $AB = BA$（可交换时乘积才对称且正定）
- $A$ 既是正定矩阵又是正交矩阵 $\Leftrightarrow$ $A = E$
- $A$ 正定，$B$ 列满秩 $\Rightarrow$ $B^T A B$ 正定

**判别正定性的方法选择**：

- 具体矩阵：顺序主子式法（低阶）或特征值法
- 抽象矩阵：定义法（凑 $x^TAx = |\cdots|^2 > 0$）或特征值法

### 6.7 二次型的最值问题

设 $A$ 为实对称阵，特征值 $\lambda_1 \le \lambda_2 \le \cdots \le \lambda_n$，则

$$\lambda_1 \le \frac{x^T A x}{x^T x} \le \lambda_n \quad (x \ne 0)$$

即 $x^TAx$ 在 $|x| = 1$ 约束下的最小值为 $\lambda_1$，最大值为 $\lambda_n$（Rayleigh 商）。

### 6.8 二次曲面（数一）

二次型 $x^TAx = c$ 经正交变换化为 $\lambda_1 y_1^2 + \lambda_2 y_2^2 + \lambda_3 y_3^2 = c$，由特征值符号判断曲面类型：

- 三特征值同号：椭球面（$c$ 与特征值同号时）
- 两正一负：单叶双曲面；一正两负：双叶双曲面
- 含零特征值：柱面或锥面

## ⭐ 重点提示

- 二次型写矩阵：平方项系数直接放对角线，交叉项系数**除以2**放对称位置
- 正交变换法 = 实对称阵正交对角化（第五章），标准形系数就是特征值
- 配方法必须验证变换可逆；正交变换法与配方法得到的标准形一般不同，但正负惯性指数相同
- 正定性判别：具体阵用顺序主子式，抽象阵用定义或特征值；必要条件（对角元>0、行列式>0）用于快速排除
- 合同看惯性指数，相似看特征值，等价看秩——三个关系不可混淆
