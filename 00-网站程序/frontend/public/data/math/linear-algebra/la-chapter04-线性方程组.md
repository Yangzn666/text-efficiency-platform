# 第四章 线性方程组

## 📖 考纲要求

- 会用克拉默法则
- 理解齐次线性方程组有非零解的充要条件及非齐次线性方程组有解的充要条件
- 理解齐次线性方程组的基础解系和通解的概念，会求基础解系和通解
- 理解非齐次线性方程组通解的结构，会求非齐次线性方程组的通解

方程组是线性代数的"枢纽"——行列式、矩阵、向量、秩、特征值全部在此交汇。本章必考且区分度高。

## 🎯 核心知识点

### 4.1 线性方程组的三种表示

$$Ax = b: \quad \begin{cases} a_{11}x_1 + \cdots + a_{1n}x_n = b_1 \\ \cdots\cdots \\ a_{m1}x_1 + \cdots + a_{mn}x_n = b_m \end{cases}$$

- **矩阵表示**：$Ax = b$（$A$ 为系数矩阵，$(A\mid b)$ 为增广矩阵）
- **向量表示**：$x_1\alpha_1 + x_2\alpha_2 + \cdots + x_n\alpha_n = b$（$\alpha_j$ 是 $A$ 的第 $j$ 列）

向量表示揭示了本质：**$Ax=b$ 有解 $\Leftrightarrow$ $b$ 可由 $A$ 的列向量组线性表示**。

### 4.2 解的判定定理（核心）

**齐次方程组 $Ax = 0$**（$A$ 为 $m\times n$）：

$$Ax = 0 \text{ 有非零解} \Leftrightarrow r(A) < n \quad (\text{未知量个数})$$

$$Ax = 0 \text{ 只有零解} \Leftrightarrow r(A) = n$$

- 推论：方程个数 < 未知量个数（$m < n$）时，$Ax=0$ 必有非零解

**非齐次方程组 $Ax = b$**：

$$Ax = b \text{ 有解} \Leftrightarrow r(A) = r(A \mid b)$$

$$Ax = b \text{ 有唯一解} \Leftrightarrow r(A) = r(A\mid b) = n$$

$$Ax = b \text{ 有无穷多解} \Leftrightarrow r(A) = r(A\mid b) < n$$

$$Ax = b \text{ 无解} \Leftrightarrow r(A) < r(A\mid b)$$

**几何意义（数一）**：以三元为例，每个方程代表空间中的一个平面。方程组的解 = 诸平面的公共点：唯一解（交于一点）、无穷多解（交于一线或一面重合）、无解（无公共点，如三棱柱的三条侧棱）。

### 4.3 克拉默法则

$n$ 个方程 $n$ 个未知量的方程组 $Ax = b$，若 $|A| \ne 0$，则有唯一解：

$$x_j = \frac{D_j}{|A|} \quad (j = 1,2,\cdots,n)$$

其中 $D_j$ 是把 $|A|$ 第 $j$ 列换成 $b$ 后的行列式。

**推论**：

- $|A|\ne 0 \Rightarrow Ax=b$ 有唯一解（对任意 $b$）
- $|A|\ne 0 \Rightarrow Ax=0$ 只有零解
- $Ax=0$ 有非零解 $\Rightarrow |A| = 0$（逆否：$|A|\ne0$ 则只有零解）

### 4.4 求方程组的解（必考）

**具体方程组求解步骤**：

1. 对增广矩阵 $(A\mid b)$ 做初等**行**变换化为行阶梯形，判断有无解
2. 有解则继续化为行最简形
3. 确定自由未知量（非主元列对应的未知量，共 $n - r(A)$ 个），令其依次取 $(1,0,\cdots),(0,1,\cdots)$ 得基础解系
4. 写出通解

**含参数方程组**：先消元（参数当常数），按主元是否为零对参数分类讨论，分别求解。注意讨论要"不重不漏"。

**矩阵方程 $AX = B$**：

- $A$ 可逆：$X = A^{-1}B$，用 $(A\mid B)\xrightarrow{行变换}(E\mid A^{-1}B)$ 求解
- $A$ 不可逆：设 $X$ 按列分块 $X = (x_1, x_2, \cdots)$，转化为多个 $Ax_j = \beta_j$ 分别求解，合并得 $X$

### 4.5 齐次方程组的基础解系

**定义**：$\xi_1, \xi_2, \cdots, \xi_s$ 是 $Ax = 0$ 的基础解系，当且仅当：

1. $\xi_1,\cdots,\xi_s$ 都是 $Ax = 0$ 的解
2. $\xi_1,\cdots,\xi_s$ 线性无关
3. $Ax = 0$ 的任一解都可由其线性表示

**核心结论**：若 $r(A) = r < n$，则基础解系含 $n - r$ 个向量；$Ax=0$ 的任意 $n-r$ 个线性无关的解都构成基础解系。

**通解**：$x = k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r}$，$k_i$ 为任意常数。

**解的性质**：

- $\xi_1, \xi_2$ 是 $Ax=0$ 的解 $\Rightarrow$ $k_1\xi_1 + k_2\xi_2$ 仍是解（解集合对线性组合封闭，构成解空间）
- 解空间 $S = \{x \mid Ax = 0\}$ 是 $\mathbb{R}^n$ 的子空间（数一），维数为 $n - r(A)$

### 4.6 非齐次方程组的解的结构

**解的性质**：

- $\eta_1, \eta_2$ 是 $Ax = b$ 的解 $\Rightarrow$ $\eta_1 - \eta_2$ 是导出组 $Ax = 0$ 的解
- $\eta$ 是 $Ax=b$ 的解，$\xi$ 是 $Ax=0$ 的解 $\Rightarrow$ $\eta + k\xi$ 是 $Ax=b$ 的解
- $\eta_1,\cdots,\eta_s$ 是 $Ax=b$ 的解，则 $k_1\eta_1 + \cdots + k_s\eta_s$ 是 $Ax=b$ 的解 $\Leftrightarrow$ $k_1 + \cdots + k_s = 1$（系数和为1）；是 $Ax=0$ 的解 $\Leftrightarrow$ 系数和为 $0$

**通解结构定理**：设 $\eta^*$ 是 $Ax = b$ 的一个特解，$\xi_1,\cdots,\xi_{n-r}$ 是导出组 $Ax=0$ 的基础解系，则

$$x = \eta^* + k_1\xi_1 + k_2\xi_2 + \cdots + k_{n-r}\xi_{n-r} \quad (k_i \text{任意})$$

即：**非齐次通解 = 一个特解 + 导出组的通解**。

**秒杀辨析**：已知 $\eta_1, \eta_2$ 是 $Ax=b$ 的解，则 $\frac{\eta_1+\eta_2}{2}$ 是 $Ax=b$ 的解（系数和为1），$\eta_1-\eta_2$ 是 $Ax=0$ 的解。

### 4.7 抽象方程组求通解（☆必考，有区分度）

抽象方程组不给具体矩阵，只给秩、部分解向量、矩阵关系等信息。核心手法：

1. **凑特解**：利用已知解的线性组合（系数和为1）构造特解
2. **凑基础解系**：利用解的差（$Ax=b$ 两解之差是 $Ax=0$ 的解）构造导出组的无关解，个数凑够 $n - r(A)$
3. **定秩**：由已知条件（如 $A$ 的某子式非零、$AB=O$ 且 $B\ne O$）确定 $r(A)$，从而确定基础解系向量个数

**由基础解系反求方程组**：已知 $Ax=0$ 的基础解系 $\xi_1,\cdots,\xi_s$（$n$ 维），求 $A$。方法：把 $\xi_i$ 按**行**排成矩阵 $B$，解 $B^T y = 0$（即求与所有 $\xi_i$ 正交的向量），其基础解系按行排列即得 $A$。原理：$A\xi_i = 0 \Leftrightarrow A$ 的行向量与每个 $\xi_i$ 正交。

### 4.8 公共解问题

**两个方程组 $Ax=0$ 与 $Bx=0$ 的公共解**：即联立方程组 $\begin{pmatrix} A \\ B \end{pmatrix}x = 0$ 的解。

**求法**：

- 法一（都具体）：联立增广矩阵做行变换求解
- 法二（一个给通解）：设 $Ax=0$ 的通解 $x = k_1\xi_1 + k_2\xi_2$，代入 $Bx = 0$ 解出 $k_i$ 满足的关系
- 法三（都抽象）：利用解的结构分析

**判断有无非零公共解**：$r\begin{pmatrix} A \\ B \end{pmatrix} < n$ 时有非零公共解。

### 4.9 同解问题 ☆

**定义**：$Ax = 0$ 与 $Bx = 0$ 同解 $\Leftrightarrow$ 两者解集合完全相同。

**核心结论**：

- $Ax=0$ 与 $Bx=0$ 同解 $\Rightarrow$ 基础解系可相互线性表示 $\Rightarrow$ $n - r(A) = n - r(B)$，即 $r(A) = r(B)$（必要条件）
- $Ax=0$ 的解都是 $Bx=0$ 的解 $\Leftrightarrow$ $B$ 的行向量可由 $A$ 的行向量线性表示（解集合的包含 $\Leftrightarrow$ 行向量组表示关系反向）
- 同解 $\Leftrightarrow$ 相互包含 $\Leftrightarrow$ $A,B$ 行向量组等价 $\Leftrightarrow$ $r(A) = r(B) = r\begin{pmatrix} A \\ B \end{pmatrix}$

**已知同解求参数**：先用必要条件 $r(A) = r(B)$ 定参数范围，再**代回验证**（把参数代回原方程组，确认解集合确实相同）——验证是最简单的保险手段。

**解的包含关系重要结论**（多角度理解同一问题）：

$$Ax=0 \text{ 的解都是 } Bx=0 \text{ 的解} \Leftrightarrow B = CA \text{（}B\text{的行向量可由}A\text{的行向量表示）}$$

$$\Leftrightarrow A^T x = 0 \text{ 的解都是 } B^T x = 0 \text{ 的解（转置后解集合包含关系保持）}$$

## ⭐ 重点提示

- 判定问题永远先**搞秩**：$r(A)$ 与 $r(A\mid b)$、$r(A)$ 与 $n$ 的比较决定一切
- 通解结构题的固定流程：定秩 → 凑特解（系数和1）→ 凑基础解系（解的差，凑够 $n-r$ 个无关解）
- 基础解系不唯一，但向量个数 $n-r(A)$ 唯一；验证一组向量是否为基础解系：是解 + 无关 + 个数对
- 公共解 = 联立；同解 = 联立后秩不变（$r\binom{A}{B} = r(A) = r(B)$）
- 含参讨论题：消元先行，分类不重不漏，最后代回检验
