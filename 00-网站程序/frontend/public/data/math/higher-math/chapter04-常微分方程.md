# 第四章 常微分方程

## 📖 考纲要求与考情

- 掌握可分离变量方程、齐次方程、一阶线性方程的解法
- 掌握伯努利方程、全微分方程（恰当方程）的解法
- 掌握二阶常系数线性齐次/非齐次方程的解法
- 了解可降阶的高阶方程

**考情**：微分方程是**计算型送分题**，每年选择/填空/解答必有1道。一阶线性方程和二阶常系数非齐次方程的求解必须做到零失误。与变上限积分、物理应用联动是常见出题方式。

## 🎯 核心知识体系

### 4.1 一阶微分方程

**可分离变量方程**：$\frac{dy}{dx} = g(x)h(y)$ → $\frac{dy}{h(y)} = g(x)dx$，两边积分。

**齐次方程**：$\frac{dy}{dx} = \varphi(\frac{y}{x})$ → 令 $u = \frac{y}{x}$（$y = ux$，$y' = u + xu'$），化为可分离变量。

**一阶线性方程（★最重要）**：$y' + P(x)y = Q(x)$

$$通解公式：y = e^{-\int P dx}[\int Q(x)e^{\int P dx}dx + C]$$

- $Q(x) = 0$（齐次）：$y = Ce^{-\int P dx}$
- $Q(x) \ne 0$（非齐次）：通解 = 齐次通解 + 一个特解

**伯努利方程**：$y' + P(x)y = Q(x)y^n$（$n \ne 0, 1$）→ 令 $z = y^{1-n}$，化为一阶线性。

**全微分方程**：$P(x,y)dx + Q(x,y)dy = 0$，若 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$（恰当条件），则存在 $u(x,y)$ 使 $du = 0$，通解 $u(x,y) = C$。

### 4.2 可降阶的高阶方程

**$y^{(n)} = f(x)$ 型**：逐次积分 $n$ 次。

**$y'' = f(x, y')$ 型**（缺 $y$）：令 $p = y'$，$y'' = p'$ → 一阶方程 $p' = f(x, p)$。

**$y'' = f(y, y')$ 型**（缺 $x$）：令 $p = y'$，$y'' = p\frac{dp}{dy}$ → 一阶方程 $p\frac{dp}{dy} = f(y, p)$。

### 4.3 线性方程解的结构

**齐次线性方程**：$y'' + p(x)y' + q(x)y = 0$

- 解的叠加性：$y_1, y_2$ 是解 → $c_1y_1 + c_2y_2$ 也是解
- **通解结构**：$y_1, y_2$ 线性无关（$\frac{y_1}{y_2} \ne$ 常数）→ 通解 $y = c_1y_1 + c_2y_2$

**非齐次线性方程**：$y'' + p(x)y' + q(x)y = f(x)$

- 通解 = 对应齐次通解 + 非齐次一个特解：$y = Y + y^*$
- $y_1^*, y_2^*$ 都是非齐次的解 → $y_1^* - y_2^*$ 是齐次的解
- 非齐次解的线性组合：$k_1y_1^* + k_2y_2^*$ 是非齐次的解 $\Leftrightarrow k_1 + k_2 = 1$

### 4.4 二阶常系数线性方程（★核心）

**齐次**：$y'' + py' + qy = 0$ → 特征方程 $r^2 + pr + q = 0$

| 特征根情况 | 通解 |
|-----------|------|
| 两个不等实根 $r_1 \ne r_2$ | $y = c_1e^{r_1x} + c_2e^{r_2x}$ |
| 二重实根 $r_1 = r_2 = r$ | $y = (c_1 + c_2x)e^{rx}$ |
| 共轭复根 $\alpha \pm \beta i$ | $y = e^{\alpha x}(c_1\cos\beta x + c_2\sin\beta x)$ |

**非齐次**：$y'' + py' + qy = f(x)$，特解形式由 $f(x)$ 决定：

**$f(x) = P_m(x)e^{\lambda x}$ 型**（$P_m$ 为 $m$ 次多项式）：

设特解 $y^* = x^k Q_m(x)e^{\lambda x}$，$k$ = $\lambda$ 作为特征根的重数（0, 1, 2）。

**$f(x) = e^{\lambda x}[P_l(x)\cos\omega x + P_n(x)\sin\omega x]$ 型**：

设 $y^* = x^k e^{\lambda x}[Q_m(x)\cos\omega x + R_m(x)\sin\omega x]$，$m = \max(l, n)$，$k$ = $\lambda + \omega i$ 作为特征根的重数（0或1）。

★ **注意**：设三角型特解时，$\cos$ 和 $\sin$ 必须**同时设**（即使 $f$ 只含 $\cos$）。

### 4.5 欧拉方程（数一要求）

$x^2y'' + pxy' + qy = f(x)$ → 令 $t = \ln x$（$x = e^t$）：

$xy' = \frac{dy}{dt}$，$x^2y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$ → 化为常系数方程。

## 📐 核心公式速查

$$一阶线性：y = e^{-\int P dx}[\int Qe^{\int P dx}dx + C]$$

$$特征方程r^2 + pr + q = 0：不等实根/重根/复根 三种通解$$

$$f = P_m(x)e^{\lambda x}：y^* = x^k Q_m(x)e^{\lambda x}（k = \lambda的重数）$$

$$通解 = 齐次通解 + 非齐次特解$$

## ✏️ 经典题型

:::fold 题型一 一阶线性方程（★年年考）
**例**：求 $y' + \frac{y}{x} = x^2$（$x > 0$）的通解。

**解**：$P = \frac{1}{x}$，$Q = x^2$。

$\int P dx = \ln x$，$e^{\int P dx} = x$

$y = \frac{1}{x}[\int x^2 \cdot x dx + C] = \frac{1}{x}[\frac{x^4}{4} + C] = \frac{x^3}{4} + \frac{C}{x}$

**例（初值问题）**：$y' - y = e^x$，$y(0) = 1$。

齐次通解 $Ce^x$；设特解 $y^* = axe^x$（$\lambda = 1$ 是一重根 → 乘 $x$）：

$y^*{}' - y^* = ae^x + axe^x - axe^x = ae^x = e^x$ → $a = 1$

$y = Ce^x + xe^x$，$y(0) = C = 1$ → $y = (1 + x)e^x$
:::

:::fold 题型二 可分离变量 / 齐次方程（★年年考）
**例（可分离）**：$y' = \frac{y}{x}\ln\frac{y}{x}$... 这其实是齐次型。

**例（分离变量）**：$xy' = y\ln y$ → $\frac{dy}{y\ln y} = \frac{dx}{x}$

1. $\int \frac{d(\ln y)}{\ln y} = \int \frac{dx}{x}$
2. $\ln|\ln y| = \ln|x| + C_1$
3. $\ln y = Cx$，即 $y = e^{Cx}$

**例（齐次方程）**：$y' = \frac{y}{x} + \tan\frac{y}{x}$，令 $u = \frac{y}{x}$：

$u + xu' = u + \tan u$ → $\frac{du}{\tan u} = \frac{dx}{x}$ → $\ln|\sin u| = \ln|x| + C$

$\sin\frac{y}{x} = Cx$
:::

:::fold 题型三 二阶常系数齐次方程（★年年考）
**例**：求 $y'' - 4y' + 4y = 0$ 的通解。

**解**：特征方程 $r^2 - 4r + 4 = 0$ → $(r - 2)^2 = 0$，二重根 $r = 2$。

通解：$y = (c_1 + c_2x)e^{2x}$

**例（复根）**：$y'' + 2y' + 5y = 0$ → $r^2 + 2r + 5 = 0$ → $r = -1 \pm 2i$

通解：$y = e^{-x}(c_1\cos 2x + c_2\sin 2x)$

**例（初值问题）**：$y'' - y = 0$，$y(0) = 0$，$y'(0) = 1$。

通解 $y = c_1e^x + c_2e^{-x}$；$y(0) = c_1 + c_2 = 0$，$y'(0) = c_1 - c_2 = 1$

→ $c_1 = \frac{1}{2}$，$c_2 = -\frac{1}{2}$ → $y = \frac{e^x - e^{-x}}{2} = \sinh x$
:::

:::fold 题型四 二阶常系数非齐次方程（★年年考·大题）
**例**：求 $y'' - 3y' + 2y = xe^x$ 的通解。

**解**：

**第1步**：特征方程 $r^2 - 3r + 2 = 0$ → $r = 1, 2$。齐次通解 $Y = c_1e^x + c_2e^{2x}$

**第2步**：$f = xe^x$，$\lambda = 1$ 是一重特征根 → $k = 1$

设 $y^* = x(ax + b)e^x = (ax^2 + bx)e^x$

**第3步**：代入求系数。$y^*{}' = (2ax + b)e^x + (ax^2 + bx)e^x = (ax^2 + (2a + b)x + b)e^x$

$y^*{}'' = (2ax + 2a + b)e^x + (ax^2 + (2a+b)x + b)e^x = (ax^2 + (4a + b)x + 2a + 2b)e^x$

$y^*{}'' - 3y^*{}' + 2y^* = [ax^2 + (4a+b)x + 2a + 2b - 3ax^2 - 3(2a+b)x - 3b + 2ax^2 + 2bx]e^x$

$= [-2ax + 2a - b]e^x = xe^x$

→ $-2a = 1$，$2a - b = 0$ → $a = -\frac{1}{2}$，$b = -1$

**第4步**：$y = c_1e^x + c_2e^{2x} + (-\frac{x^2}{2} - x)e^x$

**要点**：$\lambda$ 是特征根 → 特解乘 $x^k$；多项式次数保持 $m$ 次。
:::

:::fold 题型五 三角型非齐次特解（高频）
**例**：求 $y'' + y = \cos x$ 的一个特解。

**解**：特征根 $r = \pm i$。$f = \cos x$ 对应 $\lambda + \omega i = 0 + i$，是一重特征根 → $k = 1$。

设 $y^* = x(a\cos x + b\sin x)$（★cos和sin同时设）

$y^*{}' = (a\cos x + b\sin x) + x(-a\sin x + b\cos x)$

$y^*{}'' = 2(-a\sin x + b\cos x) + x(-a\cos x - b\sin x)$

$y^*{}'' + y^* = 2(-a\sin x + b\cos x) = \cos x$

→ $b = \frac{1}{2}$，$a = 0$ → $y^* = \frac{x\sin x}{2}$
:::

:::fold 题型六 利用解的结构求方程（高频）
**例**：设 $y_1 = e^x$，$y_2 = e^{2x}$，$y_3 = e^x + e^{3x}$ 是某二阶常系数非齐次方程的三个解，求该方程。

**解**：$y_3 - y_1 = e^{3x}$，$y_1 = e^x$ 是齐次的解...

验证：$y_2 - y_1 = e^{2x} - e^x$ 也是齐次的解。取两个线性无关的齐次解：$e^x$，$e^{3x}$（$y_3 - y_1$）。

特征根 $r = 1, 3$ → 特征方程 $(r - 1)(r - 3) = r^2 - 4r + 3 = 0$

齐次方程：$y'' - 4y' + 3y = 0$

特解：$y_1 = e^x$... 但 $e^x$ 是齐次解，不能直接作特解。用 $y_2 = e^{2x}$ 作特解：

$y_2'' - 4y_2' + 3y_2 = 4e^{2x} - 8e^{2x} + 3e^{2x} = -e^{2x}$

故方程为 $y'' - 4y' + 3y = -e^{2x}$。
:::

:::fold 题型七 可降阶的高阶微分方程（高频，数一专属）
**三种类型**：

1. $y^{(n)} = f(x)$：直接积分 $n$ 次
2. $y'' = f(x, y')$（缺 $y$）：令 $y' = p$，$y'' = p'$ → 关于 $p$ 的一阶方程
3. $y'' = f(y, y')$（缺 $x$）：令 $y' = p$，$y'' = p\frac{dp}{dy}$ → 关于 $p(y)$ 的一阶方程

**例**：求 $xy'' + y' = 0$ 的通解。

**解**：缺 $y$ 型，令 $y' = p$：

1. $xp' + p = 0$ → 分离变量 → $p = \frac{C_1}{x}$
2. 再积分：$y = C_1 \ln|x| + C_2$

**注意**：最终结果不要漏掉两个任意常数。
:::

## ⭐ 重点提示

- **一阶线性方程通解公式**和**二阶常系数特解设法**是两大必背模板
- 特解设法的 $k$ 值（$\lambda$ 是特征根的重数）是最常见错误点
- 三角型特解必须 $\cos$ 和 $\sin$ 同时设
- 解的结构题（已知几个解反推方程）是选择题高频，核心：非齐次解做差 = 齐次解
