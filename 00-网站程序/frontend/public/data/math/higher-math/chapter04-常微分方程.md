# 第四章 常微分方程

## 📖 学习目标
- 理解微分方程的基本概念
- 掌握一阶微分方程的解法
- 掌握高阶线性微分方程的解法
- 能够用微分方程建模实际问题

## 🎯 核心知识点

### 4.1 基本概念
- 微分方程：含有未知函数及其导数的方程
- 阶数：方程中最高阶导数的阶数
- 通解：含有任意常数的解
- 特解：确定常数后的解

### 4.2 一阶微分方程
#### 4.2.1 可分离变量方程
- 形式：$\frac{dy}{dx} = f(x)g(y)$
- 解法：分离变量后积分

#### 4.2.2 齐次方程
- 形式：$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$
- 解法：令 $u = \frac{y}{x}$

#### 4.2.3 一阶线性方程
- 形式：$\frac{dy}{dx} + P(x)y = Q(x)$
- 通解公式：$$y = e^{-\int P(x)dx} \left[\int Q(x)e^{\int P(x)dx}dx + C\right]$$

#### 4.2.4 伯努利方程
- 形式：$\frac{dy}{dx} + P(x)y = Q(x)y^n$
- 解法：令 $z = y^{1-n}$

### 4.3 高阶线性微分方程
#### 4.3.1 二阶常系数齐次线性方程
- 形式：$y'' + py' + qy = 0$
- 特征方程：$r^2 + pr + q = 0$
- 根据特征根分类：
  - 两个不等实根 $r_1, r_2$：$y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$
  - 两个相等实根 $r_1 = r_2$：$y = (C_1 + C_2 x)e^{r_1 x}$
  - 一对共轭复根 $\alpha \pm i\beta$：$y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$

#### 4.3.2 二阶常系数非齐次线性方程
- 形式：$y'' + py' + qy = f(x)$
- 通解：$y = Y + y^*$（齐次通解 + 特解）
- 特解形式：
  - $f(x) = P_m(x)e^{\lambda x}$：设 $y^* = x^k Q_m(x)e^{\lambda x}$
  - $f(x) = e^{\alpha x}[P_l(x)\cos \beta x + P_n(x)\sin \beta x]$：设相应形式

### 4.4 应用
- 几何应用：曲线方程
- 物理应用：运动方程
- 人口增长模型
- 放射性衰变

## ⭐ 重点提示
- 一阶线性方程的通解公式必须牢记
- 二阶常系数方程的特征方程法是核心
- 非齐次方程特解的形式要根据$f(x)$正确设定
