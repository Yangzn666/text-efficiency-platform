# 第七章 无穷级数

## 📖 学习目标
- 理解无穷级数的概念和敛散性
- 掌握数项级数的审敛法
- 掌握幂级数的收敛域和展开方法
- 了解傅里叶级数

## 🎯 核心知识点

### 7.1 数项级数
#### 7.1.1 基本概念
- 定义：$\sum_{n=1}^{\infty} u_n = u_1 + u_2 + \cdots + u_n + \cdots$
- 部分和：$S_n = u_1 + u_2 + \cdots + u_n$
- 收敛：$\lim_{n \to \infty} S_n = S$存在
- 必要条件：$\lim_{n \to \infty} u_n = 0$

#### 7.1.2 正项级数审敛法
**比较审敛法**：
- $0 \leq u_n \leq v_n$，$\sum v_n$收敛则$\sum u_n$收敛

**比值审敛法（达朗贝尔判别法）**：
$$\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \rho$$
- $\rho < 1$：收敛
- $\rho > 1$：发散
- $\rho = 1$：无法判断

**根值审敛法（柯西判别法）**：
$$\lim_{n \to \infty} \sqrt[n]{u_n} = \rho$$
- $\rho < 1$：收敛
- $\rho > 1$：发散

**积分审敛法**：
- 若$f(x)$在$[1, +\infty)$单调递减且非负
- $\sum_{n=1}^{\infty} f(n)$与$\int_{1}^{+\infty} f(x)dx$同敛散

#### 7.1.3 交错级数
- 形式：$\sum_{n=1}^{\infty} (-1)^{n-1}u_n$（$u_n > 0$）
- 莱布尼茨判别法：
  - $u_n \geq u_{n+1}$（单调递减）
  - $\lim_{n \to \infty} u_n = 0$
  - 满足则收敛

#### 7.1.4 绝对收敛与条件收敛
- 绝对收敛：$\sum |u_n|$收敛
- 条件收敛：$\sum u_n$收敛但$\sum |u_n|$发散
- 定理：绝对收敛必收敛

### 7.2 幂级数
#### 7.2.1 幂级数的收敛性
- 标准形式：$\sum_{n=0}^{\infty} a_n x^n$
- 收敛半径：$R = \lim_{n \to \infty} \left|\frac{a_n}{a_{n+1}}\right|$或$R = \lim_{n \to \infty} \frac{1}{\sqrt[n]{|a_n|}}$
- 收敛区间：$(-R, R)$
- 收敛域：需要单独检验端点$x = \pm R$

#### 7.2.2 幂级数的运算
- 加减法：收敛半径取小的
- 乘法：柯西乘积
- 逐项求导：$$\left(\sum_{n=0}^{\infty} a_n x^n\right)' = \sum_{n=1}^{\infty} na_n x^{n-1}$$
- 逐项积分：$$\int_0^x \sum_{n=0}^{\infty} a_n t^n dt = \sum_{n=0}^{\infty} \frac{a_n}{n+1}x^{n+1}$$
- 逐项求导和积分不改变收敛半径

#### 7.2.3 函数的幂级数展开
**常用展开式**（$|x| < 1$或指定区间）：
- $$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n$$
- $$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!}$$
- $$\sin x = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!}x^{2n+1}$$
- $$\cos x = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n)!}x^{2n}$$
- $$\ln(1+x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n}x^n$$

**展开方法**：
- 直接法：利用泰勒公式
- 间接法：利用已知展开式、变量代换、逐项求导或积分

### 7.3 傅里叶级数
#### 7.3.1 三角函数系的正交性
- $\{1, \cos x, \sin x, \cos 2x, \sin 2x, \cdots\}$在$[-\pi, \pi]$上正交

#### 7.3.2 傅里叶级数展开
- 周期为$2\pi$的函数：$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx)$$
- 傅里叶系数：
  $$a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\cos nx dx$$
  $$b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x)\sin nx dx$$

#### 7.3.3 收敛定理（狄利克雷定理）
- $f(x)$在一个周期内分段光滑
- 在连续点：级数收敛于$f(x)$
- 在间断点：级数收敛于$\frac{f(x^+) + f(x^-)}{2}$

#### 7.3.4 奇偶函数的傅里叶级数
- 奇函数：只含正弦项（$a_n = 0$）
- 偶函数：只含余弦项（$b_n = 0$）

## ⭐ 重点提示
- 数项级数的审敛法要灵活选用
- 幂级数的收敛域一定要检验端点
- 函数展开为幂级数是常考题型
- 傅里叶级数注意奇偶性可以简化计算
