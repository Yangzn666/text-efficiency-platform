## 🎯 核心知识体系

### 8.1 向量代数

**数量积（点积）**：$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1b_1 + a_2b_2 + a_3b_3$

- $\vec{a} \perp \vec{b} \Leftrightarrow \vec{a} \cdot \vec{b} = 0$
- 夹角：$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|}$

**向量积（叉积）**：$\vec{a} \times \vec{b}$ 是向量，模 $= |\vec{a}||\vec{b}|\sin\theta$，方向按右手系。

$$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \end{vmatrix}$$

- $\vec{a} \parallel \vec{b} \Leftrightarrow \vec{a} \times \vec{b} = \vec{0}$
- $|\vec{a} \times \vec{b}|$ = 以 $\vec{a}, \vec{b}$ 为邻边的平行四边形面积
- 反交换：$\vec{a} \times \vec{b} = -\vec{b} \times \vec{a}$

**混合积**：$(\vec{a}, \vec{b}, \vec{c}) = (\vec{a} \times \vec{b}) \cdot \vec{c}$ = 三向量构成的行列式

- 三向量共面 $\Leftrightarrow$ 混合积 $= 0$
- $|(\vec{a}, \vec{b}, \vec{c})|$ = 平行六面体体积

### 8.2 平面方程

**点法式**（过点 $M_0(x_0, y_0, z_0)$，法向量 $\vec{n} = (A, B, C)$）：

$$A(x - x_0) + B(y - y_0) + C(z - z_0) = 0$$

**一般式**：$Ax + By + Cz + D = 0$（法向量 $\vec{n} = (A, B, C)$）

**截距式**：$\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$（截距分别为 $a, b, c$）

**三点式**：过三点的平面 → 用混合积 $= 0$ 或行列式表示。

**点到平面的距离**：

$$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

**两平面的夹角**：$\cos\theta = \frac{|\vec{n_1} \cdot \vec{n_2}|}{|\vec{n_1}||\vec{n_2}|}$

- 平行：$\vec{n_1} \parallel \vec{n_2}$（$\frac{A_1}{A_2} = \frac{B_1}{B_2} = \frac{C_1}{C_2}$）
- 垂直：$\vec{n_1} \cdot \vec{n_2} = 0$

### 8.3 直线方程

**点向式（对称式）**（过点 $M_0$，方向向量 $\vec{s} = (l, m, n)$）：

$$\frac{x - x_0}{l} = \frac{y - y_0}{m} = \frac{z - z_0}{n}$$

**参数式**：$x = x_0 + lt$，$y = y_0 + mt$，$z = z_0 + nt$

**一般式**（两平面交线）：$\begin{cases} A_1x + B_1y + C_1z + D_1 = 0 \\ A_2x + B_2y + C_2z + D_2 = 0 \end{cases}$，方向向量 $\vec{s} = \vec{n_1} \times \vec{n_2}$

**两点式**：过 $M_1, M_2$：方向向量 $\vec{s} = \overrightarrow{M_1M_2}$

**直线与平面的夹角**：$\sin\theta = \frac{|\vec{s} \cdot \vec{n}|}{|\vec{s}||\vec{n}|}$（★注意是sin，因为是直线与法向量夹角的余角）

- 直线与平面平行：$\vec{s} \perp \vec{n}$（$\vec{s} \cdot \vec{n} = 0$）
- 直线与平面垂直：$\vec{s} \parallel \vec{n}$

**两直线的夹角**：$\cos\theta = \frac{|\vec{s_1} \cdot \vec{s_2}|}{|\vec{s_1}||\vec{s_2}|}$

### 8.4 常用二次曲面（识别图形）

| 曲面 | 方程 | 特征 |
|------|------|------|
| 椭球面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ | 封闭曲面 |
| 单叶双曲面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 一个负号，连通 |
| 双叶双曲面 | $\frac{x^2}{a^2} - \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 两个负号，两片 |
| 椭圆抛物面 | $z = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ | 碗状，开口向上 |
| 双曲抛物面（马鞍面） | $z = \frac{x^2}{a^2} - \frac{y^2}{b^2}$ | 马鞍形 |
| 圆锥面 | $z^2 = \frac{x^2}{a^2} + \frac{y^2}{b^2}$ | 锥面 |
| 椭圆柱面 | $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ | 缺 $z$ → 母线平行于 $z$ 轴 |

**识别口诀**：看正负号个数与常数项；缺哪个变量就是沿哪个方向的柱面。

### 8.5 旋转曲面

**绕 $z$ 轴旋转**：曲线 $f(y, z) = 0$（$yOz$ 面上）绕 $z$ 轴 → 把 $y$ 换成 $\pm\sqrt{x^2 + y^2}$：

$$f(\sqrt{x^2 + y^2}, z) = 0$$

例：$yOz$ 面上直线 $z = y$ 绕 $z$ 轴 → $z = \sqrt{x^2 + y^2}$（圆锥面）

## 📐 核心公式速查

$$\vec{a} \perp \vec{b} \Leftrightarrow \vec{a} \cdot \vec{b} = 0; \quad \vec{a} \parallel \vec{b} \Leftrightarrow \vec{a} \times \vec{b} = 0$$

$$点面距：d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

$$线面角：\sin\theta = \frac{|\vec{s} \cdot \vec{n}|}{|\vec{s}||\vec{n}|}$$

$$两平面交线的方向向量 = \vec{n_1} \times \vec{n_2}$$

## ✏️ 经典题型

:::fold 题型一 求平面方程（中频）
**例**：求过点 $(1, 2, 3)$ 且垂直于向量 $\vec{n} = (2, -1, 3)$ 的平面。

**解**：点法式：$2(x - 1) - (y - 2) + 3(z - 3) = 0$ → $2x - y + 3z - 9 = 0$

**例（过三点的平面）**：求过 $(1, 0, 0)$，$(0, 2, 0)$，$(0, 0, 3)$ 的平面。

截距式：$\frac{x}{1} + \frac{y}{2} + \frac{z}{3} = 1$ → $6x + 3y + 2z - 6 = 0$

**例（过两平面交线且过某点）**：过交线 $\begin{cases} x + y + z = 1 \\ 2x - y + z = 0 \end{cases}$ 且过 $(1, 1, 1)$ 的平面。

设平面束：$(x + y + z - 1) + \lambda(2x - y + z) = 0$，代入 $(1, 1, 1)$：$2 + 4\lambda = 0$ → $\lambda = -\frac{1}{2}$

平面：$2(x + y + z - 1) - (2x - y + z) = 0$ → $3y + z - 2 = 0$
:::

:::fold 题型二 求直线方程（中频）
**例**：求过点 $(1, 0, -2)$ 且与两平面 $x + y + z = 0$，$2x - y + 3z = 5$ 都平行的直线。

**解**：直线方向 $\vec{s} = \vec{n_1} \times \vec{n_2} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ 1 & 1 & 1 \\ 2 & -1 & 3 \end{vmatrix} = (4, -1, -3)$

直线：$\frac{x - 1}{4} = \frac{y}{-1} = \frac{z + 2}{-3}$

**例（两点的直线）**：过 $(1, 2, 3)$ 与 $(4, 5, 6)$：$\vec{s} = (3, 3, 3) \parallel (1, 1, 1)$

$\frac{x - 1}{1} = \frac{y - 2}{1} = \frac{z - 3}{1}$
:::

:::fold 题型三 位置关系与夹角（中频）
**例**：判断直线 $\frac{x - 1}{2} = \frac{y + 1}{-1} = \frac{z}{3}$ 与平面 $x - y + z = 2$ 的位置关系。

**解**：$\vec{s} = (2, -1, 3)$，$\vec{n} = (1, -1, 1)$

$\vec{s} \cdot \vec{n} = 2 + 1 + 3 = 6 \ne 0$ → 不平行（必相交）

$\sin\theta = \frac{6}{\sqrt{14} \cdot \sqrt{3}} = \frac{6}{\sqrt{42}} = \frac{\sqrt{42}}{7}$

**例（点到平面的距离）**：点 $(1, 2, 1)$ 到平面 $x + 2y + 2z - 10 = 0$ 的距离：

$d = \frac{|1 + 4 + 2 - 10|}{\sqrt{1 + 4 + 4}} = \frac{3}{3} = 1$
:::

:::fold 题型四 投影与对称问题（低频）
**例**：求点 $P(1, 2, 3)$ 在平面 $x + y + z = 0$ 上的投影点。

**解**：过 $P$ 作平面的垂线：$\frac{x - 1}{1} = \frac{y - 2}{1} = \frac{z - 3}{1} = t$

垂线上点 $(1 + t, 2 + t, 3 + t)$ 代入平面：$(1 + t) + (2 + t) + (3 + t) = 0$ → $t = -2$

投影点：$(-1, 0, 1)$

**例（点关于平面的对称点）**：对称点 $= P + 2t\vec{n}$（$t$ 为投影参数）$= (1, 2, 3) + 2(-2)(1, 1, 1) = (-3, -2, -1)$
:::

:::fold 题型五 二次曲面与旋转曲面（低频）
**例**：识别曲面 $x^2 + y^2 - z^2 = 1$。

**解**：两个正号一个负号，常数 $= 1$ → **单叶双曲面**（绕 $z$ 轴的旋转曲面）。

**例（旋转曲面）**：$yOz$ 面上的椭圆 $\frac{y^2}{4} + z^2 = 1$ 绕 $y$ 轴旋转所得曲面：

把 $z$ 换成 $\sqrt{x^2 + z^2}$：$\frac{y^2}{4} + x^2 + z^2 = 1$（旋转椭球面）

**识别技巧**：方程中两个变量的地位对称（系数相同）→ 旋转曲面，对称轴是第三个变量的轴。
:::
