## 📝 实施步骤

1. **第一步**: 在CSLearning.vue中确保knowledgeCardRef已正确传递
   - 检查 `<KnowledgeCard ref="knowledgeCardRef" />` 是否存在
   - 检查 `const knowledgeCardRef = ref()` 是否已定义

2. **第二步**: 在composition.ts的各个section的content字段中添加上述链接

3. **第三步**: 由于content是Markdown字符串,需要使用HTML格式的链接
   - 注意: Markdown中的链接语法 `[text](url)` 不支持@click事件
   - 必须使用原生HTML: `<a @click="...">text</a>`

4. **第四步**: 测试点击链接是否能正确弹出知识卡片

## ⚠️ 注意事项

1. **Vue模板字符串中的@符号**: 在TypeScript模板字符串中,@符号不需要转义
2. **引号嵌套**: 使用单引号和双引号交替,避免冲突
3. **可选链操作符**: 使用 `$knowledgeCardRef?.show()` 防止ref为null时报错
4. **样式统一**: 所有链接使用相同的蓝色(#409eff)和下划线样式
