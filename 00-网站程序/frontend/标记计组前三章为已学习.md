# 标记计组前三章为已学习

## 方法一：在浏览器控制台运行（推荐）

1. 打开考研效率平台网站
2. 按 `F12` 打开开发者工具
3. 切换到 **Console（控制台）** 标签
4. 复制以下代码并粘贴到控制台中
5. 按 `Enter` 执行
6. 刷新页面即可看到效果

```javascript
// 标记计组前三章为已学习
const chaptersToMark = [
  '1.1', '1.2', '1.3',           // 第一章
  '2.1', '2.2', '2.3', '2.4',   // 第二章
  '3.1', '3.2', '3.3', '3.4', '3.5', '3.6'  // 第三章
];

const savedProgress = localStorage.getItem('composition_studied_sections');
let studiedSections = savedProgress ? new Set(JSON.parse(savedProgress)) : new Set();

chaptersToMark.forEach(id => studiedSections.add(id));
localStorage.setItem('composition_studied_sections', JSON.stringify([...studiedSections]));

console.log('✅ 已成功标记计组前三章（共13个小节）为已学习！');
console.log('当前已学习小节总数:', studiedSections.size);
location.reload(); // 自动刷新页面
```

## 方法二：手动点击标记

如果你更喜欢手动操作：

1. 打开计组学习页面
2. 依次进入每个小节（1.1 → 1.2 → 1.3 → ... → 3.6）
3. 点击每个小节右上角的 **"标记为已学习"** 按钮
4. 总共需要点击13次

执行脚本后，你可以：
1. 查看页面上已学习的小节是否有绿色勾选标记 ✓
2. 在控制台输入以下代码查看已学习的小节列表：
   ```javascript
   console.log(JSON.parse(localStorage.getItem('composition_studied_sections')));
   ```
