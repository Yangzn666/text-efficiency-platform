# 八哥英语课程更新说明

## 📚 课程内容

已成功将八哥老师27考研英语一/二全程班的完整课程安排记录到系统中。

## 🎯 课程结构

### 基础阶段（开始 —— 6月）

1. **词汇1800核心词汇（录播）** - 4天 30课时
   - 词根词缀扩词：500单词
   - 形近法辨析：500单词
   - 派生法记忆：100单词
   - 同义词实战：400单词

2. **基础语法（直播）**
   - 长难句所需要的所有基础语法

3. **长难句四步法（录播）** - 4天 32课时
   - 第1步：找主干（框架+顺口溜，讲解3h）
   - 第2步：找并列（大并列+小并列，5个长难句）
   - 第3步：找从句（6大从句=主/宾/表/同/定/状，35个长难句）
   - 第4步：去修饰（定语+状语+同位语+插入语，16个长难句）
   - 真题定位句

4. **阅读逐句精读（录播）**
   - 2005年——2009年（20篇超细精读）

5. **阅读四步法（直播）**
   - 英语一/二：2011年—2015年（1.做题 2.讲题 3.长难句分析）

### 暑期强化阶段（7月 —— 9月）

1. **阅读四步法强化（直播+录播）**
   - 直播：阅读四步法"看、找、读、比"
   - 录播：2016—2020真题讲解

2. **翻译二步法（直播+录播）**
   - 直播：翻译二步法
   - 录播：2016—2020真题讲解

3. **完形三步法（直播+录播）**
   - 直播：完形三步法
   - 录播：2016—2020真题讲解

4. **新题型三步法（直播+录播）**
   - 直播：完新题型三步法
   - 直播：2016—2020真题讲解

5. **八哥写作保命（绝招）** - 9月初直播
   - 英语一/二：大小作文
   - 写作全程直播：模板+带背+带练

### 冲刺模拟阶段（10月 —— 12月底考前）

1. **五大题型综合训练**
   - 阅读+翻译+完形+新题型+写作 ️

2. **2021年—2026年真题** - 4套直播讲解
   - 最新5年真题精讲

3. **八哥写作带练 ** - 11月初开始
   - 冲刺50天带练直播

##  如何更新进度

### 方法1：使用浏览器控制台

1. 打开考研效率平台
2. 按 `F12` 打开开发者工具
3. 切换到 `Console`（控制台）标签
4. 复制并粘贴以下代码，然后按 `Enter`：

```javascript
(async function updateEnglishProgress() {
  try {
    const studyRecords = JSON.parse(localStorage.getItem('studyRecords') || '[]');
    const today = new Date().toISOString().split('T')[0];
    const timestamp = Date.now();
    
    const newRecords = [{
      id: `record_${timestamp}_english_update`,
      date: today,
      subject: '英语',
      duration: 0,
```
