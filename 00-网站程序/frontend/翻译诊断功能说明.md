# 翻译诊断与提升计划功能说明

## 📋 功能概述

在英语一翻译学习系统中新增了**智能诊断**和**18天个性化提升计划**功能，帮助用户快速识别翻译问题并制定科学的备考方案。

---

## ✨ 核心功能

### 1. 翻译能力诊断

**入口位置**：英语模块 → 翻译练习页面顶部

**诊断流程**：
1. 点击"开始翻译能力诊断"按钮
2. 系统提供一道六级翻译真题（茶文化主题）
3. 用户在12分钟内完成翻译
4. 系统自动生成详细诊断报告

**诊断维度**：
- 📚 词汇准确性
- 🔧 句型结构
- 💬 地道表达
- ⏱️ 时间控制
- ✨ 整体流畅度

---

### 2. 诊断报告展示

#### A. 总体评分卡片
- 综合评分（星级制）
- 预估六级翻译得分
- 五个维度分项评分

#### B. 逐句详细分析
对每句话进行深度分析：
- ✅ 原文对照
- ❌ 用户翻译（错误处高亮标注）
- ✅ 参考译文
- ⚠️ 问题分析（拼写/语法/表达三类标签）

**示例**：
```
第1句 [需改进]
原文：中国茶文化源远流长，可以追溯到几千年前。
你的翻译：Chinese tea culture has a long histroy with thousands years
参考译文：Chinese tea culture has a long history, dating back thousands of years.

问题分析：
- [拼写] histroy → history
- [表达] with thousands years → dating back thousands of years
- [表达] 遗漏"可以追溯到"的翻译
```

#### C. 核心问题总结
识别4大类核心问题：
1. ❌ 拼写错误频发
2. ⚠️ 主谓一致错误
3. 🇨🇳 中式英语明显
4. 📝 标点符号不规范

每个问题包含：
- 问题描述
- 具体案例
- 对分数的影响

---

### 3. 18天冲刺提升计划

#### 阶段划分（5个阶段）

**阶段1：纠正基础错误（第1-3天）**
- 目标：消除拼写和主谓一致错误
- 每日任务：
  - 写完必须通读检查拼写
  - 主谓一致专项训练
  - 标点规范练习
- 每日投入：40分钟

**阶段2：积累固定搭配（第4-7天）**
- 目标：掌握六级翻译高频搭配
- 重点搭配：
  - quench thirst（解渴）
  - date back to（追溯到）
  - cultural exchange（文化交流）
  - attach importance to（重视）
  - play an important role in（起重要作用）
  - serve as a bridge（充当桥梁）
- 每日投入：40分钟

**阶段3：句型升级训练（第8-12天）**
- 目标：学会使用3个万能句型
- 重点句型：
  - Not only...but also...
  - 定语从句which/that
  - By doing...句式
- 每日投入：40分钟

**阶段4：真题实战+复盘（第13-16天）**
- 目标：适应考试节奏，查漏补缺
- 每日任务：
  - 限时25分钟完成1篇真题
  - 对照答案找差距
  - 建立错题本
- 每日投入：40分钟

**阶段5：考前模拟+模板固化（第17-18天）**
- 目标：保持手感，巩固成果
- 任务：
  - 完整模拟测试
  - 复习错题本
  - 背诵万能句式
- 每日投入：30分钟

## 💾 数据持久化

### localStorage存储项

1. **translation-diagnosis-completed**
   - 类型：Boolean
   - 用途：记录是否已完成诊断
   - 值：'true' / 'false'

2. **translation-today-tasks**
   - 类型：Array
   - 用途：保存今日任务完成状态
   - 格式：`[{ content: string, completed: boolean }]`

3. **english-translation-practices**
   - 类型：Array
   - 用途：保存用户自定义的翻译练习
   - 原有功能，保持不变

## 🔧 技术实现

### 组件结构
```
TranslationLearning.vue
├── 诊断入口按钮区
├── 诊断结果展示区（条件渲染）
│   ├── 总体评分卡片
│   ├── 逐句详细分析
│   ├── 核心问题总结
│   ├── 18天提升计划
│   │   ├── 阶段时间线
│   │   └── 今日任务
│   └── 高频搭配卡片
└── 原有翻译练习区（保留）
```

### 关键代码逻辑

**诊断启动**：
```typescript
function startDiagnosis() {
  showDiagnosis.value = true
  hasCompletedDiagnosis.value = true
  localStorage.setItem('translation-diagnosis-completed', 'true')
  ElMessage.success('诊断完成！已生成个性化提升计划')
}
```

**任务进度保存**：
```typescript
function saveTaskProgress(task: any) {
  const saved = localStorage.getItem('translation-today-tasks')
  const tasks = saved ? JSON.parse(saved) : []
  // 更新或添加任务状态
  localStorage.setItem('translation-today-tasks', JSON.stringify(tasks))
  
  if (task.completed) {
    ElMessage.success('任务完成！继续加油！')
  }
}
```

## 📱 使用指南

### 首次使用
1. 进入英语模块 → 翻译练习
2. 点击"开始翻译能力诊断"按钮
3. 查看生成的诊断报告和提升计划
4. 按照"今日任务"开始执行

### 日常使用
1. 每天打开页面查看今日任务
2. 完成任务后勾选复选框
3. 背诵高频搭配卡片中的内容
4. 按照18天计划逐步推进

### 重新开始诊断
如需重新诊断，可在浏览器控制台执行：
```javascript
localStorage.removeItem('translation-diagnosis-completed')
location.reload()
```
