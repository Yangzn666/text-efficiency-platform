# 个性化学习路径功能说明

## 📋 功能概述

基于你目前的学习情况，我为你设计了一个**智能个性化学习路径展示界面**，它会：

1. **自动分析你的学习记录** - 从study-records.json中提取真实数据
2. **可视化各科目进度** - 用直观的卡片展示每个科目的学习状态
3. **智能推荐学习计划** - 根据你的进度给出每日建议
4. **里程碑追踪** - 清晰显示每个科目的关键节点

## 🎯 核心特性

### 1. 顶部总览卡片
- **累计学习时间**：统计所有科目的总学习时长
- **学习天数**：有学习记录的总天数
- **日均学习时长**：平均每天学习多少小时
- **学习科目数**：正在学习的科目数量
- **总体进度**：所有科目的平均完成度

### 2. 今日学习建议
系统会根据以下因素生成建议：
- 今天是否已有学习记录
- 各科目的平衡性（避免偏科）
- 当前学习阶段的重点任务

例如：
- "数学一：继续概率论强化学习，保持每天2-3小时"
- "408：操作系统刚开始，建议每天1.5-2小时"
- "英语一：今天还没背单词，建议安排15-30分钟"

## 🎨 视觉设计

### 颜色方案
- **数学一**：蓝色 (#409EFF) - 代表理性思维
- **408计算机**：绿色 (#67C23A) - 代表技术成长
- **英语一**：橙色 (#E6A23C) - 代表语言活力
- **政治**：红色 (#F56C6C) - 代表重要提醒

### 进度环
每个科目右上角有一个圆形进度条，直观显示完成百分比。

### 里程碑动画
进行中的里程碑会有脉冲动画效果，提醒你当前的重点任务。

## 📊 数据来源

所有数据来自：
- `study-data/study-records.json` - 学习记录
- `frontend/src/stores/study.ts` - Pinia状态管理
- `frontend/src/stores/learningPath.ts` - 学习路径配置

## 🚀 如何使用

1. **打开学习路径页面**
   - 在导航栏点击"学习路径"
   - 默认显示"个性化路径"标签页

2. **查看各科目详情**
   - 滚动页面查看所有科目卡片
   - 每个卡片显示该科目的完整学习路线

3. **关注今日建议**
   - 页面顶部的建议区域会动态更新
   - 根据你今天的学习情况给出针对性建议

4. **追踪里程碑**
   - 每个科目的里程碑列表清晰显示进度
   - 已完成的显示✅，进行中的显示🔄，待开始的显示⏳

## 💡 智能分析逻辑

### 进度计算
```typescript
// 数学一：35%
- 高数基础：已完成 (10%)
- 线代基础：已完成 (10%)
- 概率论强化：35%完成 (15% × 35% = 5.25%)
总计 ≈ 35%

// 408：45%
- 数据结构：已完成 (20%)
- 组成原理：已完成 (25%)
- 操作系统：刚开始 (0%)
- 计网：未开始 (0%)
总计 ≈ 45%

// 英语一：60%
- 词汇：80%完成 (30% × 80% = 24%)
- 语法：40%完成 (20% × 40% = 8%)
- 其他模块：未开始
总计 ≈ 60%（加权估算）
```

### 建议生成
系统会检查：
1. 今日是否有学习记录
2. 学习的科目是否单一（偏科警告）
3. 各科目当前阶段的优先级
4. 距离考研的时间压力

## 🔄 数据更新

当你添加新的学习记录时：
1. 刷新页面
2. 数据会自动从JSON文件加载
3. 进度和建议会实时更新
