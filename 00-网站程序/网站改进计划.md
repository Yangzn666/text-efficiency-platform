## 〇、总体约束：移动端优先

电脑不能保证一直开着，手机才是随身入口。

- [x] 每日任务、倒计时、打卡链三个核心功能按 **Mobile First** 开发，电脑端自动适配
- [x] PWA 支持：添加到手机主屏幕、全屏打开、离线可查看（Service Worker）
- [x] 云同步（Supabase 免费层）：手机打卡 → 电脑自动同步，解决 localStorage 各设备不通的问题
  - ✅ 同步层代码已完成（`src/utils/cloudSync.ts`），未配置时自动回退纯本地模式
  - ⏳ 激活需用户操作：supabase.com 建免费项目 → 运行 `.env.example` 中的建表SQL → 复制为 `.env` 填入URL和公钥
- [ ] 其余功能（进度表、错题本等）保持桌面端为主，不急

## 一、今日状态页（最高优先级，一个页面一次做完）

**定位**：独立的「今日状态」页面，进网站默认落地页。一屏看完，不滚动就能看到全部关键信息。

**页面布局（从上到下四个区）**：

```
┌─────────────────────────────────────┐
│  距考试还有 153 天                    │  ← 倒计时（大字）
├─────────────────────────────────────┤
│  今日任务（3/5 已完成）               │  ← 任务清单 + 打勾
├─────────────────────────────────────┤
│  打卡链：🔥连续12天   [热力图一行]     │  ← 连续性
├─────────────────────────────────────┤
│  各科进度条（实际 vs 应达）            │  ← 预警
└─────────────────────────────────────┘
```

**① 倒计时区**：
- [x] 大字显示距12月考试还有X天

**② 今日任务区（核心，原“每日任务生成器”）**：
- [x] 根据各科剩余章节 + 剩余天数，自动算出每天各科应完成的量
- [x] 任务具体到“第几章第几节 + 做什么题”（如：线代第5章听课+1000题 / 408数据结构·线性表费曼讲解 / 英语2007-Text1精读 / 政治马原第1讲+肖1000对应章节）
- [x] 完成后打勾，自动更新进度
- [x] 某天某科没完成，自动顺延到第二天
- [x] 手机端：大按钮打勾，30秒完成操作

**③ 打卡链区**：
- [x] 热力图显示连续学习天数，断链时弹出“链断了”警告
- [x] 一键番茄钟：点击启动25分钟，结束自动写入学习记录
- [x] 每日极简复盘：弹窗点选完成项数（30秒内），周自动汇总完成率

**④ 进度预警区**：
- [x] 各科进度条：实际进度 vs 应达进度（按剩余天数反推）
- [x] 落后标橙，严重落后标红（如政治未启动 → 红色警告）
