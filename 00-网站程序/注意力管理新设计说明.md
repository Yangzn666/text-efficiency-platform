# 注意力管理界面 - 全新设计

## 🎯 设计理念

专为考研备考打造的专业级注意力管理系统，采用**极简深色主题**，减少视觉干扰，提升专注效率。

---

## ✨ 核心特性

### 1. **一体化设计**
- ❌ 移除了复杂的标签页切换
- ✅ 所有功能集成在一个页面
- ✅ 快速访问，零操作步骤

### 2. **深色专业主题**
- 🌙 深色背景（#1a1a1a）减少眼部疲劳
- 🎨 科目配色系统（蓝/绿/橙/红）
- 💫 微妙的动画和过渡效果

### 3. **顶部统计栏**
实时显示4个关键指标：
- 📊 今日专注会话数
- ⏱️ 专注总分钟数
- ✅ 会话完成率
- ⚠️ 诱惑次数（可点击快速记录）

### 4. **智能科目选择**
- 4个考研科目卡片式选择
- 颜色编码便于识别
- 选中状态清晰可见

### 5. **环形进度计时器**
- 🎯 280px大尺寸圆形进度环
- 🌈 动态颜色跟随科目
- ⏰ 超大数字显示（4em）
- 📍 当前科目徽章

### 6. **简化控制按钮**
- ▶️ 开始专注（主按钮，渐变蓝色）
- ⏸️ 暂停/继续（次要按钮）
- ❌ 中断（警告色边框）

### 7. **今日数据概览**
4个数据卡片展示：
- 🎯 专注会话次数
- ⏱️ 专注时长统计
- ✅ 完成率百分比
- ⚠️ 诱惑对抗记录

### 8. **诱惑对抗弹窗**
- 🚫 全屏遮罩，聚焦注意力
- 📱 5种诱惑类型（图标+文字）
- 🎲 自动分配替代任务
- ✅ 一键记录，立即返回学习

## 🎨 美术风格

### 色彩系统
```css
背景色: #1a1a1a (深灰黑)
卡片色: #2a2a2a (中灰)
边框色: #2a2a2a / #333 (悬停)
文字主色: #e0e0e0 (浅灰白)
文字次色: #999 (灰色)

科目配色:
- 408: #409EFF (蓝色)
- 数学: #67C23A (绿色)
- 英语: #E6A23C (橙色)
- 政治: #F56C6C (红色)

强调色:
- 主要: #409EFF (蓝色渐变)
- 警告: #E6A23C (橙色渐变)
- 危险: #F56C6C (红色)
```

### 圆角规范
- 大容器: 20px
- 卡片: 12-15px
- 按钮: 12px
- 徽章: 20px

### 阴影效果
- 卡片悬停: `0 8px 20px rgba(0, 0, 0, 0.3)`
- 进度环: `0 0 40px rgba(64, 158, 255, 0.2)`
- 按钮悬停: 对应颜色的发光效果

### 动画过渡
- 所有交互: `transition: all 0.3s ease`
- 悬停上浮: `transform: translateY(-2px)` 或 `-3px`
- 脉冲效果: 用于进行中的任务

## 🚀 使用流程

### 开始专注
1. 选择学习科目（点击科目卡片）
2. 点击"开始专注"按钮
3. 进入25分钟倒计时
4. 可以暂停/继续/中断

### 记录诱惑
1. 点击顶部统计栏的"诱惑次数"
   或等待诱惑出现时主动记录
2. 选择诱惑类型（短视频/社交媒体等）
3. 系统自动分配替代任务
4. 确认记录，获得提示

### 查看数据
- 顶部统计栏：实时数据
- 底部数据概览：详细统计
- 所有数据自动保存到localStorage

## 🔧 技术实现

### 组件结构
```
AttentionViewNew.vue (主视图)
├─ StatsBar (顶部统计)
├─ TimerSection (计时器区域)
│  ├─ SubjectSelector (科目选择)
│  ├─ ProgressRing (进度环)
│  └─ Controls (控制按钮)
├─ DailyOverview (数据概览)
└─ DistractionModal (诱惑弹窗)
```

### 状态管理
- 使用 `useAttentionStore` (Pinia)
- 所有数据持久化到 localStorage
- 响应式更新UI

### 图标系统
- Element Plus Icons
- Emoji表情增强可读性
- 统一尺寸和样式

---

## 📊 数据流

```
用户操作 → Store方法 → 数据更新 → UI响应 → localStorage保存
    ↓
开始专注 → startPomodoroSession → timerState改变 → 计时器启动 → 保存会话
    ↓
记录诱惑 → recordDistraction → distractionRecords增加 → 弹窗关闭 → 保存记录
    ↓
完成会话 → completeSession → todaysSessions增加 → 显示成功 → 保存数据
```
