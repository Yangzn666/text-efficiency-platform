# 408知识点导出工具

## 📖 简介

这套工具可以将考研效率平台网站中的408专业课知识点自动导出为Obsidian格式的Markdown文件，方便你在Obsidian中进行知识管理和复习。

## 🚀 快速开始

### 方法一：双击运行（推荐）

**Windows用户**：
1. 双击 `导出数据结构到Obsidian.bat` 
2. 等待导出完成
3. 在Obsidian中打开 `D:\Obsidian\408-数据结构`

### 方法二：命令行运行

```bash
# 进入工具目录
cd d:\学习\效率

# 运行导出脚本
python export-datastructure-to-obsidian.py
```

### 方法三：PowerShell运行

右键点击 `导出数据结构到Obsidian.ps1` → 选择"使用PowerShell运行"

## 🔧 技术细节

### 工作原理

1. 读取 `dataStructure.ts` 文件
2. 使用正则表达式提取章节和小节数据
3. 转换为标准的Markdown格式
4. 添加YAML frontmatter元数据
5. 按章节组织文件夹结构
6. 生成索引文件和使用指南

### 依赖要求

- Python 3.6+
- 无需额外安装第三方库（仅使用标准库）

## ❓ 常见问题

### Q: 导出后找不到文件？
A: 检查 `D:\Obsidian\408-数据结构` 文件夹是否存在

### Q: 如何更新导出的内容？
A: 重新运行导出脚本即可，会覆盖旧文件

### Q: 会丢失我添加的个人笔记吗？
A: ⚠️ 重新导出会覆盖文件，建议：
   - 在单独的文件中记录个人笔记
   - 或使用Git版本控制

### Q: 可以自定义输出路径吗？
A: 编辑 `export-datastructure-to-obsidian.py` 中的 `output_dir` 变量
