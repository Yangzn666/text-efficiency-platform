### 题1 ⭐ 拐点判断
**题目**：曲线 y = (x-1)(x-2)²(x-3)³(x-4)⁴ 的拐点是？
- 我的答案：B (2,0)
- 正确答案：C (3,0)

**错误原因**：没学过穿针引线法

**正确思路**：
1. 拐点是二阶导数变号的点
2. 用穿针引线法判断y''的符号变化
3. 零点：x=1,2,3,4，对应次数：1,2,3,4
4. 从右上方开始，奇次穿过，偶次反弹
5. x=3处符号变化，是拐点

**反思**：这是工具缺失，必须学会穿针引线法

### 题2 ⭐ 幂级数收敛域
**题目**：数列{a}单调减少，lim aₙ=0，Sₙ=Σaₖ无界，则幂级数Σaₙ(x-1)的收敛域为？
- 我的答案：A (-1,1]
- 正确答案：C [0,2)

**错误原因**：没看懂出题人意图

**正确思路**：
1. 由条件知Σaₙ发散（Sₙ无界），但aₙ→0
2. 类似调和级数，收敛半径R=1
3. x=2时，Σaₙ·1=Σaₙ发散
4. x=0时，Σaₙ·(-1)，由莱布尼茨判别法收敛
5. 收敛域[0,2)

**反思**：要理解条件背后的含义，Sₙ无界=级数发散

### 题9 弧长计算
**题目**：曲线 y = ∫₀ˣ tan t dt (0≤x≤π/4) 的弧长 s = ?

**错误原因**：记不得sec、csc、cot的积分公式

**正确思路**：
1. y' = tan x
2. 弧长 s = ∫₀^(π/4) √(1+tan²x) dx = ∫₀^(π/4) sec x dx
3. sec x dx = ln|sec x + tan x| + C
4. 代入上下限得 s = ln(√2+1)

**反思**：冷门公式也要背，这是硬伤

### 题12 曲线积分
**题目**：设L是柱面x²+y²=1与半面z=x+y的交线，计算∮_L xz dx + xy dy + (y²/2) dz

**错误原因**：不熟练，不知道用什么方法最简便

**正确思路**：
1. 这是空间曲线积分，考虑斯托克斯公式
2. 或者参数化：x=cos t, y=sin t, z=cos t+sin t
3. 直接代入计算

**反思**：曲线积分方法选择要形成条件反射

### 题18  证明题
**题目**：
(I) 证明：对任意正整数n，都有 1/(n+1) < ln(1+1/n) < 1/n
(II) 设 aₙ = 1+1/2+...+1/n - ln n，证明数列{aₙ}收敛

**错误原因**：证明题依旧没头绪

**正确思路**：
(I) 对ln(1+1/n)用拉格朗日中值定理，或构造函数f(x)=ln(1+x)-x/(1+x)
(II) 由(I)知aₙ单调递减有下界，由单调有界准则收敛

**反思**：证明题需要系统训练，不能逃避

### 题19 二重积分
**题目**：已知f(x,y)有二阶连续偏导数，f(1,y)=0, f(x,1)=0, ∬_D f(x,y)dxdy=a，计算I=∬_D xyf''_xy(x,y)dxdy

**错误原因**：好题，很新颖的做法

**正确思路**：
1. 用分部积分法，对f''_xy积分
2. 利用边界条件f(1,y)=0, f(x,1)=0化简
3. 最终I = a

**反思**：这类题见识太少，要多看新颖解法

### 题21 矩阵特征值
**题目**：设A为3阶实对称矩阵，A的秩为2，且A·[1,0,-1;1,0,1] = [-1,0,1;1,0,1]，求A的所有特征值与特征向量

**错误原因**：这类题做的比较少，开局思路不对，概念模糊

**正确思路**：
1. 由A·α = λα知α是特征向量，λ是特征值
2. 从矩阵等式提取特征值和特征向量
3. 实对称矩阵不同特征值的特征向量正交
4. 由秩为2知有一个特征值为0

**反思**：线代题要理解几何意义，不能只会算

### 题22 ⭐ 二维随机变量
**题目**：X与Y的概率分布分别为P(X=0)=1/3, P(X=1)=2/3; P(Y=-1)=P(Y=0)=P(Y=1)=1/3，且P{X²=Y²}=1，求(X,Y)的联合分布

**错误原因**：直接下意识默认XY独立了，结果错了

**正确思路**：
1. P{X²=Y²}=1意味着X²=Y²几乎必然成立
2. 所以P(X=0,Y=0)+P(X=1,Y=-1)+P(X=1,Y=1)=1
3. 结合边际分布求联合分布

**反思**：独立性必须验证，不能想当然

### 题23 ⭐ 参数估计
**题目**：设X₁,...,Xₙ来自正态总体N(μ₀,σ²)，μ₀已知，σ²>0未知，求σ²的最大似然估计

**错误原因**：公式有遗忘

**正确思路**：
1. 似然函数 L(σ²) = (1/√(2πσ²))·exp(-(xᵢ-μ₀)²/(2σ²))
2. ln L = -n/2·ln(2π) - n/2·ln(σ²) - Σ(xᵢ-μ₀)²/(2σ²)
3. 对σ²求导，令=0，解得σ̂² = Σ(xᵢ-μ₀)²/n

**反思**：最大似然是必考点，步骤必须滚瓜烂熟

### 题7 指数分布概率
**题目**：X与Y相互独立，分别服从参数为1与4的指数分布，求P{X<Y}

**错误原因**：想当然了，直接求两个概率密度函数的交点去求二次积分

**正确思路**：
1. P{X<Y} = ∫_{x<y} f_X(x)·f_Y(y) dxdy
2. = ∫₀^∞ e^(-x) · [∫_x^∞ 4e^(-4y) dy] dx
3. = ∫₀^∞ e^(-x) · e^(-4x) dx = ∫₀^∞ e^(-5x) dx = 1/5

**反思**：连续型随机变量的概率要画区域，不能想当然

### 题3 多元函数可微性
**题目**：如果f(x,y)在(0,0)处连续，判断下列命题哪个正确

**错误原因**：有点猜的成分，虽然对了，但原理说不清楚

**正确思路**：
- 可微⇒连续，但连续⇏可微
- 可微的充分条件：偏导数连续
- 选项B正确：若lim f(x,y)/(x²+y²)存在，则f(x,y)=o(√(x²+y²))，可微

**反思**：概念题要能说出原理，不能靠猜

### 题6 矩阵相似
**题目**：P⁻¹AP=diag(1,1,2)，Q=(α₁+α₂,α₂,α)，求Q⁻¹AQ

**错误原因**：直接当第一列和第二类的特征值相加了，想当然

**正确思路**：
1. AP=P·diag(1,1,2)，所以Aα₁=α₁, Aα₂=α₂, Aα₃=2α₃
2. AQ = A(α₁+α₂,α₂,α₃) = (α₁+α₂,α₂,2α₃)
3. Q⁻¹AQ = Q⁻¹·(α₁+α₂,α₂,2α₃) = diag(1,1,2)

**反思**：相似变换要按定义算，不能 invent 公式

### 题10 定积分
**题目**：∫₀² x√(2x-x²) dx = ?

**错误原因**：没有考虑对称性简化计算

**正确思路**：
1. 2x-x² = 1-(x-1)²，令t=x-1
2. 积分变为∫_{-1}^1 (t+1)√(1-t²) dt
3. t√(1-t²)是奇函数，积分为0
4. 只剩∫_{-1}^1 (1-t²) dt = π/2（半圆面积）

**反思**：定积分先观察对称性，能省一半时间

### 题15  不等式证明
**题目**：证明 x·ln((1+x)/(1-x)) + cos x ≥ 1 + x²/2 (-1<x<1)

**错误原因**：单调性的总思路想到了，但里面的巧妙处理没想到

**正确思路**：
1. 构造f(x) = x·ln((1+x)/(1-x)) + cos x - 1 - x²/2
2. 证f(x)≥0，f(0)=0，只需证f'(x)≥0
3. f'(x) = ln((1+x)/(1-x)) + 2x/(1-x²) - sin x - x
4. 再构造g(x)=f'(x)，证g'(x)≥0...

**反思**：这种题考场上可以放弃，不要纠结

### 题17 ⭐ 幂级数求和
**题目**：求幂级数 Σ(4n²+4n+3)/(2n+1)·x^(2n) 的收敛域及和函数

**错误原因**：做少了，忘了固定步骤

**正确思路**：
1. 收敛半径：用比值法，R=1
2. 端点x=±1时发散
3. 拆分：(4n²+4n+3)/(2n+1) = 2n+1 + 2/(2n+1)
4. 分别求和：Σ(2n+1)x^(2n) 和 Σ(2/(2n+1))x^(2n)
5. 前者用求导，后者用积分

**反思**：幂级数求和是高频考点，必须练熟

### 题18 参数方程曲线
**题目**：曲线L: x=f(t), y=cos t (0≤t<π/2)，f(0)=0, f'(t)>0，切线与x轴交点到切点距离恒为1，求f(t)并求面积

**错误原因**：第一小问三角计算有误，第二小问没思路

**正确思路**：
1. 切线方程：Y-cos t = (dy/dx)(X-f(t))
2. 令Y=0，求X，用距离=1列方程
3. 解微分方程得f(t)
4. 面积用参数方程面积公式

**反思**：这种题确实难，考场上可以战略放弃

### 题22 协方差计算
**题目**：二维离散型随机变量(X,Y)的联合分布如表，求P{X=2Y}和Cov(X-Y,Y)

**错误原因**：协方差没有用公式化解，硬算了

**正确思路**：
1. P{X=2Y} = P(X=0,Y=0)+P(X=2,Y=1) = 1/4+0 = 1/4
2. Cov(X-Y,Y) = Cov(X,Y) - Cov(Y,Y) = Cov(X,Y) - D(Y)
3. 用公式算Cov(X,Y)=E(XY)-E(X)E(Y)

**反思**：协方差性质要熟，能省很多计算

### 题23 ⭐ 正态分布参数估计
**题目**：X~N(μ,σ²), Y~N(μ,2σ²)独立，Z=X-Y，求Z的密度、σ²的最大似然估计、证明无偏性

**错误原因**：正态分布概率密度函数忘了，后面套路不清晰

**正确思路**：
1. Z=X-Y~N(0,3σ²)，直接写密度
2. 似然函数L(σ²)=∏f_Z(z;σ²)
3. 求导解得σ̂²=Σzᵢ²/(3n)
4. E(σ̂²)=σ²，是无偏估计

**反思**：概率论太久没看，要集中复习
