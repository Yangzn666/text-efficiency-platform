## 三、核心问题诊断

### 1. 基础知识遗忘严重
- **积分公式**：sec、csc、cot的积分公式记不得
- **概率密度**：正态分布的概率密度函数忘了
- **参数估计**：最大似然估计的公式和步骤模糊

### 2. 概念理解浮于表面
- **独立性**：下意识默认XY独立，忽略题目条件P{X²=Y²}=1
- **可微性**：虽然选对了，但原理说不清楚
- **实对称矩阵**：特征值与特征向量的关系概念模糊

### 3. 方法技巧储备不足
- **穿针引线法**：完全没学过，拐点判断无法下手
- **对称性简化**：定积分没考虑对称性，硬算出错
- **协方差公式**：没用Cov(X-Y,Y)=Cov(X,Y)-D(Y)化解

### 4. 想当然思维危险
- **矩阵相似**：直接把第一列和第二列的特征值相加，没有这种公式
- **独立性假设**：看到X和Y的边际分布就默认独立

### 5. 证明题思路不清
- **不等式证明**：单调性思路想到了，但巧妙处理没想到
- **数列收敛**：依旧没头绪，缺乏系统训练

## 四、专项复习建议

### 🔴 优先级1：立即补救（1-2天内）

#### 1. 积分公式专项（30分钟）
**必须背熟：**
```
∫sec x dx = ln|sec x + tan x| + C
∫csc x dx = -ln|csc x + cot x| + C = ln|csc x - cot x| + C
∫cot x dx = ln|sin x| + C
∫tan x dx = -ln|cos x| + C = ln|sec x| + C
```
**练习**：找5道含tan/sec/csc的弧长/曲线积分题

#### 2. 概率论公式重温（1小时）
**正态分布：**
- X~N(μ,σ²)，密度函数 f(x) = (1/√(2π)σ)·e^(-(x-μ)²/(2σ²))
- 若X~N(μ₁,σ₁²), Y~N(μ₂,σ₂²)独立，则X±Y~N(μ₁±μ₂, σ₁²+σ₂²)

**最大似然估计步骤：**
1. 写似然函数 L(θ) = ∏f(xᵢ;θ)
2. 取对数 ln L(θ)
3. 求导 d/dθ ln L(θ) = 0
4. 解方程得θ̂

**协方差公式：**
- Cov(X-Y,Y) = Cov(X,Y) - Cov(Y,Y) = Cov(X,Y) - D(Y)
- 若X,Y独立，Cov(X,Y)=0

**练习**：找3道正态分布+最大似然的真题

#### 3. 独立性判断专项（30分钟）
**关键原则：**
- 边际分布不能决定独立性
- 必须验证 P(X,Y)=P(X)·P(Y) 对所有(x,y)成立
- 题目给的条件（如P{X²=Y²}=1）可能暗示不独立

**练习**：找2道二维随机变量独立性判断题

---

### 🟡 优先级2：系统强化（3-5天内）

#### 4. 幂级数求和函数（2小时）
**固定步骤：**
1. 求收敛半径（比值法/根值法）
2. 端点单独判断
3. 求和函数：
   - 先积分再求导（或先求导再积分）
   - 利用已知展开式：1/(1-x), e^x, sin x, cos x, ln(1+x)
   - 拆分分子：(4n²+4n+3)/(2n+1) = 2n+1 + 2/(2n+1)

**练习**：找5道幂级数求和题（含x^(2n)形式）

#### 5. 矩阵特征值与相似（2小时）
**实对称矩阵性质：**
- 不同特征值的特征向量正交
- 必可正交对角化：A = PΛP^T，P是正交矩阵
- 秩=非零特征值个数

**相似变换：**
- P⁻¹AP = Λ，P的列是特征向量
- 若Q = (α₁+α₂, α₂, α₃)，需重新计算Q⁻¹AQ，不能想当然

**练习**：找3道实对称矩阵+相似变换题

#### 6. 穿针引线法（30分钟）
**用途**：判断高次多项式的符号变化，用于拐点/极值判断

**步骤：**
1. 找出所有零点（按大小排列）
2. 从右上方开始画线
3. 奇次幂穿过x轴，偶次幂反弹
4. 线在x轴上方为正，下方为负

**例题**：y=(x-1)(x-2)²(x-3)³(x-4)⁴
- 零点：1,2,3,4
- 次数：1(奇),2(偶),3(奇),4(偶)
- 穿-弹-穿-弹

**练习**：找2道拐点判断+2道极值判断题

---

### 🟢 优先级3：长期提升（1-2周）

#### 7. 证明题系统训练（每天30分钟）
**不等式证明常用方法：**
1. 单调性：构造f(x)，证f'(x)>0或<0
2. 最值法：证f(x)≥f(x₀)=0
3. 中值定理：拉格朗日/柯西中值定理
4. 泰勒展开：展开到适当阶数

**数列收敛证明：**
- 单调有界准则
- 夹逼准则
- 定义法（ε-N语言）

**练习**：每天1道证明题，重点看答案的"巧妙处理"

#### 8. 曲线积分与曲面积分（2小时）
**方法选择：**
- 第一类曲线积分：参数化直接算
- 第二类曲线积分：
  - 格林公式（封闭曲线）
  - 参数化（非封闭）
  - 与路径无关条件：∂P/∂y=∂Q/∂x

**练习**：找3道曲线积分题（含格林公式应用）

#### 9. 参数方程曲线（1小时）
**弧长公式：**
s = ∫√[(x'(t))² + (y'(t))²] dt

**面积公式：**
S = ∫y(t)·x'(t) dt 或 S = ∫x(t)·y'(t) dt

**练习**：找2道参数方程弧长/面积题

## 六、反思与提醒

### 你的进步
- 能准确识别自己的错误原因（"想当然"、"公式遗忘"、"概念模糊"）
- 开始关注"巧妙处理"和"新颖做法"，说明在思考更深层的解法
- 概率论意识到"太长时间没看有点忘了"，及时补救

### 需要警惕
1. **"想当然"是最大敌人**：两次都出现（特征值相加、XY独立），做题时要问自己"这个结论有依据吗？"
2. **公式不能只记不用**：积分公式、概率密度、最大似然，都要通过练习巩固
3. **证明题不能逃避**：每次都"没头绪"，需要系统学习证明方法，不能只靠感觉

### 心态调整
- 18题/2天 = 平均每天9题错题，这个量是正常的（真题难度大）
- 关键是每道错题都搞懂，而不是追求数量
- 证明题和难题（如15、18）考场上可能就是要放弃的，不要有压力
