# 第三章 一元函数积分学

## 📖 学习目标
- 理解不定积分和定积分的概念
- 掌握各类积分计算方法
- 熟练运用积分解决实际问题
- 理解微积分基本定理

## 🎯 核心知识点

### 3.1 不定积分
#### 3.1.1 原函数与不定积分
- 原函数：$F'(x) = f(x)$，则$F(x)$是$f(x)$的原函数
- 不定积分：$\int f(x)dx = F(x) + C$
- 性质：线性性

#### 3.1.2 基本积分公式
- $\int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1)$
- $\int \frac{1}{x} dx = \ln|x| + C$
- $\int e^x dx = e^x + C$
- $\int \sin x dx = -\cos x + C$
- $\int \cos x dx = \sin x + C$
- $\int \frac{1}{1+x^2} dx = \arctan x + C$
- $\int \frac{1}{\sqrt{1-x^2}} dx = \arcsin x + C$

### 3.2 积分方法
#### 3.2.1 换元积分法
**第一类换元（凑微分）**：
$$\int f[\varphi(x)]\varphi'(x)dx = \int f(u)du \quad (u = \varphi(x))$$

**第二类换元（变量代换）**：
- 三角代换：$\sqrt{a^2-x^2}$ 令 $x=a\sin t$
- 根式代换：$\sqrt[n]{ax+b}$ 令 $t=\sqrt[n]{ax+b}$
- 倒代换：$x = \frac{1}{t}$

#### 3.2.2 分部积分法
- 公式：$$\int u dv = uv - \int v du$$
- 选取原则：反对幂三指（反三角、对数、幂函数、三角、指数）
- 常见类型：
  - $\int x e^x dx$
  - $\int x \sin x dx$
  - $\int e^x \sin x dx$（循环型）

#### 3.2.3 有理函数积分
- 部分分式分解法
- 奥斯特罗格拉德斯基方法

### 3.3 定积分
#### 3.3.1 定积分的定义
- 定义：$$\int_{a}^{b} f(x)dx = \lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i)\Delta x_i$$
- 几何意义：曲边梯形的面积（代数和）

#### 3.3.2 定积分的性质
- 线性性
- 区间可加性：$\int_{a}^{b} = \int_{a}^{c} + \int_{c}^{b}$
- 保号性
- 估值定理
- 积分中值定理：$$\int_{a}^{b} f(x)dx = f(\xi)(b-a), \quad \xi \in [a,b]$$

#### 3.3.3 牛顿-莱布尼茨公式
- 公式：$$\int_{a}^{b} f(x)dx = F(b) - F(a)$$
- 条件：$f(x)$在$[a,b]$连续，$F(x)$是$f(x)$的原函数

### 3.4 广义积分
#### 3.4.1 无穷区间上的广义积分
- $\int_{a}^{+\infty} f(x)dx = \lim_{b \to +\infty} \int_{a}^{b} f(x)dx$
- $\int_{-\infty}^{b} f(x)dx = \lim_{a \to -\infty} \int_{a}^{b} f(x)dx$

#### 3.4.2 瑕积分
- 瑕点：函数无界的点
- $\int_{a}^{b} f(x)dx = \lim_{\epsilon \to 0^+} \int_{a}^{b-\epsilon} f(x)dx$

#### 3.4.3 收敛性判别
- 比较判别法
- 极限比较判别法
- $p$-积分：$\int_{1}^{+\infty} \frac{1}{x^p} dx$ 当 $p>1$ 时收敛

### 3.5 定积分的应用
#### 3.5.1 几何应用
- 平面图形的面积
- 旋转体的体积：
  - 绕x轴：$V = \pi \int_{a}^{b} [f(x)]^2 dx$
  - 绕y轴：$V = 2\pi \int_{a}^{b} x f(x) dx$
- 平面曲线的弧长：$s = \int_{a}^{b} \sqrt{1 + [f'(x)]^2} dx$

#### 3.5.2 物理应用
- 变力做功：$W = \int_{a}^{b} F(x)dx$
- 液体压力
- 质心坐标

## ⭐ 重点提示
- 积分计算是考研重点，必须熟练掌握换元和分部积分
- 牛顿-莱布尼茨公式是连接微分和积分的桥梁
- 定积分应用题常与几何、物理结合
- 广义积分的收敛性判别是难点
