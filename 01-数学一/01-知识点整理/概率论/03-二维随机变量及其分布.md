## 1.2 二维随机变量的联合分布函数 ⭐⭐⭐

### 一、联合分布函数的定义

**定义**：二维随机变量 $(X, Y)$ 的**联合分布函数**定义为：
$$F(x, y) = P(X \leq x, Y \leq y), \quad -\infty < x < +\infty, -\infty < y < +\infty$$

**几何意义**：
- $F(x, y)$ 表示随机点 $(X, Y)$ 落在区域 $\{(-\infty, x] \times (-\infty, y]\}$ 内的概率
- 即落在点 $(x, y)$ 左下方的无穷矩形区域内的概率

---

### 二、联合分布函数的性质 ⭐⭐⭐重要

联合分布函数 $F(x, y)$ 具有以下**六大性质**：

#### 性质1：单调性

- $F(x, y)$ 关于 $x$ **单调不减**：若 $x_1 < x_2$，则 $F(x_1, y) \leq F(x_2, y)$
- $F(x, y)$ 关于 $y$ **单调不减**：若 $y_1 < y_2$，则 $F(x, y_1) \leq F(x, y_2)$

**直观理解**：区域扩大，概率不会减小

---

#### 性质2：有界性

- $0 \leq F(x, y) \leq 1$
- $F(-\infty, y) = \lim_{x \to -\infty} F(x, y) = 0$
- $F(x, -\infty) = \lim_{y \to -\infty} F(x, y) = 0$
- $F(+\infty, +\infty) = \lim_{x \to +\infty, y \to +\infty} F(x, y) = 1$
- $F(-\infty, -\infty) = 0$

**记忆技巧**：
- 往左下无限远：概率为0
- 往右上无限远：概率为1

---

#### 性质3：右连续性

- $F(x, y)$ 关于 $x$ **右连续**：$F(x+0, y) = F(x, y)$
- $F(x, y)$ 关于 $y$ **右连续**：$F(x, y+0) = F(x, y)$

**注意**：这是分布函数的共性，与一维情况类似

---

#### 性质4：矩形概率公式 ⭐⭐⭐核心考点

对于任意 $x_1 < x_2$，$y_1 < y_2$，有：
$$P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_2, y_1) - F(x_1, y_2) + F(x_1, y_1)$$

**记忆技巧**：类似二重积分的区域分解
```
        y₂ ┌──────────┐
           │    +     │  -
           ├──────────┤
        y₁ │    -     │  +
           └──────────┘
          x₁         x₂
```

**推导过程**：
- 大矩形 $(x_1, x_2] \times (y_1, y_2]$ 的概率
- = $F(x_2, y_2)$（左下角到右上角的大矩形）
- - $F(x_2, y_1)$（减去下方部分）
- - $F(x_1, y_2)$（减去左方部分）
- + $F(x_1, y_1)$（加回重复减去的左下角）

**考研应用**：
- 选择题：判断某个函数是否可以作为联合分布函数
- 计算题：已知联合分布函数，求矩形区域的概率

---

#### 性质5：边缘分布函数

从联合分布函数可以得到边缘分布函数：

- $X$ 的边缘分布函数：$F_X(x) = F(x, +\infty) = \lim_{y \to +\infty} F(x, y)$
- $Y$ 的边缘分布函数：$F_Y(y) = F(+\infty, y) = \lim_{x \to +\infty} F(x, y)$

**重要结论**：
> **联合分布可以推出边缘分布，但边缘分布不能推出联合分布！**
> 
> 原因：边缘分布丢失了 $X$ 和 $Y$ 之间的相关性信息

---

#### 性质6：独立性的判定

若 $X$ 和 $Y$ 相互独立，则：
$$F(x, y) = F_X(x) F_Y(y)$$

反之，如果对所有 $x, y$ 都有 $F(x, y) = F_X(x) F_Y(y)$，则 $X$ 和 $Y$ 独立。

---

### 三、典型例题

**例题1**：已知二维随机变量 $(X, Y)$ 的联合分布函数为
$$F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$$

求：
1. $P(0 < X \leq 1, 0 < Y \leq 2)$
2. $X$ 的边缘分布函数 $F_X(x)$
3. 判断 $X$ 和 $Y$ 是否独立

**解**：

**1. 求矩形概率**：

利用矩形概率公式：
$$P(0 < X \leq 1, 0 < Y \leq 2) = F(1, 2) - F(1, 0) - F(0, 2) + F(0, 0)$$

计算各值：
- $F(1, 2) = (1 - e^{-1})(1 - e^{-2})$
- $F(1, 0) = 0$（因为 $y = 0$ 不在 $y > 0$ 范围内）
- $F(0, 2) = 0$（因为 $x = 0$ 不在 $x > 0$ 范围内）
- $F(0, 0) = 0$

所以：
$$P(0 < X \leq 1, 0 < Y \leq 2) = (1 - e^{-1})(1 - e^{-2})$$
$$= (1 - 0.3679)(1 - 0.1353) = 0.6321 \times 0.8647 \approx 0.5466$$

**2. 求边缘分布函数**：

$$F_X(x) = F(x, +\infty) = \lim_{y \to +\infty} F(x, y)$$

当 $x > 0$ 时：
$$F_X(x) = \lim_{y \to +\infty} (1 - e^{-x})(1 - e^{-y}) = (1 - e^{-x}) \cdot 1 = 1 - e^{-x}$$

当 $x \leq 0$ 时：
$$F_X(x) = 0$$

所以：
$$F_X(x) = \begin{cases} 1 - e^{-x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

同理可得：
$$F_Y(y) = \begin{cases} 1 - e^{-y}, & y > 0 \\ 0, & y \leq 0 \end{cases}$$

**3. 判断独立性**：

验证：$F(x, y) = F_X(x) F_Y(y)$？

当 $x > 0, y > 0$ 时：
$$F_X(x) F_Y(y) = (1 - e^{-x})(1 - e^{-y}) = F(x, y)$$ ✓

当 $x \leq 0$ 或 $y \leq 0$ 时：
$$F_X(x) F_Y(y) = 0 = F(x, y)$$ ✓

**结论**：$X$ 和 $Y$ **相互独立**

**答案**：1. $(1 - e^{-1})(1 - e^{-2})$；2. $F_X(x) = 1 - e^{-x}$，$x > 0$；3. 独立

---

**例题2**（判断是否为联合分布函数）：

下列函数中，哪个可以作为二维随机变量的联合分布函数？

A. $F(x, y) = \begin{cases} xy, & 0 \leq x \leq 1, 0 \leq y \leq 1 \\ 0, & \text{其他} \end{cases}$

B. $F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$

C. $F(x, y) = \begin{cases} \frac{1}{\pi^2}(\frac{\pi}{2} + \arctan x)(\frac{\pi}{2} + \arctan y), & -\infty < x, y < +\infty \end{cases}$

**解**：逐一验证六大性质

**A选项**：
- 检查 $F(+\infty, +\infty)$：但定义域只在 $[0,1] \times [0,1]$，超出范围为0
- $F(1, 1) = 1 \times 1 = 1$ ✓
- 但在 $x > 1$ 或 $y > 1$ 时，$F(x, y) = 0$，不满足单调性 ✗
- **结论**：不是联合分布函数

**B选项**：
- 单调性：$(1 - e^{-x})$ 和 $(1 - e^{-y})$ 都单调递增 ✓
- 有界性：$F(-\infty, y) = 0$，$F(x, -\infty) = 0$，$F(+\infty, +\infty) = 1$ ✓
- 右连续性：指数函数连续 ✓
- **结论**：是联合分布函数 ✓

**C选项**：
- 这是两个标准柯西分布的独立联合分布
- $\lim_{x \to +\infty} (\frac{\pi}{2} + \arctan x) = \pi$
- $F(+\infty, +\infty) = \frac{1}{\pi^2} \cdot \pi \cdot \pi = 1$ ✓
- **结论**：是联合分布函数 ✓

**答案**：B、C都可以

## 1.3 二维随机变量的边缘分布 ⭐⭐

### 一、边缘分布的概念

**定义**：从二维随机变量 $(X, Y)$ 的联合分布中，分别提取出 $X$ 和 $Y$ 各自的分布，称为**边缘分布**。

**核心理解**：
- 边缘分布只关注单个随机变量，忽略另一个
- 类似于“投影”的概念

---

### 二、联合分布与边缘分布的关系 ⭐⭐⭐重要结论

**关键结论**：
> **联合分布 $\Rightarrow$ 边缘分布（可以）**
> 
> **边缘分布 $\Rightarrow$ 联合分布（不可以）**

**原因分析**：
- 联合分布包含了 $X$ 和 $Y$ 的**全部信息**，包括它们之间的**相关性**
- 边缘分布只包含单个变量的信息，**丢失了相关性信息**
- 不同的联合分布可能有相同的边缘分布

**举例说明**：

假设有两个不同的联合分布：

**情况1**：$X$ 和 $Y$ 独立
- 联合分布：$f(x, y) = f_X(x) f_Y(y)$

**情况2**：$X$ 和 $Y$ 相关
- 联合分布：$g(x, y) \neq g_X(x) g_Y(y)$

但它们的边缘分布可能相同：
- $f_X(x) = g_X(x)$
- $f_Y(y) = g_Y(y)$

**结论**：仅知道边缘分布，无法唯一确定联合分布！

---

### 三、如何从联合分布求边缘分布

#### 离散型

**$X$ 的边缘分布律**：
$$P(X = x_i) = \sum_{j} P(X = x_i, Y = y_j) = \sum_{j} p_{ij}$$

**$Y$ 的边缘分布律**：
$$P(Y = y_j) = \sum_{i} P(X = x_i, Y = y_j) = \sum_{i} p_{ij}$$

**记忆**：行和/列和

---

#### 连续型

**$X$ 的边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$

**$Y$ 的边缘概率密度**：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

**记忆**：对另一个变量积分（消去）

---

### 四、典型例题

**例题1**：设二维离散型随机变量 $(X, Y)$ 的联合分布律为

| $X \setminus Y$ | 0 | 1 | 2 |
|----------------|---|---|---|
| 0 | 0.1 | 0.2 | 0.1 |
| 1 | 0.2 | 0.3 | 0.1 |

求 $X$ 和 $Y$ 的边缘分布律。

**解**：

**$X$ 的边缘分布律**（行和）：
- $P(X = 0) = 0.1 + 0.2 + 0.1 = 0.4$
- $P(X = 1) = 0.2 + 0.3 + 0.1 = 0.6$

| $X$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

**$Y$ 的边缘分布律**（列和）：
- $P(Y = 0) = 0.1 + 0.2 = 0.3$
- $P(Y = 1) = 0.2 + 0.3 = 0.5$
- $P(Y = 2) = 0.1 + 0.1 = 0.2$

| $Y$ | 0 | 1 | 2 |
|-----|---|---|---|
| $P$ | 0.3 | 0.5 | 0.2 |

**验证**：$0.4 + 0.6 = 1$ ✓，$0.3 + 0.5 + 0.2 = 1$ ✓

## 1.4 二维离散型随机变量 ⭐⭐⭐

### 一、引入二维随机变量的原因

**问题**：很多实际问题需要同时研究两个或多个随机变量

**举例**：
- 某地区的气温和降水量
- 学生的身高和体重
- 产品的长度和宽度

**解决方案**：将多个随机变量作为一个整体来研究

---

### 二、二维随机变量的定义 ⭐⭐

**定义3.1**：设 $X$ 和 $Y$ 是两个随机变量，如果对于任意实数 $x, y$，二元事件 $\{X \leq x, Y \leq y\}$ 都有确定的概率，则称 $(X, Y)$ 为**二维随机变量**（或**随机向量**）。

**核心理解**：
- $(X, Y)$ 是一个整体，不是两个独立的随机变量
- $X$ 和 $Y$ 之间可能存在依赖关系
- 需要研究它们的**联合分布**

---

### 三、联合分布函数 ⭐⭐⭐

**定义**：二维随机变量 $(X, Y)$ 的**联合分布函数**定义为：
$$F(x, y) = P(X \leq x, Y \leq y), \quad -\infty < x < +\infty, -\infty < y < +\infty$$

**几何意义**：
- $F(x, y)$ 表示随机点 $(X, Y)$ 落在区域 $\{(-\infty, x] \times (-\infty, y]\}$ 内的概率
- 即落在点 $(x, y)$ 左下方的无穷矩形区域内的概率

---

#### 联合分布函数的性质

**性质1：单调性**
- $F(x, y)$ 关于 $x$ 单调不减
- $F(x, y)$ 关于 $y$ 单调不减

**性质2：有界性**
- $0 \leq F(x, y) \leq 1$
- $F(-\infty, y) = F(x, -\infty) = 0$
- $F(+\infty, +\infty) = 1$

**性质3：右连续性**
- $F(x, y)$ 关于 $x$ 右连续
- $F(x, y)$ 关于 $y$ 右连续

**性质4：矩形概率公式** ⭐⭐⭐重要

对于任意 $x_1 < x_2$，$y_1 < y_2$，有：
$$P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_2, y_1) - F(x_1, y_2) + F(x_1, y_1)$$

**记忆技巧**：类似二重积分的区域分解
```
        y₂ ┌──────────┐
           │    +     │  -
           ├──────────┤
        y₁ │    -     │  +
           └──────────┘
          x₁         x₂
```

**证明思路**：
- 大矩形 $(x_1, x_2] \times (y_1, y_2]$ 的概率
- = $F(x_2, y_2)$（左下角到右上角）
- - $F(x_2, y_1)$（减去下方部分）
- - $F(x_1, y_2)$（减去左方部分）
- + $F(x_1, y_1)$（加回重复减去的部分）

---

#### 典型例题

**例题1**：已知二维随机变量 $(X, Y)$ 的联合分布函数为
$$F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$$

求 $P(0 < X \leq 1, 0 < Y \leq 2)$。

**解**：

利用矩形概率公式：
$$P(0 < X \leq 1, 0 < Y \leq 2) = F(1, 2) - F(1, 0) - F(0, 2) + F(0, 0)$$

计算各值：
- $F(1, 2) = (1 - e^{-1})(1 - e^{-2})$
- $F(1, 0) = 0$（因为 $y = 0$ 不在 $y > 0$ 范围内）
- $F(0, 2) = 0$（因为 $x = 0$ 不在 $x > 0$ 范围内）
- $F(0, 0) = 0$

所以：
$$P(0 < X \leq 1, 0 < Y \leq 2) = (1 - e^{-1})(1 - e^{-2})$$
$$= (1 - 0.3679)(1 - 0.1353) = 0.6321 \times 0.8647 \approx 0.5466$$

**答案**：$(1 - e^{-1})(1 - e^{-2}) \approx 0.5466$

## 1.4 二维离散型随机变量 ⭐⭐⭐

### 一、联合分布律

**定义**：若二维随机变量 $(X, Y)$ 的所有可能取值为有限对或可列无限对 $(x_i, y_j)$，则称 $(X, Y)$ 为**二维离散型随机变量**。

**联合分布律**：
$$p_{ij} = P(X = x_i, Y = y_j), \quad i, j = 1, 2, ...$$

**性质**：
1. **非负性**：$p_{ij} \geq 0$
2. **归一性**：$\sum_{i}\sum_{j} p_{ij} = 1$

**表示方法**：通常用表格表示

| $X \setminus Y$ | $y_1$ | $y_2$ | $\cdots$ | $y_j$ | $\cdots$ |
|----------------|-------|-------|---------|-------|---------|
| $x_1$ | $p_{11}$ | $p_{12}$ | $\cdots$ | $p_{1j}$ | $\cdots$ |
| $x_2$ | $p_{21}$ | $p_{22}$ | $\cdots$ | $p_{2j}$ | $\cdots$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ | $\ddots$ |
| $x_i$ | $p_{i1}$ | $p_{i2}$ | $\cdots$ | $p_{ij}$ | $\cdots$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ | $\ddots$ |

---

### 二、解题步骤（四步法）⭐⭐⭐核心技巧

**做题顺序**（非常重要）：

```
第1步：确立表格维度 → 第2步：利用约束化简 → 第3步：求Pij → 第4步：验算Σ=1
```

---

**第1步：确立表格维度** 📊

**目的**：确定 $X$ 和 $Y$ 的所有可能取值

**操作**：
- 找出 $X$ 的所有可能取值：$x_1, x_2, ..., x_m$
- 找出 $Y$ 的所有可能取值：$y_1, y_2, ..., y_n$
- 确定表格大小：$m \times n$

**示例**：
- 掷两颗骰子，$X$ = 第一颗的点数，$Y$ = 第二颗的点数
- $X$ 的取值：$1, 2, 3, 4, 5, 6$
- $Y$ 的取值：$1, 2, 3, 4, 5, 6$
- 表格维度：$6 \times 6$

---

**第2步：利用约束化简** 🔍

**目的**：根据题目条件，排除不可能的组合，减少计算量

**常见约束**：
- $X + Y = k$（和为定值）
- $X < Y$（大小关系）
- $X = Y$（相等）
- $XY = k$（积为定值）

**操作**：
- 画表格，标记出不可能的格子（概率为0）
- 只计算可能的格子

**示例**：
- 若 $X + Y = 5$，则只有 $(1,4), (2,3), (3,2), (4,1)$ 四种可能
- 其他格子概率都为0

---

**第3步：求 $p_{ij}$** ✍️

**目的**：计算每个可能组合的概率

**方法**：
- **古典概型**：$p_{ij} = \frac{\text{有利样本点数}}{\text{总样本点数}}$
- **独立性**：若 $X$ 和 $Y$ 独立，则 $p_{ij} = P(X=x_i)P(Y=y_j)$
- **条件概率**：$p_{ij} = P(X=x_i)P(Y=y_j|X=x_i)$

**技巧**：
- 利用对称性简化计算
- 注意有序vs无序

---

**第4步：验算 $\sum = 1$** ✓

**目的**：验证计算的正确性

**操作**：
- 计算所有 $p_{ij}$ 的和
- 检查是否等于1

**如果不等于1**：
- 检查是否有遗漏的组合
- 检查概率计算是否正确
- 检查归一化常数是否正确

---

### 三、边缘分布律

**定义**：从联合分布律中分别求出 $X$ 和 $Y$ 各自的分布律

**$X$ 的边缘分布律**：
$$P(X = x_i) = \sum_{j} P(X = x_i, Y = y_j) = \sum_{j} p_{ij} \triangleq p_{i\cdot}$$

**$Y$ 的边缘分布律**：
$$P(Y = y_j) = \sum_{i} P(X = x_i, Y = y_j) = \sum_{i} p_{ij} \triangleq p_{\cdot j}$$

**记忆技巧**：
- $p_{i\cdot}$：第 $i$ 行的和（固定 $X$，对 $Y$ 求和）
- $p_{\cdot j}$：第 $j$ 列的和（固定 $Y$，对 $X$ 求和）

---

### 四、条件分布律 ⭐⭐

**定义**：在已知 $Y = y_j$ 的条件下，$X$ 的条件分布律为：
$$P(X = x_i | Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)} = \frac{p_{ij}}{p_{\cdot j}}, \quad p_{\cdot j} > 0$$

同理，在已知 $X = x_i$ 的条件下，$Y$ 的条件分布律为：
$$P(Y = y_j | X = x_i) = \frac{P(X = x_i, Y = y_j)}{P(X = x_i)} = \frac{p_{ij}}{p_{i\cdot}}, \quad p_{i\cdot} > 0$$

---

### 五、联合、边缘、条件的关系 ⭐⭐⭐重要结论

**关键结论**：

1. **联合 $\Rightarrow$ 条件（可以）**
   $$P(X = x_i | Y = y_j) = \frac{p_{ij}}{p_{\cdot j}}$$

2. **条件 $\Rightarrow$ 联合（不可以）**
   - 仅知道条件分布，无法唯一确定联合分布
   - 原因：缺少边缘分布的信息

3. **边缘 + 条件 $\Rightarrow$ 联合（可以）** ⭐⭐⭐
   $$p_{ij} = P(X = x_i, Y = y_j) = P(X = x_i) P(Y = y_j | X = x_i) = p_{i\cdot} \cdot P(Y = y_j | X = x_i)$$
   
   或：
   $$p_{ij} = P(Y = y_j) P(X = x_i | Y = y_j) = p_{\cdot j} \cdot P(X = x_i | Y = y_j)$$

**记忆口诀**：
> "联合能推条件，条件推不出联合"
> 
> "边缘加条件，可以推联合"

---

### 六、典型例题

**例题1**（完整演示四步法）：

从装有3个红球、2个白球的袋中无放回地抽取2个球，设 $X$ = 第1次抽到红球的个数（0或1），$Y$ = 第2次抽到红球的个数（0或1）。求 $(X, Y)$ 的联合分布律、边缘分布律和条件分布律。

**解**：

**第1步：确立表格维度**
- $X$ 的可能取值：0, 1
- $Y$ 的可能取值：0, 1
- 表格维度：$2 \times 2$

**第2步：利用约束化简**
- 无放回抽取，所有组合都可能
- 没有特殊约束，4个格子都需要计算

**第3步：求 $p_{ij}$**

总样本空间：从5个球中无放回抽2个，考虑顺序
- 总样本点数：$5 \times 4 = 20$

**(1) $P(X=0, Y=0)$**：两次都抽到白球
- 第1次抽白球：2种选择
- 第2次抽白球：剩1个白球，1种选择
- $p_{00} = \frac{2 \times 1}{20} = \frac{2}{20} = 0.1$

**(2) $P(X=0, Y=1)$**：第1次白球，第2次红球
- 第1次抽白球：2种选择
- 第2次抽红球：3种选择
- $p_{01} = \frac{2 \times 3}{20} = \frac{6}{20} = 0.3$

**(3) $P(X=1, Y=0)$**：第1次红球，第2次白球
- 第1次抽红球：3种选择
- 第2次抽白球：2种选择
- $p_{10} = \frac{3 \times 2}{20} = \frac{6}{20} = 0.3$

**(4) $P(X=1, Y=1)$**：两次都抽到红球
- 第1次抽红球：3种选择
- 第2次抽红球：剩2个红球，2种选择
- $p_{11} = \frac{3 \times 2}{20} = \frac{6}{20} = 0.3$

**第4步：验算 $\sum = 1$**
$$0.1 + 0.3 + 0.3 + 0.3 = 1.0$$ ✓

**联合分布律表格**：

| $X \setminus Y$ | 0 | 1 |
|----------------|---|---|
| 0 | 0.1 | 0.3 |
| 1 | 0.3 | 0.3 |

---

**求边缘分布律**：

**$X$ 的边缘分布律**（行和）：
- $P(X = 0) = 0.1 + 0.3 = 0.4$
- $P(X = 1) = 0.3 + 0.3 = 0.6$

| $X$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

**$Y$ 的边缘分布律**（列和）：
- $P(Y = 0) = 0.1 + 0.3 = 0.4$
- $P(Y = 1) = 0.3 + 0.3 = 0.6$

| $Y$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

---

**求条件分布律**：

**1. 在 $Y = 0$ 的条件下，$X$ 的条件分布律**：
- $P(Y = 0) = 0.4$
- $P(X = 0 | Y = 0) = \frac{p_{00}}{p_{\cdot 0}} = \frac{0.1}{0.4} = 0.25$
- $P(X = 1 | Y = 0) = \frac{p_{10}}{p_{\cdot 0}} = \frac{0.3}{0.4} = 0.75$

| $X | Y=0$ | 0 | 1 |
|-----------|-----|---|
| $P$ | 0.25 | 0.75 |

**2. 在 $X = 0$ 的条件下，$Y$ 的条件分布律**：
- $P(X = 0) = 0.4$
- $P(Y = 0 | X = 0) = \frac{p_{00}}{p_{0\cdot}} = \frac{0.1}{0.4} = 0.25$
- $P(Y = 1 | X = 0) = \frac{p_{01}}{p_{0\cdot}} = \frac{0.3}{0.4} = 0.75$

| $Y | X=0$ | 0 | 1 |
|-----------|-----|---|
| $P$ | 0.25 | 0.75 |

---

**验证"边缘+条件→联合"**：

已知：
- $P(X = 0) = 0.4$
- $P(Y = 0 | X = 0) = 0.25$

求 $P(X = 0, Y = 0)$：
$$P(X = 0, Y = 0) = P(X = 0) P(Y = 0 | X = 0) = 0.4 \times 0.25 = 0.1$$ ✓

与直接计算的 $p_{00} = 0.1$ 一致！

---

**例题2**（利用独立性简化）：

设 $X$ 和 $Y$ 相互独立，且

| $X$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

| $Y$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.3 | 0.7 |

求 $(X, Y)$ 的联合分布律。

**解**：

因为 $X$ 和 $Y$ 独立，所以：
$$p_{ij} = P(X = x_i) P(Y = y_j)$$

计算各值：
- $p_{00} = 0.4 \times 0.3 = 0.12$
- $p_{01} = 0.4 \times 0.7 = 0.28$
- $p_{10} = 0.6 \times 0.3 = 0.18$
- $p_{11} = 0.6 \times 0.7 = 0.42$

**联合分布律表格**：

| $X \setminus Y$ | 0 | 1 |
|----------------|-----|-----|
| 0 | 0.12 | 0.28 |
| 1 | 0.18 | 0.42 |

**验算**：$0.12 + 0.28 + 0.18 + 0.42 = 1.0$ ✓

### 七、解题技巧总结

**1. 四步法的灵活运用**

| 步骤 | 操作要点 | 注意事项 |
|------|---------|----------|
| **确立维度** | 找出所有可能取值 | 不要遗漏 |
| **约束化简** | 排除不可能组合 | 减少计算量 |
| **求Pij** | 古典概型/独立性/条件概率 | 注意有序vs无序 |
| **验算Σ=1** | 检查归一性 | 发现错误及时修正 |

---

**2. 联合、边缘、条件的转换关系**

```
联合分布律
    ↓ (求和)
边缘分布律
    ↑ (相乘)
边缘 + 条件 → 联合
```

**公式总结**：
- 联合 → 边缘：$p_{i\cdot} = \sum_j p_{ij}$
- 联合 → 条件：$P(X=x_i|Y=y_j) = \frac{p_{ij}}{p_{\cdot j}}$
- 边缘 + 条件 → 联合：$p_{ij} = p_{i\cdot} \cdot P(Y=y_j|X=x_i)$

---

**3. 常见错误警示**

**⚠️ 错误1**：忘记验算 $\sum = 1$
- 必须最后检查归一性
- 发现不等于1时，回头检查计算

**⚠️ 错误2**：混淆有序和无序
- 无放回抽样要考虑顺序
- 有放回抽样也要考虑顺序

**⚠️ 错误3**：条件分布的分母错误
- $P(X|Y)$ 的分母是 $P(Y)$
- $P(Y|X)$ 的分母是 $P(X)$

**⚠️ 错误4**：误认为条件可以推出联合
- 仅知道条件分布，无法确定联合分布
- 必须同时知道边缘分布

## 1.5 二维连续型随机变量

| $X \setminus Y$ | $y_1$ | $y_2$ | $\cdots$ | $y_j$ | $\cdots$ |
|----------------|-------|-------|---------|-------|---------|
| $x_1$ | $p_{11}$ | $p_{12}$ | $\cdots$ | $p_{1j}$ | $\cdots$ |
| $x_2$ | $p_{21}$ | $p_{22}$ | $\cdots$ | $p_{2j}$ | $\cdots$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ | $\ddots$ |
| $x_i$ | $p_{i1}$ | $p_{i2}$ | $\cdots$ | $p_{ij}$ | $\cdots$ |
| $\vdots$ | $\vdots$ | $\vdots$ | $\ddots$ | $\vdots$ | $\ddots$ |

---

### 二、边缘分布律 ⭐⭐

**定义**：从联合分布律中分别求出 $X$ 和 $Y$ 各自的分布律

**$X$ 的边缘分布律**：
$$P(X = x_i) = \sum_{j} P(X = x_i, Y = y_j) = \sum_{j} p_{ij} \triangleq p_{i\cdot}$$

**$Y$ 的边缘分布律**：
$$P(Y = y_j) = \sum_{i} P(X = x_i, Y = y_j) = \sum_{i} p_{ij} \triangleq p_{\cdot j}$$

**记忆技巧**：
- $p_{i\cdot}$：第 $i$ 行的和（固定 $X$，对 $Y$ 求和）
- $p_{\cdot j}$：第 $j$ 列的和（固定 $Y$，对 $X$ 求和）

---

#### 典型例题

**例题1**：设二维离散型随机变量 $(X, Y)$ 的联合分布律为

| $X \setminus Y$ | 0 | 1 | 2 |
|----------------|---|---|---|
| 0 | 0.1 | 0.2 | 0.1 |
| 1 | 0.2 | 0.3 | 0.1 |

求：
1. $X$ 的边缘分布律
2. $Y$ 的边缘分布律
3. $P(X + Y \leq 1)$

**解**：

**1. $X$ 的边缘分布律**：
- $P(X = 0) = 0.1 + 0.2 + 0.1 = 0.4$
- $P(X = 1) = 0.2 + 0.3 + 0.1 = 0.6$

| $X$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

**2. $Y$ 的边缘分布律**：
- $P(Y = 0) = 0.1 + 0.2 = 0.3$
- $P(Y = 1) = 0.2 + 0.3 = 0.5$
- $P(Y = 2) = 0.1 + 0.1 = 0.2$

| $Y$ | 0 | 1 | 2 |
|-----|---|---|---|
| $P$ | 0.3 | 0.5 | 0.2 |

**验证**：$0.3 + 0.5 + 0.2 = 1$ ✓

**3. $P(X + Y \leq 1)$**：
- 满足条件的点：$(0,0), (0,1), (1,0)$
- $P(X + Y \leq 1) = p_{00} + p_{01} + p_{10} = 0.1 + 0.2 + 0.2 = 0.5$

**答案**：1. 见上表；2. 见上表；3. 0.5

### 三、条件分布律 ⭐⭐

**定义**：在已知 $Y = y_j$ 的条件下，$X$ 的条件分布律为：
$$P(X = x_i | Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)} = \frac{p_{ij}}{p_{\cdot j}}, \quad p_{\cdot j} > 0$$

同理，在已知 $X = x_i$ 的条件下，$Y$ 的条件分布律为：
$$P(Y = y_j | X = x_i) = \frac{P(X = x_i, Y = y_j)}{P(X = x_i)} = \frac{p_{ij}}{p_{i\cdot}}, \quad p_{i\cdot} > 0$$

**理解**：
- 条件分布律是在缩小样本空间后的分布
- 类似于条件概率的概念

#### 典型例题

**例题2**：接例题1，求：

- $P(X = 1 | Y = 1) = \frac{p_{11}}{p_{\cdot 1}} = \frac{0.3}{0.5} = 0.6$

| $X | Y=1$ | 0 | 1 |
|-----------|---|---|
| $P$ | 0.4 | 0.6 |

**2. 在 $X = 0$ 的条件下，$Y$ 的条件分布律**：
- $P(X = 0) = 0.4$
- $P(Y = 0 | X = 0) = \frac{p_{00}}{p_{0\cdot}} = \frac{0.1}{0.4} = 0.25$
- $P(Y = 1 | X = 0) = \frac{p_{01}}{p_{0\cdot}} = \frac{0.2}{0.4} = 0.5$

## 1.5 二维连续型随机变量 ⭐⭐⭐

### 一、联合概率密度 ⭐⭐⭐

**定义**：如果存在非负函数 $f(x, y)$，使得对于任意实数 $x, y$，有：
$$F(x, y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u, v) \, du \, dv$$

则称 $(X, Y)$ 为**二维连续型随机变量**，$f(x, y)$ 称为 $(X, Y)$ 的**联合概率密度函数**。

---

#### 联合概率密度的性质 ⭐⭐⭐

**性质1：非负性**
$$f(x, y) \geq 0, \quad -\infty < x < +\infty, -\infty < y < +\infty$$

**性质2：归一性**
$$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$$

**几何意义**：概率密度曲面下方的总体积为1

---

**性质3：概率计算**

对于平面区域 $D$，$(X, Y)$ 落在 $D$ 内的概率为：
$$P((X, Y) \in D) = \iint_{D} f(x, y) \, dx \, dy$$

**特例**（矩形区域）：
$$P(a < X \leq b, c < Y \leq d) = \int_{a}^{b} \int_{c}^{d} f(x, y) \, dy \, dx$$

---

**性质4：与分布函数的关系**

若 $f(x, y)$ 在点 $(x, y)$ 处连续，则：
$$f(x, y) = \frac{\partial^2 F(x, y)}{\partial x \partial y}$$

**理解**：
- 分布函数求偏导得到概率密度
- 概率密度积分得到分布函数

---

**性质5：边缘分布函数**

从联合概率密度可以得到边缘概率密度：
- $X$ 的边缘概率密度：$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$
- $Y$ 的边缘概率密度：$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$

---

### 二、边缘概率密度 ⭐⭐

**定义**：从联合概率密度中分别求出 $X$ 和 $Y$ 各自的概率密度

**$X$ 的边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$

**$Y$ 的边缘概率密度**：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

**记忆技巧**：
- $f_X(x)$：对 $y$ 积分（消去 $y$）
- $f_Y(y)$：对 $x$ 积分（消去 $x$）
- "想要谁，就积分掉另一个"

---

**重要注意**：
> 积分时需要注意 $f(x, y)$ 的非零区域（定义域）
> 
> 必须先确定积分上下限，不能直接写 $-\infty$ 到 $+\infty$

---

#### 典型例题

**例题1**：设二维随机变量 $(X, Y)$ 的联合概率密度为
$$f(x, y) = \begin{cases} 6xy, & 0 < x < 1, 0 < y < 1 - x \\ 0, & \text{其他} \end{cases}$$

求：
1. $X$ 的边缘概率密度 $f_X(x)$
2. $Y$ 的边缘概率密度 $f_Y(y)$

**解**：

**1. 求 $f_X(x)$**：

首先确定积分区域：$0 < x < 1$，$0 < y < 1 - x$

当 $0 < x < 1$ 时：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{0}^{1-x} 6xy \, dy$$
$$= 6x \left[\frac{y^2}{2}\right]_{0}^{1-x} = 3x(1-x)^2$$

所以：
$$f_X(x) = \begin{cases} 3x(1-x)^2, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$

**2. 求 $f_Y(y)$**：

首先确定积分区域：$0 < y < 1$，由 $y < 1 - x$ 得 $x < 1 - y$，且 $x > 0$

当 $0 < y < 1$ 时：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx = \int_{0}^{1-y} 6xy \, dx$$
$$= 6y \left[\frac{x^2}{2}\right]_{0}^{1-y} = 3y(1-y)^2$$

所以：
$$f_Y(y) = \begin{cases} 3y(1-y)^2, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**答案**：$f_X(x) = 3x(1-x)^2$，$0 < x < 1$；$f_Y(y) = 3y(1-y)^2$，$0 < y < 1$

---

### 三、条件概率密度 ⭐⭐⭐非常重要

**定义**：

在已知 $Y = y$ 的条件下，$X$ 的**条件概率密度**为：
$$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}, \quad \textbf{其中 } f_Y(y) > 0$$

同理，在已知 $X = x$ 的条件下，$Y$ 的**条件概率密度**为：
$$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)}, \quad \textbf{其中 } f_X(x) > 0$$

---

#### ⚠️ 重要声明：分母不为0

**必须首先声明**：
> **条件概率密度的定义要求分母不为0！**
> 
> - $f_{X|Y}(x|y)$ 仅在 $f_Y(y) > 0$ 时有定义
> - $f_{Y|X}(y|x)$ 仅在 $f_X(x) > 0$ 时有定义
> 
> **如果边缘概率密度为0，则条件概率密度无定义！**

**原因**：
- 条件概率的本质是在缩小样本空间后的概率
- 如果 $f_Y(y) = 0$，说明事件 $\{Y = y\}$ 的概率为0
- 在概率为0的事件上无法定义条件概率

---

#### 条件概率密度的性质 ⭐⭐⭐

**性质1：非负性**
$$f_{X|Y}(x|y) \geq 0, \quad \text{当 } f_Y(y) > 0$$

**性质2：归一性**
$$\int_{-\infty}^{+\infty} f_{X|Y}(x|y) \, dx = 1, \quad \text{当 } f_Y(y) > 0$$

**证明**：
$$\int_{-\infty}^{+\infty} f_{X|Y}(x|y) \, dx = \int_{-\infty}^{+\infty} \frac{f(x, y)}{f_Y(y)} \, dx = \frac{1}{f_Y(y)} \int_{-\infty}^{+\infty} f(x, y) \, dx = \frac{f_Y(y)}{f_Y(y)} = 1$$

**理解**：
> 条件概率密度也是概率密度，满足概率密度的所有性质！
> 
> 它描述了在已知 $Y=y$ 的条件下，$X$ 的分布情况

---

**性质3：条件概率的计算**

对于区间 $(a, b]$，有：
$$P(a < X \leq b | Y = y) = \int_{a}^{b} f_{X|Y}(x|y) \, dx$$

---

**性质4：联合、边缘、条件的关系**

$$f(x, y) = f_X(x) f_{Y|X}(y|x) = f_Y(y) f_{X|Y}(x|y)$$

**理解**：
> 这与离散型的公式完全类似！
> 
> 联合 = 边缘 × 条件

---

#### 条件概率密度的重要性 ⭐⭐⭐⭐

**为什么条件概率密度非常重要？**

1. **理论意义**：
   - 是研究随机变量之间依赖关系的核心工具
   - 揭示了在已知一个变量条件下，另一个变量的分布规律

2. **实际应用**：
   - **回归分析**：$E(X|Y=y)$ 是回归函数的基础
   - **贝叶斯统计**：后验分布本质上是条件分布
   - **信号处理**：噪声条件下的信号估计
   - **金融风控**：已知某些指标下的风险评估

3. **考研重点**：
   - 几乎每年必考条件概率密度的计算
   - 常与独立性、期望等结合考查
   - 大题中经常作为关键步骤

4. **解题关键**：
   - 很多复杂问题需要通过条件分布简化
   - 全概率公式和贝叶斯公式的连续型版本都依赖条件密度

---

#### 典型例题

**例题2**：接例题1，求在 $Y = y$ 的条件下，$X$ 的条件概率密度 $f_{X|Y}(x|y)$。

**解**：

**第一步：声明分母不为0**

由例题1知：
- $f_Y(y) = 3y(1-y)^2$，$0 < y < 1$
- **当 $0 < y < 1$ 时，$f_Y(y) > 0$** ✓
- 因此条件概率密度有定义

**第二步：写出联合概率密度和边缘概率密度**

- $f(x, y) = 6xy$，$0 < x < 1 - y$，$0 < y < 1$
- $f_Y(y) = 3y(1-y)^2$，$0 < y < 1$

**第三步：代入公式**

当 $0 < y < 1$ 时：
$$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)} = \frac{6xy}{3y(1-y)^2} = \frac{2x}{(1-y)^2}$$

注意 $x$ 的范围：$0 < x < 1 - y$

**第四步：写出完整表达式**

$$f_{X|Y}(x|y) = \begin{cases} \frac{2x}{(1-y)^2}, & 0 < x < 1 - y \\ 0, & \text{其他} \end{cases}$$

**第五步：验证归一性**

$$\int_{0}^{1-y} \frac{2x}{(1-y)^2} \, dx = \frac{2}{(1-y)^2} \left[\frac{x^2}{2}\right]_{0}^{1-y} = \frac{(1-y)^2}{(1-y)^2} = 1$$ ✓

**答案**：$f_{X|Y}(x|y) = \frac{2x}{(1-y)^2}$，$0 < x < 1 - y$

---

**例题3**（综合应用）：设 $(X, Y)$ 的联合概率密度为
$$f(x, y) = \begin{cases} e^{-y}, & 0 < x < y < +\infty \\ 0, & \text{其他} \end{cases}$$

求：
1. $X$ 和 $Y$ 的边缘概率密度
2. 条件概率密度 $f_{Y|X}(y|x)$
3. $P(Y > 2 | X = 1)$

**解**：

**1. 求边缘概率密度**

**(1) $X$ 的边缘概率密度**：

首先确定积分区域：$0 < x < y < +\infty$ ⟹ 固定 $x$，$y$ 从 $x$ 到 $+\infty$

当 $x > 0$ 时：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{x}^{+\infty} e^{-y} \, dy$$
$$= \left[-e^{-y}\right]_{x}^{+\infty} = 0 - (-e^{-x}) = e^{-x}$$

所以：
$$f_X(x) = \begin{cases} e^{-x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

即 $X \sim E(1)$（参数为1的指数分布）

**(2) $Y$ 的边缘概率密度**：

首先确定积分区域：$0 < x < y$ ⟹ 固定 $y$，$x$ 从 $0$ 到 $y$

当 $y > 0$ 时：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx = \int_{0}^{y} e^{-y} \, dx$$
$$= e^{-y} \cdot [x]_{0}^{y} = ye^{-y}$$

所以：
$$f_Y(y) = \begin{cases} ye^{-y}, & y > 0 \\ 0, & y \leq 0 \end{cases}$$

---

**2. 求条件概率密度 $f_{Y|X}(y|x)$**

**第一步：声明分母不为0**

- $f_X(x) = e^{-x}$，当 $x > 0$ 时，$f_X(x) > 0$ ✓
- 因此当 $x > 0$ 时，条件概率密度有定义

**第二步：代入公式**

当 $x > 0$ 时：
$$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)} = \frac{e^{-y}}{e^{-x}} = e^{-(y-x)}, \quad y > x$$

**完整表达式**：
$$f_{Y|X}(y|x) = \begin{cases} e^{-(y-x)}, & y > x \\ 0, & \text{其他} \end{cases}$$

**理解**：在已知 $X=x$ 的条件下，$Y-x$ 服从参数为1的指数分布

---

**3. 求 $P(Y > 2 | X = 1)$**

利用条件概率密度：
$$P(Y > 2 | X = 1) = \int_{2}^{+\infty} f_{Y|X}(y|1) \, dy$$

当 $x = 1$ 时：
$$f_{Y|X}(y|1) = e^{-(y-1)}, \quad y > 1$$

所以：
$$P(Y > 2 | X = 1) = \int_{2}^{+\infty} e^{-(y-1)} \, dy = \int_{2}^{+\infty} e^{1-y} \, dy$$
$$= \left[-e^{1-y}\right]_{2}^{+\infty} = 0 - (-e^{1-2}) = e^{-1} \approx 0.3679$$

**答案**：$P(Y > 2 | X = 1) = e^{-1}$

---

### 四、解题技巧总结

**1. 求边缘概率密度的步骤**

```
第1步：确定积分区域（画图辅助）
第2步：确定积分上下限
第3步：计算定积分
第4步：写出分段表达式
```

**关键点**：
- 必须考虑 $f(x, y)$ 的非零区域
- 积分限不是固定的 $-\infty$ 到 $+\infty$
- 最后要写出完整的分段函数

---

**2. 求条件概率密度的步骤**

```
第1步：⚠️ 声明分母不为0（f_Y(y) > 0 或 f_X(x) > 0）
第2步：写出联合概率密度和边缘概率密度
第3步：代入公式 f_{X|Y} = f / f_Y
第4步：化简并确定取值范围
第5步：验证归一性（可选，但推荐）
```

**⚠️ 易错点**：
- 忘记声明分母不为0
- 忘记确定条件密度的取值范围
- 化简时出错

---

**3. 常见错误警示**

**⚠️ 错误1**：忽略定义域的限制
- 积分时必须考虑 $f(x, y)$ 的非零区域
- 不能盲目地从 $-\infty$ 积分到 $+\infty$

**⚠️ 错误2**：忘记声明分母不为0
- 条件概率密度仅在边缘密度大于0时有定义
- 必须在解答中明确声明

**⚠️ 错误3**：混淆条件概率密度的变量
- $f_{X|Y}(x|y)$ 是关于 $x$ 的函数，$y$ 是参数
- $f_{Y|X}(y|x)$ 是关于 $y$ 的函数，$x$ 是参数

**⚠️ 错误4**：验证归一性时积分范围错误
- 条件密度的积分范围可能与联合密度不同
- 要根据具体条件确定

## 2.1 二维随机变量独立性的定义 ⭐⭐⭐

### 一、独立性的定义

**定义**：二维随机变量 $(X, Y)$ 的两个分量 $X$ 和 $Y$ **相互独立**，如果对于任意实数 $x, y$，有：
$$F(x, y) = F_X(x) F_Y(y)$$

其中：
- $F(x, y)$ 是联合分布函数
- $F_X(x)$ 是 $X$ 的边缘分布函数
- $F_Y(y)$ 是 $Y$ 的边缘分布函数

**核心理解**：
> 独立性意味着 $X$ 和 $Y$ 之间**没有任何依赖关系**
> 
> 知道 $X$ 的取值不会提供关于 $Y$ 的任何信息，反之亦然

---

### 二、等价表述

独立性可以用不同的方式表述，它们是等价的：

#### 1. 用分布函数表述（定义）
$$F(x, y) = F_X(x) F_Y(y), \quad \forall x, y$$

#### 2. 离散型：用分布律表述
$$P(X = x_i, Y = y_j) = P(X = x_i) P(Y = y_j)$$
即：
$$p_{ij} = p_{i\cdot} p_{\cdot j}, \quad \forall i, j$$

#### 3. 连续型：用概率密度表述
$$f(x, y) = f_X(x) f_Y(y), \quad \forall x, y$$

**重要说明**：
> 这三种表述是完全等价的！
> 
> - 离散型通常用分布律判断
> - 连续型通常用概率密度判断
> - 理论上都可以用分布函数判断

---

## 2.2 二维离散型随机变量独立的充分必要条件 ⭐⭐⭐

### 一、充分必要条件

**定理**：二维离散型随机变量 $(X, Y)$ 相互独立的**充分必要条件**是：
$$p_{ij} = p_{i\cdot} p_{\cdot j}, \quad \forall i, j$$

即：**联合分布律 = 边缘分布律的乘积**

---

### 二、快速判断方法 ⭐⭐⭐核心技巧

**一般情况：不独立**

> **大多数情况下，两个随机变量是不独立的！**
> 
> 独立性是一个很强的条件，需要同时满足两个要求：

#### 要求1：矩形区域 ✅

**联合分布律的非零区域必须是矩形**

**举例**：
- ✓ 矩形区域：$X \in \{0,1,2\}$，$Y \in \{0,1\}$（所有组合都可能）
- ✗ 非矩形区域：$X + Y \leq 2$（三角形区域，某些组合不可能）

**直观理解**：
- 如果某些 $(x_i, y_j)$ 组合的概率为0，而其他组合不为0
- 则一定不独立

---

#### 要求2：可分离性 ✅

**联合分布律可以分解为两个函数的乘积**

即存在函数 $g(x_i)$ 和 $h(y_j)$，使得：
$$p_{ij} = g(x_i) \cdot h(y_j)$$

**检验方法**：
- 检查表格中每一行的比例是否相同
- 检查表格中每一列的比例是否相同

**举例**：

| $X \setminus Y$ | 0 | 1 |
|----------------|---|---|
| 0 | 0.2 | 0.3 |
| 1 | 0.4 | 0.6 |

- 第1行比例：$0.2 : 0.3 = 2 : 3$
- 第2行比例：$0.4 : 0.6 = 2 : 3$ ✓
- 第1列比例：$0.2 : 0.4 = 1 : 2$
- 第2列比例：$0.3 : 0.6 = 1 : 2$ ✓
- **结论**：可分离，可能独立

验证：
- $p_{0\cdot} = 0.5$，$p_{\cdot 0} = 0.6$
- $p_{0\cdot} p_{\cdot 0} = 0.5 \times 0.6 = 0.3 \neq 0.2 = p_{00}$ ✗
- **最终结论**：不独立（虽然可分离，但乘积不对）

---

### 三、如果独立，边缘相乘等于联合 ⭐⭐⭐

**重要结论**：
> **若 $X$ 和 $Y$ 独立，则**：
> $$p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$$
> 
> **反之，若对所有 $i,j$ 都有 $p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$，则 $X$ 和 $Y$ 独立**

**应用**：
1. **已知边缘分布，求联合分布**（当独立时）
   $$p_{ij} = P(X=x_i) \cdot P(Y=y_j)$$

2. **判断独立性**
   - 计算所有 $p_{i\cdot} \cdot p_{\cdot j}$
   - 与 $p_{ij}$ 比较
   - 若全部相等，则独立；否则不独立

---

### 四、典型例题

**例题1**（判断独立性）：设 $(X, Y)$ 的联合分布律为

| $X \setminus Y$ | 0 | 1 |
|----------------|---|---|
| 0 | 0.2 | 0.3 |
| 1 | 0.3 | 0.2 |

判断 $X$ 和 $Y$ 是否独立。

**解**：

**第1步：检查是否为矩形区域**
- 所有4个格子都有非零概率 ✓
- 是矩形区域

**第2步：求边缘分布律**
- $P(X=0) = 0.2 + 0.3 = 0.5$
- $P(X=1) = 0.3 + 0.2 = 0.5$
- $P(Y=0) = 0.2 + 0.3 = 0.5$
- $P(Y=1) = 0.3 + 0.2 = 0.5$

**第3步：验证 $p_{ij} = p_{i\cdot} p_{\cdot j}$**
- $p_{00} = 0.2$，但 $p_{0\cdot} p_{\cdot 0} = 0.5 \times 0.5 = 0.25$
- $0.2 \neq 0.25$ ✗

**结论**：$X$ 和 $Y$ **不独立**

---

**例题2**（利用独立性求联合分布）：

设 $X$ 和 $Y$ 相互独立，且

| $X$ | 0 | 1 | 2 |
|-----|---|---|---|
| $P$ | 0.2 | 0.5 | 0.3 |

| $Y$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.4 | 0.6 |

求 $(X, Y)$ 的联合分布律。

**解**：

因为 $X$ 和 $Y$ 独立，所以：
$$p_{ij} = P(X=x_i) P(Y=y_j)$$

计算各值：
- $p_{00} = 0.2 \times 0.4 = 0.08$
- $p_{01} = 0.2 \times 0.6 = 0.12$
- $p_{10} = 0.5 \times 0.4 = 0.20$
- $p_{11} = 0.5 \times 0.6 = 0.30$
- $p_{20} = 0.3 \times 0.4 = 0.12$
- $p_{21} = 0.3 \times 0.6 = 0.18$

**联合分布律表格**：

| $X \setminus Y$ | 0 | 1 |
|----------------|-----|-----|
| 0 | 0.08 | 0.12 |
| 1 | 0.20 | 0.30 |
| 2 | 0.12 | 0.18 |

**验算**：$0.08+0.12+0.20+0.30+0.12+0.18 = 1.0$ ✓

---

**例题3**（快速排除法）：

设 $(X, Y)$ 的联合分布律为

| $X \setminus Y$ | 0 | 1 | 2 |
|----------------|---|---|---|
| 0 | 0.1 | 0.2 | 0 |
| 1 | 0.2 | 0.3 | 0.2 |

判断 $X$ 和 $Y$ 是否独立。

**解**：

**快速判断**：
- 观察表格：$p_{02} = 0$，但 $p_{0\cdot} = 0.3 > 0$，$p_{\cdot 2} = 0.2 > 0$
- 若独立，应有 $p_{02} = p_{0\cdot} p_{\cdot 2} = 0.3 \times 0.2 = 0.06 \neq 0$ ✗
- **结论**：$X$ 和 $Y$ **不独立**

**或者用矩形区域判断**：
- $p_{02} = 0$，其他格子非零
- 不是矩形区域 ✗
- **结论**：不独立

**技巧**：看到有0的格子，立即判断不独立（除非整行或整列为0）

## 2.3 二维连续型随机变量独立的充分必要条件

### 一、充分必要条件

**定理**：二维连续型随机变量 $(X, Y)$ 相互独立的**充分必要条件**是：
$$f(x, y) = f_X(x) f_Y(y), \quad \forall x, y$$

即：**联合概率密度 = 边缘概率密度的乘积**

---

### 二、快速判断方法

#### 要求1：矩形区域 ✅

**联合概率密度的非零区域必须是矩形**

**举例**：
- ✓ 矩形区域：$0 < x < 1$，$0 < y < 1$
- ✗ 非矩形区域：$0 < x < 1$，$0 < y < 1-x$（三角形）
- ✗ 非矩形区域：$x^2 + y^2 < 1$（圆形）

**重要结论**：
> **如果定义域不是矩形区域，则一定不独立！**
> 
> 这是最快 的判断方法，无需计算

---

#### 要求2：可分离性 ✅

**联合概率密度可以分解为两个函数的乘积**

即存在函数 $g(x)$ 和 $h(y)$，使得：
$$f(x, y) = g(x) \cdot h(y)$$

**检验方法**：
- 看能否将 $f(x, y)$ 写成只含 $x$ 的函数乘以只含 $y$ 的函数
- 例如：$f(x,y) = 4xy = (2x) \cdot (2y)$ ✓ 可分离
- 例如：$f(x,y) = x + y$ ✗ 不可分离

---

### 三、典型例题

**例题1**：判断下列二维随机变量是否独立

**(1)** $f(x, y) = \begin{cases} 4xy, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$

**(2)** $f(x, y) = \begin{cases} 6xy, & 0 < x < 1, 0 < y < 1 - x \\ 0, & \text{其他} \end{cases}$

**(3)** $f(x, y) = \begin{cases} e^{-(x+y)}, & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$

**解**：

**(1)** 
- 定义域：$0 < x < 1$，$0 < y < 1$（矩形区域）✓
- 可分离性：$4xy = (2x) \cdot (2y)$ ✓
- **结论**：$X$ 和 $Y$ **独立**

**(2)**
- 定义域：$0 < x < 1$，$0 < y < 1-x$（三角形区域）✗
- **结论**：$X$ 和 $Y$ **不独立**（无需进一步验证）

**(3)**
- 定义域：$x > 0$，$y > 0$（矩形区域，第一象限）✓
- 可分离性：$e^{-(x+y)} = e^{-x} \cdot e^{-y}$ ✓
- **结论**：$X$ 和 $Y$ **独立**

## 2.4 二维随机变量独立的性质 ⭐⭐⭐

### 一、基本性质

**性质1：独立 ⟹ 不相关**

若 $X$ 和 $Y$ 独立，则：
$$E(XY) = E(X)E(Y)$$
$$Cov(X, Y) = 0$$
$$\rho_{XY} = 0$$

**注意**：
> **逆命题不成立！**
> 
> 不相关不一定独立
> 
> 独立是比不相关更强的条件

---

**性质2：方差的加法公式**

若 $X$ 和 $Y$ 独立，则：
$$D(X + Y) = D(X) + D(Y)$$
$$D(X - Y) = D(X) + D(Y)$$

**推广**：若 $X_1, X_2, ..., X_n$ 相互独立，则：
$$D\left(\sum_{i=1}^{n} X_i\right) = \sum_{i=1}^{n} D(X_i)$$

---

**性质3：函数的独立性**

若 $X$ 和 $Y$ 独立，则对于任意函数 $g$ 和 $h$，$g(X)$ 和 $h(Y)$ 也相互独立。

**举例**：
- 若 $X$ 和 $Y$ 独立，则 $X^2$ 和 $Y^2$ 独立
- 若 $X$ 和 $Y$ 独立，则 $e^X$ 和 $\ln Y$ 独立
- 若 $X$ 和 $Y$ 独立，则 $\sin X$ 和 $\cos Y$ 独立

---

**性质4：正态分布的独立性**

若 $(X, Y)$ 服从二维正态分布，则：
$$X \text{ 和 } Y \text{ 独立} \iff \rho_{XY} = 0$$

**重要说明**：
> 对于一般的随机变量，不相关不一定独立
> 
> 但对于**二维正态分布**，不相关等价于独立！
> 
> 这是正态分布的特殊性质

---

**性质5：独立随机变量和的分布**

若 $X$ 和 $Y$ 独立，则：

**离散型**：
$$P(X + Y = z) = \sum_{i} P(X = x_i) P(Y = z - x_i)$$

**连续型**（卷积公式）：
$$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \, dx$$

---

**性质6：独立同分布的性质**

若 $X_1, X_2, ..., X_n$ 独立同分布（i.i.d.），且 $E(X_i) = \mu$，$D(X_i) = \sigma^2$，则：

- 样本均值：$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$
  - $E(\bar{X}) = \mu$
  - $D(\bar{X}) = \frac{\sigma^2}{n}$

- 样本和：$S_n = \sum_{i=1}^{n} X_i$
  - $E(S_n) = n\mu$
  - $D(S_n) = n\sigma^2$

---

### 二、典型例题

**例题1**（方差计算）：设 $X$ 和 $Y$ 独立，且 $D(X) = 4$，$D(Y) = 9$，求 $D(2X - 3Y + 5)$。

**解**：

利用方差的性质：
$$D(aX + bY + c) = a^2 D(X) + b^2 D(Y)$$

所以：
$$D(2X - 3Y + 5) = 2^2 D(X) + (-3)^2 D(Y)$$
$$= 4 \times 4 + 9 \times 9 = 16 + 81 = 97$$

**答案**：97

**注意**：常数5对方差无影响

---

**例题2**（期望计算）：设 $X$ 和 $Y$ 独立，且 $E(X) = 2$，$E(Y) = 3$，求 $E(XY)$ 和 $E(X^2 Y)$。

**解**：

**1. 求 $E(XY)$**：

因为 $X$ 和 $Y$ 独立，所以：
$$E(XY) = E(X)E(Y) = 2 \times 3 = 6$$

**2. 求 $E(X^2 Y)$**：

因为 $X$ 和 $Y$ 独立，所以 $X^2$ 和 $Y$ 也独立：
$$E(X^2 Y) = E(X^2)E(Y)$$

但题目未给出 $E(X^2)$，无法直接计算。

若补充条件：$D(X) = 1$，则：
$$D(X) = E(X^2) - [E(X)]^2$$
$$1 = E(X^2) - 2^2$$
$$E(X^2) = 5$$

所以：
$$E(X^2 Y) = 5 \times 3 = 15$$

**答案**：$E(XY) = 6$；若 $D(X)=1$，则 $E(X^2 Y) = 15$

---

**例题3**（正态分布的独立性）：设 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，问 $X$ 和 $Y$ 何时独立？

**解**：

对于二维正态分布：
$$X \text{ 和 } Y \text{ 独立} \iff \rho = 0$$

**答案**：当相关系数 $\rho = 0$ 时，$X$ 和 $Y$ 独立

---

### 三、解题技巧总结

**1. 判断独立性的步骤**

```
第1步：检查定义域是否为矩形
      ├─ 不是矩形 → 一定不独立
      └─ 是矩形 → 继续第2步

第2步：检查是否可分离
      ├─ 不可分离 → 不独立
      └─ 可分离 → 继续第3步

第3步：验证 p_ij = p_i· × p_·j 或 f(x,y) = f_X(x) × f_Y(y)
      ├─ 全部相等 → 独立
      └─ 有一个不等 → 不独立
```

---

**2. 独立性 vs 不相关性**

| 对比项 | 独立性 | 不相关性 |
|--------|--------|----------|
| **定义** | $F(x,y)=F_X(x)F_Y(y)$ | $Cov(X,Y)=0$ |
| **强度** | 强条件 | 弱条件 |
| **关系** | 独立 ⟹ 不相关 | 不相关 ⇏ 独立 |
| **特例** | 二维正态：等价 | 二维正态：等价 |

---

**3. 常见错误警示**

**⚠️ 错误1**：认为不相关就是独立
- 一般情况下，不相关不一定独立
- 只有二维正态分布才等价

**⚠️ 错误2**：忽略定义域的检查
- 定义域不是矩形，一定不独立
- 这是最快的判断方法

**⚠️ 错误3**：混淆独立和不相关的条件
- 独立：$E(XY) = E(X)E(Y)$
- 不相关：$Cov(X,Y) = 0$，即 $E(XY) = E(X)E(Y)$
- 两者公式相同，但含义不同

**⚠️ 错误4**：忘记独立性的传递性
- 若 $X$ 和 $Y$ 独立，则 $g(X)$ 和 $h(Y)$ 也独立
- 这个性质经常用于简化计算

## 3.1 二维均匀分布 ⭐⭐

### 一、定义

**定义**：设 $D$ 是平面上的有界区域，其面积为 $A$。若二维随机变量 $(X, Y)$ 的联合概率密度为：
$$f(x, y) = \begin{cases} \frac{1}{A}, & (x, y) \in D \\ 0, & \text{其他} \end{cases}$$

则称 $(X, Y)$ 服从区域 $D$ 上的**二维均匀分布**。

**核心理解**：
> **密度等于面积的倒数！**
> 
> $$f(x, y) = \frac{1}{\text{面积}}$$
> 
> 在区域 $D$ 内，概率密度是常数；在区域外，概率密度为0

---

### 二、几何意义

对于区域 $D$ 内的任意子区域 $G$，$(X, Y)$ 落在 $G$ 内的概率为：
$$P((X, Y) \in G) = \iint_{G} f(x, y) \, dx \, dy = \frac{\text{Area}(G)}{\text{Area}(D)}$$

**理解**：
- 概率与面积成正比
- 类似于古典概型中的“等可能性”
- 在连续情形下，“点数”变成了“面积”

---

### 三、二维均匀分布的性质 ⭐⭐

#### 性质1：边缘分布不一定是均匀分布

**重要结论**：
> 即使 $(X, Y)$ 在区域 $D$ 上服从均匀分布，$X$ 和 $Y$ 的边缘分布**不一定**是均匀分布！
> 
> 边缘分布的形状取决于区域 $D$ 的形状

**举例**：
- 若 $D$ 是矩形：边缘分布是均匀分布 ✓
- 若 $D$ 是三角形：边缘分布不是均匀分布 ✗
- 若 $D$ 是圆形：边缘分布不是均匀分布 ✗

---

#### 性质2：独立性与区域形状有关

**结论**：
- 若 $D$ 是**矩形区域**（且边平行于坐标轴），则 $X$ 和 $Y$ **独立**
- 若 $D$ 是**非矩形区域**，则 $X$ 和 $Y$ **不独立**

**原因**：
- 矩形区域是可分离的：$D = [a,b] \times [c,d]$
- 非矩形区域不可分离，如三角形、圆形等

---

#### 性质3：期望的计算

若 $(X, Y) \sim U(D)$，则：
$$E(X) = \iint_{D} x \cdot \frac{1}{A} \, dx \, dy = \frac{1}{A} \iint_{D} x \, dx \, dy$$
$$E(Y) = \iint_{D} y \cdot \frac{1}{A} \, dx \, dy = \frac{1}{A} \iint_{D} y \, dx \, dy$$

**几何意义**：
- $E(X)$ 和 $E(Y)$ 是区域 $D$ 的**形心**（重心）坐标
- 对于对称区域，期望在对称中心

---

### 四、典型例题

**例题1**（矩形区域）：设 $(X, Y)$ 在矩形区域 $D = \{(x,y) | 0 < x < 2, 0 < y < 3\}$ 上服从均匀分布，求：
1. 联合概率密度 $f(x, y)$
2. 边缘概率密度 $f_X(x)$ 和 $f_Y(y)$
3. 判断 $X$ 和 $Y$ 是否独立

**解**：

**1. 求联合概率密度**：

区域 $D$ 的面积：$A = 2 \times 3 = 6$

所以：
$$f(x, y) = \begin{cases} \frac{1}{6}, & 0 < x < 2, 0 < y < 3 \\ 0, & \text{其他} \end{cases}$$

**2. 求边缘概率密度**：

**$X$ 的边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{0}^{3} \frac{1}{6} \, dy = \frac{1}{6} \cdot 3 = \frac{1}{2}, \quad 0 < x < 2$$

所以：
$$f_X(x) = \begin{cases} \frac{1}{2}, & 0 < x < 2 \\ 0, & \text{其他} \end{cases}$$

即 $X \sim U(0, 2)$

**$Y$ 的边缘概率密度**：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx = \int_{0}^{2} \frac{1}{6} \, dx = \frac{1}{6} \cdot 2 = \frac{1}{3}, \quad 0 < y < 3$$

所以：
$$f_Y(y) = \begin{cases} \frac{1}{3}, & 0 < y < 3 \\ 0, & \text{其他} \end{cases}$$

即 $Y \sim U(0, 3)$

**3. 判断独立性**：

验证：$f(x, y) = f_X(x) f_Y(y)$？

$$f_X(x) f_Y(y) = \frac{1}{2} \cdot \frac{1}{3} = \frac{1}{6} = f(x, y)$$ ✓

**结论**：$X$ 和 $Y$ **相互独立**

---

**例题2**（三角形区域）：设 $(X, Y)$ 在三角形区域 $D = \{(x,y) | 0 < x < 1, 0 < y < 1-x\}$ 上服从均匀分布，求：
1. 联合概率密度 $f(x, y)$
2. $X$ 的边缘概率密度 $f_X(x)$
3. 判断 $X$ 和 $Y$ 是否独立

**解**：

**1. 求联合概率密度**：

区域 $D$ 的面积：$A = \frac{1}{2} \times 1 \times 1 = \frac{1}{2}$

所以：
$$f(x, y) = \begin{cases} \frac{1}{1/2} = 2, & 0 < x < 1, 0 < y < 1-x \\ 0, & \text{其他} \end{cases}$$

**2. 求 $X$ 的边缘概率密度**：

当 $0 < x < 1$ 时：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{0}^{1-x} 2 \, dy = 2(1-x)$$

所以：
$$f_X(x) = \begin{cases} 2(1-x), & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$

**注意**：$X$ 的边缘分布**不是**均匀分布！

**3. 判断独立性**：

**快速判断**：
- 区域 $D$ 是三角形，不是矩形 ✗
- **结论**：$X$ 和 $Y$ **不独立**

---

## 3.2 二维正态分布 ⭐⭐⭐天花板级别的重要分布

### 一、二维正态分布的定义

**定义**：若二维随机变量 $(X, Y)$ 的联合概率密度为：
$$f(x, y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - 2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right\}$$

其中 $\mu_1, \mu_2 \in \mathbb{R}$，$\sigma_1 > 0$，$\sigma_2 > 0$，$|\rho| < 1$，则称 $(X, Y)$ 服从**二维正态分布**，记作：
$$(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$$

**参数说明**：
- $\mu_1, \mu_2$：$X$ 和 $Y$ 的均值
- $\sigma_1^2, \sigma_2^2$：$X$ 和 $Y$ 的方差
- $\rho$：$X$ 和 $Y$ 的相关系数

---

### 二、二维正态分布的识别 ⭐⭐⭐核心技巧

**您特别强调的识别要点**：

> **二维正态分布的识别特征**：
> 
> 1. **$x$ 和 $y$ 的取值范围都是从 $-\infty$ 到 $+\infty$**
> 2. **$e$ 的指数里面一定有 $x^2$ 和 $y^2$ 项**
> 3. **指数部分是二次型**（包含 $x^2$, $xy$, $y^2$ 项）

---

#### 识别步骤

**第1步：检查定义域**
- $x \in (-\infty, +\infty)$ ✓
- $y \in (-\infty, +\infty)$ ✓
- 如果不是整个平面，一定不是二维正态分布

**第2步：检查指数形式**
- 必须是 $e^{-Q(x,y)}$ 的形式
- $Q(x,y)$ 是关于 $x$ 和 $y$ 的**二次型**
- 必须包含 $x^2$ 项和 $y^2$ 项

**第3步：检查系数**
- 前面的系数应该是 $\frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}$
- 保证归一性（积分为1）

---

#### 典型识别例题

**例题1**：判断下列函数是否为二维正态分布的概率密度

**(1)** $f(x, y) = \frac{1}{2\pi}e^{-\frac{x^2+y^2}{2}}$，$-\infty < x, y < +\infty$

**(2)** $f(x, y) = \frac{1}{\pi}e^{-(x^2+y^2)}$，$-\infty < x, y < +\infty$

**(3)** $f(x, y) = \frac{1}{2\pi}e^{-\frac{x^2+y^2}{2}}$，$x > 0, y > 0$

**解**：

**(1)** 
- 定义域：$(-\infty, +\infty) \times (-\infty, +\infty)$ ✓
- 指数部分：$-\frac{x^2+y^2}{2}$，包含 $x^2$ 和 $y^2$ ✓
- 系数：$\frac{1}{2\pi}$，对应 $\sigma_1=\sigma_2=1$，$\rho=0$ ✓
- **结论**：是二维正态分布，$N(0, 0, 1, 1, 0)$

**(2)**
- 定义域：$(-\infty, +\infty) \times (-\infty, +\infty)$ ✓
- 指数部分：$-(x^2+y^2)$，包含 $x^2$ 和 $y^2$ ✓
- 但需要验证系数是否正确
- 实际上这是 $N(0, 0, \frac{1}{2}, \frac{1}{2}, 0)$，因为 $\sigma^2 = \frac{1}{2}$
- **结论**：是二维正态分布

**(3)**
- 定义域：$x > 0, y > 0$（第一象限）✗
- **结论**：不是二维正态分布（定义域不对）

---

### 三、二维正态分布的性质 ⭐⭐⭐非常重要

#### 性质1：边缘分布是一维正态分布

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则：
$$X \sim N(\mu_1, \sigma_1^2)$$
$$Y \sim N(\mu_2, \sigma_2^2)$$

**重要说明**：
> 边缘分布的参数与相关系数 $\rho$ **无关**！
> 
> 无论 $X$ 和 $Y$ 是否相关，边缘分布都是正态分布

---

#### 性质2：条件分布是一维正态分布

在已知 $Y = y$ 的条件下，$X$ 的条件分布为正态分布：
$$X | Y=y \sim N\left(\mu_1 + \rho\frac{\sigma_1}{\sigma_2}(y-\mu_2), \sigma_1^2(1-\rho^2)\right)$$

同理：
$$Y | X=x \sim N\left(\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x-\mu_1), \sigma_2^2(1-\rho^2)\right)$$

**理解**：
- 条件均值是 $y$ 的线性函数（回归直线）
- 条件方差小于边缘方差（因为 $1-\rho^2 < 1$）

---

#### 性质3：独立性与不相关性等价 ⭐⭐⭐

对于二维正态分布：
$$X \text{ 和 } Y \text{ 独立} \iff \rho = 0 \iff X \text{ 和 } Y \text{ 不相关}$$

**重要说明**：
> 这是二维正态分布的**特殊性质**！
> 
> 对于一般的随机变量，不相关不一定独立
> 
> 但对于二维正态分布，两者等价

**证明思路**：
- 若 $\rho = 0$，则联合密度可分离：$f(x,y) = f_X(x)f_Y(y)$
- 所以独立

---

#### 性质4：线性变换仍为正态分布

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则对于任意常数 $a, b, c, d$，有：
$$(aX + bY, cX + dY)$$

仍服从二维正态分布（只要变换矩阵非奇异）。

**特例**：
- $X + Y$ 服从一维正态分布
- $X - Y$ 服从一维正态分布

---

#### 性质5：和的分布

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则：
$$X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2)$$

**推导**：
- 均值：$E(X+Y) = E(X) + E(Y) = \mu_1 + \mu_2$
- 方差：$D(X+Y) = D(X) + D(Y) + 2Cov(X,Y)$
  $$= \sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2$$

---

#### 性质6：标准化

若 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则：
$$\left(\frac{X-\mu_1}{\sigma_1}, \frac{Y-\mu_2}{\sigma_2}\right) \sim N(0, 0, 1, 1, \rho)$$

**理解**：
- 标准化后，均值为0，方差为1
- 相关系数 $\rho$ 保持不变

---

### 四、典型例题

**例题1**（识别与参数）：设 $(X, Y)$ 的联合概率密度为
$$f(x, y) = \frac{1}{2\pi\sqrt{3}}e^{-\frac{1}{6}(4x^2 - 4xy + y^2)}$$

判断是否为二维正态分布，若是，写出参数。

**解**：

**第1步：检查定义域**
- 题目未限制，默认为 $(-\infty, +\infty) \times (-\infty, +\infty)$ ✓

**第2步：检查指数形式**
- 指数：$-\frac{1}{6}(4x^2 - 4xy + y^2)$
- 包含 $x^2$、$xy$、$y^2$ 项 ✓
- 是二次型 ✓

**第3步：对比标准形式**

标准形式的指数部分：
$$-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - 2\rho\frac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]$$

假设 $\mu_1 = \mu_2 = 0$（因为没有一次项），则：
$$-\frac{1}{2(1-\rho^2)}\left[\frac{x^2}{\sigma_1^2} - 2\rho\frac{xy}{\sigma_1\sigma_2} + \frac{y^2}{\sigma_2^2}\right]$$

对比系数：
- $\frac{1}{2(1-\rho^2)\sigma_1^2} = \frac{4}{6} = \frac{2}{3}$
- $\frac{\rho}{(1-\rho^2)\sigma_1\sigma_2} = \frac{4}{6} = \frac{2}{3}$
- $\frac{1}{2(1-\rho^2)\sigma_2^2} = \frac{1}{6}$

解得：
- $\sigma_1^2 = \frac{3}{4}$，$\sigma_2^2 = 3$
- $\rho = \frac{1}{2}$

**答案**：是二维正态分布，$(X, Y) \sim N(0, 0, \frac{3}{4}, 3, \frac{1}{2})$

---

**例题2**（独立性判断）：设 $(X, Y) \sim N(1, 2, 4, 9, 0)$，判断 $X$ 和 $Y$ 是否独立，并写出边缘分布。

**解**：

**判断独立性**：
- $\rho = 0$
- 对于二维正态分布，$\rho = 0$ ⟺ 独立
- **结论**：$X$ 和 $Y$ **相互独立**

**边缘分布**：
- $X \sim N(1, 4)$
- $Y \sim N(2, 9)$

**答案**：独立；$X \sim N(1, 4)$，$Y \sim N(2, 9)$

---

**例题3**（和的分布）：设 $(X, Y) \sim N(0, 0, 1, 1, 0.5)$，求 $Z = X + Y$ 的分布。

**解**：

利用性质5：
$$X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2)$$

代入参数：
- $\mu_1 + \mu_2 = 0 + 0 = 0$
- $\sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2 = 1 + 1 + 2 \times 0.5 \times 1 \times 1 = 3$

**答案**：$Z = X + Y \sim N(0, 3)$

### 五、解题技巧总结

**1. 二维正态分布的识别要点**

```
第1步：检查定义域是否为整个平面
      ├─ 不是 → 不是二维正态
      └─ 是 → 继续

第2步：检查指数是否包含x²和y²
      ├─ 不包含 → 不是二维正态
      └─ 包含 → 继续

第3步：对比标准形式，提取参数
      - μ₁, μ₂：均值
      - σ₁², σ₂²：方差
      - ρ：相关系数
```

---

**2. 二维正态分布的核心性质记忆**

| 性质 | 内容 |
|------|------|
| **边缘分布** | 一维正态 |
| **条件分布** | 一维正态 |
| **独立⟺不相关** | ρ=0 |
| **线性变换** | 仍为正态 |
| **和的分布** | 正态，方差含ρ项 |

---

**3. 常见错误警示**

**⚠️ 错误1**：认为边缘正态就是联合正态
- 边缘分布是正态，联合分布不一定是二维正态
- 二维正态是更强的条件

**⚠️ 错误2**：忽略定义域的检查
- 如果定义域不是整个平面，一定不是二维正态

**⚠️ 错误3**：混淆独立和不相关
- 一般情况：独立 ⟹ 不相关，但逆命题不成立
- 二维正态：独立 ⟺ 不相关

**⚠️ 错误4**：计算和的方差时忘记相关系数项
- $D(X+Y) = \sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2$
- 不要漏掉 $2\rho\sigma_1\sigma_2$ 这一项

## 3.3 两个随机变量函数的分布

---

### 二、边缘概率密度 ⭐⭐

**定义**：从联合概率密度中分别求出 $X$ 和 $Y$ 各自的概率密度

**$X$ 的边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$

**$Y$ 的边缘概率密度**：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

**记忆技巧**：
- $f_X(x)$：对 $y$ 积分（消去 $y$）
- $f_Y(y)$：对 $x$ 积分（消去 $x$）

---

#### 典型例题

**例题1**：设二维随机变量 $(X, Y)$ 的联合概率密度为
$$f(x, y) = \begin{cases} 6xy, & 0 < x < 1, 0 < y < 1 - x \\ 0, & \text{其他} \end{cases}$$

求：
1. $X$ 的边缘概率密度 $f_X(x)$
2. $Y$ 的边缘概率密度 $f_Y(y)$

**解**：

**1. 求 $f_X(x)$**：

首先确定积分区域：$0 < x < 1$，$0 < y < 1 - x$

当 $0 < x < 1$ 时：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{0}^{1-x} 6xy \, dy$$
$$= 6x \left[\\frac{y^2}{2}\\right]_{0}^{1-x} = 3x(1-x)^2$$

所以：
$$f_X(x) = \begin{cases} 3x(1-x)^2, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$

**2. 求 $f_Y(y)$**：

首先确定积分区域：$0 < y < 1$，由 $y < 1 - x$ 得 $x < 1 - y$，且 $x > 0$

当 $0 < y < 1$ 时：
$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx = \int_{0}^{1-y} 6xy \, dx$$
$$= 6y \left[\\frac{x^2}{2}\\right]_{0}^{1-y} = 3y(1-y)^2$$

所以：
$$f_Y(y) = \begin{cases} 3y(1-y)^2, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**答案**：$f_X(x) = 3x(1-x)^2$，$0 < x < 1$；$f_Y(y) = 3y(1-y)^2$，$0 < y < 1$

---

### 三、条件概率密度 ⭐⭐

**定义**：在已知 $Y = y$ 的条件下，$X$ 的条件概率密度为：
$$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}, \quad f_Y(y) > 0$$

同理，在已知 $X = x$ 的条件下，$Y$ 的条件概率密度为：
$$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)}, \quad f_X(x) > 0$$

**理解**：
- 条件概率密度也是概率密度，满足非负性和归一性
- $\int_{-\infty}^{+\infty} f_{X|Y}(x|y) \, dx = 1$

---

#### 典型例题

**例题2**：接例题1，求在 $Y = y$ 的条件下，$X$ 的条件概率密度 $f_{X|Y}(x|y)$。

**解**：

由例题1知：
- $f(x, y) = 6xy$，$0 < x < 1 - y$，$0 < y < 1$
- $f_Y(y) = 3y(1-y)^2$，$0 < y < 1$

所以，当 $0 < y < 1$ 时：
$$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)} = \frac{6xy}{3y(1-y)^2} = \frac{2x}{(1-y)^2}$$

注意 $x$ 的范围：$0 < x < 1 - y$

**完整表达式**：
$$f_{X|Y}(x|y) = \begin{cases} \frac{2x}{(1-y)^2}, & 0 < x < 1 - y \\ 0, & \text{其他} \end{cases}$$

**验证归一性**：
$$\int_{0}^{1-y} \frac{2x}{(1-y)^2} \, dx = \frac{2}{(1-y)^2} \left[\\frac{x^2}{2}\\right]_{0}^{1-y} = \frac{(1-y)^2}{(1-y)^2} = 1$$ ✓

## 3.4 随机变量的独立性 ⭐⭐⭐

### 一、独立性的定义

**定义**：二维随机变量 $(X, Y)$ 的两个分量 $X$ 和 $Y$ **相互独立**，如果对于任意实数 $x, y$，有：
$$F(x, y) = F_X(x) F_Y(y)$$

等价地：
- **离散型**：$P(X = x_i, Y = y_j) = P(X = x_i) P(Y = y_j)$，即 $p_{ij} = p_{i\cdot} p_{\cdot j}$
- **连续型**：$f(x, y) = f_X(x) f_Y(y)$

---

### 二、独立性的判断方法

**方法1：用分布函数判断**
- 验证 $F(x, y) = F_X(x) F_Y(y)$ 是否对所有 $x, y$ 成立

**方法2：用概率密度/分布律判断**
- 离散型：验证 $p_{ij} = p_{i\cdot} p_{\cdot j}$
- 连续型：验证 $f(x, y) = f_X(x) f_Y(y)$

**方法3：用定义域判断**（快速排除法）
- 如果联合概率密度的定义域不是矩形区域，则 $X$ 和 $Y$ **一定不独立**
- 例如：$0 < x < 1$，$0 < y < 1 - x$（三角形区域）⟹ 不独立

---

#### 典型例题

**例题1**：判断下列二维随机变量是否独立

**(1)** $f(x, y) = \begin{cases} 4xy, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$

**(2)** $f(x, y) = \begin{cases} 6xy, & 0 < x < 1, 0 < y < 1 - x \\ 0, & \text{其他} \end{cases}$

**解**：

**(1)** 
- 定义域是矩形区域 $[0,1] \times [0,1]$ ✓（可能独立）
- 求边缘密度：
  - $f_X(x) = \int_{0}^{1} 4xy \, dy = 4x \cdot \frac{1}{2} = 2x$，$0 < x < 1$
  - $f_Y(y) = \int_{0}^{1} 4xy \, dx = 4y \cdot \frac{1}{2} = 2y$，$0 < y < 1$
- 验证：$f_X(x) f_Y(y) = 2x \cdot 2y = 4xy = f(x, y)$ ✓
- **结论**：$X$ 和 $Y$ **独立**

**(2)**
- 定义域是三角形区域 $0 < x < 1$，$0 < y < 1 - x$ ✗（不是矩形）
- **结论**：$X$ 和 $Y$ **不独立**（无需进一步计算）

---

**例题2**：设 $(X, Y)$ 的联合分布律为

| $X \setminus Y$ | 0 | 1 |
|----------------|---|---|
| 0 | 0.2 | 0.3 |
| 1 | 0.3 | 0.2 |

判断 $X$ 和 $Y$ 是否独立。

**解**：

**第一步**：求边缘分布律
- $P(X = 0) = 0.2 + 0.3 = 0.5$
- $P(X = 1) = 0.3 + 0.2 = 0.5$
- $P(Y = 0) = 0.2 + 0.3 = 0.5$
- $P(Y = 1) = 0.3 + 0.2 = 0.5$

**第二步**：验证独立性
- 检查 $p_{00} = p_{0\cdot} p_{\cdot 0}$？
  - $p_{00} = 0.2$
  - $p_{0\cdot} p_{\cdot 0} = 0.5 \times 0.5 = 0.25$
  - $0.2 \neq 0.25$ ✗

**结论**：$X$ 和 $Y$ **不独立**

---

### 三、独立性的性质

**性质1**：若 $X$ 和 $Y$ 独立，则：
- $E(XY) = E(X)E(Y)$
- $D(X + Y) = D(X) + D(Y)$

**性质2**：若 $X$ 和 $Y$ 独立，则 $g(X)$ 和 $h(Y)$ 也独立（$g, h$ 为任意函数）

**性质3**：若 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$，且 $X$ 和 $Y$ 独立，则：
$$X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$$

## 3.5 两个随机变量函数的分布 ⭐⭐⭐

### 一、常见函数类型

1. **和的分布**：$Z = X + Y$
2. **差的分布**：$Z = X - Y$
3. **积的分布**：$Z = XY$
4. **商的分布**：$Z = \frac{X}{Y}$
5. **最大最小值**：$Z = \max(X, Y)$，$Z = \min(X, Y)$

---

### 二、和的分布（卷积公式）⭐⭐⭐

**离散型**：
$$P(Z = z_k) = \sum_{i} P(X = x_i, Y = z_k - x_i)$$

**连续型**（卷积公式）：
$$f_Z(z) = \int_{-\infty}^{+\infty} f(x, z - x) \, dx$$

若 $X$ 和 $Y$ 独立，则：
$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) \, dx$$

---

#### 典型例题

**例题1**：设 $X$ 和 $Y$ 独立同分布，且 $X \sim U(0, 1)$，求 $Z = X + Y$ 的概率密度。

**解**：

**第一步**：写出 $X$ 和 $Y$ 的概率密度
$$f_X(x) = \begin{cases} 1, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$
$$f_Y(y) = \begin{cases} 1, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**第二步**：确定 $Z$ 的取值范围
- $X \in (0, 1)$，$Y \in (0, 1)$ ⟹ $Z = X + Y \in (0, 2)$

**第三步**：应用卷积公式
$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) \, dx$$

被积函数非零的条件：
- $0 < x < 1$
- $0 < z - x < 1$ ⟹ $z - 1 < x < z$

综合得：$\max(0, z-1) < x < \min(1, z)$

**分情况讨论**：

**情况1**：$0 < z \leq 1$
- 积分区间：$0 < x < z$
- $f_Z(z) = \int_{0}^{z} 1 \cdot 1 \, dx = z$

**情况2**：$1 < z < 2$
- 积分区间：$z - 1 < x < 1$
- $f_Z(z) = \int_{z-1}^{1} 1 \cdot 1 \, dx = 1 - (z - 1) = 2 - z$

**完整表达式**：
$$f_Z(z) = \begin{cases} z, & 0 < z \leq 1 \\ 2 - z, & 1 < z < 2 \\ 0, & \text{其他} \end{cases}$$

**结论**：$Z = X + Y$ 服从**三角分布**

---

### 三、最大值和最小值的分布

**最大值 $Z = \max(X, Y)$ 的分布函数**：
$$F_Z(z) = P(\max(X, Y) \leq z) = P(X \leq z, Y \leq z) = F(z, z)$$

若 $X$ 和 $Y$ 独立：
$$F_Z(z) = F_X(z) F_Y(z)$$

**最小值 $W = \min(X, Y)$ 的分布函数**：
$$F_W(w) = P(\min(X, Y) \leq w) = 1 - P(\min(X, Y) > w)$$
$$= 1 - P(X > w, Y > w) = 1 - [1 - F_X(w)][1 - F_Y(w)]$$

若 $X$ 和 $Y$ 独立：
$$F_W(w) = 1 - [1 - F_X(w)][1 - F_Y(w)]$$

---

## 4.1 二维随机变量函数的分布函数

### 一、问题描述

**已知**：二维随机变量 $(X, Y)$ 的联合分布（联合分布律或联合概率密度）

**求解**：$Z = g(X, Y)$ 的分布

**常见函数类型**：
1. **和**：$Z = X + Y$
2. **差**：$Z = X - Y$
3. **积**：$Z = XY$
4. **商**：$Z = \frac{X}{Y}$
5. **最大值**：$Z = \max(X, Y)$
6. **最小值**：$Z = \min(X, Y)$

---

### 二、分布函数法（通用方法）⭐⭐⭐

**核心思想**：先求分布函数 $F_Z(z)$，再求导得到概率密度 $f_Z(z)$

**解题步骤**：

**第1步：写出分布函数定义**
$$F_Z(z) = P(Z \leq z) = P(g(X, Y) \leq z)$$

**第2步：转化为关于 $(X, Y)$ 的事件**
- 解不等式 $g(X, Y) \leq z$
- 确定 $(X, Y)$ 的取值区域 $D_z$

**第3步：计算概率**

**离散型**：
$$F_Z(z) = \sum_{(x_i, y_j) \in D_z} p_{ij}$$

**连续型**：
$$F_Z(z) = \iint_{D_z} f(x, y) \, dx \, dy$$

**第4步：求导得到概率密度**
$$f_Z(z) = F'_Z(z)$$

---

## 4.2 分布的求法——几种常见的二维连续分布求解

### 一、卷积公式（和的分布）⭐⭐⭐核心考点

#### 1. 卷积公式的推导

设 $Z = X + Y$，则：
$$F_Z(z) = P(X + Y \leq z) = \iint_{x+y \leq z} f(x, y) \, dx \, dy$$

交换积分次序：
$$F_Z(z) = \int_{-\infty}^{+\infty} \left[\int_{-\infty}^{z-x} f(x, y) \, dy\right] dx$$

对 $z$ 求导：
$$f_Z(z) = \frac{d}{dz} F_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) \, dx$$

这就是**卷积公式**！

---

#### 2. 卷积公式的形式

**一般形式**：
$$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f(x, z-x) \, dx$$

或者对称地：
$$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f(z-y, y) \, dy$$

**若 $X$ 和 $Y$ 独立**：
$$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \, dx$$

这就是**独立随机变量和的卷积公式**！

---

#### 3. 卷积公式的解题步骤 ⭐⭐⭐

**第1步：确定积分区间**
- 找出 $f(x, z-x)$ 非零的条件
- 即同时满足：
  - $(x, z-x)$ 在 $f(x, y)$ 的非零区域内
  - 解出 $x$ 的范围（含参数 $z$）

**第2步：分情况讨论**
- 根据 $z$ 的不同取值范围，确定不同的积分限
- 通常需要画图辅助

**第3步：计算积分**
- 对每一段分别计算定积分
- 注意被积函数的具体形式

**第4步：写出完整表达式**
- 合并各段结果
- 标注每段的 $z$ 范围

---

#### 4. 典型例题

**例题1**（独立均匀分布的和）：设 $X$ 和 $Y$ 独立同分布，且 $X, Y \sim U(0, 1)$，求 $Z = X + Y$ 的概率密度。

**解**：

**第1步：写出边缘概率密度**
$$f_X(x) = \begin{cases} 1, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$
$$f_Y(y) = \begin{cases} 1, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**第2步：应用卷积公式**
$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \, dx$$

被积函数非零的条件：
- $0 < x < 1$
- $0 < z-x < 1$ ⟹ $z-1 < x < z$

综合得：$\max(0, z-1) < x < \min(1, z)$

**第3步：确定 $Z$ 的取值范围**
- $X \in (0, 1)$，$Y \in (0, 1)$ ⟹ $Z = X+Y \in (0, 2)$

**第4步：分情况讨论**

**情况1**：$0 < z \leq 1$
- 积分区间：$0 < x < z$
- $$f_Z(z) = \int_{0}^{z} 1 \cdot 1 \, dx = z$$

**情况2**：$1 < z < 2$
- 积分区间：$z-1 < x < 1$
- $$f_Z(z) = \int_{z-1}^{1} 1 \cdot 1 \, dx = 1 - (z-1) = 2 - z$$

**第5步：写出完整表达式**
$$f_Z(z) = \begin{cases} z, & 0 < z \leq 1 \\ 2-z, & 1 < z < 2 \\ 0, & \text{其他} \end{cases}$$

**结论**：$Z = X+Y$ 服从**三角分布**

---

**例题2**（独立指数分布的和）：设 $X$ 和 $Y$ 独立，且 $X \sim E(\lambda)$，$Y \sim E(\mu)$（$\lambda \neq \mu$），求 $Z = X + Y$ 的概率密度。

**解**：

**第1步：写出边缘概率密度**
$$f_X(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$
$$f_Y(y) = \begin{cases} \mu e^{-\mu y}, & y > 0 \\ 0, & y \leq 0 \end{cases}$$

**第2步：应用卷积公式**
$$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) \, dx$$

被积函数非零的条件：
- $x > 0$
- $z-x > 0$ ⟹ $x < z$

所以：$0 < x < z$，且需要 $z > 0$

**第3步：计算积分**

当 $z > 0$ 时：
$$f_Z(z) = \int_{0}^{z} \lambda e^{-\lambda x} \cdot \mu e^{-\mu(z-x)} \, dx$$
$$= \lambda\mu e^{-\mu z} \int_{0}^{z} e^{-(\lambda-\mu)x} \, dx$$

**分两种情况**：

**(1) 若 $\lambda \neq \mu$**：
$$f_Z(z) = \lambda\mu e^{-\mu z} \cdot \left[\frac{e^{-(\lambda-\mu)x}}{-(\lambda-\mu)}\right]_{0}^{z}$$
$$= \frac{\lambda\mu}{\lambda-\mu} e^{-\mu z} \left[e^{-(\lambda-\mu)z} - 1\right]$$
$$= \frac{\lambda\mu}{\lambda-\mu} \left(e^{-\lambda z} - e^{-\mu z}\right)$$

**(2) 若 $\lambda = \mu$**：
$$f_Z(z) = \lambda^2 e^{-\lambda z} \int_{0}^{z} 1 \, dx = \lambda^2 z e^{-\lambda z}$$

**完整表达式**（$\lambda \neq \mu$）：
$$f_Z(z) = \begin{cases} \frac{\lambda\mu}{\lambda-\mu} \left(e^{-\lambda z} - e^{-\mu z}\right), & z > 0 \\ 0, & z \leq 0 \end{cases}$$

---

### 二、其他常见函数的分布

#### 1. 差的分布 $Z = X - Y$

**卷积公式**：
$$f_{X-Y}(z) = \int_{-\infty}^{+\infty} f(x, x-z) \, dx$$

若独立：
$$f_{X-Y}(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(x-z) \, dx$$

---

#### 2. 积的分布 $Z = XY$

**公式**：
$$f_{XY}(z) = \int_{-\infty}^{+\infty} \frac{1}{|x|} f\left(x, \frac{z}{x}\right) \, dx$$

若独立：
$$f_{XY}(z) = \int_{-\infty}^{+\infty} \frac{1}{|x|} f_X(x) f_Y\left(\frac{z}{x}\right) \, dx$$

---

#### 3. 商的分布 $Z = \frac{X}{Y}$

**公式**：
$$f_{X/Y}(z) = \int_{-\infty}^{+\infty} |y| f(yz, y) \, dy$$

若独立：
$$f_{X/Y}(z) = \int_{-\infty}^{+\infty} |y| f_X(yz) f_Y(y) \, dy$$

---

#### 4. 最大值和最小值的分布

**最大值 $Z = \max(X, Y)$**：
$$F_Z(z) = P(\max(X, Y) \leq z) = P(X \leq z, Y \leq z) = F(z, z)$$

若独立：
$$F_Z(z) = F_X(z) F_Y(z)$$

**最小值 $W = \min(X, Y)$**：
$$F_W(w) = P(\min(X, Y) \leq w) = 1 - P(X > w, Y > w)$$
$$= 1 - [1 - F_X(w)][1 - F_Y(w)]$$

若独立：
$$F_W(w) = 1 - [1 - F_X(w)][1 - F_Y(w)]$$

### 三、二维混合型随机变量函数的分布求法 ⭐⭐⭐重点

**什么是混合型随机变量？**

混合型随机变量是指：
- 一个分量是**离散型**，另一个分量是**连续型**
- 或者函数本身既有离散部分又有连续部分

---

#### 解题思路

**核心思想**：利用**全概率公式**的思想，分情况讨论

**步骤**：

**第1步：识别离散部分**
- 找出离散型随机变量的所有可能取值
- 例如：$X$ 是离散型，取值为 $x_1, x_2, ...$

**第2步：条件化**
- 在已知离散变量取某个值的条件下，分析连续变量的分布
- 例如：已知 $X = x_i$，求 $Z = g(x_i, Y)$ 的分布

**第3步：加权求和**
- 利用全概率公式：
  $$F_Z(z) = \sum_{i} P(X = x_i) P(Z \leq z | X = x_i)$$

**第4步：求导（如果需要概率密度）**
- 对分布函数求导得到概率密度

---

#### 典型例题

**例题3**（混合型）：设 $X$ 是离散型随机变量，$P(X=0) = P(X=1) = 0.5$；$Y$ 是连续型随机变量，$Y \sim U(0, 1)$，且 $X$ 和 $Y$ 独立。求 $Z = X + Y$ 的分布。

**解**：

**第1步：识别离散部分**
- $X$ 的可能取值：0, 1
- $Y \sim U(0, 1)$

**第2步：条件化**

**情况1**：$X = 0$（概率0.5）
- $Z = 0 + Y = Y$
- $Z | X=0 \sim U(0, 1)$
- $F_{Z|X=0}(z) = \begin{cases} 0, & z \leq 0 \\ z, & 0 < z < 1 \\ 1, & z \geq 1 \end{cases}$

**情况2**：$X = 1$（概率0.5）
- $Z = 1 + Y$
- $Z | X=1 \sim U(1, 2)$
- $F_{Z|X=1}(z) = \begin{cases} 0, & z \leq 1 \\ z-1, & 1 < z < 2 \\ 1, & z \geq 2 \end{cases}$

**第3步：加权求和**

$$F_Z(z) = P(X=0)F_{Z|X=0}(z) + P(X=1)F_{Z|X=1}(z)$$
$$= 0.5 F_{Z|X=0}(z) + 0.5 F_{Z|X=1}(z)$$

**分情况讨论**：

- 当 $z \leq 0$：$F_Z(z) = 0$
- 当 $0 < z \leq 1$：$F_Z(z) = 0.5 \cdot z + 0.5 \cdot 0 = 0.5z$
- 当 $1 < z < 2$：$F_Z(z) = 0.5 \cdot 1 + 0.5 \cdot (z-1) = 0.5 + 0.5z - 0.5 = 0.5z$
- 当 $z \geq 2$：$F_Z(z) = 1$

等等，这里需要仔细计算：

- 当 $0 < z \leq 1$：
  $$F_Z(z) = 0.5 \cdot z + 0.5 \cdot 0 = 0.5z$$

- 当 $1 < z < 2$：
  $$F_Z(z) = 0.5 \cdot 1 + 0.5 \cdot (z-1) = 0.5 + 0.5z - 0.5 = 0.5z$$

实际上，在这个例子中，$F_Z(z) = 0.5z$ 对于 $0 < z < 2$，但这不对，让我重新计算：

当 $1 < z < 2$：
$$F_Z(z) = 0.5 \times 1 + 0.5 \times (z-1) = 0.5 + 0.5z - 0.5 = 0.5z$$

这个结果是线性的，说明 $Z$ 在 $(0, 2)$ 上服从均匀分布！

**验证**：
$$f_Z(z) = F'_Z(z) = \begin{cases} 0.5, & 0 < z < 2 \\ 0, & \text{其他} \end{cases}$$

即 $Z \sim U(0, 2)$

**答案**：$Z \sim U(0, 2)$

---

**例题4**（更复杂的混合型）：设 $X$ 服从0-1分布，$P(X=0)=0.3$，$P(X=1)=0.7$；给定 $X=0$ 时，$Y \sim U(0, 1)$；给定 $X=1$ 时，$Y \sim U(1, 2)$。求 $Z = X + Y$ 的概率密度。

**解**：

**第1步：条件化**

**情况1**：$X = 0$（概率0.3）
- $Y | X=0 \sim U(0, 1)$
- $Z = 0 + Y = Y$
- $Z | X=0 \sim U(0, 1)$
- $f_{Z|X=0}(z) = \begin{cases} 1, & 0 < z < 1 \\ 0, & \text{其他} \end{cases}$

**情况2**：$X = 1$（概率0.7）
- $Y | X=1 \sim U(1, 2)$
- $Z = 1 + Y \sim U(2, 3)$
- $f_{Z|X=1}(z) = \begin{cases} 1, & 2 < z < 3 \\ 0, & \text{其他} \end{cases}$

**第2步：加权求和**

$$f_Z(z) = P(X=0)f_{Z|X=0}(z) + P(X=1)f_{Z|X=1}(z)$$
$$= 0.3 f_{Z|X=0}(z) + 0.7 f_{Z|X=1}(z)$$

**分情况**：
- 当 $0 < z < 1$：$f_Z(z) = 0.3 \times 1 + 0.7 \times 0 = 0.3$
- 当 $1 \leq z \leq 2$：$f_Z(z) = 0$
- 当 $2 < z < 3$：$f_Z(z) = 0.3 \times 0 + 0.7 \times 1 = 0.7$
- 其他：$f_Z(z) = 0$

**完整表达式**：
$$f_Z(z) = \begin{cases} 0.3, & 0 < z < 1 \\ 0, & 1 \leq z \leq 2 \\ 0.7, & 2 < z < 3 \\ 0, & \text{其他} \end{cases}$$

**注意**：这是一个**分段常数函数**，不是传统的连续分布

## 4.3 独立同分布的可加性计算公式 ⭐⭐⭐

### 一、独立同分布的概念

**定义**：若随机变量 $X_1, X_2, ..., X_n$ 满足：
1. **相互独立**
2. **同分布**（具有相同的分布）

则称 $X_1, X_2, ..., X_n$ **独立同分布**（i.i.d., independent and identically distributed）

记作：$X_1, X_2, ..., X_n \overset{i.i.d.}{\sim} F$

---

### 二、常见分布的可加性

#### 1. 正态分布的可加性 ⭐⭐⭐

若 $X_1, X_2, ..., X_n \overset{i.i.d.}{\sim} N(\mu, \sigma^2)$，则：
$$S_n = \sum_{i=1}^{n} X_i \sim N(n\mu, n\sigma^2)$$

**样本均值**：
$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i \sim N\left(\mu, \frac{\sigma^2}{n}\right)$$

**标准化**：
$$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)$$

---

#### 2. 泊松分布的可加性

若 $X_1, X_2, ..., X_n \overset{i.i.d.}{\sim} P(\lambda)$，则：
$$S_n = \sum_{i=1}^{n} X_i \sim P(n\lambda)$$

---

#### 3. 二项分布的可加性

若 $X_1 \sim B(n_1, p)$，$X_2 \sim B(n_2, p)$，且独立，则：
$$X_1 + X_2 \sim B(n_1 + n_2, p)$$

**推广**：若 $X_i \sim B(n_i, p)$ 且独立，则：
$$\sum_{i=1}^{k} X_i \sim B\left(\sum_{i=1}^{k} n_i, p\right)$$

**特例**：若 $X_1, ..., X_n \overset{i.i.d.}{\sim} B(1, p)$（0-1分布），则：
$$\sum_{i=1}^{n} X_i \sim B(n, p)$$

---

#### 4. 指数分布的可加性

若 $X_1, X_2, ..., X_n \overset{i.i.d.}{\sim} E(\lambda)$，则：
$$S_n = \sum_{i=1}^{n} X_i \sim \Gamma(n, \lambda)$$

即服从**伽马分布**（Erlang分布）

概率密度：
$$f_{S_n}(z) = \frac{\lambda^n z^{n-1} e^{-\lambda z}}{(n-1)!}, \quad z > 0$$

---

#### 5. 卡方分布的可加性

若 $X_1 \sim \chi^2(n_1)$，$X_2 \sim \chi^2(n_2)$，且独立，则：
$$X_1 + X_2 \sim \chi^2(n_1 + n_2)$$

---

### 三、中心极限定理（CLT）⭐⭐⭐

**定理**：设 $X_1, X_2, ..., X_n \overset{i.i.d.}{\sim}$ 任意分布，且 $E(X_i) = \mu$，$D(X_i) = \sigma^2 < \infty$，则当 $n$ 充分大时：

$$\frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n}\sigma} \approx N(0, 1)$$

或等价地：
$$\sum_{i=1}^{n} X_i \approx N(n\mu, n\sigma^2)$$

**意义**：
> 无论原始分布是什么，只要样本量足够大，样本和近似服从正态分布！
> 
> 这是统计学中最重要的定理之一

---

### 四、典型例题

**例题5**（正态分布可加性）：设 $X_1, X_2, ..., X_{10} \overset{i.i.d.}{\sim} N(5, 4)$，求 $P(\sum_{i=1}^{10} X_i > 55)$。

**解**：

**第1步：确定和的分布**
$$S_{10} = \sum_{i=1}^{10} X_i \sim N(10 \times 5, 10 \times 4) = N(50, 40)$$

**第2步：标准化**
$$P(S_{10} > 55) = P\left(\frac{S_{10} - 50}{\sqrt{40}} > \frac{55 - 50}{\sqrt{40}}\right)$$
$$= P\left(Z > \frac{5}{\sqrt{40}}\right) = P(Z > 0.79)$$
$$= 1 - \Phi(0.79) \approx 1 - 0.7852 = 0.2148$$

**答案**：约0.2148

---

**例题6**（中心极限定理应用）：某保险公司有10000个投保人，每人每年索赔金额 $X_i$ 独立同分布，$E(X_i) = 100$元，$D(X_i) = 10000$。求总索赔金额超过1050000元的概率。

**解**：

**第1步：确定参数**
- $n = 10000$
- $\mu = 100$，$\sigma^2 = 10000$，$\sigma = 100$
- $S_n = \sum_{i=1}^{10000} X_i$

**第2步：应用中心极限定理**
$$S_n \approx N(n\mu, n\sigma^2) = N(1000000, 100000000)$$

**第3步：标准化**
$$P(S_n > 1050000) = P\left(\frac{S_n - 1000000}{\sqrt{100000000}} > \frac{1050000 - 1000000}{10000}\right)$$
$$= P\left(Z > \frac{50000}{10000}\right) = P(Z > 5)$$
$$= 1 - \Phi(5) \approx 1 - 0.9999997 = 0.0000003$$

**答案**：约 $3 \times 10^{-7}$（几乎不可能发生）

### 五、解题技巧总结

**1. 卷积公式的应用要点**

```
第1步：确定积分区间（画图找非零区域）
第2步：分情况讨论（根据z的范围）
第3步：计算定积分
第4步：写出分段表达式
```

**关键点**：
- 必须考虑被积函数非零的条件
- 积分限通常与 $z$ 有关
- 最后要验证归一性

---

**2. 混合型随机变量的处理**

**核心思路**：
- 利用全概率公式
- 先条件化，再加权求和
- 离散部分作为权重，连续部分作为条件分布

---

**3. 独立同分布可加性的记忆**

| 分布 | 可加性 |
|------|--------|
| **正态** | $N(\mu, \sigma^2)$ → $N(n\mu, n\sigma^2)$ |
| **泊松** | $P(\lambda)$ → $P(n\lambda)$ |
| **二项** | $B(n_1, p) + B(n_2, p)$ → $B(n_1+n_2, p)$ |
| **指数** | $E(\lambda)$ → $\Gamma(n, \lambda)$ |
| **卡方** | $\chi^2(n_1) + \chi^2(n_2)$ → $\chi^2(n_1+n_2)$ |

---

**4. 常见错误警示**

**⚠️ 错误1**：卷积公式积分区间错误
- 必须仔细分析被积函数非零的条件
- 画图辅助确定积分限

**⚠️ 错误2**：忘记分情况讨论
- 不同 $z$ 范围对应不同的积分限
- 必须分段计算

**⚠️ 错误3**：混淆独立和不独立的情况
- 卷积公式在独立时有简化形式
- 不独立时必须用联合密度

**⚠️ 错误4**：中心极限定理滥用
- CLT要求 $n$ 充分大（通常 $n \geq 30$）
- 小样本时不能用CLT近似

## ⭐ 本章重点总结

### 核心概念
1. **联合分布函数**：$F(x, y) = P(X \leq x, Y \leq y)$
2. **联合概率密度**：$f(x, y) = \frac{\partial^2 F(x, y)}{\partial x \partial y}$
3. **边缘分布**：从联合分布中提取单个变量的分布
4. **条件分布**：在已知一个变量条件下的分布
5. **独立性**：$f(x, y) = f_X(x) f_Y(y)$

### 重要公式
1. **矩形概率公式**：
   $$P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_2, y_1) - F(x_1, y_2) + F(x_1, y_1)$$

2. **边缘概率密度**：
   $$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$
   $$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

3. **条件概率密度**：
   $$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}$$

4. **卷积公式**（和的分布）：
   $$f_{X+Y}(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z - x) \, dx$$

### 解题技巧

**1. 判断独立性的快速方法**
- 看定义域：如果不是矩形区域，一定不独立
- 验证乘积：$f(x, y) = f_X(x) f_Y(y)$

**2. 求边缘分布的技巧**
- 离散型：行和/列和
- 连续型：对另一个变量积分

**3. 卷积公式的应用**
- 先确定积分区间（画图辅助）
- 分情况讨论（根据 $z$ 的范围）
- 注意被积函数非零的条件

**4. 易错点警示**
- ⚠️ 忘记考虑定义域的限制
- ⚠️ 卷积公式积分区间错误
- ⚠️ 混淆边缘分布和条件分布
- ⚠️ 独立性判断不完整

#### 考查要点

1. **判断某函数是否可以作为联合分布函数**

3. **求边缘分布函数**
4. **判断独立性**

#### 典型例题

**例题1**（判断是否为联合分布函数）：

下列函数中，哪个可以作为二维随机变量的联合分布函数？

A. $F(x, y) = \begin{cases} xy, & 0 \leq x \leq 1, 0 \leq y \leq 1 \\ 0, & \text{其他} \end{cases}$

B. $F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$

C. $F(x, y) = \begin{cases} \frac{1}{\pi^2}(\frac{\pi}{2} + \arctan x)(\frac{\pi}{2} + \arctan y), & -\infty < x, y < +\infty \end{cases}$

**解**：逐一验证六大性质

**A选项**：
- 检查 $F(+\infty, +\infty)$：但定义域只在 $[0,1] \times [0,1]$，超出范围为0
- $F(1, 1) = 1 \times 1 = 1$ ✓
- 但在 $x > 1$ 或 $y > 1$ 时，$F(x, y) = 0$，不满足单调性 ✗
- **结论**：不是联合分布函数

**B选项**：
- 单调性：$(1 - e^{-x})$ 和 $(1 - e^{-y})$ 都单调递增 ✓
- 有界性：$F(-\infty, y) = 0$，$F(x, -\infty) = 0$，$F(+\infty, +\infty) = 1$ ✓
- 右连续性：指数函数连续 ✓
- **结论**：是联合分布函数 ✓

**C选项**：
- 这是两个标准柯西分布的独立联合分布
- $\lim_{x \to +\infty} (\frac{\pi}{2} + \arctan x) = \pi$
- $F(+\infty, +\infty) = \frac{1}{\pi^2} \cdot \pi \cdot \pi = 1$ ✓
- **结论**：是联合分布函数 ✓

**答案**：B、C都可以

---

**例题2**（矩形概率公式应用）：

已知二维随机变量 $(X, Y)$ 的联合分布函数为
$$F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$$

求 $P(0 < X \leq 1, 0 < Y \leq 2)$。

**解**：

利用矩形概率公式：
$$P(0 < X \leq 1, 0 < Y \leq 2) = F(1, 2) - F(1, 0) - F(0, 2) + F(0, 0)$$

计算各值：
- $F(1, 2) = (1 - e^{-1})(1 - e^{-2})$
- $F(1, 0) = 0$（因为 $y = 0$ 不在 $y > 0$ 范围内）
- $F(0, 2) = 0$（因为 $x = 0$ 不在 $x > 0$ 范围内）
- $F(0, 0) = 0$

所以：
$$P(0 < X \leq 1, 0 < Y \leq 2) = (1 - e^{-1})(1 - e^{-2})$$
$$= (1 - 0.3679)(1 - 0.1353) = 0.6321 \times 0.8647 \approx 0.5466$$

**答案**：$(1 - e^{-1})(1 - e^{-2}) \approx 0.5466$

---

**例题3**（求边缘分布函数）：

接例题2，求 $X$ 和 $Y$ 的边缘分布函数，并判断是否独立。

**解**：

**求边缘分布函数**：

$$F_X(x) = F(x, +\infty) = \lim_{y \to +\infty} F(x, y)$$

当 $x > 0$ 时：
$$F_X(x) = \lim_{y \to +\infty} (1 - e^{-x})(1 - e^{-y}) = (1 - e^{-x}) \cdot 1 = 1 - e^{-x}$$

当 $x \leq 0$ 时：
$$F_X(x) = 0$$

所以：
$$F_X(x) = \begin{cases} 1 - e^{-x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

同理：
$$F_Y(y) = \begin{cases} 1 - e^{-y}, & y > 0 \\ 0, & y \leq 0 \end{cases}$$

**判断独立性**：

验证：$F(x, y) = F_X(x) F_Y(y)$？

当 $x > 0, y > 0$ 时：
$$F_X(x) F_Y(y) = (1 - e^{-x})(1 - e^{-y}) = F(x, y)$$ ✓

当 $x \leq 0$ 或 $y \leq 0$ 时：
$$F_X(x) F_Y(y) = 0 = F(x, y)$$ ✓

**结论**：$X$ 和 $Y$ **相互独立**

---

#### 解题技巧

**1. 判断联合分布函数的步骤**

```
第1步：检查单调性（关于x和y都单调不减）
第2步：检查有界性（边界值是否正确）
第3步：检查右连续性
第4步：特殊情况下检查矩形概率非负
```

**2. 矩形概率公式的记忆**

```
P(x₁<X≤x₂, y₁<Y≤y₂) = F(x₂,y₂) - F(x₂,y₁) - F(x₁,y₂) + F(x₁,y₁)
```

**记忆技巧**：类似二重积分的区域分解，正负交替

**3. 边缘分布函数的求法**

- $F_X(x) = F(x, +\infty)$
- $F_Y(y) = F(+\infty, y)$

**4. 独立性判断**

- 验证 $F(x,y) = F_X(x)F_Y(y)$ 对所有 $x,y$ 成立

#### 典型例题（离散型）

**例题4**（完整流程）：

从装有3个红球、2个白球的袋中无放回地抽取2个球，设 $X$ = 第1次抽到红球的个数（0或1），$Y$ = 第2次抽到红球的个数（0或1）。求：
1. $(X, Y)$ 的联合分布律
2. 边缘分布律
3. 条件分布律 $P(X|Y=0)$
4. 判断 $X$ 和 $Y$ 是否独立

**解**：

**1. 求联合分布律（四步法）**

**第1步：确立表格维度**
- $X$ 的可能取值：0, 1
- $Y$ 的可能取值：0, 1
- 表格维度：$2 \times 2$

**第2步：利用约束化简**
- 无放回抽取，所有组合都可能
- 没有特殊约束，4个格子都需要计算

**第3步：求 $p_{ij}$**

总样本空间：从5个球中无放回抽2个，考虑顺序
- 总样本点数：$5 \times 4 = 20$

- $p_{00} = P(X=0, Y=0) = \frac{2 \times 1}{20} = 0.1$
- $p_{01} = P(X=0, Y=1) = \frac{2 \times 3}{20} = 0.3$
- $p_{10} = P(X=1, Y=0) = \frac{3 \times 2}{20} = 0.3$
- $p_{11} = P(X=1, Y=1) = \frac{3 \times 2}{20} = 0.3$

**第4步：验算 $\sum = 1$**
$$0.1 + 0.3 + 0.3 + 0.3 = 1.0$$ ✓

**联合分布律表格**：

| $X \setminus Y$ | 0 | 1 |
|----------------|---|---|
| 0 | 0.1 | 0.3 |
| 1 | 0.3 | 0.3 |

---

**2. 求边缘分布律**

**$X$ 的边缘分布律**（行和）：
- $P(X = 0) = 0.1 + 0.3 = 0.4$
- $P(X = 1) = 0.3 + 0.3 = 0.6$

**$Y$ 的边缘分布律**（列和）：
- $P(Y = 0) = 0.1 + 0.3 = 0.4$
- $P(Y = 1) = 0.3 + 0.3 = 0.6$

---

**3. 求条件分布律 $P(X|Y=0)$**

- $P(Y = 0) = 0.4$
- $P(X = 0 | Y = 0) = \frac{p_{00}}{p_{\cdot 0}} = \frac{0.1}{0.4} = 0.25$
- $P(X = 1 | Y = 0) = \frac{p_{10}}{p_{\cdot 0}} = \frac{0.3}{0.4} = 0.75$

---

**4. 判断独立性**

验证：$p_{ij} = p_{i\cdot} p_{\cdot j}$？

- $p_{00} = 0.1$，但 $p_{0\cdot} p_{\cdot 0} = 0.4 \times 0.4 = 0.16$
- $0.1 \neq 0.16$ ✗

**结论**：$X$ 和 $Y$ **不独立**

#### 典型例题（连续型）

**例题5**（完整流程）：

设二维随机变量 $(X, Y)$ 的联合概率密度为
$$f(x, y) = \begin{cases} kxy, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

求：
1. 常数 $k$
2. 边缘概率密度 $f_X(x)$ 和 $f_Y(y)$
3. 条件概率密度 $f_{Y|X}(y|x)$
4. $P(X + Y < 1)$
5. 判断 $X$ 和 $Y$ 是否独立

**解**：

**1. 求常数 $k$**

利用归一性：
$$\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$$

$$\int_{0}^{1} \int_{0}^{1} kxy \, dy \, dx = 1$$

$$k \int_{0}^{1} x \left[\frac{y^2}{2}\right]_{0}^{1} dx = k \int_{0}^{1} \frac{x}{2} dx = k \left[\frac{x^2}{4}\right]_{0}^{1} = \frac{k}{4} = 1$$

所以：$k = 4$

**答案**：$k = 4$

---

**2. 求边缘概率密度**

**$X$ 的边缘概率密度**：
$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy = \int_{0}^{1} 4xy \, dy$$
$$= 4x \left[\frac{y^2}{2}\right]_{0}^{1} = 2x, \quad 0 < x < 1$$

所以：
$$f_X(x) = \begin{cases} 2x, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$$

**$Y$ 的边缘概率密度**：
由对称性：
$$f_Y(y) = \begin{cases} 2y, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

---

**3. 求条件概率密度 $f_{Y|X}(y|x)$**

**第一步：声明分母不为0**
- $f_X(x) = 2x$，当 $0 < x < 1$ 时，$f_X(x) > 0$ ✓

**第二步：代入公式**
$$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)} = \frac{4xy}{2x} = 2y, \quad 0 < y < 1$$

所以：
$$f_{Y|X}(y|x) = \begin{cases} 2y, & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

**注意**：条件密度与 $x$ 无关，说明在已知 $X=x$ 的条件下，$Y$ 的分布不依赖于 $x$

---

**4. 求 $P(X + Y < 1)$**

$$P(X + Y < 1) = \iint_{x+y<1} f(x, y) \, dx \, dy$$

积分区域：$0 < x < 1$，$0 < y < 1-x$

$$P(X + Y < 1) = \int_{0}^{1} \int_{0}^{1-x} 4xy \, dy \, dx$$
$$= \int_{0}^{1} 4x \left[\frac{y^2}{2}\right]_{0}^{1-x} dx = \int_{0}^{1} 2x(1-x)^2 dx$$
$$= 2 \int_{0}^{1} x(1 - 2x + x^2) dx = 2 \int_{0}^{1} (x - 2x^2 + x^3) dx$$
$$= 2 \left[\frac{x^2}{2} - \frac{2x^3}{3} + \frac{x^4}{4}\right]_{0}^{1} = 2 \left(\frac{1}{2} - \frac{2}{3} + \frac{1}{4}\right)$$
$$= 2 \left(\frac{6 - 8 + 3}{12}\right) = 2 \cdot \frac{1}{12} = \frac{1}{6}$$

**答案**：$\frac{1}{6}$

---

**5. 判断独立性**

验证：$f(x, y) = f_X(x) f_Y(y)$？

$$f_X(x) f_Y(y) = 2x \cdot 2y = 4xy = f(x, y)$$ ✓

**结论**：$X$ 和 $Y$ **相互独立**

#### 解题技巧

**1. 离散型四步法**

```
第1步：确立表格维度（找出所有可能取值）
第2步：利用约束化简（排除不可能组合）
第3步：求Pij（古典概型/独立性/条件概率）
第4步：验算Σ=1（检查归一性）
```

---

**2. 连续型解题流程**

```
第1步：确定参数（利用归一性）
第2步：求边缘密度（对另一个变量积分）
第3步：求条件密度（先声明分母≠0，再代入公式）
第4步：计算概率（二重积分，画图确定积分限）
第5步：判断独立性（f(x,y)=f_X(x)f_Y(y)？）
```

---

**3. 独立性快速判断**

**离散型**：
- 检查是否有0的格子（但整行整列不为0）→ 一定不独立
- 验证 $p_{ij} = p_{i\cdot} p_{\cdot j}$

**连续型**：
- 检查定义域是否为矩形 → 不是矩形一定不独立
- 验证 $f(x,y) = f_X(x) f_Y(y)$

---

**4. 常见错误警示**

**⚠️ 错误1**：忘记验算归一性
- 离散型：必须检查 $\sum p_{ij} = 1$
- 连续型：必须检查 $\iint f(x,y)dxdy = 1$

**⚠️ 错误2**：边缘密度积分区间错误
- 必须考虑联合密度的非零区域
- 不能盲目地从 $-\infty$ 积分到 $+\infty$

**⚠️ 错误3**：条件密度忘记声明分母不为0
- 必须在解答中明确声明 $f_X(x) > 0$ 或 $f_Y(y) > 0$

**⚠️ 错误4**：二重积分积分限错误
- 必须先画图确定积分区域
- 注意积分次序的选择
