## 1.1 随机变量的概念

### 一、引入随机变量的原因

**问题**：随机试验的结果不一定是数，如何定量研究？

**举例**：
- 抛硬币：{正面, 反面} → 不是数
- 产品质量检查：{合格, 不合格} → 不是数

**解决方案**：将随机试验的结果**数量化**

### 二、随机变量的定义 ⭐⭐⭐

**定义2.1**：设随机试验的样本空间为 $S = \{e\}$，如果对于每一个样本点 $e \in S$，都有一个**实数** $X(e)$ 与之对应，则称 $X = X(e)$ 为**随机变量**（Random Variable）。

**核心理解**：
> - 随机变量 $X$ 是**函数**，定义域是样本空间 $S$，值域是实数集
> - $X$ 的取值依赖于随机试验的结果
> - 试验前，$X$ 取什么值是**不确定**的（随机的）
> - 试验后，$X$ 的取值是**确定**的

**重要辨析**：
> **随机变量是随机的，概率是死的，很不一样！**
> 
> - **随机变量 $X$**：取值不确定，依赖于随机试验的结果
> - **概率 $P$**：是一个确定的数值，描述事件发生的可能性大小
> - $X$ 是研究对象，$P$ 是研究工具

### 三、随机变量的分类

#### 1. 离散型随机变量
- 可能取值是**有限个**或**可列无限个**
- 例如：掷骰子的点数 $X \in \{1, 2, 3, 4, 5, 6\}$

#### 2. 连续型随机变量
- 可能取值充满某个**区间**
- 例如：某地区降雨量 $X \in [0, +\infty)$

#### 3. 混合型随机变量
- 既有离散部分，又有连续部分
- 考研一般不考

### 四、随机变量的表示

**约定**：
- 用大写字母 $X, Y, Z$ 表示随机变量
- 用小写字母 $x, y, z$ 表示随机变量的取值

**随机事件的数量化表示**：
- $\{X = k\}$：随机变量 $X$ 取值为 $k$ 的事件
- $\{X \leq x\}$：随机变量 $X$ 取值不超过 $x$ 的事件
- $\{a < X \leq b\}$：随机变量 $X$ 取值在 $(a, b]$ 内的事件

### 五、为什么要研究随机变量？

**优势**：
1. **统一性**：无论样本空间是什么，都转化为实数研究
2. **运算性**：可以对随机变量进行四则运算
3. **一般性**：可以研究随机变量的函数

## 1.2 分布函数的定义和性质

### 一、分布函数的定义 ⭐⭐⭐

**定义2.2**：设 $X$ 是一个随机变量，$x$ 是任意实数，称函数

$$F(x) = P(X \leq x), \quad -\infty < x < +\infty$$

为随机变量 $X$ 的**分布函数**（Distribution Function）。

---

**⭐⭐⭐⭐ 分布函数定义的极端重要性**：

> **分布函数是整个概率论的核心概念之一！**
>
> 它是连接"随机变量"和"概率计算"的桥梁，是研究随机变量的**最根本工具**。

#### 1. 直观理解

**分布函数 $F(x)$ 的物理意义**：
- 想象一个随机变量 $X$（比如某地区一天的降雨量）
- $F(x)$ 表示："降雨量不超过 $x$ 毫米"这个事件的概率
- 当 $x$ 从 $-\infty$ 逐渐增大到 $+\infty$ 时，$F(x)$ 从 0 逐渐增加到 1
- 这就是**累积概率**的过程

**举例说明**：
- $F(0) = P(X \leq 0)$：降雨量为 0 或负数（不可能）的概率，约为 0
- $F(50) = P(X \leq 50)$：降雨量不超过 50 毫米的概率，比如 0.8
- $F(100) = P(X \leq 100)$：降雨量不超过 100 毫米的概率，比如 0.95
- $F(+\infty) = P(X \leq +\infty)$：降雨量不超过正无穷的概率，必然为 1

#### 2. 核心思想

**为什么分布函数如此重要？**

1. **统一性**：
   - 无论是离散型还是连续型随机变量，都可以用分布函数来描述
   - 提供了一个**统一的研究框架**

2. **完备性**：
   - 分布函数 $F(x)$ **完整地刻画**了随机变量的概率分布
   - 知道 $F(x)$，就能计算 $X$ 在**任何区间**上的概率

3. **可计算性**：
   - 利用分布函数，可以方便地计算各种区间概率
   - $P(a < X \leq b) = F(b) - F(a)$

4. **可逆性**：
   - 随机变量 $\iff$ 分布函数 $\iff$ 概率分布/密度
   - 三者等价，知道一个就能确定另外两个

#### 3. 与随机事件的关系

**分布函数是概率的"积分"形式**：
- 第一章：研究单个事件的概率 $P(A)$
- 第二章：研究随机变量落在区间上的概率 $P(X \leq x)$
- 分布函数将"点"的概率累积成"区间"的概率

**重要转化**：
$$\text{随机变量 } X \xrightarrow{\text{定义分布函数}} F(x) = P(X \leq x) \xrightarrow{\text{求导/求差}} \text{概率分布/密度}$$

#### 4. 几何意义

**分布函数图像**：
```
F(x)
  |
1 +                                    ─────────
  |                                /
  |                            /
  |                        /
  |                    /
0 +────────────────────────────────────── x
 -∞                                  +∞
```
- 图像从 $(-\infty, 0)$ 开始
- 单调上升到 $(+\infty, 1)$
- 离散型：阶梯状（跳跃点处有概率质量）
- 连续型：光滑曲线（处处连续）

#### 5. 考研中的考查方式

**选择题**：
- 判断某函数是否为分布函数（利用四大性质）
- 利用分布函数计算区间概率
- 分布函数与概率密度的关系

**填空题**：
- 已知分布函数，求某点概率 $P(X = a)$
- 已知概率密度，求分布函数

**大题**：
- 求随机变量的分布函数
- 利用分布函数求期望、方差
- 随机变量函数的分布

## 1.3 离散型随机变量 ⭐⭐⭐

### 一、离散型随机变量的定义

**定义2.3**：如果随机变量 $X$ 的所有可能取值是**有限个**或**可列无限个**，则称 $X$ 为**离散型随机变量**。

**核心理解**：
> - **有限个**：取值个数是有限的，如掷骰子 $X \in \{1,2,3,4,5,6\}$
> - **可列无限个**：取值个数是无限的，但可以按一定顺序排列，如 $X \in \{0,1,2,3,\cdots\}$
> - **不可列**：取值充满某个区间，这是连续型随机变量

**常见例子**：
1. 掷骰子的点数：$X \in \{1,2,3,4,5,6\}$ （有限个）
2. 抛硬币$次正面朝上的次数：$X \in \{0,1,2,\cdots,n\}$ （有限个）
3. 某电话交换台每分钟接到的呼叫次数：$X \in \{0,1,2,\cdots\}$ （可列无限个）
4. 某产品的不合格品数：$X \in \{0,1,2,\cdots\}$ （可列无限个）

---

### 二、分布律（概率分布）⭐⭐⭐

#### 1. 分布律的定义

**定义2.4**：设离散型随机变量 $X$ 的所有可能取值为 $x_1, x_2, \cdots, x_n, \cdots$，称

$$P(X = x_k) = p_k, \quad k = 1, 2, \cdots$$

为 $X$ 的**分布律**（Probability Distribution）或**概率分布**。

**分布律的表示方法**：

**表格形式**（最常用）：

| $X$ | $x_1$ | $x_2$ | $\cdots$ | $x_k$ | $\cdots$ |
|-----|-------|-------|---------|-------|--------|
| $P$ | $p_1$ | $p_2$ | $\cdots$ | $p_k$ | $\cdots$ |

**公式形式**：
$$P(X = x_k) = p_k, \quad k = 1, 2, \cdots$$

**举例**：

抛一枚均匀硬币，$X$ = 正面朝上的次数：

| $X$ | 0 | 1 |
|-----|---|---|
| $P$ | 0.5 | 0.5 |

---

#### 2. 分布律的性质 ⭐⭐⭐

**性质1：非负性**
$$p_k \geq 0, \quad k = 1, 2, \cdots$$

**性质2：归一性**
$$\sum_{k=1}^{\infty} p_k = 1$$

**直观理解**：
- 非负性：概率不能是负数
- 归一性：所有可能取值的概率之和为1（必然事件）

**重要应用**：
1. **判断某表格是否为分布律**：
   - 检查所有 $p_k \geq 0$
   - 检查 $\sum p_k = 1$
   - 两个条件都满足才是分布律

2. **求未知参数**：
   - 利用 $\sum p_k = 1$ 建立方程
   - 解方程求出参数

**例题**：

设随机变量 $X$ 的分布律为：

| $X$ | -1 | 0 | 1 | 2 |
|-----|----|---|---|---|
| $P$ | 0.2 | $a$ | 0.3 | 0.1 |

求 $a$ 的值。

**解**：
- 由归一性：$0.2 + a + 0.3 + 0.1 = 1$
- 解得：$a = 0.4$

**验证**：$0.2 + 0.4 + 0.3 + 0.1 = 1$ ✓

**答案**：$a = 0.4$

---

#### 3. 分布律的计算

**求离散型随机变量的分布律步骤**：

1. **确定所有可能取值**：$x_1, x_2, \cdots, x_n$
2. **计算每个取值的概率**：$p_k = P(X = x_k)$
3. **验证**：$\sum p_k = 1$
4. **列表表示**

**例题**：

从1,2,3,4,5中随机抽取3个数，$X$ = 抽到的最大数，求 $X$ 的分布律。

**解**：
1. **确定取值**：$X$ 的可能取值为 3, 4, 5
   - 最小可能是 3（抽到1,2,3）
   - 最大可能是 5（抽到3,4,5或1,4,5等）

2. **计算概率**：
   - 总样本点数：$C_5^3 = 10$
   - $P(X=3)$：最大数是3，只能抽到{1,2,3}，$P(X=3) = \frac{1}{10}$
   - $P(X=4)$：最大数是4，从{1,2,3}中再选2个，$C_3^2 = 3$，$P(X=4) = \frac{3}{10}$
   - $P(X=5)$：最大数是5，从{1,2,3,4}中再选2个，$C_4^2 = 6$，$P(X=5) = \frac{6}{10}$

3. **验证**：$\frac{1}{10} + \frac{3}{10} + \frac{6}{10} = 1$ ✓

4. **分布律**：

| $X$ | 3 | 4 | 5 |
|-----|---|---|---|
| $P$ | 0.1 | 0.3 | 0.6 |

---

### 三、利用分布律计算概率 ⭐⭐

#### 1. 基本公式

$$P(X \in D) = \sum_{x_k \in D} p_k$$

即：事件 $\{X \in D\}$ 的概率等于 $D$ 中所有取值点的概率之和。

#### 2. 常见区间概率

1. **单点概率**：$P(X = x_k) = p_k$（直接从分布律读取）

2. **区间概率**：$P(a \leq X \leq b) = \sum_{a \leq x_k \leq b} p_k$

3. **不等式概率**：
   - $P(X < a) = \sum_{x_k < a} p_k$
   - $P(X \leq a) = \sum_{x_k \leq a} p_k$
   - $P(X > a) = \sum_{x_k > a} p_k = 1 - P(X \leq a)$
   - $P(X \geq a) = \sum_{x_k \geq a} p_k = 1 - P(X < a)$

**例题**：

已知 $X$ 的分布律：

| $X$ | -1 | 0 | 1 | 2 | 3 |
|-----|----|---|---|---|---|
| $P$ | 0.1 | 0.2 | 0.3 | 0.25 | 0.15 |

求：
1. $P(X \leq 1)$
2. $P(0 < X \leq 2)$
3. $P(X \geq 1)$

**解**：
1. $P(X \leq 1) = P(X=-1) + P(X=0) + P(X=1) = 0.1 + 0.2 + 0.3 = 0.6$

2. $P(0 < X \leq 2) = P(X=1) + P(X=2) = 0.3 + 0.25 = 0.55$

3. $P(X \geq 1) = P(X=1) + P(X=2) + P(X=3) = 0.3 + 0.25 + 0.15 = 0.7$
   - 或：$P(X \geq 1) = 1 - P(X < 1) = 1 - (0.1 + 0.2) = 0.7$

**答案**：1. 0.6；2. 0.55；3. 0.7

### 四、离散型随机变量的分布函数

#### 1. 分布函数的求法 ⭐⭐⭐

**公式**：
$$F(x) = P(X \leq x) = \sum_{x_k \leq x} p_k$$

**⭐⭐⭐ 分布函数计算的核心技巧：寻找关键点**

> **计算分布函数的第一步，也是最重要的一步：找到所有关键点！**
>
> 关键点就是离散型随机变量的所有**取值点**，这些点是分布函数发生**跳跃**的位置。

**计算步骤**：

**第一步：寻找关键点** 最重要
- 关键点 = 随机变量的所有可能取值 $x_1, x_2, \cdots, x_n$
- 将这些关键点按从小到大排序：$x_1 < x_2 < \cdots < x_n$
- 关键点将数轴分成 $n+1$ 个区间

**第二步：确定分段区间**（左闭右开原则）
- 区间1：$(-\infty, x_1)$
- 区间2：$[x_1, x_2)$
- 区间3：$[x_2, x_3)$
- ...
- 区间n：$[x_{n-1}, x_n)$
- 区间n+1：$[x_n, +\infty)$

**为什么左闭右开？**
- 左闭：$x_k \leq x$，包含关键点 $x_k$
- 右开：$x < x_{k+1}$，不包含下一个关键点
- 这样保证在每个关键点处**右连续**

**第三步：逐段计算累积概率**
- 在区间 $[x_k, x_{k+1})$ 内：$F(x) = p_1 + p_2 + \cdots + p_k$
- 累加到当前关键点为止的所有概率

**第四步：写出分段函数**
- 检查 $F(-\infty)=0$，$F(+\infty)=1$
- 检查右连续性

---

**关键点的作用**：

1. **分段点**：关键点将数轴分成若干区间
2. **跳跃点**：分布函数在每个关键点处跳跃
3. **概率质量点**：每个关键点对应一个概率 $p_k$

**图示理解**：

```
关键点：x1      x2      x3      x4
        |       |       |       |
        ↓       ↓       ↓       ↓
F(x)   0  ─────┴───────┴────────────── 1
              p1      p1+p2   p1+p2+p3
```

- 在 $x_1$ 处跳跃 $p_1$
- 在 $x_2$ 处跳跃 $p_2$
- 在 $x_3$ 处跳跃 $p_3$
- 关键点之间的区间内，$F(x)$ 是常数

---

**特点**：
- 分布函数是**阶梯函数**
- 在每个取值点 $x_k$ 处有**跳跃**
- 跳跃高度 = $P(X = x_k) = p_k$
- **右连续**：$F(x_k+0) = F(x_k)$

#### 2. 分布函数与分布律的关系

**从分布律到分布函数**：
$$F(x) = \sum_{x_k \leq x} p_k \quad \text{（累加）}$$

**从分布函数到分布律**：
$$p_k = F(x_k) - F(x_k-0) \quad \text{（跳跃高度）}$$

**例题**：

已知 $X$ 的分布律：

| $X$ | 0 | 1 | 2 |
|-----|---|---|---|
| $P$ | 0.3 | 0.5 | 0.2 |

求分布函数 $F(x)$。

**解**：
- 当 $x < 0$ 时：$F(x) = 0$
- 当 $0 \leq x < 1$ 时：$F(x) = P(X=0) = 0.3$
- 当 $1 \leq x < 2$ 时：$F(x) = P(X=0) + P(X=1) = 0.3 + 0.5 = 0.8$
- 当 $x \geq 2$ 时：$F(x) = 0.3 + 0.5 + 0.2 = 1$

所以：
$$F(x) = \begin{cases}
0, & x < 0 \\
0.3, & 0 \leq x < 1 \\
0.8, & 1 \leq x < 2 \\
1, & x \geq 2
\end{cases}$$

| 对比项 | **离散型** | **连续型** |

### 1.2 分布函数的定义和性质 ⭐⭐⭐

> **四大性质是分布函数的核心特征，考研必考！**
>
> 判断一个函数是否为分布函数，就是看它是否满足这四大性质。

#### 性质1：单调不减性

若 $x_1 < x_2$，则 $F(x_1) \leq F(x_2)$

**证明**：
- 因为 $\{X \leq x_1\} \subset \{X \leq x_2\}$
- 由概率的单调性：$P(X \leq x_1) \leq P(X \leq x_2)$
- 即 $F(x_1) \leq F(x_2)$

**直观理解**：
- 随着 $x$ 增大，区间 $(-\infty, x]$ 越来越大
- 包含的样本点越来越多
- 所以概率不会减小，只会增加或不变

---

#### 性质2：有界性

$$0 \leq F(x) \leq 1$$
$$\lim_{x \to -\infty} F(x) = F(-\infty) = 0$$
$$\lim_{x \to +\infty} F(x) = F(+\infty) = 1$$

**直观理解**：
- $F(-\infty) = 0$：$X$ 小于负无穷的概率为0（不可能事件）
- $F(+\infty) = 1$：$X$ 小于正无穷的概率为1（必然事件）
- 任何 $x$ 处的概率都在 $[0, 1]$ 之间

**考研应用**：
- 判断某函数是否为分布函数时，首先检查 $F(-\infty)=0$ 和 $F(+\infty)=1$
- 如果不满足，直接排除

---

#### 性质3：右连续性 ⭐⭐⭐⭐非常重要

$$F(x+0) = F(x)$$

即分布函数 $F(x)$ 在每个点处**右连续**。

**⭐⭐⭐⭐ 右连续性的极端重要性**：

> **右连续性是分布函数最容易被忽视但最重要的性质！**
>
> 它揭示了分布函数在跳跃点处的行为，是理解离散型随机变量的关键。

##### 1. 什么是右连续？

**定义**：函数 $F(x)$ 在点 $x_0$ 处右连续，是指：
$$\lim_{x \to x_0^+} F(x) = F(x_0)$$

即：从右侧趋近 $x_0$ 时的极限等于函数值。

**对比**：
- **右连续**：$F(x+0) = F(x)$ ✓ 分布函数一定满足
- **左连续**：$F(x-0) = F(x)$ ✗ 分布函数不一定满足

##### 2. 为什么分布函数是右连续的？

**直观理解**：

考虑 $F(x) = P(X \leq x)$：
- 当 $x$ 从右侧趋近 $x_0$ 时，$F(x) = P(X \leq x)$
- 因为 $x > x_0$，所以 $\{X \leq x_0\} \subset \{X \leq x\}$
- 当 $x \to x_0^+$ 时，$\{X \leq x\} \to \{X \leq x_0\}$
- 所以 $\lim_{x \to x_0^+} F(x) = F(x_0)$

**关键点**：
- 分布函数定义中使用的是 $X \leq x$（包含等号）
- 这保证了在跳跃点处取的是**右边的值**
- 如果是 $X < x$（不包含等号），就是左连续了

##### 3. 左极限 $F(x-0)$ 的含义

**左极限**：
$$F(x-0) = \lim_{t \to x^-} F(t) = P(X < x)$$

**重要区别**：
- $F(x) = P(X \leq x)$：包含 $x$ 点
- $F(x-0) = P(X < x)$：不包含 $x$ 点

**两者之差**：
$$F(x) - F(x-0) = P(X \leq x) - P(X < x) = P(X = x)$$

##### 4. 离散型vs连续型的右连续性

**离散型随机变量**：
```
F(x)
  |
1 +             ┌─────
  |         ┌───┤
  |     ┌───┤
  | ┌───┤
0 +─┴───┴───┴───┴─── x
    x1  x2  x3
```
- $F(x)$ 是**阶梯函数**
- 在每个取值点 $x_k$ 处有**跳跃**
- 跳跃高度 = $P(X = x_k)$
- **在跳跃点处右连续**：取的是上面的值

**举例**：
- 在 $x_1$ 处，$F(x_1) = P(X \leq x_1)$
- 左极限 $F(x_1-0) = P(X < x_1)$
- 跳跃高度 $F(x_1) - F(x_1-0) = P(X = x_1)$

**连续型随机变量**：
```
F(x)
  |
1 +                        /
  |                    /
  |                /
  |            /
0 +────────────/───────── x
```
- $F(x)$ 是**连续函数**
- 处处连续，没有跳跃
- $F(x+0) = F(x-0) = F(x)$

##### 5. 考研中的应用

**考点1：求单点概率**

$$P(X = a) = F(a) - F(a-0)$$

- 离散型：$F(a-0) \neq F(a)$，所以 $P(X=a) > 0$
- 连续型：$F(a-0) = F(a)$，所以 $P(X=a) = 0$

**考点2：判断分布函数**

题目给出一个分段函数，判断是否为分布函数：
1. 检查各段是否单调不减
2. 检查 $F(-\infty)=0$，$F(+\infty)=1$
3. **重点检查分段点处是否右连续**

**例题**：判断下列函数是否为分布函数：
$$F(x) = \begin{cases}
0, & x < 0 \\
0.3, & 0 \leq x < 1 \\
0.8, & 1 \leq x < 2 \\
1, & x \geq 2
\end{cases}$$

**解**：
- 单调性：0 → 0.3 → 0.8 → 1，单调不减 ✓
- 有界性：$F(-\infty)=0$，$F(+\infty)=1$ ✓
- 右连续性：
  - $x=0$ 处：$F(0)=0.3$，$\lim_{x\to 0^+} F(x)=0.3$ ✓
  - $x=1$ 处：$F(1)=0.8$，$\lim_{x\to 1^+} F(x)=0.8$ ✓
  - $x=2$ 处：$F(2)=1$，$\lim_{x\to 2^+} F(x)=1$ ✓
- 结论：是分布函数 ✓

**考点3：求区间概率**

利用右连续性确定区间端点的处理：
- $P(a < X \leq b) = F(b) - F(a)$ （不需要考虑连续性）
- $P(a \leq X \leq b) = F(b) - F(a-0)$ （需要考虑左极限）

##### 6. 常见错误

**错误1**：认为分布函数一定连续
- ✗ 离散型的分布函数不连续（有跳跃）
- ✓ 但一定右连续

**错误2**：混淆左极限和右极限
- $F(x+0)$：右极限 = $F(x)$ （右连续）
- $F(x-0)$：左极限 ≠ $F(x)$ （离散型在跳跃点）

**错误3**：计算 $P(X=a)$ 时忘记用左极限
- ✗ $P(X=a) = F(a)$
- ✓ $P(X=a) = F(a) - F(a-0)$

---

#### 性质4：区间概率公式 ⭐常用

$$P(a < X \leq b) = F(b) - F(a)$$

**推导**：
- $\{X \leq b\} = \{X \leq a\} \cup \{a < X \leq b\}$
- 两个事件互斥
- $P(X \leq b) = P(X \leq a) + P(a < X \leq b)$
- 所以 $P(a < X \leq b) = F(b) - F(a)$

**重要说明**：
- 这是**最常用**的区间概率公式
- 注意区间是**左开右闭** $(a, b]$
- 其他区间的概率需要利用右连续性调整

### 三、区间概率的各种表示

利用分布函数 $F(x)$，可以计算各种区间概率：

1. **$P(a < X \leq b) = F(b) - F(a)$** ⭐最常用

2. **$P(a \leq X \leq b) = F(b) - F(a-0)$**
   - 离散型：$F(a-0) \neq F(a)$（有跳跃）
   - 连续型：$F(a-0) = F(a)$（连续）

3. **$P(a < X < b) = F(b-0) - F(a)$**

4. **$P(a \leq X < b) = F(b-0) - F(a-0)$**

5. **$P(X = a) = F(a) - F(a-0)$**
   - 离散型：可能 $>0$（在跳跃点）
   - 连续型：$=0$（处处连续）

**重要结论**：
> **连续型随机变量在任意单点的概率为0**
> $$P(X = a) = 0$$
> 
> 因此，对于连续型随机变量：
> $$P(a < X < b) = P(a \leq X < b) = P(a < X \leq b) = P(a \leq X \leq b)$$

### 三、求分布函数的方法 ⭐⭐⭐

#### 1. 离散型随机变量求分布函数

**步骤**：
1. 确定随机变量的所有可能取值 $x_1 < x_2 < \cdots < x_n < \cdots$
2. 求出分布律 $P(X = x_k) = p_k$
3. 分段写出分布函数：
   $$F(x) = \sum_{x_k \leq x} p_k$$

**关键**：
- 在每个区间 $(x_k, x_{k+1}]$ 内，$F(x)$ 是常数
- 在取值点 $x_k$ 处有跳跃
- **区间左闭右开**：$(x_k, x_{k+1}]$

**举例**：

设 $X$ 的分布律为：
$$P(X=0)=0.2, \quad P(X=1)=0.5, \quad P(X=2)=0.3$$

求分布函数 $F(x)$。

**解**：
- 当 $x < 0$ 时：$F(x) = 0$
- 当 $0 \leq x < 1$ 时：$F(x) = P(X=0) = 0.2$
- 当 $1 \leq x < 2$ 时：$F(x) = P(X=0) + P(X=1) = 0.2 + 0.5 = 0.7$
- 当 $x \geq 2$ 时：$F(x) = P(X=0) + P(X=1) + P(X=2) = 1$

所以：
$$F(x) = \begin{cases}
0, & x < 0 \\
0.2, & 0 \leq x < 1 \\
0.7, & 1 \leq x < 2 \\
1, & x \geq 2
\end{cases}$$

**注意区间的写法**：
- 每个区间都是**左闭右开** $[x_k, x_{k+1})$
- 最后一个区间是 $[x_n, +\infty)$
- 这样保证在每个跳跃点处右连续

---

#### 2. 连续型随机变量求分布函数

**步骤**：
1. 已知概率密度函数 $f(x)$
2. 利用积分求分布函数：
   $$F(x) = \int_{-\infty}^{x} f(t) dt$$

**关键**：
- 分段积分，注意积分下限
- 利用 $F(+\infty) = 1$ 确定常数
- 利用右连续性确定分段点处的值

**举例**：

已知 $X$ 的概率密度为：
$$f(x) = \begin{cases}
2x, & 0 < x < 1 \\
0, & \text{其他}
\end{cases}$$

求分布函数 $F(x)$。

**解**：
- 当 $x \leq 0$ 时：$F(x) = \int_{-\infty}^{x} 0 dt = 0$
- 当 $0 < x < 1$ 时：$F(x) = \int_{-\infty}^{0} 0 dt + \int_{0}^{x} 2t dt = 0 + t^2|_0^x = x^2$
- 当 $x \geq 1$ 时：$F(x) = \int_{-\infty}^{0} 0 dt + \int_{0}^{1} 2t dt + \int_{1}^{x} 0 dt = 0 + 1 + 0 = 1$

所以：
$$F(x) = \begin{cases}
0, & x \leq 0 \\
x^2, & 0 < x < 1 \\
1, & x \geq 1
\end{cases}$$

**验证右连续性**：
- $x=0$ 处：$F(0)=0$，$\lim_{x\to 0^+} F(x) = 0^2 = 0$ ✓
- $x=1$ 处：$F(1)=1$，$\lim_{x\to 1^-} F(x) = 1^2 = 1$ ✓

---

#### 3. ⭐ 区域左闭右开原则

**核心原则**：
> 在分段写出分布函数时，区间通常采用**左闭右开**的形式！
>
> 这是为了保证分布函数的**右连续性**。

**标准写法**：
$$F(x) = \begin{cases}
F_1(x), & x < x_1 \\
F_2(x), & x_1 \leq x < x_2 \\
F_3(x), & x_2 \leq x < x_3 \\
\cdots \\
F_n(x), & x \geq x_{n-1}
\end{cases}$$

**为什么左闭右开？**

考虑在分段点 $x_k$ 处：
- 左闭：$x_k \leq x$，包含 $x_k$ 点
- 右开：$x < x_{k+1}$，不包含 $x_{k+1}$ 点
- 这样保证在 $x_k$ 处取的是**右边的值**，即右连续

**反例**（错误的写法）：

如果写成左开右闭：
$$F(x) = \begin{cases}
0, & x < 0 \\
0.2, & 0 < x \leq 1 \quad \text{✗ 错误！}\\
0.7, & 1 < x \leq 2 \\
1, & x > 2
\end{cases}$$

问题：
- 在 $x=0$ 处没有定义 $F(0)$
- 在 $x=1$ 处，$F(1)=0.2$，但 $\lim_{x\to 1^+} F(x) = 0.7$，不右连续 

**正确理解**：
- 左闭右开是为了**保证右连续性**
- 在每个分段点处，函数值等于右极限
- 这与分布函数的定义 $F(x) = P(X \leq x)$ 是一致的

---

#### 4. 考研常见题型

**题型1：已知分布律，求分布函数**

步骤：
1. 确定所有取值点 $x_1 < x_2 < \cdots < x_n$
2. 按左闭右开原则分段
3. 累加概率：$F(x) = \sum_{x_k \leq x} p_k$

**题型2：已知概率密度，求分布函数**

步骤：
1. 确定密度的非零区间
2. 分段积分：$F(x) = \int_{-\infty}^{x} f(t) dt$
3. 利用连续性确定常数

**题型3：已知分布函数，反求参数**

利用：
- $F(-\infty) = 0$
- $F(+\infty) = 1$
- 右连续性：$F(x_k+0) = F(x_k)$

---

**⭐⭐⭐ 重要结论：分布函数和分布律可以互相推出**

> **对于离散型随机变量，分布函数和分布律是一一对应的！**
>
> 知道其中一个，就能唯一确定另一个。它们包含了**完全相同的信息**。

#### 从分布律推出分布函数

**公式**：
$$F(x) = P(X \leq x) = \sum_{x_k \leq x} p_k$$

**步骤**：
1. 确定所有取值点 $x_1 < x_2 < \cdots < x_n$
2. 对任意 $x$，找到所有满足 $x_k \leq x$ 的取值点
3. 将这些取值点的概率累加

**几何理解**：
- 分布函数是分布律的"累积"
- 从左到右，逐个累加概率
- 形成阶梯函数

**例题**：

已知 $X$ 的分布律：
$$P(X=-1)=0.2, \quad P(X=0)=0.5, \quad P(X=1)=0.3$$

求分布函数 $F(x)$。

**解**：
- 当 $x < -1$ 时：$F(x) = 0$
- 当 $-1 \leq x < 0$ 时：$F(x) = P(X=-1) = 0.2$
- 当 $0 \leq x < 1$ 时：$F(x) = P(X=-1) + P(X=0) = 0.2 + 0.5 = 0.7$
- 当 $x \geq 1$ 时：$F(x) = 0.2 + 0.5 + 0.3 = 1$

所以：
$$F(x) = \begin{cases}
0, & x < -1 \\
0.2, & -1 \leq x < 0 \\
0.7, & 0 \leq x < 1 \\
1, & x \geq 1
\end{cases}$$

---

#### 从分布函数推出分布律

**公式**：
$$p_k = P(X = x_k) = F(x_k) - F(x_k-0)$$

**步骤**：
1. 找到分布函数的**跳跃点**（不连续点）
2. 每个跳跃点就是一个取值点 $x_k$
3. 跳跃高度就是该点的概率 $p_k$

**几何理解**：
- 分布律是分布函数的"差分"
- 在每个跳跃点处，计算跳跃高度
- 跳跃高度 = 右极限 - 左极限

**例题**：

已知 $X$ 的分布函数：
$$F(x) = \begin{cases}
0, & x < -1 \\
0.2, & -1 \leq x < 0 \\
0.7, & 0 \leq x < 1 \\
1, & x \geq 1
\end{cases}$$

求分布律。

**解**：
- 找到跳跃点：$x = -1, 0, 1$
- 计算跳跃高度：
  - $x = -1$：$P(X=-1) = F(-1) - F(-1-0) = 0.2 - 0 = 0.2$
  - $x = 0$：$P(X=0) = F(0) - F(0-0) = 0.7 - 0.2 = 0.5$
  - $x = 1$：$P(X=1) = F(1) - F(1-0) = 1 - 0.7 = 0.3$

所以分布律为：
$$P(X=-1)=0.2, \quad P(X=0)=0.5, \quad P(X=1)=0.3$$

---

#### 互相推出的考研应用

**考点1：已知分布函数求概率**

$$P(X = x_k) = F(x_k) - F(x_k-0)$$

**例题**：

已知分布函数：
$$F(x) = \begin{cases}
0, & x < 0 \\
0.3, & 0 \leq x < 1 \\
0.8, & 1 \leq x < 2 \\
1, & x \geq 2
\end{cases}$$

求 $P(X=1)$。

**解**：
- $P(X=1) = F(1) - F(1-0) = 0.8 - 0.3 = 0.5$

**答案**：0.5

---

**考点2：已知分布律求分布函数**

这是最常见的基础题，务必熟练掌握累加方法。

**考点3：判断离散型随机变量**

如果分布函数是阶梯函数（分段常数），则一定是离散型随机变量。
- 跳跃点 = 取值点
- 跳跃高度 = 概率

---

#### 总结：分布函数与分布律的关系

| 方向 | 公式 | 操作 | 类比 |
|------|------|------|------|
| **分布律 → 分布函数** | $F(x) = \sum_{x_k \leq x} p_k$ | **累加** | 积分 |
| **分布函数 → 分布律** | $p_k = F(x_k) - F(x_k-0)$ | **差分** | 求导 |

**核心思想**：
> - 分布函数是分布律的"积分"（累积）
> - 分布律是分布函数的"微分"（差分）
> - 两者等价，包含了相同的信息
> - 知道一个就能推出另一个

**考研技巧**：
- 看到分布函数求概率 → 找跳跃点，算跳跃高度
- 看到分布律求分布函数 → 从左到右累加
- 判断离散型 → 看分布函数是否有跳跃

**例题**：

设随机变量 $X$ 的分布函数为：
$$F(x) = \begin{cases}
0, & x < 0 \\
A + Be^{-2x}, & x \geq 0
\end{cases}$$

求常数 $A$ 和 $B$。

**解**：
- 由 $F(+\infty) = 1$：$\lim_{x\to +\infty} (A + Be^{-2x}) = A = 1$
- 由右连续性（$x=0$ 处）：$F(0) = A + B = F(0+0)$
  - 但 $F(0) = A + B$（由定义）
  - $\lim_{x\to 0^+} F(x) = A + B$
  - 需要利用 $F(0) = P(X \leq 0)$
  - 更简单：利用 $F(0-0) = 0$，右连续 $\implies F(0) = 0$
  - 所以 $A + B = 0 \implies B = -1$

**答案**：$A = 1$，$B = -1$

验证：$F(x) = 1 - e^{-2x}$（$x \geq 0$），满足 $F(0)=0$，$F(+\infty)=1$ ✓

### 四、分布函数、分布律、概率密度的对比 ⭐⭐⭐

> **三种描述方式各有优缺点，理解它们的关系是掌握本章的关键！**

#### 1. 三种描述方式的比较

| 对比项 | **分布函数** $F(x)$ | **分布律** $P(X=x_k)=p_k$ | **概率密度** $f(x)$ |
|--------|-------------------|------------------------|------------------|
| **适用对象** | **所有随机变量**（普遍适用） | **仅离散型** | **仅连续型** |
| **定义** | $F(x)=P(X \leq x)$ | $p_k = P(X=x_k)$ | $f(x)=F'(x)$ |
| **性质** | 单调不减、右连续、$F(-\infty)=0$、$F(+\infty)=1$ | $p_k \geq 0$，$\sum p_k = 1$ | $f(x) \geq 0$，$\int_{-\infty}^{+\infty} f(x)dx = 1$ |
| **计算概率** | $P(a<X\leq b)=F(b)-F(a)$ | $P(X \in D)=\sum_{x_k \in D} p_k$ | $P(a<X<b)=\int_a^b f(x)dx$ |
| **优点** | **普遍适用**，统一框架 | **直观、方便**，离散值一目了然 | **连续函数**，便于积分运算 |
| **缺点** | 离散型不够直观 | 不适用于连续型 | 不适用于离散型，且物理意义不直观 |

---

#### 2. 分布函数的核心地位

**为什么分布函数是"普遍适用"的？**

1. **统一性**：
   - 无论是离散型还是连续型，都可以用分布函数描述
   - 提供了一个**统一的研究框架**
   - 在理论研究中，分布函数是最基本的概念

2. **完备性**：
   - 分布函数**完整刻画**了随机变量的概率分布
   - 知道 $F(x)$，就能确定随机变量的所有概率特性

3. **桥梁作用**：
   - 分布函数是连接分布律和概率密度的桥梁
   - 离散型：$p_k = F(x_k) - F(x_k-0)$（跳跃高度）
   - 连续型：$f(x) = F'(x)$（求导）

---

#### 3. 分布律的特点

**分布律"离散、方便"的体现**：

1. **直观性**：
   - 离散型随机变量的取值是有限或可列的
   - 分布律直接给出每个取值的概率
   - 一目了然，非常**直观**

2. **方便性**：
   - 计算概率只需**求和**，不需要积分
   - 公式简单：$P(X \in D) = \sum_{x_k \in D} p_k$
   - 在实际应用中非常方便

3. **局限性**：
   - **只适用于离散型**随机变量
   - 对于连续型，单点概率都是0，分布律没有意义

**举例**：

抛两枚硬币，$X$ = 正面朝上的次数：

分布律：
$$P(X=0)=\frac{1}{4}, \quad P(X=1)=\frac{1}{2}, \quad P(X=2)=\frac{1}{4}$$

- **直观**：一看就知道每个结果的概率
- **方便**：求 $P(X \geq 1) = P(X=1) + P(X=2) = \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$

但如果用分布函数：
$$F(x) = \begin{cases}
0, & x < 0 \\
\frac{1}{4}, & 0 \leq x < 1 \\
\frac{3}{4}, & 1 \leq x < 2 \\
1, & x \geq 2
\end{cases}$$

虽然正确，但不如分布律直观方便。

---

#### 4. 概率密度的特点

**概率密度是连续型的专用工具**：

1. **连续性**：
   - 概率密度 $f(x)$ 通常是连续函数（或分段连续）
   - 便于进行微积分运算

2. **物理意义**：
   - $f(x)$ 本身不是概率，$f(x)dx$ 才是概率的近似
   - $f(x)$ 描述的是概率在 $x$ 处的"密度"
   - 类似物理学中的"质量密度"

3. **计算便利**：
   - 求概率用积分：$P(a < X < b) = \int_a^b f(x)dx$
   - 求期望、方差也用积分

4. **与分布函数的关系**：
   - $F(x) = \int_{-\infty}^{x} f(t)dt$（积分）
   - $f(x) = F'(x)$（求导，在连续点处）

---

#### 5. 三者之间的转换关系

**离散型**：
```
分布律 {p_k} ←→ 分布函数 F(x)

从分布律到分布函数：
F(x) = Σ_{x_k ≤ x} p_k  （累加）

从分布函数到分布律：
p_k = F(x_k) - F(x_k-0)  （跳跃高度）
```

**连续型**：
```
概率密度 f(x) ←→ 分布函数 F(x)

从概率密度到分布函数：
F(x) = ∫_{-∞}^{x} f(t)dt  （积分）

从分布函数到概率密度：
f(x) = F'(x)  （求导）
```

**核心思想**：
> - 分布函数是**中间桥梁**，普遍适用
> - 分布律是离散型的**方便工具**
> - 概率密度是连续型的**方便工具**

---

#### 6. 考研中的应用

**考查方式**：

1. **选择题**：
   - 判断某函数是否为分布函数/概率密度
   - 三者之间的关系
   - 离散型vs连续型的特点

2. **填空题**：
   - 已知分布律求分布函数
   - 已知概率密度求分布函数
   - 已知分布函数求某点概率

3. **大题**：
   - 求随机变量的分布函数
   - 利用分布函数求期望、方差
   - 随机变量函数的分布

**解题策略**：
- 离散型：优先用**分布律**（方便）
- 连续型：优先用**概率密度**（方便）
- 理论证明、统一处理：用**分布函数**（普遍适用）

---

### 五、分布函数与概率的关系

**分布函数的本质**：
> - 分布函数 $F(x)$ 完整地刻画了随机变量 $X$ 的概率分布
> - 知道 $F(x)$，就能计算 $X$ 在任何区间上的概率
> - $F(x)$ 是研究随机变量的**核心工具**

**三种等价表述**：
1. 随机变量 $X$
2. 分布函数 $F(x)$
3. 概率分布（离散型）或概率密度（连续型）

这三种表述是**等价**的，知道其中一个就能确定另外两个。
