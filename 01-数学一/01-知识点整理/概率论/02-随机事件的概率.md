# 第二章 随机事件的概率

## 2.1 概率的公理化定义 ⭐核心基础

### 一、概率公理（Kolmogorov公理体系）

设随机试验的样本空间为 $S$，对于每个事件 $A \subset S$，赋予一个实数 $P(A)$，称为事件 $A$ 的**概率**，满足以下三条公理：

#### 公理1：非负性
$$P(A) \geq 0$$

**含义**：任何事件的概率都是非负数

---

#### 公理2：规范性（归一性）
$$P(S) = 1$$

**含义**：必然事件的概率为1

---

#### 公理3：可列可加性（完全可加性）
若事件序列 $A_1, A_2, ..., A_n, ...$ **两两互不相容**（即 $A_i A_j = \emptyset, i \neq j$），则：

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

**含义**：互不相容事件并的概率等于各事件概率之和

**特殊情况（有限可加性）**：
若 $A_1, A_2, ..., A_n$ 两两互不相容，则：
$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

---

### 二、概率公理的重要性

**为什么需要公理化定义？**

1. **统一框架**：为古典概型、几何概型等具体概率模型提供统一的理论基础
2. **严谨性**：避免直观理解的局限性，建立严格的数学体系
3. **推导基础**：所有概率性质都可以从这三条公理推导出来

**考研考查方式**：
- 选择题：判断某个函数是否可以作为概率（验证三条公理）
- 概念题：理解可列可加性的含义和应用条件

---

### 三、概率的基本性质（6个）⭐核心

从概率公理可以推导出以下6个基本性质，这些是考研中最常用的：

---

#### 性质1：不可能事件的概率为0
$$P(\emptyset) = 0$$

**证明**：
- 因为 $\emptyset \cup \emptyset = \emptyset$，且 $\emptyset \cap \emptyset = \emptyset$
- 由可列可加性：$P(\emptyset) = P(\emptyset) + P(\emptyset)$
- 所以 $P(\emptyset) = 0$

**注意**：$P(A) = 0$ 不一定推出 $A = \emptyset$（在几何概型中，单点集的概率为0但不是空集）

---

#### 性质2：有限可加性
若 $A_1, A_2, ..., A_n$ **两两互不相容**，则：
$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

**证明思路**：取 $A_{n+1} = A_{n+2} = ... = \emptyset$，应用公理3

**特例**（两个事件）：若 $AB = \emptyset$，则 $P(A \cup B) = P(A) + P(B)$

---

#### 性质3：对立事件的概率公式 ⭐重要
$$P(\bar{A}) = 1 - P(A)$$

**证明**：
- 因为 $A \cup \bar{A} = S$，$A \cap \bar{A} = \emptyset$
- 由有限可加性：$P(A) + P(\bar{A}) = P(S) = 1$
- 所以 $P(\bar{A}) = 1 - P(A)$

**推论**：$0 \leq P(A) \leq 1$

**应用技巧**：
> 当直接计算 $P(A)$ 困难时，可以考虑计算 $P(\bar{A})$，然后用 $P(A) = 1 - P(\bar{A})$
> 
> **典型场景**：“至少有一个”的问题，用对立事件“一个都没有”来计算

---

#### 性质4：单调性
若 $A \subset B$，则 $P(A) \leq P(B)$

**证明**：
- 因为 $B = A \cup (B - A)$，且 $A \cap (B - A) = \emptyset$
- 所以 $P(B) = P(A) + P(B - A) \geq P(A)$

**推论**：对任意事件 $A$，有 $0 \leq P(A) \leq 1$

---

#### 性质5：加法公式（一般情况）⭐⭐高频考点
$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**证明**：
- $A \cup B = A \cup (\bar{A}B)$，且 $A \cap (\bar{A}B) = \emptyset$
- 所以 $P(A \cup B) = P(A) + P(\bar{A}B)$
- 又因为 $B = AB \cup \bar{A}B$，且 $AB \cap \bar{A}B = \emptyset$
- 所以 $P(B) = P(AB) + P(\bar{A}B)$ ⟹ $P(\bar{A}B) = P(B) - P(AB)$
- 代入得：$P(A \cup B) = P(A) + P(B) - P(AB)$

**特殊情况**：
- 若 $A$ 与 $B$ 互斥（$AB = \emptyset$），则 $P(A \cup B) = P(A) + P(B)$
- 若 $A \subset B$，则 $P(A \cup B) = P(B)$

**推广（三个事件）**：
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$

**推广（n个事件）**：容斥原理
$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i} P(A_i) - \sum_{i<j} P(A_i A_j) + \sum_{i<j<k} P(A_i A_j A_k) - ... + (-1)^{n-1} P(A_1 A_2 ... A_n)$$

**记忆技巧**：奇加偶减

**例题**：已知 $P(A) = 0.5$，$P(B) = 0.4$，$P(A \cup B) = 0.7$，求 $P(AB)$。

**解**：
$$P(AB) = P(A) + P(B) - P(A \cup B) = 0.5 + 0.4 - 0.7 = 0.2$$

---

#### 性质6：条件概率与乘法公式 ⭐⭐核心考点

**（1）条件概率的定义**

设 $A$、$B$ 为两个事件，且 $P(A) > 0$，则在事件 $A$ 发生的条件下，事件 $B$ 发生的**条件概率**定义为：
$$P(B|A) = \frac{P(AB)}{P(A)}$$

**理解**：
- 条件概率是在缩小样本空间后的概率
- 原样本空间为 $S$，在 $A$ 发生的条件下，样本空间缩小为 $A$
- $P(B|A)$ 表示在 $A$ 已经发生的前提下，$B$ 发生的概率

**条件概率的性质**：

条件概率 $P(\cdot|A)$ 本身也是一个概率测度，满足概率的所有公理和性质：

1. **非负性**：$P(B|A) \geq 0$
2. **规范性**：$P(S|A) = 1$
3. **可列可加性**：若 $B_1, B_2, ...$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{\infty} B_i | A\right) = \sum_{i=1}^{\infty} P(B_i|A)$$

**⭐⭐⭐重要结论**：
> **条件概率符合概率的一切性质！**
> 
> 这意味着所有关于概率的公式和定理，在条件概率下仍然成立！只需在所有概率符号后面加上条件 $|A$ 即可。

**具体应用举例**：

1. **对立事件公式**（在条件 $A$ 下）：
   $$P(\bar{B}|A) = 1 - P(B|A)$$

2. **加法公式**（在条件 $A$ 下）：
   $$P(B \cup C|A) = P(B|A) + P(C|A) - P(BC|A)$$

3. **乘法公式**（在条件 $A$ 下）：
   $$P(BC|A) = P(B|A)P(C|AB)$$

4. **全概率公式**（在条件 $A$ 下）：
   若 $C_1, C_2, ..., C_n$ 是划分，则
   $$P(B|A) = \sum_{i=1}^{n} P(C_i|A)P(B|AC_i)$$

5. **单调性**（在条件 $A$ 下）：
   若 $B \subset C$，则 $P(B|A) \leq P(C|A)$

**解题技巧**：
> 当题目中出现复杂的条件概率时，可以把条件概率当作普通概率来处理，直接套用所有概率公式！
> 
> 例如：看到 $P(B \cup C|A)$，立即想到用加法公式展开为 $P(B|A) + P(C|A) - P(BC|A)$

---

**（2）乘法公式**

由条件概率的定义可直接得到乘法公式：

**两个事件**：
$$P(AB) = P(A)P(B|A) \quad (P(A) > 0)$$
或
$$P(AB) = P(B)P(A|B) \quad (P(B) > 0)$$

**推广（多个事件）**：
$$P(A_1 A_2 ... A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2)...P(A_n|A_1 A_2 ... A_{n-1})$$

**记忆技巧**：链式法则，逐个条件化

**例题1**：袋中有5个红球、3个白球，无放回地摸2次，求两次都摸到红球的概率。

**解**：
- 设 $A_1$ = "第1次摸到红球"，$A_2$ = "第2次摸到红球"
- $P(A_1) = \frac{5}{8}$
- $P(A_2|A_1) = \frac{4}{7}$（第1次摸走一个红球后，剩4红3白）
- 由乘法公式：$P(A_1 A_2) = P(A_1)P(A_2|A_1) = \frac{5}{8} \times \frac{4}{7} = \frac{5}{14}$

**例题2**：某产品需经过3道工序，各道工序的合格率分别为0.9、0.8、0.7，求产品最终合格的概率。

**解**：
- 设 $A_i$ = "第 $i$ 道工序合格"（$i=1,2,3$）
- 假设各工序独立，则 $P(A_1 A_2 A_3) = P(A_1)P(A_2)P(A_3) = 0.9 \times 0.8 \times 0.7 = 0.504$

---

### 四、其他常用性质（补充）

除了上述6个基本性质外，还有以下常用性质：

#### 性质7：减法公式
$$P(A - B) = P(A) - P(AB)$$

**特别地**：若 $B \subset A$，则 $P(A - B) = P(A) - P(B)$

**证明**：
- $A = AB \cup (A - B)$，且 $AB \cap (A - B) = \emptyset$
- 所以 $P(A) = P(AB) + P(A - B)$
- 即 $P(A - B) = P(A) - P(AB)$

**注意**：一般情况下 $P(A - B) \neq P(A) - P(B)$，只有当 $B \subset A$ 时才成立！

---

#### 性质8：连续性 ⭐理论重点

**下连续性**：若 $A_1 \subset A_2 \subset A_3 \subset ...$（递增序列），则
$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \lim_{n \to \infty} P(A_n)$$

**上连续性**：若 $A_1 \supset A_2 \supset A_3 \supset ...$（递减序列），则
$$P\left(\bigcap_{i=1}^{\infty} A_i\right) = \lim_{n \to \infty} P(A_n)$$

**考研提示**：这个性质在证明题中可能用到，选择题较少直接考查

---

## 2.2 古典概型 ⭐（考查较少）

**考研提示**：古典概型和几何概型在考研中考查相对较少，主要掌握基本概念和计算方法即可，不必过度深入复杂模型。

### 一、定义

满足以下两个条件的概率模型称为**古典概型**（等可能概型）：

1. **有限性**：样本空间 $S$ 只有有限个样本点，设 $|S| = n$
2. **等可能性**：每个样本点发生的可能性相同

### 二、计算公式

若事件 $A$ 包含 $m$ 个样本点，则：
$$P(A) = \frac{m}{n} = \frac{|A|}{|S|} = \frac{\text{事件A包含的样本点数}}{\text{样本空间的总样本点数}}$$

### 三、解题步骤

1. **确定样本空间**：明确试验的所有可能结果
2. **计算总样本点数** $n$
3. **确定事件A**：明确事件A包含哪些结果
4. **计算有利样本点数** $m$
5. **代入公式**：$P(A) = \frac{m}{n}$

### 四、常用计数方法

#### 1. 排列数
$$P_n^m = A_n^m = \frac{n!}{(n-m)!}$$

**含义**：从 $n$ 个不同元素中取出 $m$ 个进行排列

#### 2. 组合数
$$C_n^m = \binom{n}{m} = \frac{n!}{m!(n-m)!}$$

**含义**：从 $n$ 个不同元素中取出 $m$ 个（不考虑顺序）

**重要性质**：
- $C_n^m = C_n^{n-m}$
- $C_n^m = C_{n-1}^{m-1} + C_{n-1}^m$
- $\sum_{k=0}^{n} C_n^k = 2^n$

#### 3. 重复排列
从 $n$ 个不同元素中有放回地取 $m$ 次：$n^m$ 种

#### 4. 隔板法
将 $n$ 个相同元素分成 $k$ 组（每组至少1个）：$C_{n-1}^{k-1}$ 种

---

### 五、经典模型

#### 模型1：摸球问题

**有放回摸球**：
- 从 $N$ 个球中（$M$ 个红球，$N-M$ 个白球）有放回地摸 $n$ 次
- 每次摸到红球的概率：$p = \frac{M}{N}$
- $n$ 次中恰好 $k$ 次红球：$P = C_n^k p^k (1-p)^{n-k}$（二项分布）

**无放回摸球**：
- 从 $N$ 个球中无放回地摸 $n$ 个
- 恰好 $k$ 个红球：$P = \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$（超几何分布）

**例题**：袋中有5个红球、3个白球，无放回地摸3个，求恰好2个红球的概率。

**解**：
$$P = \frac{C_5^2 C_3^1}{C_8^3} = \frac{10 \times 3}{56} = \frac{30}{56} = \frac{15}{28}$$

---

#### 模型2：分房问题

**问题**：将 $n$ 个不同的球放入 $N$ 个不同的盒子中，求指定盒子恰有 $k$ 个球的概率。

**解**：
- 总放法：$N^n$
- 指定盒子恰有 $k$ 个球：先从 $n$ 个球中选 $k$ 个放入指定盒子 $C_n^k$，剩余 $n-k$ 个球放入其余 $N-1$ 个盒子 $(N-1)^{n-k}$
- 概率：$P = \frac{C_n^k (N-1)^{n-k}}{N^n}$

---

#### 模型3：配对问题

**问题**：$n$ 封信随机放入 $n$ 个信封，求恰好 $k$ 封信配对的概率。

**关键**：错排公式
- $n$ 个元素的错排数：$D_n = n! \sum_{i=0}^{n} \frac{(-1)^i}{i!}$
- 恰好 $k$ 个配对：先选 $k$ 个配对 $C_n^k$，剩余 $n-k$ 个错排 $D_{n-k}$
- 概率：$P = \frac{C_n^k D_{n-k}}{n!}$

---

## 2.3 几何概型 ⭐（考查较少）

**考研提示**：几何概型考查频率较低，重点掌握基本概念和简单应用（如约会问题）。

### 一、定义

当样本空间是某个可度量的几何区域 $\Omega$，且每个样本点出现的可能性相同时，称为**几何概型**。

### 二、计算公式

$$P(A) = \frac{\text{事件A对应的几何度量}}{\text{样本空间的几何度量}} = \frac{L(A)}{L(\Omega)}$$

其中几何度量 $L$ 可以是：
- **长度**（一维）
- **面积**（二维）
- **体积**（三维）

### 三、典型例题

#### 例题1：约会问题 ⭐经典

甲乙两人约定在 [0, T] 时间段内见面，先到者等待 $t$ 时间后离开，求两人能见面的概率。

**解**：
- 设甲到达时间为 $x$，乙到达时间为 $y$，则样本空间 $\Omega = \{(x,y) | 0 \leq x \leq T, 0 \leq y \leq T\}$
- 能见面条件：$|x - y| \leq t$
- 样本空间面积：$T^2$
- 不能见面的区域：两个三角形，每个面积 $\frac{1}{2}(T-t)^2$
- 能见面概率：
  $$P = 1 - \frac{2 \times \frac{1}{2}(T-t)^2}{T^2} = 1 - \left(\frac{T-t}{T}\right)^2 = \frac{2Tt - t^2}{T^2}$$

**特例**：若 $T = 60$ 分钟，$t = 15$ 分钟
$$P = 1 - \left(\frac{45}{60}\right)^2 = 1 - \frac{9}{16} = \frac{7}{16}$$

---

#### 例题2： Buffon投针问题

平面上画有间距为 $a$ 的平行线，向平面随机投掷长度为 $l$ ($l < a$) 的针，求针与平行线相交的概率。

**答案**：$P = \frac{2l}{\pi a}$

**意义**：可以通过实验估算 $\pi$ 的值

---

## 2.3 条件概率与全概率公式 ⭐⭐⭐超级重要

**考研提示**：这是概率论的**核心内容**，几乎每年必考！必须熟练掌握条件概率、乘法公式、全概率公式和贝叶斯公式。

### 一、条件概率 ⭐⭐⭐

#### 1. 定义

设 $A$、$B$ 为两个事件，且 $P(A) > 0$，则在事件 $A$ 发生的条件下，事件 $B$ 发生的**条件概率**定义为：
$$P(B|A) = \frac{P(AB)}{P(A)}$$

**核心理解**：
- 条件概率是在**缩小样本空间**后的概率
- 原样本空间为 $S$，在 $A$ 发生的条件下，样本空间缩小为 $A$
- $P(B|A)$ 表示在 $A$ **已经发生**的前提下，$B$ 发生的概率

**直观例子**：
> 掷一颗骰子，已知出现偶数点（$A$），求出现2点（$B$）的概率。
> - 无条件时：$P(B) = \frac{1}{6}$
> - 已知 $A$ 发生后：样本空间从 $\{1,2,3,4,5,6\}$ 缩小为 $\{2,4,6\}$
> - 所以 $P(B|A) = \frac{1}{3}$

#### 2. 条件概率的性质

条件概率也满足概率的所有公理和性质：

1. **非负性**：$P(B|A) \geq 0$
2. **规范性**：$P(S|A) = 1$
3. **可列可加性**：若 $B_1, B_2, ...$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{\infty} B_i | A\right) = \sum_{i=1}^{\infty} P(B_i|A)$$

**重要结论**：条件概率可以看作一个新的概率测度，所有概率公式在条件概率下仍然成立！

例如，在条件 $A$ 下，加法公式仍然成立：
$$P(B \cup C|A) = P(B|A) + P(C|A) - P(BC|A)$$

---

### 二、乘法公式 ⭐⭐

由条件概率的定义可直接得到乘法公式：

#### 1. 两个事件的乘法公式

$$P(AB) = P(A)P(B|A) \quad (P(A) > 0)$$

或

$$P(AB) = P(B)P(A|B) \quad (P(B) > 0)$$

**理解**：$A$ 和 $B$ 同时发生的概率 = $A$ 发生的概率 × 在 $A$ 发生的条件下 $B$ 发生的概率

#### 2. 多个事件的乘法公式（链式法则）

$$P(A_1 A_2 ... A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2)...P(A_n|A_1 A_2 ... A_{n-1})$$

**记忆技巧**：链式展开，逐个条件化

#### 3. 典型应用

**例题1**：袋中有5个红球、3个白球，无放回地摸3次，求三次都摸到红球的概率。

**解**：
- 设 $A_i$ = "第 $i$ 次摸到红球"（$i=1,2,3$）
- $P(A_1) = \frac{5}{8}$
- $P(A_2|A_1) = \frac{4}{7}$（第1次摸走一个红球后，剩4红3白）
- $P(A_3|A_1 A_2) = \frac{3}{6} = \frac{1}{2}$（前两次摸走两个红球后，剩3红3白）
- 由乘法公式：
  $$P(A_1 A_2 A_3) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2) = \frac{5}{8} \times \frac{4}{7} \times \frac{1}{2} = \frac{5}{28}$$

**例题2**：某产品需经过3道工序，各道工序的合格率分别为0.9、0.8、0.7，假设各工序独立，求产品最终合格的概率。

**解**：
- 设 $A_i$ = "第 $i$ 道工序合格"（$i=1,2,3$）
- 由于各工序独立，$P(A_2|A_1) = P(A_2)$，$P(A_3|A_1 A_2) = P(A_3)$
- $P(A_1 A_2 A_3) = P(A_1)P(A_2)P(A_3) = 0.9 \times 0.8 \times 0.7 = 0.504$

### 三、全概率公式 ⭐⭐⭐核心考点

#### 1. 完备事件组（样本空间的划分）⭐⭐重要概念

**定义**：
设 $S$ 为样本空间，$B_1, B_2, ..., B_n$ 为一组事件，如果满足：
1. **两两互斥**：$B_i B_j = \emptyset$（$i \neq j$），即任意两个事件不能同时发生
2. **完备性**：$\bigcup_{i=1}^{n} B_i = S$，即所有事件的并集等于样本空间
3. **非零概率**：$P(B_i) > 0$（$i = 1, 2, ..., n$）

则称 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个**完备事件组**（或**划分**）。

**核心理解**：
> 完备事件组就是将样本空间"分完"且"不重叠"地分成若干部分
> - "分完"：所有部分加起来覆盖整个样本空间（完备性）
> - "不重叠"：任意两个部分没有交集（互斥性）

**直观图示**：
```
样本空间 S
┌─────────────────┐
│  B₁  │  B₂      │
│──────┼──────┤   │
│  B₃  │  B₄  │   │
└─────────────────┘
```
$B_1, B_2, B_3, B_4$ 构成一个完备事件组

**常见完备事件组**：

1. **最简单的情形**：$B$ 和 $\bar{B}$ 构成一个完备事件组
   - $B \cap \bar{B} = \emptyset$（互斥）
   - $B \cup \bar{B} = S$（完备）

2. **摸球问题**：
   - "第一次摸到红球"（$B_1$）和"第一次摸到白球"（$B_2$）构成完备事件组
   
3. **多分类问题**：
   - "产品来自第1条生产线"（$B_1$）
   - "产品来自第2条生产线"（$B_2$）
   - "产品来自第3条生产线"（$B_3$）
   - 这三个事件构成完备事件组

4. **考试成绩**：
   - "优秀"（$B_1$）、"良好"（$B_2$）、"中等"（$B_3$）、"及格"（$B_4$）、"不及格"（$B_5$）
   - 这五个事件构成完备事件组

**⚠️ 易错点**：
- 必须同时满足"互斥"和"完备"两个条件
- 只有互斥但不完备：如掷骰子的"出现1点"和"出现2点"（还有3、4、5、6点没包括）
- 完备但不互斥：如"出现偶数点"和"出现不大于4的点"（有重叠：2和4）

**判断方法**：
1. 检查是否两两互斥：$B_i B_j = \emptyset$（$i \neq j$）
2. 检查是否完备：$\bigcup_{i=1}^{n} B_i = S$
3. 检查概率是否为正：$P(B_i) > 0$

#### 2. 全概率公式

设 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个划分，$A$ 为任意事件，则：

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) + ... + P(B_n)P(A|B_n)$$

**证明**：
- 因为 $B_1, B_2, ..., B_n$ 是划分，所以 $A = A \cap S = A \cap \left(\bigcup_{i=1}^{n} B_i\right) = \bigcup_{i=1}^{n} (AB_i)$
- 又因为 $B_i$ 两两互斥，所以 $AB_i$ 也两两互斥
- 由可加性：$P(A) = \sum_{i=1}^{n} P(AB_i)$
- 由乘法公式：$P(AB_i) = P(B_i)P(A|B_i)$
- 所以 $P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$

**核心理解**：
> 全概率公式的本质是**"分情况讨论"**
> 
> 计算事件 $A$ 的概率时，如果直接计算困难，可以将样本空间划分为若干种情况 $B_1, B_2, ..., B_n$，分别计算每种情况下 $A$ 发生的概率，然后加权求和。

**解题步骤**：
1. **找划分**：找到合适的完备事件组 $B_1, B_2, ..., B_n$
2. **算先验概率**：计算 $P(B_i)$
3. **算条件概率**：计算 $P(A|B_i)$
4. **代入公式**：$P(A) = \sum P(B_i)P(A|B_i)$

#### 3. 典型例题

**例题1**（经典摸球问题）：

袋中有5个红球、3个白球，有放回地摸2次，求第2次摸到红球的概率。

**解**：
- 设 $A$ = "第2次摸到红球"
- 设 $B_1$ = "第1次摸到红球"，$B_2$ = "第1次摸到白球"
- $B_1, B_2$ 构成一个划分
- $P(B_1) = \frac{5}{8}$，$P(B_2) = \frac{3}{8}$
- $P(A|B_1) = \frac{5}{8}$（有放回，第1次摸到红球不影响第2次）
- $P(A|B_2) = \frac{5}{8}$（有放回，第1次摸到白球不影响第2次）
- 由全概率公式：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = \frac{5}{8} \times \frac{5}{8} + \frac{3}{8} \times \frac{5}{8} = \frac{5}{8}$$

**例题2**（无放回摸球）：

袋中有5个红球、3个白球，**无放回**地摸2次，求第2次摸到红球的概率。

**解**：
- 设 $A$ = "第2次摸到红球"
- 设 $B_1$ = "第1次摸到红球"，$B_2$ = "第1次摸到白球"
- $P(B_1) = \frac{5}{8}$，$P(B_2) = \frac{3}{8}$
- $P(A|B_1) = \frac{4}{7}$（第1次摸走一个红球后，剩4红3白）
- $P(A|B_2) = \frac{5}{7}$（第1次摸走一个白球后，剩5红2白）
- 由全概率公式：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = \frac{5}{8} \times \frac{4}{7} + \frac{3}{8} \times \frac{5}{7} = \frac{35}{56} = \frac{5}{8}$$

**有趣结论**：无论是否有放回，第2次摸到红球的概率都等于第1次摸到红球的概率（对称性）！

**重要启示**：
> 这个结论可以推广：在无放回摸球中，第 $k$ 次摸到红球的概率与第1次相同，都是 $\frac{5}{8}$。
> 
> 这体现了**抽签的公平性**：先抽后抽概率一样！

---

**例题3**（产品质量检验）：

某工厂有3条生产线，产量分别占总产量的30%、40%、30%，次品率分别为2%、3%、1%。从产品中任取一件，求它是次品的概率。

**解**：
- 设 $A$ = "取到次品"
- 设 $B_i$ = "产品来自第 $i$ 条生产线"（$i=1,2,3$）
- $P(B_1) = 0.3$，$P(B_2) = 0.4$，$P(B_3) = 0.3$
- $P(A|B_1) = 0.02$，$P(A|B_2) = 0.03$，$P(A|B_3) = 0.01$
- 由全概率公式：
  $$P(A) = 0.3 \times 0.02 + 0.4 \times 0.03 + 0.3 \times 0.01 = 0.006 + 0.012 + 0.003 = 0.021$$

**例题4**（疾病诊断问题）：

某疾病的患病率为0.1%，一种检测方法的准确率为：如果患病，检测为阳性的概率为99%；如果未患病，检测为阴性的概率为95%。现某人检测结果为阳性，求他确实患病的概率。

**解**：
- 设 $A$ = "检测结果为阳性"
- 设 $B_1$ = "患病"，$B_2$ = "未患病"
- $B_1, B_2$ 构成完备事件组
- $P(B_1) = 0.001$，$P(B_2) = 0.999$
- $P(A|B_1) = 0.99$（患病时检测为阳性的概率）
- $P(A|B_2) = 0.05$（未患病时检测为阳性的概率，即误诊率）
- 由全概率公式，先计算 $P(A)$：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = 0.001 \times 0.99 + 0.999 \times 0.05 = 0.05094$$
- 这步是全概率公式的典型应用！

**注意**：这个题目继续用贝叶斯公式求后验概率，见下文。

#### 4. 全概率公式的应用场景总结

**何时使用全概率公式？**

1. **“来自不同来源”的问题**：
   - 产品来自不同生产线
   - 病人来自不同地区
   - 信号来自不同发送端

2. **“分阶段进行”的问题**：
   - 多次摸球（第2次、第3次的概率）
   - 多道工序加工
   - 多轮比赛

3. **“至少有一个”的复杂情况**：
   - 有时可以用对立事件，有时需要用全概率公式分情况讨论

**解题关键点**：
- **找准划分**：这是最关键的一步！要根据题意找到合适的完备事件组
- **常见划分方式**：
  - 按“第一次的结果”划分（摸球问题）
  - 按“来源”划分（产品质量问题）
  - 按“状态”划分（患病/未患病）
  - 按“真假”划分（真币/假币、真品/赝品）

### 四、贝叶斯公式（逆概率公式）⭐⭐⭐核心考点

#### 1. 贝叶斯公式

设 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个划分，$A$ 为任意事件且 $P(A) > 0$，则：

$$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)} = \frac{P(B_k)P(A|B_k)}{P(A)} \quad (k = 1, 2, ..., n)$$

**理解**：
- 贝叶斯公式用于计算**后验概率** $P(B_k|A)$
- 已知"原因" $B_k$ 导致"结果" $A$ 的概率 $P(A|B_k)$，反过来求已知"结果" $A$ 发生时，是由"原因" $B_k$ 导致的概率 $P(B_k|A)$
- 分母 $P(A)$ 用全概率公式计算

#### 2. 相关概念

- **先验概率**：$P(B_k)$，在观察到结果之前，对各种原因的概率估计
- **似然度**：$P(A|B_k)$，在原因 $B_k$ 下，观察到结果 $A$ 的可能性
- **后验概率**：$P(B_k|A)$，观察到结果 $A$ 后，对原因 $B_k$ 的修正概率

#### 3. 典型例题

**例题**（接上面的产品质量检验）：

某工厂有3条生产线，产量分别占总产量的30%、40%、30%，次品率分别为2%、3%、1%。从产品中任取一件，发现是次品，求它来自第2条生产线的概率。

**解**：
- 设 $A$ = "取到次品"
- 设 $B_i$ = "产品来自第 $i$ 条生产线"（$i=1,2,3$）
- 已知：$P(B_1) = 0.3$，$P(B_2) = 0.4$，$P(B_3) = 0.3$
- 已知：$P(A|B_1) = 0.02$，$P(A|B_2) = 0.03$，$P(A|B_3) = 0.01$
- 由全概率公式：$P(A) = 0.021$（前面已计算）
- 由贝叶斯公式：
  $$P(B_2|A) = \frac{P(B_2)P(A|B_2)}{P(A)} = \frac{0.4 \times 0.03}{0.021} = \frac{0.012}{0.021} = \frac{4}{7} \approx 0.571$$

**解读**：虽然第2条生产线的产量占40%，但已知取到的是次品后，它来自第2条生产线的概率上升到约57.1%，因为第2条生产线的次品率最高。

---

**例题2**（疾病诊断问题，接全概率公式例题4）：

某疾病的患病率为0.1%，一种检测方法的准确率为：如果患病，检测为阳性的概率为99%；如果未患病，检测为阴性的概率为95%。现某人检测结果为阳性，求他确实患病的概率。

**解**：
- 设 $A$ = "检测结果为阳性"
- 设 $B_1$ = "患病"，$B_2$ = "未患病"
- 已知：$P(B_1) = 0.001$，$P(B_2) = 0.999$
- 已知：$P(A|B_1) = 0.99$，$P(A|B_2) = 0.05$
- 由全概率公式（前面已计算）：$P(A) = 0.05094$
- 由贝叶斯公式：
  $$P(B_1|A) = \frac{P(B_1)P(A|B_1)}{P(A)} = \frac{0.001 \times 0.99}{0.05094} = \frac{0.00099}{0.05094} \approx 0.0194$$

**惊人的结论**：
> 即使检测结果为阳性，真正患病的概率只有约1.94%！
> 
> **原因分析**：
> - 患病率很低（0.1%），所以大部分人都是未患病的
> - 虽然检测准确率很高，但未患病人数太多，导致误诊的绝对数量很大
> - 这就是**假阳性问题**，在医学检测中非常重要

**启示**：
- 对于罕见病，即使检测准确率很高，阳性结果也不一定意味着真的患病
- 通常需要多次检测来降低误诊率

---

**例题3**（信号传输问题）：

某通信系统发送信号0和1，发送0的概率为0.6，发送1的概率为0.4。由于噪声干扰，接收端可能出错：
- 发送0时，接收为0的概率为0.9，接收为1的概率为0.1
- 发送1时，接收为1的概率为0.8，接收为0的概率为0.2

现接收端收到信号1，求发送端实际发送的是1的概率。

**解**：
- 设 $A$ = "接收为1"
- 设 $B_0$ = "发送0"，$B_1$ = "发送1"
- 已知：$P(B_0) = 0.6$，$P(B_1) = 0.4$
- 已知：$P(A|B_0) = 0.1$，$P(A|B_1) = 0.8$
- 由全概率公式：
  $$P(A) = P(B_0)P(A|B_0) + P(B_1)P(A|B_1) = 0.6 \times 0.1 + 0.4 \times 0.8 = 0.06 + 0.32 = 0.38$$
- 由贝叶斯公式：
  $$P(B_1|A) = \frac{P(B_1)P(A|B_1)}{P(A)} = \frac{0.4 \times 0.8}{0.38} = \frac{0.32}{0.38} = \frac{16}{19} \approx 0.842$$

**解读**：接收到1后，有约84.2%的把握认为发送的就是1。

#### 4. 贝叶斯公式的核心思想 ⭐⭐⭐重要理解

**全概率公式（因→果）vs 贝叶斯公式（果→因）**：

这是理解两个公式本质的关键！

| 对比项 | 全概率公式 | 贝叶斯公式 |
|--------|-----------|----------|
| **方向** | 因 → 果 | 果 → 因 |
| **已知** | 各种原因 $B_i$ 的概率 $P(B_i)$ <br> 各原因导致结果的概率 $P(A\|B_i)$ | 观察到结果 $A$ <br> 各种原因的先验概率 $P(B_i)$ <br> 各原因的似然度 $P(A\|B_i)$ |
| **求解** | 结果 $A$ 发生的总概率 $P(A)$ | 某个原因 $B_k$ 导致的后验概率 $P(B_k\|A)$ |
| **公式** | $P(A) = \sum P(B_i)P(A\|B_i)$ | $P(B_k\|A) = \frac{P(B_k)P(A\|B_k)}{P(A)}$ |
| **思维** | 正向推理：从原因推结果 | 逆向推理：从结果推原因 |
| **应用** | 计算复杂事件的概率 | 根据证据推断最可能的原因 |

**直观例子**（产品质量问题）：

- **全概率公式（因→果）**：
  > 已知：产品来自三条生产线的比例，以及各生产线的次品率
  > 
  > 问：任取一件产品，是次品的概率是多少？
  > 
  > 思路：从"生产线"（因）推到"次品"（果）

- **贝叶斯公式（果→因）**：
  > 已知：取到一件次品
  > 
  > 问：它来自第2条生产线的概率是多少？
  > 
  > 思路：从"次品"（果）推到"生产线"（因）

---

**从"因"到"果" vs 从"果"到"因"的完整对比**：

| 方向 | 公式 | 名称 | 含义 | 典型问题 |
|------|------|------|------|----------|
| 因→果 | $P(A\|B_k)$ | 似然度/条件概率 | 已知原因，求结果的概率 | "如果患病，检测阳性的概率是多少？" |
| 果→因 | $P(B_k\|A)$ | 后验概率 | 已知结果，推断原因的概率 | "检测阳性，患病的概率是多少？" |

**贝叶斯思维的本质**：
> 贝叶斯公式体现了**"根据新证据更新信念"**的思想
> 
> 1. **先验概率** $P(B_k)$：在观察到证据之前的初始信念
> 2. **新证据** $A$：观察到的结果
> 3. **后验概率** $P(B_k|A)$：根据新证据修正后的信念
>
> **核心**：用新的信息（证据）来修正我们原有的判断！

**应用场景**：
- **医学诊断**：根据检测结果推断是否患病
- **质量控制**：根据产品缺陷推断来自哪条生产线
- **机器学习**：朴素贝叶斯分类器
- **人工智能**：贝叶斯网络、概率推理
- **金融风控**：根据行为特征判断是否为欺诈

---

#### 5. 解题步骤总结

**使用贝叶斯公式的标准流程**：

1. **确定事件**：
   - 明确"结果"事件 $A$
   - 明确"原因"事件 $B_1, B_2, ..., B_n$（构成完备事件组）

2. **收集已知信息**：
   - 先验概率：$P(B_i)$
   - 似然度：$P(A|B_i)$

3. **计算分母**（用全概率公式）：
   $$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$

4. **代入贝叶斯公式**：
   $$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{P(A)}$$

5. **解释结果**：
   - 后验概率与先验概率的对比
   - 为什么会有这样的变化

### 五、解题技巧总结 ⭐⭐⭐

#### 1. 如何判断使用哪个公式？

| 问题类型 | 使用公式 | 特征 |
|---------|---------|------|
| 求积事件概率 $P(AB)$ | 乘法公式 | "同时发生"、"连续发生" |
| 求某个事件概率 $P(A)$ | 全概率公式 | "分情况讨论"、"来自不同来源" |
| 求后验概率 $P(B_k\|A)$ | 贝叶斯公式 | "已知结果，求原因"、"来自哪里的概率" |

#### 2. 常见模型

1. **摸球模型**：有放回/无放回，多次摸球
2. **产品质量检验**：多条生产线、多个批次
3. **疾病诊断**：检测准确率、患病率
4. **信号传输**：发送端、接收端、错误率

#### 3. 易错点

1. **混淆条件概率和积事件概率**：$P(B|A) \neq P(AB)$
2. **忽视划分的完整性**：确保 $B_1, B_2, ..., B_n$ 构成完整划分
3. **先验概率和后验概率混淆**：$P(B_k)$ vs $P(B_k|A)$
4. **独立性假设滥用**：不是所有情况都能假设独立

## ⭐ 本章重点总结

### 核心概念
1. **概率公理化定义**：非负性、规范性、可列可加性
2. **古典概型**：有限性 + 等可能性
3. **几何概型**：几何度量之比

### 重要公式
1. 对立事件：$P(\bar{A}) = 1 - P(A)$
2. 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. 减法公式：$P(A - B) = P(A) - P(AB)$
4. **条件概率**：$P(B|A) = \frac{P(AB)}{P(A)}$
5. **乘法公式**：$P(AB) = P(A)P(B|A)$
6. **全概率公式**：$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$
7. **贝叶斯公式**：$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{P(A)}$
8. 古典概型：$P(A) = \frac{m}{n}$
9. 几何概型：$P(A) = \frac{L(A)}{L(\Omega)}$

### 解题技巧

#### 1. "至少有一个"问题
用对立事件“一个都没有”来计算：
$$P(\text{至少一个}) = 1 - P(\text{都没有})$$

#### 2. 古典概型
关键是正确计数（排列组合），注意有序vs无序

#### 3. 几何概型
画图分析，计算面积/长度比

#### 4. ⭐⭐ 复杂事件的处理方法

**方法1：特例法（赋值法）**

**适用场景**：选择题中，题目给出抽象事件关系，求概率关系

**思路**：
- 将抽象事件具体化，构造一个简单的特例
- 通过特例验证选项的正确性
- 如果特例不满足某个选项，则该选项错误

**例题**：设 $A$、$B$ 为任意两个事件，则下列正确的是：
A. $P(A \cup B) = P(A) + P(B)$
B. $P(A - B) = P(A) - P(B)$
C. $P(AB) \leq P(A)$
D. $P(A \cup B) \geq P(A) + P(B)$

**解**（特例法）：
- 取特例：$A = B$，且 $P(A) = 0.5$
- A选项：$P(A \cup A) = P(A) = 0.5$，但 $P(A) + P(A) = 1$，不相等 ✗
- B选项：$P(A - A) = P(\emptyset) = 0$，但 $P(A) - P(A) = 0$，相等 ✓（但这只是特例，需要进一步验证）
  - 再取特例：$B \subset A$，$P(A)=0.6$，$P(B)=0.3$
  - $P(A-B) = 0.3$，但 $P(A)-P(B) = 0.3$，相等
  - 再取特例：$A$、$B$ 有交集但不包含
  - $P(A-B) = P(A) - P(AB) \neq P(A) - P(B)$ ✗
- C选项：因为 $AB \subset A$，由单调性知 $P(AB) \leq P(A)$ ✓
- D选项：取 $A=B$，$P(A)=0.5$，则 $P(A \cup B) = 0.5$，但 $P(A)+P(B) = 1$，$0.5 \geq 1$ 不成立 ✗

**答案**：C

---

**方法2：文氏图法（Venn Diagram）**

**适用场景**：
- 多个事件的并、交、差运算
- 直观理解事件关系
- 计算复杂事件的概率

**基本图形**：
```
     ┌─────────────┐
     │      A      │
     │   ┌─────┐   │
     │   │ AB  │   │
     │   └─────┘   │
     │             │
     └─────────────┘
```

**常用区域标记**：
- $A$ 独有的部分：$A - B$ 或 $A\bar{B}$
- $B$ 独有的部分：$B - A$ 或 $\bar{A}B$
- $A$ 和 $B$ 的交集：$AB$
- $A$ 和 $B$ 的并集：$A \cup B$

**三事件文氏图**：
```
        ┌───────┐
       /    A    \
      /  ┌─────┐  \
     |  /   ABC   \  |
    |  |  ┌─────┐  |  |
    | /  /   AB   \  \ |
    ||  ||  ┌─────┐  || |
    ||  || /   A   \  || |
    ||  || |       |  || |
    | \  \ \       / /  | |
     |  |  \     /  |  | |
     |   \  \___/   /   | |
      \   \_____/   /   /
       \           /   /
        \_________/   /
         \    B      / /
          \_________/ /
           \       / /
            \_____/_/
             \   / /
              \_/_/
               C
```

**应用步骤**：
1. **画文氏图**：根据事件个数画出相应的文氏图
2. **标记已知概率**：将已知的概率值标在对应区域
3. **推导未知概率**：利用概率性质推导其他区域的概率
4. **计算目标概率**：将相关区域的概率相加

**例题**：已知 $P(A) = 0.5$，$P(B) = 0.4$，$P(A \cup B) = 0.7$，求 $P(A\bar{B})$。

**解**（文氏图法）：
1. 画两个相交的圆，分别表示 $A$ 和 $B$
2. 计算交集：$P(AB) = P(A) + P(B) - P(A \cup B) = 0.5 + 0.4 - 0.7 = 0.2$
3. $A$ 独有的部分：$P(A\bar{B}) = P(A) - P(AB) = 0.5 - 0.2 = 0.3$

**答案**：$P(A\bar{B}) = 0.3$

---

**方法对比**：

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **特例法** | 选择题、判断题 | 快速排除错误选项 | 不能用于证明题 |
| **文氏图法** | 多事件运算、直观理解 | 形象直观，不易出错 | 事件较多时图形复杂 |

### 易错点
1. 混淆"互斥"与"独立"
2. 加法公式忘记减去 $P(AB)$
3. 古典概型中样本点计数错误（有序vs无序）
4. 几何概型中几何区域确定错误
