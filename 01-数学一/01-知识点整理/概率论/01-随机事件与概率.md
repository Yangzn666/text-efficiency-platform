# 第一章 随机事件与概率

## 1.1 基本概念

### 一、随机试验（Random Experiment）

**定义**：满足以下三个条件的试验称为随机试验：
1. **可重复性**：在相同条件下可以重复进行
2. **可知性**：所有可能的结果是明确可知的
3. **不确定性**：每次试验之前不能确定哪个结果会出现

**典型例子**：
- 抛硬币：结果为正面或反面
- 掷骰子：结果为1,2,3,4,5,6点
- 从一批产品中抽取一件检验

---

### 二、样本空间（Sample Space）⭐重要概念

**定义**：随机试验的所有可能结果组成的集合，记为 $S$ 或 $\Omega$

**样本点**：样本空间中的每个元素，记为 $\omega$

**关键点**：
- 样本空间的确定依赖于试验的具体描述
- 同一个试验，观察角度不同，样本空间可能不同
- 样本空间是后续定义事件和概率的基础

**例题**：
1. 抛一枚硬币：$S = \{正面, 反面\}$ 或 $S = \{H, T\}$
2. 掷一颗骰子：$S = \{1, 2, 3, 4, 5, 6\}$
3. 记录某网站一天的访问量：$S = \{0, 1, 2, 3, ...\}$（非负整数集）

---

### 三、随机事件（Random Event）

**定义**：样本空间的子集称为随机事件，通常用大写字母 $A, B, C$ 等表示

**事件的本质**：
- 事件是**集合**，不是概率
- 事件是样本点的集合，表示某些结果的组合
- 事件发生后，可以计算其发生的概率

#### 1. 特殊事件

**必然事件**：
- 样本空间 $S$ 本身
- 每次试验必定发生
- $P(S) = 1$

**不可能事件**：
- 空集 $\emptyset$
- 每次试验必定不发生
- $P(\emptyset) = 0$

**⚠️ 重要辨析**：
> **必然事件和不可能事件都是"事件"，不是"概率"！**
> - 事件是可以计算概率的对象
> - 概率是事件发生的可能性大小的数值度量
> - **概率不能反推事件**：知道概率值无法唯一确定是哪个事件

**举例说明**：
- 事件 $A$ = "掷骰子出现偶数点" = $\{2, 4, 6\}$，则 $P(A) = \frac{1}{2}$
- 事件 $B$ = "抛两次硬币至少一次正面" = $\{HH, HT, TH\}$，则 $P(B) = \frac{3}{4}$
- 不同的事件可能有相同的概率，因此**概率不能反推事件**

#### 2. 基本事件

**定义**：只包含一个样本点的事件，也称为简单事件

**性质**：
- 基本事件之间互不相容
- 所有基本事件的并集等于样本空间

---

### 四、事件的关系与运算

#### 1. 事件的包含与相等

- **包含**：若 $A$ 发生必导致 $B$ 发生，则称 $A$ 包含于 $B$，记为 $A \subset B$
- **相等**：若 $A \subset B$ 且 $B \subset A$，则 $A = B$

#### 2. 事件的和（并）

$A \cup B$ 或 $A + B$：事件 $A$ 与事件 $B$ 至少有一个发生

**推广**：$\bigcup_{i=1}^{n} A_i$ 表示 $n$ 个事件中至少有一个发生

#### 3. 事件的积（交）

$A \cap B$ 或 $AB$：事件 $A$ 与事件 $B$ 同时发生

**推广**：$\bigcap_{i=1}^{n} A_i$ 表示 $n$ 个事件同时发生

#### 4. 事件的差

$A - B$ 或 $A\bar{B}$：事件 $A$ 发生但事件 $B$ 不发生

**性质**：
- $A - B = A \cap \bar{B}$
- $P(A - B) = P(A) - P(AB)$

**例题**：掷骰子，$A$="出现偶数"=$\{2,4,6\}$，$B$="出现3的倍数"=$\{3,6\}$
- 则 $A - B = \{2, 4\}$（出现偶数但不是3的倍数）

---

#### 5. 互不相容（互斥）⭐重要概念

**定义**：若 $AB = \emptyset$，则称 $A$ 与 $B$ 互不相容（互斥）

**含义**：两个事件不能同时发生

**重要性质**：
1. 若 $A$ 与 $B$ 互斥，则 $P(A \cup B) = P(A) + P(B)$
2. 多个事件两两互斥：$A_1, A_2, ..., A_n$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

**典型例子**：
- 掷骰子：$A$="出现1点"，$B$="出现2点"，则 $A$ 与 $B$ 互斥
- 抛硬币：$A$="正面"，$B$="反面"，则 $A$ 与 $B$ 互斥且对立

**⚠️ 易错点**：
- 互斥的事件不一定对立（如上面的掷骰子例子）
- 对立是互斥的特殊情况

---

#### 6. 对立事件（逆事件）⭐重要概念

**定义**：$\bar{A}$ 表示事件 $A$ 不发生

**性质**：
- $A \cup \bar{A} = S$（必然事件）
- $A \cap \bar{A} = \emptyset$（不可能事件）
- $P(A) + P(\bar{A}) = 1$ ⟹ $P(\bar{A}) = 1 - P(A)$

**解题技巧**：
> 当直接计算 $P(A)$ 困难时，可以考虑计算 $P(\bar{A})$，然后用 $P(A) = 1 - P(\bar{A})$
> 
> **典型应用**："至少有一个"的问题，通常用对立事件"一个都没有"来计算

**例题**：
从10个产品（8个合格，2个次品）中任取3个，求"至少有1个次品"的概率。

**解法**：
- 直接算：$P($至少1个次品$) = P(1个次品) + P(2个次品)$
- 用对立事件：$P($至少1个次品$) = 1 - P($没有次品$) = 1 - \frac{C_8^3}{C_{10}^3}$

显然用对立事件更简单！

---

**⚠️ 对立 vs 互斥的核心区别**：

| 对比项 | 互斥 | 对立 |
|--------|------|------|
| 定义 | $AB = \emptyset$ | $AB = \emptyset$ 且 $A \cup B = S$ |
| 能否同时发生 | 不能 | 不能 |
| 是否必有一个发生 | 不一定 | 一定 |
| 关系 | 对立一定互斥 | 互斥不一定对立 |
| 适用范围 | 可以是多个事件 | 只能针对两个事件 |

**记忆口诀**：
- 互斥："有你没我，有我没你"（但不能保证一定有其中一个）
- 对立："非此即彼，必有其一"（要么是你，要么是我，必须有其中一个）

---

### 五、事件的运算律

#### 1. 交换律
$$A \cup B = B \cup A, \quad AB = BA$$

#### 2. 结合律
$$(A \cup B) \cup C = A \cup (B \cup C)$$
$$(AB)C = A(BC)$$

#### 3. 分配律
$$A \cup (BC) = (A \cup B)(A \cup C)$$
$$A(B \cup C) = AB \cup AC$$

**记忆技巧**：类似于代数中的分配律 $a(b+c) = ab + ac$

#### 4. 吸收律 ⭐重要
$$A \cup (AB) = A$$
$$A(A \cup B) = A$$

**含义**：
- $A \cup (AB) = A$：如果 $A$ 发生，或者 "$A$ 和 $B$ 同时发生"，等价于 "$A$ 发生"
- $A(A \cup B) = A$：如果 "$A$ 发生" 且 "$A$ 或 $B$ 至少一个发生"，等价于 "$A$ 发生"

**直观理解**：大集合吸收小集合
- $AB \subset A$，所以 $A \cup (AB) = A$
- $A \subset (A \cup B)$，所以 $A(A \cup B) = A$

**例题**：化简 $(A \cup B)(A \cup \bar{B})$

**解**：
$$(A \cup B)(A \cup \bar{B}) = A \cup (B\bar{B}) = A \cup \emptyset = A$$

这里用了分配律和吸收律的思想。

#### 5. 德摩根律（对偶律）⭐⭐非常重要
$$\overline{A \cup B} = \bar{A} \cap \bar{B}$$
$$\overline{A \cap B} = \bar{A} \cup \bar{B}$$

**推广**：
$$\overline{\bigcup_{i=1}^{n} A_i} = \bigcap_{i=1}^{n} \bar{A_i}$$
$$\overline{\bigcap_{i=1}^{n} A_i} = \bigcup_{i=1}^{n} \bar{A_i}$$

**记忆口诀**：“并变交，交变并，外面加否定”

**德摩根律的应用**：
1. **化简复杂事件**：将多个事件的并/交的否定转化为单个事件的否定
2. **概率计算**：$P(\overline{A \cup B}) = P(\bar{A} \cap \bar{B})$
3. **考研高频考点**：经常与对立事件结合考查

**例题**：设 $A, B, C$ 为三个事件，用运算表示“$A, B, C$ 中至少有一个不发生”

**解**：
- “至少有一个不发生” = “不是全部都发生”
- 即 $\overline{ABC}$
- 由德摩根律：$\overline{ABC} = \bar{A} \cup \bar{B} \cup \bar{C}$

---

#### 6. 其他常用恒等式

1. **幂等律**：$A \cup A = A$，$AA = A$
2. **零一律**：$A \cup S = S$，$AS = A$
3. **互补律**：$A \cup \bar{A} = S$，$A\bar{A} = \emptyset$
4. **双重否定**：$\bar{\bar{A}} = A$

---

## 1.2 概率的定义与性质

### 一、概率的公理化定义

设随机试验的样本空间为 $S$，对于每个事件 $A$，赋予一个实数 $P(A)$，满足：

1. **非负性**：$P(A) \geq 0$
2. **规范性**：$P(S) = 1$
3. **可列可加性**：若 $A_1, A_2, ...$ 两两互不相容，则
   $$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

---

### 二、概率的性质

#### 性质1：不可能事件的概率为0
$$P(\emptyset) = 0$$

#### 性质2：有限可加性
若 $A_1, A_2, ..., A_n$ 两两互不相容，则
$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

#### 性质3：对立事件的概率
$$P(\bar{A}) = 1 - P(A)$$

#### 性质4：单调性
若 $A \subset B$，则 $P(A) \leq P(B)$

#### 性质5：加法公式
$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**推广（三个事件）**：
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$

#### 性质6：连续性
若 $A_1 \subset A_2 \subset ...$，则
$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \lim_{n \to \infty} P(A_n)$$

---

## 1.3 古典概型

### 一、定义

满足以下两个条件的概率模型称为古典概型：
1. **有限性**：样本空间只有有限个样本点
2. **等可能性**：每个样本点发生的可能性相同

### 二、计算公式

若样本空间 $S$ 包含 $n$ 个样本点，事件 $A$ 包含 $m$ 个样本点，则
$$P(A) = \frac{m}{n} = \frac{\text{事件A包含的样本点数}}{\text{样本空间的总样本点数}}$$

### 三、解题关键

**核心**：正确计算分子和分母（常用排列组合知识）

**常见模型**：
1. **摸球模型**：有放回、无放回
2. **分房模型**：将物品分配到不同位置
3. **配对模型**：信封与信件的匹配

---

## 1.4 几何概型

### 一、定义

当样本空间是某个可度量的几何区域，且每个样本点出现的可能性相同时，称为几何概型。

### 二、计算公式

$$P(A) = \frac{\text{事件A对应的几何度量}}{\text{样本空间的几何度量}}$$

其中几何度量可以是长度、面积、体积等。

### 三、典型例题

**约会问题**：两人约定在某时间段内见面，先到者等待一定时间后离开，求两人能见面的概率。

**解法**：用平面区域的面积比来计算。

---

## ⭐ 本章重点总结

### 核心概念
1. **样本空间**：所有可能结果的集合（基础中的基础）
2. **随机事件**：样本空间的子集（是集合，不是概率）
3. **必然事件与不可能事件**：都是事件，概率分别为1和0
4. **概率不能反推事件**：不同事件可能有相同概率

### 重要公式
1. 德摩根律：$\overline{A \cup B} = \bar{A} \cap \bar{B}$
2. 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. 对立事件：$P(\bar{A}) = 1 - P(A)$

### 易错点
1. 混淆"事件"与"概率"的概念
2. 混淆"互斥"与"对立"
3. 古典概型中样本点计数错误
4. 忽视事件的独立性条件

## ⭐ 第一章题型总结

### 题型1：事件的关系与运算 ⭐⭐

#### 考查方式

1. **选择题**：判断事件之间的关系（包含、互斥、对立、独立）
2. **填空题**：用事件运算表示复杂事件
3. **计算题**：利用事件运算律化简表达式

---

#### 典型例题

**例题1**（事件关系判断）：

设 $A$、$B$ 为两个事件，且 $P(A) > 0$，$P(B) > 0$，则下列说法正确的是：

A. 若 $A$ 与 $B$ 互斥，则 $A$ 与 $B$ 独立
B. 若 $A$ 与 $B$ 独立，则 $A$ 与 $B$ 互斥
C. 若 $A \subset B$，则 $A$ 与 $B$ 独立
D. 若 $A$ 与 $B$ 互斥，则 $A$ 与 $B$ 不独立

**解**：
- A选项：互斥 ⟹ $P(AB) = 0$，但 $P(A)P(B) > 0$，所以 $P(AB) \neq P(A)P(B)$，不独立 ✗
- B选项：独立 ⟹ $P(AB) = P(A)P(B) > 0$，所以 $AB \neq \emptyset$，不互斥 ✗
- C选项：$A \subset B$ ⟹ $AB = A$，若独立则 $P(A) = P(A)P(B)$ ⟹ $P(B) = 1$，不一定成立 ✗
- D选项：互斥 ⟹ $P(AB) = 0$，但 $P(A)P(B) > 0$，所以不独立 ✓

**答案**：D

**考点**：互斥与独立的区别（正概率事件互斥必不独立）

---

**例题2**（事件运算表示）：

用事件 $A$、$B$、$C$ 的运算表示下列事件：
1. $A$、$B$、$C$ 中至少有一个发生
2. $A$、$B$、$C$ 中都发生
3. $A$、$B$、$C$ 中恰好有一个发生
4. $A$、$B$、$C$ 中最多有一个发生
5. $A$、$B$、$C$ 中至少有两个发生

**解**：
1. **至少有一个发生**：$A \cup B \cup C$
2. **都发生**：$ABC$
3. **恰好有一个发生**：$A\bar{B}\bar{C} \cup \bar{A}B\bar{C} \cup \bar{A}\bar{B}C$
4. **最多有一个发生**：$\bar{A}\bar{B}\bar{C} \cup A\bar{B}\bar{C} \cup \bar{A}B\bar{C} \cup \bar{A}\bar{B}C$
   - 或：$\overline{AB \cup AC \cup BC}$（不是至少两个发生）
5. **至少有两个发生**：$AB \cup AC \cup BC$

**技巧**：
- “至少有一个”用并集
- “都发生”用交集
- “恰好k个”需要分别列出所有情况
- “最多k个”可以用对立事件“至少k+1个”

---

**例题3**（事件运算化简）：

化简下列事件表达式：
1. $(A \cup B)(A \cup \bar{B})$
2. $A \cup AB$
3. $(A - B) \cup (B - A)$

**解**：
1. **$(A \cup B)(A \cup \bar{B})$**：
   - 用分配律：$= A \cup (B\bar{B}) = A \cup \emptyset = A$
   - 或用吸收律：$= A$

2. **$A \cup AB$**：
   - 用吸收律：$= A$
   - 直观理解：$AB \subset A$，所以并集就是 $A$

3. **$(A - B) \cup (B - A)$**：
   - $= A\bar{B} \cup \bar{A}B$
   - 这是对称差，表示“A发生B不发生”或“B发生A不发生”
   - 不能进一步化简

**答案**：1. $A$；2. $A$；3. $A\bar{B} \cup \bar{A}B$

---

**例题4**（德摩根律应用）：

设 $A$、$B$、$C$ 为三个事件，用运算表示“$A$、$B$、$C$ 中至少有一个不发生”。

**解**：
- “至少有一个不发生” = “不是全部都发生”
- $= \overline{ABC}$
- 由德摩根律：$= \bar{A} \cup \bar{B} \cup \bar{C}$

**答案**：$\bar{A} \cup \bar{B} \cup \bar{C}$

**技巧**：遇到“至少有一个不...”时，先写成“不是全部...”，再用德摩根律

---

#### 解题技巧总结

1. **判断事件关系**：
   - 互斥 vs 独立：正概率事件互斥必不独立
   - 包含关系：$A \subset B$ 一般不独立（除非 $P(A)=1$ 或 $P(B)=0$）
   - 对立事件：一定互斥，且并集为样本空间

2. **事件运算表示**：
   - “至少有一个” → 并集 $\cup$
   - “都发生” → 交集 $\cap$ 或直接写 $ABC$
   - “恰好k个” → 列举所有情况再并起来
   - “最多k个” → 考虑用对立事件

3. **化简技巧**：
   - 熟记运算律：交换律、结合律、分配律、吸收律、德摩根律
   - 吸收律最常用：$A \cup AB = A$，$A(A \cup B) = A$
   - 德摩根律处理否定：$\overline{A \cup B} = \bar{A} \cap \bar{B}$

4. **文氏图辅助**：
   - 复杂事件关系可以画文氏图直观理解
   - 标记各区域，帮助分析

---

### 题型2：古典概型与几何概型 ⭐（考查较少）

#### 考查方式

1. **选择题/填空题**：计算简单古典概型或几何概型的概率
2. **特点**：考查频率较低，主要掌握基本概念和计算方法

---

#### 典型例题

**例题1**（古典概型-摸球问题）：

袋中有5个红球、3个白球，从中无放回地抽取3个球，求恰好抽到2个红球的概率。

**解**：
- 总样本点数：从8个球中取3个，$n = C_8^3 = 56$
- 有利样本点数：从5个红球中取2个，从3个白球中取1个，$m = C_5^2 C_3^1 = 10 \times 3 = 30$
- 概率：$P = \frac{m}{n} = \frac{30}{56} = \frac{15}{28}$

**答案**：$\frac{15}{28}$

---

**例题2**（几何概型-约会问题）：

甲乙两人约定在下午2:00-3:00之间见面，先到者等待15分钟后离开，求两人能见面的概率。

**解**：
- 设甲到达时间为 $x$，乙到达时间为 $y$（单位：分钟，从2:00开始计）
- 样本空间：$\Omega = \{(x,y) | 0 \leq x \leq 60, 0 \leq y \leq 60\}$，面积 $S_\Omega = 60^2 = 3600$
- 能见面条件：$|x - y| \leq 15$
- 不能见面的区域：两个三角形，每个面积 $\frac{1}{2} \times 45 \times 45 = 1012.5$
- 能见面概率：
  $$P = 1 - \frac{2 \times 1012.5}{3600} = 1 - \frac{2025}{3600} = 1 - \frac{9}{16} = \frac{7}{16}$$

**答案**：$\frac{7}{16}$

---

#### 解题技巧

1. **古典概型**：
   - 关键是正确计数（排列组合）
   - 注意有序vs无序
   - 常见模型：摸球、分房、配对

2. **几何概型**：
   - 画图分析，确定几何区域
   - 计算面积/长度/体积比
   - 典型问题：约会问题、Buffon投针

### 题型3：概率的性质与运算 ⭐⭐⭐高频考点

#### 考查方式

1. **选择题**：利用概率性质判断选项正误
2. **填空题**：已知部分概率，求其他概率
3. **计算题**：综合运用加法公式、减法公式等

---

#### 核心公式回顾

1. **对立事件**：$P(\bar{A}) = 1 - P(A)$
2. **加法公式**：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. **减法公式**：$P(A - B) = P(A) - P(AB)$
4. **单调性**：若 $A \subset B$，则 $P(A) \leq P(B)$
5. **取值范围**：$0 \leq P(A) \leq 1$

---

#### 典型例题

**例题1**（加法公式应用）：

已知 $P(A) = 0.5$，$P(B) = 0.4$，$P(A \cup B) = 0.7$，求：
1. $P(AB)$
2. $P(A - B)$
3. $P(\bar{A} \cup \bar{B})$

**解**：
1. **求 $P(AB)$**：
   - 由加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
   - $0.7 = 0.5 + 0.4 - P(AB)$
   - $P(AB) = 0.9 - 0.7 = 0.2$

2. **求 $P(A - B)$**：
   - $P(A - B) = P(A) - P(AB) = 0.5 - 0.2 = 0.3$

3. **求 $P(\bar{A} \cup \bar{B})$**：
   - 由德摩根律：$\bar{A} \cup \bar{B} = \overline{AB}$
   - $P(\bar{A} \cup \bar{B}) = P(\overline{AB}) = 1 - P(AB) = 1 - 0.2 = 0.8$

**答案**：1. 0.2；2. 0.3；3. 0.8

---

**例题2**（多个事件的概率）：

已知 $P(A) = P(B) = P(C) = \frac{1}{4}$，$P(AB) = P(BC) = 0$，$P(AC) = \frac{1}{8}$，求 $A$、$B$、$C$ 中至少有一个发生的概率。

**解**：
- 由三个事件的加法公式：
  $$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$
- 因为 $P(AB) = 0$，所以 $ABC \subset AB$，故 $P(ABC) = 0$
- 代入得：
  $$P(A \cup B \cup C) = \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 0 - \frac{1}{8} - 0 + 0 = \frac{3}{4} - \frac{1}{8} = \frac{5}{8}$$

**答案**：$\frac{5}{8}$

---

**⭐⭐⭐ 真题链接（2020年，数一数三）**：

设 $A, B, C$ 为三个随机事件，且 $P(A) = P(B) = P(C) = \frac{1}{4}$，$P(AB) = 0$，$P(AC) = P(BC) = \frac{1}{12}$，则 $A, B, C$ 中恰有一个事件发生的概率为：

(A) $\frac{3}{4}$  (B) $\frac{2}{3}$  (C) $\frac{1}{2}$  (D) $\frac{5}{12}$

**解**：

**方法1：直接计算（一个一个算）**

恰有一个事件发生 = $A$ 发生且 $B, C$ 不发生 + $B$ 发生且 $A, C$ 不发生 + $C$ 发生且 $A, B$ 不发生

$$P = P(A\bar{B}\bar{C}) + P(\bar{A}B\bar{C}) + P(\bar{A}\bar{B}C)$$

- $P(A\bar{B}\bar{C}) = P(A) - P(AB) - P(AC) + P(ABC)$
  - 因为 $P(AB) = 0$，所以 $P(ABC) = 0$
  - $P(A\bar{B}\bar{C}) = \frac{1}{4} - 0 - \frac{1}{12} + 0 = \frac{1}{6}$

- $P(\bar{A}B\bar{C}) = P(B) - P(AB) - P(BC) + P(ABC)$
  - $P(\bar{A}B\bar{C}) = \frac{1}{4} - 0 - \frac{1}{12} + 0 = \frac{1}{6}$

- $P(\bar{A}\bar{B}C) = P(C) - P(AC) - P(BC) + P(ABC)$
  - $P(\bar{A}\bar{B}C) = \frac{1}{4} - \frac{1}{12} - \frac{1}{12} + 0 = \frac{1}{12}$

- 总和：$P = \frac{1}{6} + \frac{1}{6} + \frac{1}{12} = \frac{2}{12} + \frac{2}{12} + \frac{1}{12} = \frac{5}{12}$

**方法2：利用文氏图思想**

$$P(\text{恰有一个}) = P(A) + P(B) + P(C) - 2[P(AB) + P(AC) + P(BC)] + 3P(ABC)$$

- $P = \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 2(0 + \frac{1}{12} + \frac{1}{12}) + 3 \times 0$
- $P = \frac{3}{4} - 2 \times \frac{2}{12} = \frac{3}{4} - \frac{1}{3} = \frac{9}{12} - \frac{4}{12} = \frac{5}{12}$

**答案**：(D) $\frac{5}{12}$

**考点分析**：
1. "恰好有一个发生"的表示方法
2. 利用 $P(AB)=0$ 推导 $P(ABC)=0$
3. 减法公式的灵活运用
4. 文氏图区域计算思想

---

**例题3**（特例法快速判断）：

设 $A$、$B$ 为任意两个事件，且 $0 < P(A) < 1$，$0 < P(B) < 1$，则下列正确的是：

A. $P(A \cup B) = P(A) + P(B)$
B. $P(A - B) = P(A) - P(B)$
C. $P(AB) \leq \min\{P(A), P(B)\}$
D. $P(A \cup B) \geq P(A) + P(B)$

**解**（特例法）：
- 取特例：$A = B$，且 $P(A) = 0.5$
- A选项：$P(A \cup A) = 0.5$，但 $P(A) + P(A) = 1$，不相等 ✗
- B选项：$P(A - A) = 0$，但 $P(A) - P(A) = 0$，相等（需进一步验证）
  - 再取特例：$A$、$B$ 有交集，$P(A)=0.6$，$P(B)=0.4$，$P(AB)=0.2$
  - $P(A-B) = 0.6 - 0.2 = 0.4$，但 $P(A)-P(B) = 0.2$，不相等 ✗
- C选项：因为 $AB \subset A$ 且 $AB \subset B$，由单调性知 $P(AB) \leq P(A)$ 且 $P(AB) \leq P(B)$
  - 所以 $P(AB) \leq \min\{P(A), P(B)\}$ ✓
- D选项：取 $A=B$，$P(A)=0.5$，则 $P(A \cup B) = 0.5$，但 $P(A)+P(B) = 1$，$0.5 \geq 1$ 不成立 ✗

**答案**：C

---

**例题4**（综合应用）：

已知 $P(A) = 0.6$，$P(B) = 0.5$，$P(A|B) = 0.8$，求：
1. $P(AB)$
2. $P(A \cup B)$
3. $P(\bar{A}|\bar{B})$

**解**：
1. **求 $P(AB)$**：
   - 由条件概率定义：$P(A|B) = \frac{P(AB)}{P(B)}$
   - $P(AB) = P(B)P(A|B) = 0.5 \times 0.8 = 0.4$

2. **求 $P(A \cup B)$**：
   - $P(A \cup B) = P(A) + P(B) - P(AB) = 0.6 + 0.5 - 0.4 = 0.7$

3. **求 $P(\bar{A}|\bar{B})$**：
   - $P(\bar{A}|\bar{B}) = \frac{P(\bar{A}\bar{B})}{P(\bar{B})}$
   - $P(\bar{B}) = 1 - P(B) = 1 - 0.5 = 0.5$
   - $P(\bar{A}\bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B) = 1 - 0.7 = 0.3$
   - $P(\bar{A}|\bar{B}) = \frac{0.3}{0.5} = 0.6$

**答案**：1. 0.4；2. 0.7；3. 0.6

1. **熟练运用基本公式**：
   - 加法公式、减法公式、对立事件公式
   - 条件概率定义式

2. **灵活转化**：
   - $P(\bar{A}\bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B)$
   - $P(A - B) = P(A\bar{B}) = P(A) - P(AB)$

3. **特例法快速排除**：
   - 选择题中，构造简单特例验证选项
   - 常用特例：$A=B$、$A \subset B$、$AB=\emptyset$

4. **文氏图辅助**：
   - 画图标出已知概率
   - 推导未知区域概率

## 1.5 条件概率、全概率公式与贝叶斯公式 ⭐⭐⭐超级重要

**考研提示**：这是概率论的**核心内容**，几乎每年必考！必须熟练掌握条件概率、乘法公式、全概率公式和贝叶斯公式。

### 一、条件概率 ⭐⭐⭐

#### 1. 定义

设 $A$、$B$ 为两个事件，且 $P(A) > 0$，则在事件 $A$ 发生的条件下，事件 $B$ 发生的**条件概率**定义为：
$$P(B|A) = \frac{P(AB)}{P(A)}$$

**核心理解**：
- 条件概率是在**缩小样本空间**后的概率
- 原样本空间为 $S$，在 $A$ 发生的条件下，样本空间缩小为 $A$
- $P(B|A)$ 表示在 $A$ **已经发生**的前提下，$B$ 发生的概率

**直观例子**：
> 掷一颗骰子，已知出现偶数点（$A$），求出现2点（$B$）的概率。
> - 无条件时：$P(B) = \frac{1}{6}$
> - 已知 $A$ 发生后：样本空间从 $\{1,2,3,4,5,6\}$ 缩小为 $\{2,4,6\}$
> - 所以 $P(B|A) = \frac{1}{3}$

#### 2. 条件概率的性质

条件概率也满足概率的所有公理和性质：

1. **非负性**：$P(B|A) \geq 0$
2. **规范性**：$P(S|A) = 1$
3. **可列可加性**：若 $B_1, B_2, ...$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{\infty} B_i | A\right) = \sum_{i=1}^{\infty} P(B_i|A)$$

**⭐⭐⭐重要结论**：
> **条件概率符合概率的一切性质！**
> 
> 这意味着所有关于概率的公式和定理，在条件概率下仍然成立！只需在所有概率符号后面加上条件 $|A$ 即可。

**具体应用举例**：

1. **对立事件公式**（在条件 $A$ 下）：
   $$P(\bar{B}|A) = 1 - P(B|A)$$

2. **加法公式**（在条件 $A$ 下）：
   $$P(B \cup C|A) = P(B|A) + P(C|A) - P(BC|A)$$

3. **乘法公式**（在条件 $A$ 下）：
   $$P(BC|A) = P(B|A)P(C|AB)$$

4. **全概率公式**（在条件 $A$ 下）：
   若 $C_1, C_2, ..., C_n$ 是划分，则
   $$P(B|A) = \sum_{i=1}^{n} P(C_i|A)P(B|AC_i)$$

5. **单调性**（在条件 $A$ 下）：
   若 $B \subset C$，则 $P(B|A) \leq P(C|A)$

**解题技巧**：
> 当题目中出现复杂的条件概率时，可以把条件概率当作普通概率来处理，直接套用所有概率公式！
> 
> 例如：看到 $P(B \cup C|A)$，立即想到用加法公式展开为 $P(B|A) + P(C|A) - P(BC|A)$

---

### 二、乘法公式 ⭐⭐

由条件概率的定义可直接得到乘法公式：

#### 1. 两个事件的乘法公式

$$P(AB) = P(A)P(B|A) \quad (P(A) > 0)$$

或

$$P(AB) = P(B)P(A|B) \quad (P(B) > 0)$$

**理解**：$A$ 和 $B$ 同时发生的概率 = $A$ 发生的概率 × 在 $A$ 发生的条件下 $B$ 发生的概率

#### 2. 多个事件的乘法公式（链式法则）

$$P(A_1 A_2 ... A_n) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2)...P(A_n|A_1 A_2 ... A_{n-1})$$

**记忆技巧**：链式展开，逐个条件化

#### 3. 典型应用

**例题1**：袋中有5个红球、3个白球，无放回地摸3次，求三次都摸到红球的概率。

**解**：
- 设 $A_i$ = "第 $i$ 次摸到红球"（$i=1,2,3$）
- $P(A_1) = \frac{5}{8}$
- $P(A_2|A_1) = \frac{4}{7}$（第1次摸走一个红球后，剩4红3白）
- $P(A_3|A_1 A_2) = \frac{3}{6} = \frac{1}{2}$（前两次摸走两个红球后，剩3红3白）
- 由乘法公式：
  $$P(A_1 A_2 A_3) = P(A_1)P(A_2|A_1)P(A_3|A_1 A_2) = \frac{5}{8} \times \frac{4}{7} \times \frac{1}{2} = \frac{5}{28}$$

**例题2**：某产品需经过3道工序，各道工序的合格率分别为0.9、0.8、0.7，假设各工序独立，求产品最终合格的概率。

**解**：
- 设 $A_i$ = "第 $i$ 道工序合格"（$i=1,2,3$）
- 由于各工序独立，$P(A_2|A_1) = P(A_2)$，$P(A_3|A_1 A_2) = P(A_3)$
- $P(A_1 A_2 A_3) = P(A_1)P(A_2)P(A_3) = 0.9 \times 0.8 \times 0.7 = 0.504$

### 三、完备事件组（样本空间的划分）⭐⭐重要概念

**定义**：
设 $S$ 为样本空间，$B_1, B_2, ..., B_n$ 为一组事件，如果满足：
1. **两两互斥**：$B_i B_j = \emptyset$（$i \neq j$），即任意两个事件不能同时发生
2. **完备性**：$\bigcup_{i=1}^{n} B_i = S$，即所有事件的并集等于样本空间
3. **非零概率**：$P(B_i) > 0$（$i = 1, 2, ..., n$）

则称 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个**完备事件组**（或**划分**）。

**核心理解**：
> 完备事件组就是将样本空间"分完"且"不重叠"地分成若干部分
> - "分完"：所有部分加起来覆盖整个样本空间（完备性）
> - "不重叠"：任意两个部分没有交集（互斥性）

**直观图示**：
```
样本空间 S
┌─────────────────┐
│  B₁  │  B₂      │
│──────┼──────┤   │
│  B₃  │  B₄  │   │
└─────────────────┘
```
$B_1, B_2, B_3, B_4$ 构成一个完备事件组

**常见完备事件组**：

1. **最简单的情形**：$B$ 和 $\bar{B}$ 构成一个完备事件组
   - $B \cap \bar{B} = \emptyset$（互斥）
   - $B \cup \bar{B} = S$（完备）

2. **摸球问题**：
   - "第一次摸到红球"（$B_1$）和"第一次摸到白球"（$B_2$）构成完备事件组
   
3. **多分类问题**：
   - "产品来自第1条生产线"（$B_1$）
   - "产品来自第2条生产线"（$B_2$）
   - "产品来自第3条生产线"（$B_3$）
   - 这三个事件构成完备事件组

4. **考试成绩**：
   - "优秀"（$B_1$）、"良好"（$B_2$）、"中等"（$B_3$）、"及格"（$B_4$）、"不及格"（$B_5$）
   - 这五个事件构成完备事件组

**⚠️ 易错点**：
- 必须同时满足"互斥"和"完备"两个条件
- 只有互斥但不完备：如掷骰子的"出现1点"和"出现2点"（还有3、4、5、6点没包括）
- 完备但不互斥：如"出现偶数点"和"出现不大于4的点"（有重叠：2和4）

**判断方法**：
1. 检查是否两两互斥：$B_i B_j = \emptyset$（$i \neq j$）
2. 检查是否完备：$\bigcup_{i=1}^{n} B_i = S$
3. 检查概率是否为正：$P(B_i) > 0$

---

### 四、全概率公式 ⭐⭐⭐核心考点

#### 1. 全概率公式

设 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个划分，$A$ 为任意事件，则：

$$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) + ... + P(B_n)P(A|B_n)$$

**证明**：
- 因为 $B_1, B_2, ..., B_n$ 是划分，所以 $A = A \cap S = A \cap \left(\bigcup_{i=1}^{n} B_i\right) = \bigcup_{i=1}^{n} (AB_i)$
- 又因为 $B_i$ 两两互斥，所以 $AB_i$ 也两两互斥
- 由可加性：$P(A) = \sum_{i=1}^{n} P(AB_i)$
- 由乘法公式：$P(AB_i) = P(B_i)P(A|B_i)$
- 所以 $P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$

**核心理解**：
> 全概率公式的本质是**"分情况讨论"**
> 
> 计算事件 $A$ 的概率时，如果直接计算困难，可以将样本空间划分为若干种情况 $B_1, B_2, ..., B_n$，分别计算每种情况下 $A$ 发生的概率，然后加权求和。

**解题步骤**：
1. **找划分**：找到合适的完备事件组 $B_1, B_2, ..., B_n$
2. **算先验概率**：计算 $P(B_i)$
3. **算条件概率**：计算 $P(A|B_i)$
4. **代入公式**：$P(A) = \sum P(B_i)P(A|B_i)$

#### 2. 典型例题

**例题1**（经典摸球问题）：

袋中有5个红球、3个白球，有放回地摸2次，求第2次摸到红球的概率。

**解**：
- 设 $A$ = "第2次摸到红球"
- 设 $B_1$ = "第1次摸到红球"，$B_2$ = "第1次摸到白球"
- $B_1, B_2$ 构成一个划分
- $P(B_1) = \frac{5}{8}$，$P(B_2) = \frac{3}{8}$
- $P(A|B_1) = \frac{5}{8}$（有放回，第1次摸到红球不影响第2次）
- $P(A|B_2) = \frac{5}{8}$（有放回，第1次摸到白球不影响第2次）
- 由全概率公式：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = \frac{5}{8} \times \frac{5}{8} + \frac{3}{8} \times \frac{5}{8} = \frac{5}{8}$$

**例题2**（无放回摸球）：

袋中有5个红球、3个白球，**无放回**地摸2次，求第2次摸到红球的概率。

**解**：
- 设 $A$ = "第2次摸到红球"
- 设 $B_1$ = "第1次摸到红球"，$B_2$ = "第1次摸到白球"
- $P(B_1) = \frac{5}{8}$，$P(B_2) = \frac{3}{8}$
- $P(A|B_1) = \frac{4}{7}$（第1次摸走一个红球后，剩4红3白）
- $P(A|B_2) = \frac{5}{7}$（第1次摸走一个白球后，剩5红2白）
- 由全概率公式：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = \frac{5}{8} \times \frac{4}{7} + \frac{3}{8} \times \frac{5}{7} = \frac{35}{56} = \frac{5}{8}$$

**有趣结论**：无论是否有放回，第2次摸到红球的概率都等于第1次摸到红球的概率（对称性）！

**重要启示**：
> 这个结论可以推广：在无放回摸球中，第 $k$ 次摸到红球的概率与第1次相同，都是 $\frac{5}{8}$。
> 
> 这体现了**抽签的公平性**：先抽后抽概率一样！

**例题3**（产品质量检验）：

某工厂有3条生产线，产量分别占总产量的30%、40%、30%，次品率分别为2%、3%、1%。从产品中任取一件，求它是次品的概率。

**解**：
- 设 $A$ = "取到次品"
- 设 $B_i$ = "产品来自第 $i$ 条生产线"（$i=1,2,3$）
- $P(B_1) = 0.3$，$P(B_2) = 0.4$，$P(B_3) = 0.3$
- $P(A|B_1) = 0.02$，$P(A|B_2) = 0.03$，$P(A|B_3) = 0.01$
- 由全概率公式：
  $$P(A) = 0.3 \times 0.02 + 0.4 \times 0.03 + 0.3 \times 0.01 = 0.006 + 0.012 + 0.003 = 0.021$$

**例题4**（疾病诊断问题）：

某疾病的患病率为0.1%，一种检测方法的准确率为：如果患病，检测为阳性的概率为99%；如果未患病，检测为阴性的概率为95%。现某人检测结果为阳性，求他确实患病的概率。

**解**：
- 设 $A$ = "检测结果为阳性"
- 设 $B_1$ = "患病"，$B_2$ = "未患病"
- $B_1, B_2$ 构成完备事件组
- $P(B_1) = 0.001$，$P(B_2) = 0.999$
- $P(A|B_1) = 0.99$（患病时检测为阳性的概率）
- $P(A|B_2) = 0.05$（未患病时检测为阳性的概率，即误诊率）
- 由全概率公式，先计算 $P(A)$：
  $$P(A) = P(B_1)P(A|B_1) + P(B_2)P(A|B_2) = 0.001 \times 0.99 + 0.999 \times 0.05 = 0.05094$$
- 这步是全概率公式的典型应用！

**注意**：这个题目继续用贝叶斯公式求后验概率，见下文。

---

#### 3. 全概率公式的应用场景总结

**何时使用全概率公式？**

1. **"来自不同来源"的问题**：
   - 产品来自不同生产线
   - 病人来自不同地区
   - 信号来自不同发送端

2. **"分阶段进行"的问题**：
   - 多次摸球（第2次、第3次的概率）
   - 多道工序加工
   - 多轮比赛

3. **"至少有一个"的复杂情况**：
   - 有时可以用对立事件，有时需要用全概率公式分情况讨论

**解题关键点**：
- **找准划分**：这是最关键的一步！要根据题意找到合适的完备事件组
- **常见划分方式**：
  - 按"第一次的结果"划分（摸球问题）
  - 按"来源"划分（产品质量问题）
  - 按"状态"划分（患病/未患病）
  - 按"真假"划分（真币/假币、真品/赝品）

### 五、贝叶斯公式（逆概率公式）⭐⭐⭐核心考点

#### 1. 贝叶斯公式

设 $B_1, B_2, ..., B_n$ 为样本空间 $S$ 的一个划分，$A$ 为任意事件且 $P(A) > 0$，则：

$$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{\sum_{i=1}^{n} P(B_i)P(A|B_i)} = \frac{P(B_k)P(A|B_k)}{P(A)} \quad (k = 1, 2, ..., n)$$

**理解**：
- 贝叶斯公式用于计算**后验概率** $P(B_k|A)$
- 已知"原因" $B_k$ 导致"结果" $A$ 的概率 $P(A|B_k)$，反过来求已知"结果" $A$ 发生时，是由"原因" $B_k$ 导致的概率 $P(B_k|A)$
- 分母 $P(A)$ 用全概率公式计算

#### 2. 相关概念

- **先验概率**：$P(B_k)$，在观察到结果之前，对各种原因的概率估计
- **似然度**：$P(A|B_k)$，在原因 $B_k$ 下，观察到结果 $A$ 的可能性
- **后验概率**：$P(B_k|A)$，观察到结果 $A$ 后，对原因 $B_k$ 的修正概率

#### 3. 典型例题

**例题**（接上面的产品质量检验）：

某工厂有3条生产线，产量分别占总产量的30%、40%、30%，次品率分别为2%、3%、1%。从产品中任取一件，发现是次品，求它来自第2条生产线的概率。

**解**：
- 设 $A$ = "取到次品"
- 设 $B_i$ = "产品来自第 $i$ 条生产线"（$i=1,2,3$）
- 已知：$P(B_1) = 0.3$，$P(B_2) = 0.4$，$P(B_3) = 0.3$
- 已知：$P(A|B_1) = 0.02$，$P(A|B_2) = 0.03$，$P(A|B_3) = 0.01$
- 由全概率公式：$P(A) = 0.021$（前面已计算）
- 由贝叶斯公式：
  $$P(B_2|A) = \frac{P(B_2)P(A|B_2)}{P(A)} = \frac{0.4 \times 0.03}{0.021} = \frac{0.012}{0.021} = \frac{4}{7} \approx 0.571$$

**解读**：虽然第2条生产线的产量占40%，但已知取到的是次品后，它来自第2条生产线的概率上升到约57.1%，因为第2条生产线的次品率最高。

---

**例题2**（疾病诊断问题，接全概率公式例题4）：

某疾病的患病率为0.1%，一种检测方法的准确率为：如果患病，检测为阳性的概率为99%；如果未患病，检测为阴性的概率为95%。现某人检测结果为阳性，求他确实患病的概率。

**解**：
- 设 $A$ = "检测结果为阳性"
- 设 $B_1$ = "患病"，$B_2$ = "未患病"
- 已知：$P(B_1) = 0.001$，$P(B_2) = 0.999$
- 已知：$P(A|B_1) = 0.99$，$P(A|B_2) = 0.05$
- 由全概率公式（前面已计算）：$P(A) = 0.05094$
- 由贝叶斯公式：
  $$P(B_1|A) = \frac{P(B_1)P(A|B_1)}{P(A)} = \frac{0.001 \times 0.99}{0.05094} = \frac{0.00099}{0.05094} \approx 0.0194$$

**惊人的结论**：
> 即使检测结果为阳性，真正患病的概率只有约1.94%！
> 
> **原因分析**：
> - 患病率很低（0.1%），所以大部分人都是未患病的
> - 虽然检测准确率很高，但未患病人数太多，导致误诊的绝对数量很大
> - 这就是**假阳性问题**，在医学检测中非常重要

**启示**：
- 对于罕见病，即使检测准确率很高，阳性结果也不一定意味着真的患病
- 通常需要多次检测来降低误诊率

---

**例题3**（信号传输问题）：

某通信系统发送信号0和1，发送0的概率为0.6，发送1的概率为0.4。由于噪声干扰，接收端可能出错：
- 发送0时，接收为0的概率为0.9，接收为1的概率为0.1
- 发送1时，接收为1的概率为0.8，接收为0的概率为0.2

现接收端收到信号1，求发送端实际发送的是1的概率。

**解**：
- 设 $A$ = "接收为1"
- 设 $B_0$ = "发送0"，$B_1$ = "发送1"
- 已知：$P(B_0) = 0.6$，$P(B_1) = 0.4$
- 已知：$P(A|B_0) = 0.1$，$P(A|B_1) = 0.8$
- 由全概率公式：
  $$P(A) = P(B_0)P(A|B_0) + P(B_1)P(A|B_1) = 0.6 \times 0.1 + 0.4 \times 0.8 = 0.06 + 0.32 = 0.38$$
- 由贝叶斯公式：
  $$P(B_1|A) = \frac{P(B_1)P(A|B_1)}{P(A)} = \frac{0.4 \times 0.8}{0.38} = \frac{0.32}{0.38} = \frac{16}{19} \approx 0.842$$

**解读**：接收到1后，有约84.2%的把握认为发送的就是1。

#### 4. 贝叶斯公式的核心思想 ⭐⭐⭐重要理解

**全概率公式（因→果）vs 贝叶斯公式（果→因）**：

这是理解两个公式本质的关键！

| 对比项 | 全概率公式 | 贝叶斯公式 |
|--------|-----------|----------|
| **方向** | 因 → 果 | 果 → 因 |
| **已知** | 各种原因 $B_i$ 的概率 $P(B_i)$ <br> 各原因导致结果的概率 $P(A|B_i)$ | 观察到结果 $A$ <br> 各种原因的先验概率 $P(B_i)$ <br> 各原因的似然度 $P(A|B_i)$ |
| **求解** | 结果 $A$ 发生的总概率 $P(A)$ | 某个原因 $B_k$ 导致的后验概率 $P(B_k|A)$ |
| **公式** | $P(A) = \sum P(B_i)P(A|B_i)$ | $P(B_k|A) = \frac{P(B_k)P(A|B_k)}{P(A)}$ |
| **思维** | 正向推理：从原因推结果 | 逆向推理：从结果推原因 |
| **应用** | 计算复杂事件的概率 | 根据证据推断最可能的原因 |

**直观例子**（产品质量问题）：

- **全概率公式（因→果）**：
  > 已知：产品来自三条生产线的比例，以及各生产线的次品率
  > 
  > 问：任取一件产品，是次品的概率是多少？
  > 
  > 思路：从"生产线"（因）推到"次品"（果）

- **贝叶斯公式（果→因）**：
  > 已知：取到一件次品
  > 
  > 问：它来自第2条生产线的概率是多少？
  > 
  > 思路：从"次品"（果）推到"生产线"（因）

---

**从"因"到"果" vs 从"果"到"因"的完整对比**：

| 方向 | 公式 | 名称 | 含义 | 典型问题 |
|------|------|------|------|----------|
| 因→果 | $P(A|B_k)$ | 似然度/条件概率 | 已知原因，求结果的概率 | "如果患病，检测阳性的概率是多少？" |
| 果→因 | $P(B_k|A)$ | 后验概率 | 已知结果，推断原因的概率 | "检测阳性，患病的概率是多少？" |

**贝叶斯思维的本质**：
> 贝叶斯公式体现了**"根据新证据更新信念"**的思想
> 
> 1. **先验概率** $P(B_k)$：在观察到证据之前的初始信念
> 2. **新证据** $A$：观察到的结果
> 3. **后验概率** $P(B_k|A)$：根据新证据修正后的信念
>
> **核心**：用新的信息（证据）来修正我们原有的判断！

**应用场景**：
- **医学诊断**：根据检测结果推断是否患病
- **质量控制**：根据产品缺陷推断来自哪条生产线
- **机器学习**：朴素贝叶斯分类器
- **人工智能**：贝叶斯网络、概率推理
- **金融风控**：根据行为特征判断是否为欺诈

---

#### 5. 解题步骤总结

**使用贝叶斯公式的标准流程**：

1. **确定事件**：
   - 明确"结果"事件 $A$
   - 明确"原因"事件 $B_1, B_2, ..., B_n$（构成完备事件组）

2. **收集已知信息**：
   - 先验概率：$P(B_i)$
   - 似然度：$P(A|B_i)$

3. **计算分母**（用全概率公式）：
   $$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$$

4. **代入贝叶斯公式**：
   $$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{P(A)}$$

5. **解释结果**：
   - 后验概率与先验概率的对比
   - 为什么会有这样的变化

## 1.6 事件的独立性

### 一、事件独立的定义 ⭐⭐

**定义**：设 $A$、$B$ 为两个事件，如果
$$P(AB) = P(A)P(B)$$
则称事件 $A$ 与事件 $B$ **相互独立**。

**核心理解**：
- 独立性描述的是两个事件之间**没有影响**的关系
- $A$ 的发生与否不影响 $B$ 发生的概率，反之亦然
- 等价表述：$P(B|A) = P(B)$（当 $P(A) > 0$ 时）

**直观例子**：
> 抛两次硬币，第一次的结果不会影响第二次的结果，所以两次抛硬币是独立的。

---

### 二、两两独立与相互独立 ⭐⭐易混淆

#### 1. 两两独立

三个事件 $A, B, C$ **两两独立**是指：
$$P(AB) = P(A)P(B), \quad P(AC) = P(A)P(C), \quad P(BC) = P(B)P(C)$$

#### 2. 相互独立

三个事件 $A, B, C$ **相互独立**是指：
1. 两两独立：$P(AB) = P(A)P(B)$，$P(AC) = P(A)P(C)$，$P(BC) = P(B)P(C)$
2. 三者积的概率：$P(ABC) = P(A)P(B)P(C)$

**关键区别**：
> **两两独立不一定相互独立！**
> 
> 相互独立要求更强，不仅要两两独立，还要三者积的概率等于概率的积。

#### 3. 伯恩斯坦反例（Bernstein's Counterexample）

**构造**：
- 一个均匀的正四面体，四个面分别涂色：
  - 第1面：红色
  - 第2面：白色
  - 第3面：黑色
  - 第4面：红白黑三色
- 抛掷一次，定义事件：
  - $A$ = "出现红色"（第1面或第4面）
  - $B$ = "出现白色"（第2面或第4面）
  - $C$ = "出现黑色"（第3面或第4面）

**验证**：
- $P(A) = P(B) = P(C) = \frac{2}{4} = \frac{1}{2}$
- $P(AB) = P(AC) = P(BC) = \frac{1}{4}$（只有第4面同时有两种颜色）
- $P(A)P(B) = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4} = P(AB)$ ✓
- 所以 $A, B, C$ 两两独立

但是：
- $P(ABC) = \frac{1}{4}$（只有第4面同时有三种颜色）
- $P(A)P(B)P(C) = \frac{1}{2} \times \frac{1}{2} \times \frac{1}{2} = \frac{1}{8}$
- $P(ABC) \neq P(A)P(B)P(C)$ ✗

**结论**：$A, B, C$ 两两独立，但不相互独立！

---

### 三、独立性与互斥性的区别 ⭐⭐⭐高频考点

| 对比项 | 独立性 | 互斥性 |
|--------|--------|--------|
| **定义** | $P(AB) = P(A)P(B)$ | $AB = \emptyset$ ⟹ $P(AB) = 0$ |
| **本质** | 两个事件互不影响 | 两个事件不能同时发生 |
| **概率关系** | $P(AB) = P(A)P(B)$ | $P(AB) = 0$ |
| **能否同时发生** | 可以同时发生（除非概率为0） | 不能同时发生 |
| **适用范围** | 可以是任意事件 | 可以是任意事件 |

**重要结论**：

1. **若 $P(A) > 0$ 且 $P(B) > 0$，则 $A$ 与 $B$ 互斥必不独立**
   - 证明：若互斥，则 $P(AB) = 0$；若独立，则 $P(AB) = P(A)P(B) > 0$，矛盾！

2. **若 $A$ 与 $B$ 独立，且 $P(A) > 0$，$P(B) > 0$，则 $A$ 与 $B$ 必不互斥**
   - 证明：若独立，则 $P(AB) = P(A)P(B) > 0$，所以 $AB \neq \emptyset$，不互斥

3. **特殊情况**：
   - 若 $P(A) = 0$ 或 $P(B) = 0$，则 $A$ 与 $B$ 既互斥又独立（因为 $P(AB) = 0 = P(A)P(B)$）

**选择题快速判断技巧**：
> - **AB互斥一般不独立**（正概率事件互斥必不独立）
> - **A包含B，一般也不独立**（除非 $P(A)=1$ 或 $P(B)=0$）

**证明"A包含B一般不独立"**：
- 若 $A \supset B$，则 $AB = B$
- 若独立，则 $P(B) = P(AB) = P(A)P(B)$
- 若 $P(B) > 0$，则 $P(A) = 1$
- 所以除非 $P(A) = 1$，否则不独立

---

### 四、独立事件的性质

#### 性质1：独立性的等价表述

若 $P(A) > 0$，则以下等价：
1. $A$ 与 $B$ 独立
2. $P(B|A) = P(B)$
3. $P(A|B) = P(A)$（若 $P(B) > 0$）

#### 性质2：独立事件的补事件也独立

若 $A$ 与 $B$ 独立，则以下四对事件都相互独立：
1. $A$ 与 $B$
2. $A$ 与 $\bar{B}$
3. $\bar{A}$ 与 $B$
4. $\bar{A}$ 与 $\bar{B}$

**证明**（以 $A$ 与 $\bar{B}$ 为例）：
- $P(A\bar{B}) = P(A) - P(AB) = P(A) - P(A)P(B) = P(A)[1 - P(B)] = P(A)P(\bar{B})$
- 所以 $A$ 与 $\bar{B}$ 独立

#### 性质3：多个事件的独立性

若 $A_1, A_2, ..., A_n$ 相互独立，则：
$$P(A_1 A_2 ... A_n) = P(A_1)P(A_2)...P(A_n)$$

且其中任意多个事件也相互独立，任意替换为补事件后仍相互独立。

#### 性质4：独立事件的并的概率

若 $A$ 与 $B$ 独立，则：
$$P(A \cup B) = P(A) + P(B) - P(A)P(B)$$

**推广**（$n$ 个独立事件）：
$$P\left(\bigcup_{i=1}^{n} A_i\right) = 1 - P\left(\bigcap_{i=1}^{n} \bar{A_i}\right) = 1 - \prod_{i=1}^{n} [1 - P(A_i)]$$

**应用**："至少有一个发生"的问题，当事件独立时，用对立事件计算更简单。

---

### 五、独立重复试验与伯努利概型

#### 1. 独立重复试验

**定义**：在相同条件下重复进行 $n$ 次试验，每次试验的结果互不影响，称为**独立重复试验**。

**特点**：
- 每次试验的条件相同
- 各次试验相互独立
- 每次试验只有两种可能结果：成功（$A$）或失败（$\bar{A}$）

#### 2. 伯努利概型（Bernoulli Scheme）

**定义**：在 $n$ 次独立重复试验中，每次试验成功的概率为 $p$，失败的概率为 $1-p$，则称为**伯努利概型**。

**二项分布公式**：
在 $n$ 次伯努利试验中，恰好成功 $k$ 次的概率为：
$$P_n(k) = C_n^k p^k (1-p)^{n-k}, \quad k = 0, 1, 2, ..., n$$

记作：$X \sim B(n, p)$

**参数说明**：
- $n$：试验次数
- $p$：每次试验成功的概率
- $k$：成功的次数（$k = 0, 1, 2, ..., n$）**⭐注意标明k的范围**

**期望与方差**：
- $E(X) = np$
- $D(X) = np(1-p)$

---

#### 3. 重要结论

**结论1**：若 $X_1, X_2, ..., X_n$ 都服从 $B(1, p)$（0-1分布），且相互独立，则
$$X = X_1 + X_2 + ... + X_n \sim B(n, p)$$

**理解**：$n$ 次独立的0-1试验之和服从二项分布

**结论2**：二项分布的最大值

若 $X \sim B(n, p)$，则 $P(X = k)$ 在 $k = [(n+1)p]$ 时取得最大值（$[x]$ 表示不超过 $x$ 的最大整数）

---

#### 4. 典型例题

**例题1**（射击问题）：

某射手命中率为0.8，独立射击5次，求：
1. 恰好命中3次的概率
2. 至少命中3次的概率

**解**：
- 设 $X$ = "命中次数"，则 $X \sim B(5, 0.8)$

1. **恰好命中3次**：
   $$P(X = 3) = C_5^3 (0.8)^3 (0.2)^2 = 10 \times 0.512 \times 0.04 = 0.2048$$

2. **至少命中3次**：
   $$P(X \geq 3) = P(X=3) + P(X=4) + P(X=5)$$
   $$= C_5^3 (0.8)^3 (0.2)^2 + C_5^4 (0.8)^4 (0.2)^1 + C_5^5 (0.8)^5 (0.2)^0$$
   $$= 0.2048 + 0.4096 + 0.3277 = 0.9421$$

**答案**：1. 0.2048；2. 0.9421

---

**例题2**（产品质量检验）：

某产品的次品率为0.1，从中随机抽取10件，求：
1. 恰好有2件次品的概率
2. 至少有1件次品的概率

**解**：
- 设 $X$ = "次品数"，则 $X \sim B(10, 0.1)$

1. **恰好2件次品**：
   $$P(X = 2) = C_{10}^2 (0.1)^2 (0.9)^8 = 45 \times 0.01 \times 0.4305 = 0.1937$$

2. **至少1件次品**（用对立事件）：
   $$P(X \geq 1) = 1 - P(X = 0) = 1 - C_{10}^0 (0.1)^0 (0.9)^{10} = 1 - 0.3487 = 0.6513$$

**答案**：1. 0.1937；2. 0.6513

---

**例题3**（考试猜题）：

某选择题有4个选项，只有一个正确答案。某学生完全不会，随机猜测10道这样的题目，求：
1. 恰好答对3道的概率
2. 至少答对1道的概率

**解**：
- 每道题答对的概率 $p = \frac{1}{4} = 0.25$
- 设 $X$ = "答对题数"，则 $X \sim B(10, 0.25)$

1. **恰好答对3道**：
   $$P(X = 3) = C_{10}^3 (0.25)^3 (0.75)^7 = 120 \times 0.015625 \times 0.1335 = 0.2503$$

2. **至少答对1道**：
   $$P(X \geq 1) = 1 - P(X = 0) = 1 - (0.75)^{10} = 1 - 0.0563 = 0.9437$$

**答案**：1. 0.2503；2. 0.9437

### 六、解题技巧总结

#### 1. 如何判断事件是否独立？

| 判断方法 | 说明 |
|---------|------|
| **定义法** | 验证 $P(AB) = P(A)P(B)$ |
| **条件概率法** | 验证 $P(B|A) = P(B)$ |
| **实际意义** | 根据问题的实际背景判断是否有影响 |
| **题目给定** | 题目明确说明"独立"或"相互独立" |

#### 2. 独立性 vs 互斥性快速判断

- **正概率事件互斥必不独立**
- **正概率事件独立必不互斥**
- **包含关系一般不独立**（除非概率为0或1）

#### 3. 伯努利概型的识别

**关键词**：
- "独立重复试验"
- "每次成功的概率为p"
- "n次试验中恰好k次成功"

**解题步骤**：
1. 确认是否符合伯努利概型（独立、重复、两种结果）
2. 确定参数 $n$ 和 $p$
3. 代入二项分布公式 $P(X=k) = C_n^k p^k (1-p)^{n-k}$
4. 注意 $k$ 的范围：$k = 0, 1, 2, ..., n$

#### 4. "至少有一个"问题的处理

**方法1**：直接相加
$$P(X \geq 1) = P(X=1) + P(X=2) + ... + P(X=n)$$

**方法2**：用对立事件（推荐）
$$P(X \geq 1) = 1 - P(X=0) = 1 - (1-p)^n$$

显然方法2更简单！

## ⭐ 本章重点总结

### 核心概念
1. **概率公理化定义**：非负性、规范性、可列可加性
2. **古典概型**：有限性 + 等可能性（考查较少）
3. **几何概型**：几何度量之比（考查较少）
4. **条件概率**：缩小样本空间后的概率
5. **完备事件组**：互斥且完备的划分
6. **事件独立性**：$P(AB) = P(A)P(B)$
7. **伯努利概型**：$n$ 次独立重复试验

### 重要公式
1. 对立事件：$P(\bar{A}) = 1 - P(A)$
2. 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. 减法公式：$P(A - B) = P(A) - P(AB)$
4. **条件概率**：$P(B|A) = \frac{P(AB)}{P(A)}$
5. **乘法公式**：$P(AB) = P(A)P(B|A)$
6. **全概率公式**：$P(A) = \sum_{i=1}^{n} P(B_i)P(A|B_i)$
7. **贝叶斯公式**：$P(B_k|A) = \frac{P(B_k)P(A|B_k)}{P(A)}$
8. **独立性定义**：$P(AB) = P(A)P(B)$
9. **二项分布**：$P(X=k) = C_n^k p^k (1-p)^{n-k}$，$k=0,1,...,n$
10. 古典概型：$P(A) = \frac{m}{n}$
11. 几何概型：$P(A) = \frac{L(A)}{L(\Omega)}$

### 解题技巧

#### 1. "至少有一个"问题
用对立事件"一个都没有"来计算：
$$P(\text{至少一个}) = 1 - P(\text{都没有})$$

#### 2. 古典概型
关键是正确计数（排列组合），注意有序vs无序

#### 3. 几何概型
画图分析，计算面积/长度比

#### 4. ⭐⭐ 复杂事件的处理方法

**方法1：特例法（赋值法）**

**适用场景**：选择题中，题目给出抽象事件关系，求概率关系

**思路**：
- 将抽象事件具体化，构造一个简单的特例
- 通过特例验证选项的正确性
- 如果特例不满足某个选项，则该选项错误

**例题**：设 $A$、$B$ 为任意两个事件，则下列正确的是：
A. $P(A \cup B) = P(A) + P(B)$
B. $P(A - B) = P(A) - P(B)$
C. $P(AB) \leq P(A)$
D. $P(A \cup B) \geq P(A) + P(B)$

**解**（特例法）：
- 取特例：$A = B$，且 $P(A) = 0.5$
- A选项：$P(A \cup A) = P(A) = 0.5$，但 $P(A) + P(A) = 1$，不相等 ✗
- B选项：$P(A - A) = P(\emptyset) = 0$，但 $P(A) - P(A) = 0$，相等 ✓（但这只是特例，需要进一步验证）
  - 再取特例：$B \subset A$，$P(A)=0.6$，$P(B)=0.3$
  - $P(A-B) = 0.3$，但 $P(A)-P(B) = 0.3$，相等
  - 再取特例：$A$、$B$ 有交集但不包含
  - $P(A-B) = P(A) - P(AB) \neq P(A) - P(B)$ ✗
- C选项：因为 $AB \subset A$，由单调性知 $P(AB) \leq P(A)$ ✓
- D选项：取 $A=B$，$P(A)=0.5$，则 $P(A \cup B) = 0.5$，但 $P(A)+P(B) = 1$，$0.5 \geq 1$ 不成立 ✗

**答案**：C

---

**方法2：文氏图法（Venn Diagram）**

**适用场景**：
- 多个事件的并、交、差运算
- 直观理解事件关系
- 计算复杂事件的概率

**基本图形**：
```
     ┌─────────────┐
     │      A      │
     │   ┌─────┐   │
     │   │ AB  │   │
     │   └─────┘   │
     │             │
     └─────────────┘
```

**常用区域标记**：
- $A$ 独有的部分：$A - B$ 或 $A\bar{B}$
- $B$ 独有的部分：$B - A$ 或 $\bar{A}B$
- $A$ 和 $B$ 的交集：$AB$
- $A$ 和 $B$ 的并集：$A \cup B$

**三事件文氏图**：
```
        ┌───────┐
       /    A    \
      /  ┌─────┐  \
     |  /   ABC   \  |
    |  |  ┌─────┐  |  |
    | /  /   AB   \  \ |
    ||  ||  ┌─────┐  || |
    ||  || /   A   \  || |
    ||  || |       |  || |
    | \  \ \       / /  | |
     |  |  \     /  |  | |
     |   \  \___/   /   |
      \   \_____/   /   /
       \           /   /
        \_________/   /
         \    B      / /
          \_________/ /
           \       / /
            \_____/_/
             \   / /
              \_/_/
               C
```

**应用步骤**：
1. **画文氏图**：根据事件个数画出相应的文氏图
2. **标记已知概率**：将已知的概率值标在对应区域
3. **推导未知概率**：利用概率性质推导其他区域的概率
4. **计算目标概率**：将相关区域的概率相加

**例题**：已知 $P(A) = 0.5$，$P(B) = 0.4$，$P(A \cup B) = 0.7$，求 $P(A\bar{B})$。

**解**（文氏图法）：
1. 画两个相交的圆，分别表示 $A$ 和 $B$
2. 计算交集：$P(AB) = P(A) + P(B) - P(A \cup B) = 0.5 + 0.4 - 0.7 = 0.2$
3. $A$ 独有的部分：$P(A\bar{B}) = P(A) - P(AB) = 0.5 - 0.2 = 0.3$

**答案**：$P(A\bar{B}) = 0.3$

---

**方法对比**：

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **特例法** | 选择题、判断题 | 快速排除错误选项 | 不能用于证明题 |
| **文氏图法** | 多事件运算、直观理解 | 形象直观，不易出错 | 事件较多时图形复杂 |

### 易错点
1. 混淆"互斥"与"独立"
2. 加法公式忘记减去 $P(AB)$
3. 古典概型中样本点计数错误（有序vs无序）
4. 几何概型中几何区域确定错误
5. **正概率事件互斥必不独立**
6. **A包含B一般不独立**
7. 两两独立不一定相互独立（伯恩斯坦反例）
8. 二项分布中忘记标明 $k$ 的范围
