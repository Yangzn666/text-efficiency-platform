# 第一章 随机事件与概率

## 1.1 基本概念

### 一、随机试验（Random Experiment）

**定义**：满足以下三个条件的试验称为随机试验：
1. **可重复性**：在相同条件下可以重复进行
2. **可知性**：所有可能的结果是明确可知的
3. **不确定性**：每次试验之前不能确定哪个结果会出现

**典型例子**：
- 抛硬币：结果为正面或反面
- 掷骰子：结果为1,2,3,4,5,6点
- 从一批产品中抽取一件检验

---

### 二、样本空间（Sample Space）⭐重要概念

**定义**：随机试验的所有可能结果组成的集合，记为 $S$ 或 $\Omega$

**样本点**：样本空间中的每个元素，记为 $\omega$

**关键点**：
- 样本空间的确定依赖于试验的具体描述
- 同一个试验，观察角度不同，样本空间可能不同
- 样本空间是后续定义事件和概率的基础

**例题**：
1. 抛一枚硬币：$S = \{正面, 反面\}$ 或 $S = \{H, T\}$
2. 掷一颗骰子：$S = \{1, 2, 3, 4, 5, 6\}$
3. 记录某网站一天的访问量：$S = \{0, 1, 2, 3, ...\}$（非负整数集）

---

### 三、随机事件（Random Event）

**定义**：样本空间的子集称为随机事件，通常用大写字母 $A, B, C$ 等表示

**事件的本质**：
- 事件是**集合**，不是概率
- 事件是样本点的集合，表示某些结果的组合
- 事件发生后，可以计算其发生的概率

#### 1. 特殊事件

**必然事件**：
- 样本空间 $S$ 本身
- 每次试验必定发生
- $P(S) = 1$

**不可能事件**：
- 空集 $\emptyset$
- 每次试验必定不发生
- $P(\emptyset) = 0$

**⚠️ 重要辨析**：
> **必然事件和不可能事件都是"事件"，不是"概率"！**
> - 事件是可以计算概率的对象
> - 概率是事件发生的可能性大小的数值度量
> - **概率不能反推事件**：知道概率值无法唯一确定是哪个事件

**举例说明**：
- 事件 $A$ = "掷骰子出现偶数点" = $\{2, 4, 6\}$，则 $P(A) = \frac{1}{2}$
- 事件 $B$ = "抛两次硬币至少一次正面" = $\{HH, HT, TH\}$，则 $P(B) = \frac{3}{4}$
- 不同的事件可能有相同的概率，因此**概率不能反推事件**

#### 2. 基本事件

**定义**：只包含一个样本点的事件，也称为简单事件

**性质**：
- 基本事件之间互不相容
- 所有基本事件的并集等于样本空间

---

### 四、事件的关系与运算

#### 1. 事件的包含与相等

- **包含**：若 $A$ 发生必导致 $B$ 发生，则称 $A$ 包含于 $B$，记为 $A \subset B$
- **相等**：若 $A \subset B$ 且 $B \subset A$，则 $A = B$

#### 2. 事件的和（并）

$A \cup B$ 或 $A + B$：事件 $A$ 与事件 $B$ 至少有一个发生

**推广**：$\bigcup_{i=1}^{n} A_i$ 表示 $n$ 个事件中至少有一个发生

#### 3. 事件的积（交）

$A \cap B$ 或 $AB$：事件 $A$ 与事件 $B$ 同时发生

**推广**：$\bigcap_{i=1}^{n} A_i$ 表示 $n$ 个事件同时发生

#### 4. 事件的差

$A - B$ 或 $A\bar{B}$：事件 $A$ 发生但事件 $B$ 不发生

**性质**：
- $A - B = A \cap \bar{B}$
- $P(A - B) = P(A) - P(AB)$

**例题**：掷骰子，$A$="出现偶数"=$\{2,4,6\}$，$B$="出现3的倍数"=$\{3,6\}$
- 则 $A - B = \{2, 4\}$（出现偶数但不是3的倍数）

---

#### 5. 互不相容（互斥）⭐重要概念

**定义**：若 $AB = \emptyset$，则称 $A$ 与 $B$ 互不相容（互斥）

**含义**：两个事件不能同时发生

**重要性质**：
1. 若 $A$ 与 $B$ 互斥，则 $P(A \cup B) = P(A) + P(B)$
2. 多个事件两两互斥：$A_1, A_2, ..., A_n$ 两两互斥，则
   $$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

**典型例子**：
- 掷骰子：$A$="出现1点"，$B$="出现2点"，则 $A$ 与 $B$ 互斥
- 抛硬币：$A$="正面"，$B$="反面"，则 $A$ 与 $B$ 互斥且对立

**⚠️ 易错点**：
- 互斥的事件不一定对立（如上面的掷骰子例子）
- 对立是互斥的特殊情况

---

#### 6. 对立事件（逆事件）⭐重要概念

**定义**：$\bar{A}$ 表示事件 $A$ 不发生

**性质**：
- $A \cup \bar{A} = S$（必然事件）
- $A \cap \bar{A} = \emptyset$（不可能事件）
- $P(A) + P(\bar{A}) = 1$ ⟹ $P(\bar{A}) = 1 - P(A)$

**解题技巧**：
> 当直接计算 $P(A)$ 困难时，可以考虑计算 $P(\bar{A})$，然后用 $P(A) = 1 - P(\bar{A})$
> 
> **典型应用**："至少有一个"的问题，通常用对立事件"一个都没有"来计算

**例题**：
从10个产品（8个合格，2个次品）中任取3个，求"至少有1个次品"的概率。

**解法**：
- 直接算：$P($至少1个次品$) = P(1个次品) + P(2个次品)$
- 用对立事件：$P($至少1个次品$) = 1 - P($没有次品$) = 1 - \frac{C_8^3}{C_{10}^3}$

显然用对立事件更简单！

---

**⚠️ 对立 vs 互斥的核心区别**：

| 对比项 | 互斥 | 对立 |
|--------|------|------|
| 定义 | $AB = \emptyset$ | $AB = \emptyset$ 且 $A \cup B = S$ |
| 能否同时发生 | 不能 | 不能 |
| 是否必有一个发生 | 不一定 | 一定 |
| 关系 | 对立一定互斥 | 互斥不一定对立 |
| 适用范围 | 可以是多个事件 | 只能针对两个事件 |

**记忆口诀**：
- 互斥："有你没我，有我没你"（但不能保证一定有其中一个）
- 对立："非此即彼，必有其一"（要么是你，要么是我，必须有其中一个）

---

### 五、事件的运算律

#### 1. 交换律
$$A \cup B = B \cup A, \quad AB = BA$$

#### 2. 结合律
$$(A \cup B) \cup C = A \cup (B \cup C)$$
$$(AB)C = A(BC)$$

#### 3. 分配律
$$A \cup (BC) = (A \cup B)(A \cup C)$$
$$A(B \cup C) = AB \cup AC$$

**记忆技巧**：类似于代数中的分配律 $a(b+c) = ab + ac$

#### 4. 吸收律 ⭐重要
$$A \cup (AB) = A$$
$$A(A \cup B) = A$$

**含义**：
- $A \cup (AB) = A$：如果 $A$ 发生，或者 "$A$ 和 $B$ 同时发生"，等价于 "$A$ 发生"
- $A(A \cup B) = A$：如果 "$A$ 发生" 且 "$A$ 或 $B$ 至少一个发生"，等价于 "$A$ 发生"

**直观理解**：大集合吸收小集合
- $AB \subset A$，所以 $A \cup (AB) = A$
- $A \subset (A \cup B)$，所以 $A(A \cup B) = A$

**例题**：化简 $(A \cup B)(A \cup \bar{B})$

**解**：
$$(A \cup B)(A \cup \bar{B}) = A \cup (B\bar{B}) = A \cup \emptyset = A$$

这里用了分配律和吸收律的思想。

#### 5. 德摩根律（对偶律）⭐⭐非常重要
$$\overline{A \cup B} = \bar{A} \cap \bar{B}$$
$$\overline{A \cap B} = \bar{A} \cup \bar{B}$$

**推广**：
$$\overline{\bigcup_{i=1}^{n} A_i} = \bigcap_{i=1}^{n} \bar{A_i}$$
$$\overline{\bigcap_{i=1}^{n} A_i} = \bigcup_{i=1}^{n} \bar{A_i}$$

**记忆口诀**：“并变交，交变并，外面加否定”

**德摩根律的应用**：
1. **化简复杂事件**：将多个事件的并/交的否定转化为单个事件的否定
2. **概率计算**：$P(\overline{A \cup B}) = P(\bar{A} \cap \bar{B})$
3. **考研高频考点**：经常与对立事件结合考查

**例题**：设 $A, B, C$ 为三个事件，用运算表示“$A, B, C$ 中至少有一个不发生”

**解**：
- “至少有一个不发生” = “不是全部都发生”
- 即 $\overline{ABC}$
- 由德摩根律：$\overline{ABC} = \bar{A} \cup \bar{B} \cup \bar{C}$

---

#### 6. 其他常用恒等式

1. **幂等律**：$A \cup A = A$，$AA = A$
2. **零一律**：$A \cup S = S$，$AS = A$
3. **互补律**：$A \cup \bar{A} = S$，$A\bar{A} = \emptyset$
4. **双重否定**：$\bar{\bar{A}} = A$

---

## 1.2 概率的定义与性质

### 一、概率的公理化定义

设随机试验的样本空间为 $S$，对于每个事件 $A$，赋予一个实数 $P(A)$，满足：

1. **非负性**：$P(A) \geq 0$
2. **规范性**：$P(S) = 1$
3. **可列可加性**：若 $A_1, A_2, ...$ 两两互不相容，则
   $$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

---

### 二、概率的性质

#### 性质1：不可能事件的概率为0
$$P(\emptyset) = 0$$

#### 性质2：有限可加性
若 $A_1, A_2, ..., A_n$ 两两互不相容，则
$$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$$

#### 性质3：对立事件的概率
$$P(\bar{A}) = 1 - P(A)$$

#### 性质4：单调性
若 $A \subset B$，则 $P(A) \leq P(B)$

#### 性质5：加法公式
$$P(A \cup B) = P(A) + P(B) - P(AB)$$

**推广（三个事件）**：
$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$

#### 性质6：连续性
若 $A_1 \subset A_2 \subset ...$，则
$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \lim_{n \to \infty} P(A_n)$$

---

## 1.3 古典概型

### 一、定义

满足以下两个条件的概率模型称为古典概型：
1. **有限性**：样本空间只有有限个样本点
2. **等可能性**：每个样本点发生的可能性相同

### 二、计算公式

若样本空间 $S$ 包含 $n$ 个样本点，事件 $A$ 包含 $m$ 个样本点，则
$$P(A) = \frac{m}{n} = \frac{\text{事件A包含的样本点数}}{\text{样本空间的总样本点数}}$$

### 三、解题关键

**核心**：正确计算分子和分母（常用排列组合知识）

**常见模型**：
1. **摸球模型**：有放回、无放回
2. **分房模型**：将物品分配到不同位置
3. **配对模型**：信封与信件的匹配

---

## 1.4 几何概型

### 一、定义

当样本空间是某个可度量的几何区域，且每个样本点出现的可能性相同时，称为几何概型。

### 二、计算公式

$$P(A) = \frac{\text{事件A对应的几何度量}}{\text{样本空间的几何度量}}$$

其中几何度量可以是长度、面积、体积等。

### 三、典型例题

**约会问题**：两人约定在某时间段内见面，先到者等待一定时间后离开，求两人能见面的概率。

**解法**：用平面区域的面积比来计算。

---

## ⭐ 本章重点总结

### 核心概念
1. **样本空间**：所有可能结果的集合（基础中的基础）
2. **随机事件**：样本空间的子集（是集合，不是概率）
3. **必然事件与不可能事件**：都是事件，概率分别为1和0
4. **概率不能反推事件**：不同事件可能有相同概率

### 重要公式
1. 德摩根律：$\overline{A \cup B} = \bar{A} \cap \bar{B}$
2. 加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. 对立事件：$P(\bar{A}) = 1 - P(A)$

### 易错点
1. 混淆"事件"与"概率"的概念
2. 混淆"互斥"与"对立"
3. 古典概型中样本点计数错误
4. 忽视事件的独立性条件

## ⭐ 第一章题型总结

### 题型1：事件的关系与运算 ⭐⭐

#### 考查方式

1. **选择题**：判断事件之间的关系（包含、互斥、对立、独立）
2. **填空题**：用事件运算表示复杂事件
3. **计算题**：利用事件运算律化简表达式

---

#### 典型例题

**例题1**（事件关系判断）：

设 $A$、$B$ 为两个事件，且 $P(A) > 0$，$P(B) > 0$，则下列说法正确的是：

A. 若 $A$ 与 $B$ 互斥，则 $A$ 与 $B$ 独立
B. 若 $A$ 与 $B$ 独立，则 $A$ 与 $B$ 互斥
C. 若 $A \subset B$，则 $A$ 与 $B$ 独立
D. 若 $A$ 与 $B$ 互斥，则 $A$ 与 $B$ 不独立

**解**：
- A选项：互斥 ⟹ $P(AB) = 0$，但 $P(A)P(B) > 0$，所以 $P(AB) \neq P(A)P(B)$，不独立 ✗
- B选项：独立 ⟹ $P(AB) = P(A)P(B) > 0$，所以 $AB \neq \emptyset$，不互斥 ✗
- C选项：$A \subset B$ ⟹ $AB = A$，若独立则 $P(A) = P(A)P(B)$ ⟹ $P(B) = 1$，不一定成立 ✗
- D选项：互斥 ⟹ $P(AB) = 0$，但 $P(A)P(B) > 0$，所以不独立 ✓

**答案**：D

**考点**：互斥与独立的区别（正概率事件互斥必不独立）

---

**例题2**（事件运算表示）：

用事件 $A$、$B$、$C$ 的运算表示下列事件：
1. $A$、$B$、$C$ 中至少有一个发生
2. $A$、$B$、$C$ 中都发生
3. $A$、$B$、$C$ 中恰好有一个发生
4. $A$、$B$、$C$ 中最多有一个发生
5. $A$、$B$、$C$ 中至少有两个发生

**解**：
1. **至少有一个发生**：$A \cup B \cup C$
2. **都发生**：$ABC$
3. **恰好有一个发生**：$A\bar{B}\bar{C} \cup \bar{A}B\bar{C} \cup \bar{A}\bar{B}C$
4. **最多有一个发生**：$\bar{A}\bar{B}\bar{C} \cup A\bar{B}\bar{C} \cup \bar{A}B\bar{C} \cup \bar{A}\bar{B}C$
   - 或：$\overline{AB \cup AC \cup BC}$（不是至少两个发生）
5. **至少有两个发生**：$AB \cup AC \cup BC$

**技巧**：
- “至少有一个”用并集
- “都发生”用交集
- “恰好k个”需要分别列出所有情况
- “最多k个”可以用对立事件“至少k+1个”

---

**例题3**（事件运算化简）：

化简下列事件表达式：
1. $(A \cup B)(A \cup \bar{B})$
2. $A \cup AB$
3. $(A - B) \cup (B - A)$

**解**：
1. **$(A \cup B)(A \cup \bar{B})$**：
   - 用分配律：$= A \cup (B\bar{B}) = A \cup \emptyset = A$
   - 或用吸收律：$= A$

2. **$A \cup AB$**：
   - 用吸收律：$= A$
   - 直观理解：$AB \subset A$，所以并集就是 $A$

3. **$(A - B) \cup (B - A)$**：
   - $= A\bar{B} \cup \bar{A}B$
   - 这是对称差，表示“A发生B不发生”或“B发生A不发生”
   - 不能进一步化简

**答案**：1. $A$；2. $A$；3. $A\bar{B} \cup \bar{A}B$

---

**例题4**（德摩根律应用）：

设 $A$、$B$、$C$ 为三个事件，用运算表示“$A$、$B$、$C$ 中至少有一个不发生”。

**解**：
- “至少有一个不发生” = “不是全部都发生”
- $= \overline{ABC}$
- 由德摩根律：$= \bar{A} \cup \bar{B} \cup \bar{C}$

**答案**：$\bar{A} \cup \bar{B} \cup \bar{C}$

**技巧**：遇到“至少有一个不...”时，先写成“不是全部...”，再用德摩根律

---

#### 解题技巧总结

1. **判断事件关系**：
   - 互斥 vs 独立：正概率事件互斥必不独立
   - 包含关系：$A \subset B$ 一般不独立（除非 $P(A)=1$ 或 $P(B)=0$）
   - 对立事件：一定互斥，且并集为样本空间

2. **事件运算表示**：
   - “至少有一个” → 并集 $\cup$
   - “都发生” → 交集 $\cap$ 或直接写 $ABC$
   - “恰好k个” → 列举所有情况再并起来
   - “最多k个” → 考虑用对立事件

3. **化简技巧**：
   - 熟记运算律：交换律、结合律、分配律、吸收律、德摩根律
   - 吸收律最常用：$A \cup AB = A$，$A(A \cup B) = A$
   - 德摩根律处理否定：$\overline{A \cup B} = \bar{A} \cap \bar{B}$

4. **文氏图辅助**：
   - 复杂事件关系可以画文氏图直观理解
   - 标记各区域，帮助分析

---

### 题型2：古典概型与几何概型 ⭐（考查较少）

#### 考查方式

1. **选择题/填空题**：计算简单古典概型或几何概型的概率
2. **特点**：考查频率较低，主要掌握基本概念和计算方法

---

#### 典型例题

**例题1**（古典概型-摸球问题）：

袋中有5个红球、3个白球，从中无放回地抽取3个球，求恰好抽到2个红球的概率。

**解**：
- 总样本点数：从8个球中取3个，$n = C_8^3 = 56$
- 有利样本点数：从5个红球中取2个，从3个白球中取1个，$m = C_5^2 C_3^1 = 10 \times 3 = 30$
- 概率：$P = \frac{m}{n} = \frac{30}{56} = \frac{15}{28}$

**答案**：$\frac{15}{28}$

---

**例题2**（几何概型-约会问题）：

甲乙两人约定在下午2:00-3:00之间见面，先到者等待15分钟后离开，求两人能见面的概率。

**解**：
- 设甲到达时间为 $x$，乙到达时间为 $y$（单位：分钟，从2:00开始计）
- 样本空间：$\Omega = \{(x,y) | 0 \leq x \leq 60, 0 \leq y \leq 60\}$，面积 $S_\Omega = 60^2 = 3600$
- 能见面条件：$|x - y| \leq 15$
- 不能见面的区域：两个三角形，每个面积 $\frac{1}{2} \times 45 \times 45 = 1012.5$
- 能见面概率：
  $$P = 1 - \frac{2 \times 1012.5}{3600} = 1 - \frac{2025}{3600} = 1 - \frac{9}{16} = \frac{7}{16}$$

**答案**：$\frac{7}{16}$

---

#### 解题技巧

1. **古典概型**：

### 题型3：概率的性质与运算 ⭐⭐⭐高频考点

#### 考查方式

1. **选择题**：利用概率性质判断选项正误
2. **填空题**：已知部分概率，求其他概率
3. **计算题**：综合运用加法公式、减法公式等

---

#### 核心公式回顾

1. **对立事件**：$P(\bar{A}) = 1 - P(A)$
2. **加法公式**：$P(A \cup B) = P(A) + P(B) - P(AB)$
3. **减法公式**：$P(A - B) = P(A) - P(AB)$
4. **单调性**：若 $A \subset B$，则 $P(A) \leq P(B)$
5. **取值范围**：$0 \leq P(A) \leq 1$

---

#### 典型例题

**例题1**（加法公式应用）：

已知 $P(A) = 0.5$，$P(B) = 0.4$，$P(A \cup B) = 0.7$，求：
1. $P(AB)$
2. $P(A - B)$
3. $P(\bar{A} \cup \bar{B})$

**解**：
1. **求 $P(AB)$**：
   - 由加法公式：$P(A \cup B) = P(A) + P(B) - P(AB)$
   - $0.7 = 0.5 + 0.4 - P(AB)$
   - $P(AB) = 0.9 - 0.7 = 0.2$

2. **求 $P(A - B)$**：
   - $P(A - B) = P(A) - P(AB) = 0.5 - 0.2 = 0.3$

3. **求 $P(\bar{A} \cup \bar{B})$**：
   - 由德摩根律：$\bar{A} \cup \bar{B} = \overline{AB}$
   - $P(\bar{A} \cup \bar{B}) = P(\overline{AB}) = 1 - P(AB) = 1 - 0.2 = 0.8$

**答案**：1. 0.2；2. 0.3；3. 0.8

**例题2**（多个事件的概率）：

已知 $P(A) = P(B) = P(C) = \frac{1}{4}$，$P(AB) = P(BC) = 0$，$P(AC) = \frac{1}{8}$，求 $A$、$B$、$C$ 中至少有一个发生的概率。

**解**：
- 由三个事件的加法公式：
  $$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$
- 因为 $P(AB) = 0$，所以 $ABC \subset AB$，故 $P(ABC) = 0$
- 代入得：
  $$P(A \cup B \cup C) = \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 0 - \frac{1}{8} - 0 + 0 = \frac{3}{4} - \frac{1}{8} = \frac{5}{8}$$

**答案**：$\frac{5}{8}$

**⭐⭐⭐ 真题链接（2020年，数一数三）**：

设 $A, B, C$ 为三个随机事件，且 $P(A) = P(B) = P(C) = \frac{1}{4}$，$P(AB) = 0$，$P(AC) = P(BC) = \frac{1}{12}$，则 $A, B, C$ 中恰有一个事件发生的概率为：

(A) $\frac{3}{4}$  (B) $\frac{2}{3}$  (C) $\frac{1}{2}$  (D) $\frac{5}{12}$

**解**：

**方法1：直接计算（一个一个算）**

恰有一个事件发生 = $A$ 发生且 $B, C$ 不发生 + $B$ 发生且 $A, C$ 不发生 + $C$ 发生且 $A, B$ 不发生

$$P = P(A\bar{B}\bar{C}) + P(\bar{A}B\bar{C}) + P(\bar{A}\bar{B}C)$$

- $P(A\bar{B}\bar{C}) = P(A) - P(AB) - P(AC) + P(ABC)$
  - 因为 $P(AB) = 0$，所以 $P(ABC) = 0$
  - $P(A\bar{B}\bar{C}) = \frac{1}{4} - 0 - \frac{1}{12} + 0 = \frac{1}{6}$

- $P(\bar{A}B\bar{C}) = P(B) - P(AB) - P(BC) + P(ABC)$
  - $P(\bar{A}B\bar{C}) = \frac{1}{4} - 0 - \frac{1}{12} + 0 = \frac{1}{6}$

- $P(\bar{A}\bar{B}C) = P(C) - P(AC) - P(BC) + P(ABC)$
  - $P(\bar{A}\bar{B}C) = \frac{1}{4} - \frac{1}{12} - \frac{1}{12} + 0 = \frac{1}{12}$

- 总和：$P = \frac{1}{6} + \frac{1}{6} + \frac{1}{12} = \frac{2}{12} + \frac{2}{12} + \frac{1}{12} = \frac{5}{12}$

**方法2：利用文氏图思想**

$$P(\text{恰有一个}) = P(A) + P(B) + P(C) - 2[P(AB) + P(AC) + P(BC)] + 3P(ABC)$$

- $P = \frac{1}{4} + \frac{1}{4} + \frac{1}{4} - 2(0 + \frac{1}{12} + \frac{1}{12}) + 3 \times 0$
- $P = \frac{3}{4} - 2 \times \frac{2}{12} = \frac{3}{4} - \frac{1}{3} = \frac{9}{12} - \frac{4}{12} = \frac{5}{12}$

**答案**：(D) $\frac{5}{12}$

**考点分析**：
1. "恰好有一个发生"的表示方法
2. 利用 $P(AB)=0$ 推导 $P(ABC)=0$
3. 减法公式的灵活运用
4. 文氏图区域计算思想

**例题3**（特例法快速判断）：

设 $A$、$B$ 为任意两个事件，且 $0 < P(A) < 1$，$0 < P(B) < 1$，则下列正确的是：

A. $P(A \cup B) = P(A) + P(B)$
B. $P(A - B) = P(A) - P(B)$
C. $P(AB) \leq \min\{P(A), P(B)\}$
D. $P(A \cup B) \geq P(A) + P(B)$

**解**（特例法）：
- 取特例：$A = B$，且 $P(A) = 0.5$
- A选项：$P(A \cup A) = 0.5$，但 $P(A) + P(A) = 1$，不相等 ✗
- B选项：$P(A - A) = 0$，但 $P(A) - P(A) = 0$，相等（需进一步验证）
  - 再取特例：$A$、$B$ 有交集，$P(A)=0.6$，$P(B)=0.4$，$P(AB)=0.2$
  - $P(A-B) = 0.6 - 0.2 = 0.4$，但 $P(A)-P(B) = 0.2$，不相等 ✗
- C选项：因为 $AB \subset A$ 且 $AB \subset B$，由单调性知 $P(AB) \leq P(A)$ 且 $P(AB) \leq P(B)$
  - 所以 $P(AB) \leq \min\{P(A), P(B)\}$ ✓
- D选项：取 $A=B$，$P(A)=0.5$，则 $P(A \cup B) = 0.5$，但 $P(A)+P(B) = 1$，$0.5 \geq 1$ 不成立 ✗

**答案**：C

**例题4**（综合应用）：

已知 $P(A) = 0.6$，$P(B) = 0.5$，$P(A|B) = 0.8$，求：
1. $P(AB)$
2. $P(A \cup B)$
3. $P(\bar{A}|\bar{B})$

**解**：
1. **求 $P(AB)$**：
   - 由条件概率定义：$P(A|B) = \frac{P(AB)}{P(B)}$
   - $P(AB) = P(B)P(A|B) = 0.5 \times 0.8 = 0.4$

2. **求 $P(A \cup B)$**：
   - $P(A \cup B) = P(A) + P(B) - P(AB) = 0.6 + 0.5 - 0.4 = 0.7$

3. **求 $P(\bar{A}|\bar{B})$**：
   - $P(\bar{A}|\bar{B}) = \frac{P(\bar{A}\bar{B})}{P(\bar{B})}$
   - $P(\bar{B}) = 1 - P(B) = 1 - 0.5 = 0.5$
   - $P(\bar{A}\bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B) = 1 - 0.7 = 0.3$
   - $P(\bar{A}|\bar{B}) = \frac{0.3}{0.5} = 0.6$

**答案**：1. 0.4；2. 0.7；3. 0.6

#### 解题技巧总结

1. **熟练运用基本公式**：
   - 加法公式、减法公式、对立事件公式
   - 条件概率定义式

2. **灵活转化**：
   - $P(\bar{A}\bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B)$
   - $P(A - B) = P(A\bar{B}) = P(A) - P(AB)$

3. **特例法快速排除**：
   - 选择题中，构造简单特例验证选项
   - 常用特例：$A=B$、$A \subset B$、$AB=\emptyset$

4. **文氏图辅助**：
   - 画图标出已知概率
   - 推导未知区域概率
