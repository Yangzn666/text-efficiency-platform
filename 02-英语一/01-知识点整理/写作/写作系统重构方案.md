# 英语一写作学习系统重构方案

## 基于一线教师教学体系的完整设计

### 核心理念

根据这位一线英语教师的教学经验，我们将写作学习系统重构为以下6大核心模块：

1. **阅卷标准与基本原则** - 第一印象、字数控制、时间分配、避免错误
2. **三大核心框架** - 议论文（引表论总）、图表（描析预）、书信（目内结）
3. **深度论证方法** - 对立假想敌、三级递进法、五种续写法
4. **功能句库** - 8大类24个核心句型，每个带记忆技巧
5. **范文库** - 真题范文+详细解析+亮点标注
6. **实战演练** - 限时写作+随机题目+自动保存

---

### 页面结构设计

#### Tab 1: Grading Standards (阅卷标准)
- 第一印象管理
- 字数要求（130-180词）
- 时间分配（3+2+20+5分钟）
- 必须避免的低级错误清单
- "不犯错"策略

#### Tab 2: Core Frameworks (三大框架)
每个框架包含：
- 口诀记忆（引表论总/描析预/目内结）
- 结构分解（每段功能、句数）
- 经典句型
- 使用要点（✅必做/❌避免）
- 联想记忆

#### Tab 3: Deep Argumentation (深度论证)
- 找对立假想敌（4步操作+模板句式）
- 三级递进法（what→how→why it matters）
- 五种续写法（详细示例）

#### Tab 4: Functional Sentences (功能句库)
8大分类，每类3个句型：
- 开头引入
- 论证过渡
- 结论总结
- 数据描述
- 高级替换
- 举例论证
- 因果分析
- 建议措施

每个句型包含：
- 英文原句 + 中文翻译
- 标签（universal/formal等）
- 使用场景
- 记忆技巧（口诀+联想图像）

#### Tab 5: Model Essays (范文库)
- 历年真题范文
- 亮点分析（标注使用的论证方法）
- 词汇积累
- 可模仿的句型结构

#### Tab 6: Practice Mode (实战演练)
- 限时写作（30分钟倒计时）
- 题目随机抽取
- 写作要求提示
- 快速参考（常用句型速查）
- 自动保存练习记录

---

### 关键改进点

1. **强化记忆技巧**
   - 每个框架配口诀（引表论总/描析预/目内结）
   - 每个句型配联想图像（🚀火箭/⚖️天平/⏰闹钟等）
   - 记忆专区独立展示三重记忆法

2. **突出深度论证**
   - 三级递进法作为核心训练内容
   - 提供before/after对比示例
   - 五种续写法解决"写不下去"的问题

3. **优化学习流程**
   - 从"知道怎么写"到"知道为什么这样写"
   - 强调逻辑链而非死记硬背
   - 实战演练与理论学习紧密结合

4. **提升用户体验**
   - 单栏布局，阅读更舒适
   - 字体增大，行高优化
   - 颜色对比度增强
   - 交互反馈更明确
