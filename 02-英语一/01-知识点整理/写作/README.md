# 写作学习模块

## 📚 资源说明

本模块包含英语写作学习的指导资料和模板背诵工具，帮助提升写作能力。

### 1. 写作指导（writing-guide.html）
- **功能**：系统化的写作技巧指导
- **内容**：
  - 各类作文题型解析
  - 写作结构和框架
  - 常用句型和表达
  - 评分标准和注意事项
- **适用场景**：学习写作方法论、掌握答题技巧

### 2. 模板背诵（template-practice.html）
- **功能**：交互式作文模板背诵系统
- **特点**：
  - 分类展示不同题型的模板
  - 支持填空练习和默写
  - 可自定义添加个人模板
- **适用场景**：熟练掌握作文模板、提高写作速度

### 3. 六级作文讲义（六级作文讲义.pdf）
- **内容**：作文写作技巧和范文分析
- **重点**：
  - 常见作文题型
  - 高分范文解析
  - 写作技巧和策略
  - 常见错误及避免方法
- **适用场景**：系统学习写作技巧

## 💡 使用建议

1. **先学方法**：仔细阅读写作指导，了解各类题型的写作要求
2. **背诵模板**：每天背诵1-2个模板，做到熟练运用
3. **练习写作**：每周至少写一篇作文，应用所学技巧和模板
4. **对照范文**：写完后对照高分范文，找出差距并改进
5. **积累素材**：记录好的句型、短语和论证方式
