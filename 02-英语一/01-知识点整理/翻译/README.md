# 翻译学习模块

## 📚 资源说明

本模块包含英语翻译学习的实践工具和讲义资料，帮助提升中英互译能力。

### 1. 中英翻译练习（chinese-to-english-practice.html）
- **功能**：交互式中英翻译练习系统
- **特点**：
  - 提供中文句子，练习翻译成英文
  - 可查看参考答案进行对比
  - 支持自定义添加练习句子
- **适用场景**：提升翻译准确度、积累表达方式

### 2. 六级翻译讲义（六级翻译讲义.pdf）
- **内容**：翻译技巧和方法论讲解
- **重点**：
  - 常见翻译题型分析
  - 翻译技巧和策略
  - 真题解析和示例
- **适用场景**：系统学习翻译方法论

## 💡 使用建议

1. **日常练习**：每天完成5-10句翻译练习
2. **对照答案**：仔细对比自己的翻译和参考答案，找出差距
3. **积累表达**：记录常用的翻译句型和表达方式
4. **结合真题**：考研英语翻译题也需要类似的训练方法
