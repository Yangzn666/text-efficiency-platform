# 词汇学习模块

## 📚 资源说明

本模块包含英语词汇学习的两个核心工具，适用于考研英语和六级备考。

### 1. 词根词缀学习（roots.html）
- **功能**：系统学习英语词根、前缀、后缀
- **特点**：
  - 交互式学习界面
  - 分类展示常见词根词缀
  - 提供记忆技巧和示例单词
- **适用场景**：扩大词汇量、提高单词记忆效率

### 2. 学习笔记系统（notes.html）
- **功能**：个人英语学习笔记整理工具
- **特点**：
  - 支持添加、编辑、删除笔记
  - 可分类管理不同主题的笔记
  - 本地存储，数据不丢失
- **适用场景**：记录生词、短语搭配、语法要点等

## 💡 使用建议

1. **词根词缀**：每天学习5-10个词根，结合例句记忆
2. **笔记系统**：遇到新单词或知识点时及时记录，定期复习
3. **配合真题**：在做真题时遇到的生词可以添加到笔记中
