# 英语一知识点整理

## 📚 模块说明

本目录包含考研英语一的三大核心学习模块，整合了从六级备考迁移过来的优质学习资源。

### 🗂️ 目录结构

```
01-知识点整理/
├── 词汇/          # 词汇学习模块
│   ├── 词根词缀学习.html    # 交互式词根词缀学习工具
│   ├── 学习笔记系统.html    # 个人笔记整理工具
│   └── README.md            # 使用说明
├── 翻译/          # 翻译学习模块
│   ├── 中英翻译练习.html    # 翻译练习工具
│   ├── 六级翻译讲义.pdf     # 翻译技巧讲义
│   └── README.md            # 使用说明
└── 写作/          # 写作学习模块
    ├── 写作指导.html        # 写作技巧指导
    ├── 模板背诵.html        # 模板背诵练习工具
    ├── 六级作文讲义.pdf     # 作文技巧讲义
    └── README.md            # 使用说明
```

## 🎯 各模块功能

### 1. 词汇模块
- **词根词缀学习**：系统掌握英语构词法，提高单词记忆效率
- **学习笔记系统**：记录生词、短语、语法要点，支持分类管理

### 2. 翻译模块
- **中英翻译练习**：交互式翻译训练，提升翻译准确度
- **翻译讲义**：系统学习翻译技巧和方法论

### 3. 写作模块
- **写作指导**：各类作文题型解析和写作技巧
- **模板背诵**：交互式模板练习，熟练掌握作文框架
- **作文讲义**：高分范文分析和写作策略

## 💡 使用建议

1. **词汇学习**：每天学习5-10个词根，结合真题积累生词
2. **翻译练习**：每周完成2-3次翻译练习，对照答案找差距
3. **写作训练**：先学方法，再背模板，最后勤加练习
4. **定期复习**：利用笔记系统定期回顾所学内容

## 📝 注意事项

- 这些资源原本为六级备考设计，但同样适用于考研英语一
- HTML文件可以直接在浏览器中打开使用
- PDF讲义可以打印或在电子设备上阅读
- 建议配合真题使用，效果更佳
