## 📝 第三步：使用第一个模板（3分钟）

### 示例：学习"定语从句"

#### 1. 选择模板
点击"**模板1：语法概念深度解释器**"卡片

#### 2. 复制模板
在弹出的对话框中，点击"**复制到剪贴板**"按钮

#### 3. 填充内容
打开AI工具（如通义千问），粘贴模板，然后替换方括号内容：

```
原模板：
我想深入学习[语法概念，如：定语从句/虚拟语气/非谓语动词]...

修改后：
我想深入学习定语从句...

背景信息：
- 我的水平：词汇量较好（红宝书4轮），语法基础薄弱
- 学习目标：考研英语一，目标分数75分
- 学习方式偏好：喜欢类比和实例
```

#### 4. 发送并阅读
点击发送，仔细阅读AI的回答

#### 5. 追问深化
如果某些地方不理解，继续追问：
- "能举个更简单的例子吗？"
- "这和中文的表达有什么不同？"
- "考研中常考哪种类型的定语从句？"

#### 6. 保存精华
将有价值的回答：
- 截图保存
- 或复制到笔记软件
- 或使用"模板9：语法知识卡片生成器"整理

✅ 完成！你已经完成了第一次AI辅助学习。

## 💡 五个立即可用的技巧

### 技巧1：明确目标
❌ 错误："帮我学英语语法"  
✅ 正确："帮我理解定语从句中which和that的区别，并出3道练习题"

### 技巧2：提供背景
告诉AI你的情况：
- "我是考研学生"
- "我词汇量较好，但语法薄弱"
- "我已经看了网课，但对某个点还有疑问"

### 技巧3：迭代追问
不满意就继续问：
- "这个解释还是不太懂，能换个角度吗？"
- "能不能用更简单的例子？"
- "有更深入的讲解吗？"

### 技巧4：验证输出
AI可能出错，要：
- 对照教材验证
- 多个AI工具对比
- 在真题中检验

### 技巧5：记录精华
保存有价值的对话：
- 建立"AI对话档案库"
- 定期回顾和整理
- 形成个人知识库

## ⚠️ 常见错误避免

### ❌ 错误1：直接问答案
```
错误示范：
"这道题选什么？"

正确做法：
"请帮我分析这道题，解释每个选项的对错原因"
```

### ❌ 错误2：不提供背景
```
错误示范：
"解释一下定语从句"

正确做法：
"我是考研学生，已经看过网课，但对限制性和非限制性定语从句的区别还不清楚，请用简单的方式解释"
```

### ❌ 错误3：不验证AI回答
```
错误做法：
盲目相信AI的所有回答

正确做法：
对照教材、真题或其他资料验证
```

### ❌ 错误4：浅层使用
```
错误做法：
只用AI查答案，不深入思考

正确做法：
让AI引导思考，培养独立分析能力
```
