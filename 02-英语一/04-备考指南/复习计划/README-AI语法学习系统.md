### 方式一：从网站开始（推荐）

## 💡 核心学习方法

### 方法一：四步学习循环

```
1️⃣ 理解本质（模板1）
   └─ 不只是记住规则，更要理解为什么
   
2️⃣ 深度分析（模板2、3）
   └─ 分析真实语料，理解实际应用
   
3️⃣ 主动应用（模板4、5）
   └─ 在写作和翻译中主动使用
   
4️⃣ 反思整理（模板9、10）
   └─ 总结经验，完善知识体系
```

---

### 方法二：AI协作原则

```
✅ 正确做法：
- 明确目标：清楚自己想要什么
- 提供背景：让AI了解你的情况
- 迭代追问：不满意就继续问
- 验证输出：交叉验证AI回答
- 记录精华：保存有价值的内容

❌ 避免陷阱：
- 不要直接抄答案
- 不要过度依赖
- 不要盲目相信
- 不要浅层使用
```

---

### 方法三：每日学习流程

```
早晨（10-15分钟）
├─ 复习昨天的知识卡片

└─ 记录疑问点

├─ 看网课时向AI提问（随时）
├─ 用模板6生成练习题

├─ 写一段话并用模板5检查
└─ 用模板9整理知识卡片

周末（30-60分钟）
├─ 用模板10诊断本周进度
├─ 整理对话历史
├─ 提取精华到知识库
└─ 制定下周计划
```

## 🎯 关键成功因素

### 1. 坚持使用
- 每天至少使用一次AI辅助学习
- 形成习惯，而非偶尔为之
- 持续迭代和优化学习流程

### 2. 深度思考
- 不要满足于表面理解
- 多问"为什么"，少问"是什么"
- 培养批判性思维能力

### 3. 主动应用
- 学到的语法要立即应用
- 在写作中有意识使用新结构
- 通过应用加深理解

### 4. 系统整理
- 定期整理学习笔记
- 建立个人知识库
- 设置复习计划

### 5. 持续反思
- 每周复盘学习效果
- 调整学习策略
- 不断优化方法
