## 🚀 使用方法

### 方式一：通过网站使用（推荐）

1. **打开平台**
   ```
   启动考研效率平台 → 点击"英语" → 选择"AI语法助手"
   ```

2. **浏览模板**
   ```
   在"模板选择器"中查看所有模板
   点击感兴趣的模板查看详情
   ```

3. **复制使用**
   ```
   点击"复制到剪贴板"
   粘贴到AI工具
   替换方括号内容
   发送并开始对话
   ```

4. **阅读文档**
   ```
   查看详细文档了解最佳实践
   遵循推荐的学习流程
   ```

---
