## 1. 语法概念深度解释器

**适用场景**：学习新语法点时，深入理解本质而非死记规则

```
我想深入学习[语法概念，如：定语从句/虚拟语气/非谓语动词]。请不要只是告诉我规则，而是帮我理解：

1. 为什么英语需要这种结构？它解决了什么表达问题？
2. 这个语法点的本质功能是什么？（用一句话概括）
3. 与其他类似结构的核心区别在哪里？
4. 能否用中文的类似表达方式做对比，帮助我理解差异？
5. 给我3个考研真题中的经典例句，并分析：
   - 句子结构
   - 为什么作者选择这样的结构
   - 如果换成其他结构会怎样

背景信息：
- 我的水平：[描述你的当前水平]
- 学习目标：考研英语一，目标分数[XX]分
- 学习方式偏好：[如：喜欢类比、喜欢实例等]

请用通俗易懂的语言，可以类比、举例，但不要过于学术化。如果某个点比较复杂，请分步骤解释。
```

## 3. 平行文本分析师

**适用场景**：对比不同表达方式，理解语法选择的深层逻辑

```
请帮我分析以下两个（或多个）句子的语法差异和语用效果：

句子A：[粘贴句子A]
句子B：[粘贴句子B]
[句子C：可选]

分析维度：

**1. 语法结构差异**
- 句子A使用了哪些语法手段？
- 句子B使用了哪些语法手段？
- 核心差异在哪里？

**2. 信息焦点差异**
- 句子A强调了什么？弱化了什么？
- 句子B强调了什么？弱化了什么？
- 信息分布有何不同？

**3. 语气和风格差异**
- 正式程度：[正式/半正式/非正式]
- 客观性：[客观/主观]
- 语气强弱：[强/中/弱]
- 文体特征：[学术/新闻/口语等]

**4. 适用场景**
- 在什么语境下用句子A更好？
- 在什么情况下用句子B更好？
- 考研阅读/作文中哪种更常见？为什么？

**5. 表达效果评估**
- 哪个句子更简洁？
- 哪个句子更精确？
- 哪个句子更有说服力/感染力？
- 有没有更好的第三种表达方式？

**总结表格**
请用一个表格对比两个句子的关键差异，方便我记忆。

**学习建议**
- 我应该优先掌握哪种结构？
- 在考研作文中如何灵活运用这些结构？
- 给我2个练习题，让我尝试类似的结构变换。
```

**第一部分：示例学习**

- 使用的语法结构：
- 语气强弱：[强/中/弱]
- 正式程度：[正式/半正式/非正式]
- 适用场景：
- 考研作文推荐度：⭐⭐⭐⭐⭐

**第二部分：实战练习**
给我3个新的核心意思，让我自己尝试用至少3种不同结构表达。

核心意思示例：
1. [示例1]
2. [示例2]
3. [示例3]

**第三部分：反馈与改进**
在我完成练习后，请：
- 评价我的变换是否正确
- 指出可以改进的地方
- 提供更地道的表达建议
- 给我打分（满分10分）

**第四部分：模式总结**
总结这类句式变换的规律和技巧，帮助我举一反三。

## 6. 个性化练习生成器

**适用场景**：针对薄弱环节生成定制练习

```
我刚学习了[语法点名称]，感觉理解得还不够扎实。请为我生成一套针对性练习题：

**我的情况**：
- 已学习内容：[简要说明]
- 困惑点：[具体说明哪里不理解]
- 常见错误：[如果有，请说明]

**练习要求**：

**1. 选择题（5道）**
- 考研真题风格
- 每题4个选项
- 覆盖该语法点的不同应用场景
- 难度：中等偏上

**2. 改错题（3道）**
- 设置典型错误
- 错误类型多样化
- 让我找出并改正

**3. 翻译题（2道）**
- 中译英
- 要求必须使用目标语法结构
- 句子难度适中

**4. 写作题（1道）**
- 要求写一个段落（80-100词）
- 必须使用目标语法结构至少2次
- 主题贴近考研作文

**5. 答案解析**
每道题都要有：
- 正确答案
- 详细解析（不仅告诉我对错，还要解释为什么）
- 相关知识点拓展
- 类似题目的解题技巧

**难度控制**：略高于我当前水平，有挑战性但不至于打击信心。

在我完成后，请批改并给出详细反馈。
```

## 7. 苏格拉底式提问导师

**适用场景**：通过引导式提问，培养深度思考能力

```
我想深入学习[语法概念]。请不要直接告诉我答案，而是通过苏格拉底式的提问引导我自己思考和发现。

**对话规则**：
1. 每次只问一个问题
2. 问题要有启发性，能引导我深入思考本质
3. 根据我的回答调整下一个问题的难度和方向
4. 如果我卡住了，给一点提示，但不要直接给答案
5. 如果我回答错误，不要直接纠正，而是通过反问让我自己发现
6. 最后帮我总结我们讨论得出的结论

**学习目标**：
- 理解[语法概念]的本质
- 掌握其使用场景和限制
- 能够灵活应用

**我的背景**：
- 当前理解程度：[初步了解/有一定基础/比较熟悉]
- 主要困惑：[如果有，请说明]

现在开始第一个问题。请记住：你的角色是引导者，不是讲解者。
```

## 🎯 使用技巧

### 高效使用原则

1. **明确目标**：每次对话前清楚自己想要什么
2. **提供背景**：让AI了解你的水平和目标
3. **迭代优化**：不满意就继续追问
4. **验证输出**：交叉验证AI的回答
5. **记录精华**：保存有价值的对话

### 追问技巧

- "这个解释还是不太懂，能换个角度吗？"
- "能不能用更简单的例子？"
- "这个太简单了，有更深入的讲解吗？"
- "能否给我一个实际应用的场景？"
- "如果[某种情况]，这个规则还适用吗？"

### 保存与管理

1. **建立对话档案**：将重要对话保存到笔记软件
2. **分类整理**：按语法点分类存储
3. **定期回顾**：每周复习之前的对话
4. **提取精华**：将有价值的内容整理到知识卡片
