## 💡 核心精华提炼

### 数学一 Top 5 建议
1. ⭐ **平时积累 > 冲刺突击** - 真正决定考场发挥的是平时积累
2. ⭐ **选填专项训练** - 考前16套选填练习,目标95%正确率
3. ⭐ **名师组合策略** - 武忠祥前六章 + 方浩无穷级数 + 张宇补充
4. ⭐ **一本保本,两本血赚** - 吃透一两本习题集就够了
5. ⭐ **真题至少刷2遍** - 真题是最宝贵的资源

### 英语一 Top 5 建议
1. ⭐ **阅读不是翻译,是找逻辑** - 掌握唐迟阅读逻辑
2. ⭐ **细节服从主旨** - 所有细节都服务于主旨
3. ⭐ **真题至少刷三遍** - 精读+归类+突破
4. ⭐ **作文一定要自己写** - 参考句式,自己写几十篇
5. ⭐ **单词反复背** - 直到考前一天都要背单词

### 政治 Top 5 建议
1. ⭐ **得选择题者得天下** - 选择题占50分,是关键
2. ⭐ **1000题三遍法** - 全面刷→错题重做→重点突破
3. ⭐ **肖四必背** - 12月拿到肖四立即背,至少3遍
4. ⭐ **10月启动** - 政治10月启动完全来得及
5. ⭐ **跟着肖秀荣没有错** - 肖秀荣是考研政治一生推

### 408 Top 5 建议
1. ⭐ **王道四本是核心** - 吃透王道就够了,不要贪多
2. ⭐ **真题至少刷3遍** - 真题是最宝贵的资源
3. ⭐ **LeetCode算法训练** - 1000题+模板总结
4. ⭐ **艾宾浩斯遗忘表** - 科学记忆,定期复习
5. ⭐ **早期启动** - 408内容多,需要早期启动

## 💬 使用建议

### 对于27考研同学

1. **立即开始**: 数学、408、英语现在就要开始,政治等到2026年7月
2. **充分利用时间优势**: 你有19个月,可以打更牢的基础
3. **稳扎稳打**: 不要急于求成,前期可以学得慢一些
4. **保持连续性**: 一天都不能断,特别是英语单词
5. **定期复盘**: 每月检查进度,及时调整计划

1. **首次使用**: 先读对应科目的27考研备考指南,了解整体策略
2. **分科复习**: 每科先看备考指南,再看原始经验贴

4. **实践为主**: 看了就要做,不要只看不练
5. **持续更新**: 关注最新经验贴,不断优化策略
