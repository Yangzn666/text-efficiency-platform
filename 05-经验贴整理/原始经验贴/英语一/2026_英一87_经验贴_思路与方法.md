## 二、单词：滚动式记忆 + 易混词对比 + 熟词生义

**时间线**：3月份开始用不背单词app背单词，每天50–100个（可按自己情况增减）。

**核心方法——滚动式、轻量且重复地记忆**：
- 刚开始记不住非常正常，别逼自己第一遍就全记住，"反正你以后还会遇到它"。
- 一个单词第一眼觉得陌生 → 早上醒来看一下意思、午休前看一下、睡前再瞟一眼；第二天忘了就再看，隔几天又瞟一眼，阅读碰到时再记一下。
- 这样"轻量且重复"地记，花不了很长时间但效果显著。

**易混词一定要搜集在一起对比记忆**（作者至今记得 ingenious / ingenuous "我恨你俩"）：单个背很难意识到它们是易混词及区别。可适当用巧记，如 command 和 commend 中间是 ma(妈)命令我、中间是 me(我)夸奖我——但**没必要专门记口诀，口诀只是辅助**。作者当时常上小红书搜大家怎么分辨易混词。

**熟词生义**：背意思尽量全面，至少把单词书里标黑的意思都记住，因为近几年阅读和完型都在增加熟词生义频率。**建议结合句子来记**（例句或真题碰到的实例），印象比干背深。词组/固定搭配不像高中那么重要，记几个核心常考的（如 take on），后续真题碰到再记即可——主要在完型考，1个0.5分性价比不高。

## 三、阅读：8月开真题 + 应试流程 + 出题人视角消化

**开真题前铁律**：做真题之前一定一定要确保单词已经熟练背诵，**千万不能浪费真题**。考英一的可以先拿一两篇英二阅读（不用太多）找回阅读感觉和做题思维，预热后再写英一真题。

**作者节奏（仅供参考）**：大约一天两三篇，从03年开始写；10年及以前的题不限时、只记录每篇用时看情况（那段题普遍比近年难，一开始做不好别灰心，后面会质变；也是找感觉的过程）；**10年以后的题开始严格限时**；**最后剩22–24年的题留到12月做全真模拟**。

**限时后的应试阅读流程**（作者原话梳理）：
1. 先看题目并划出题目里的**关键信息**（人物/时间/地点等，不要求记住，划完没印象也没关系），但**不看选项**（选项abcd内容太多，没看文章看了也看不懂，纯浪费时间）。
2. 开始读文章，要有**主旨意识**，时刻寻找作者要表达的主旨。
3. 阅读时划出每一段的**中心句**；没有中心句就划该段关键信息，可关注**连词**（连词代表段内或段与段之间的**逻辑结构**）。
4. 一遍看不太明白可看第二遍。
5. 开始做题，依旧带着主旨意识，**每做一题都要在原文划出依据**（这一步非常重要：避免"想当然"，也方便回头检查、知道自己为什么选、要不要改）。
6. 碰到"二选一"就仔细比对两个选项的**用词差异**、判断双方不同的**侧重点**，再根据**主旨意识**选和主旨接近的那个（需多做题自己感受）。

**真题的消化（读完 + 做对题两部分）**：
- 每篇阅读先拿**黄皮书真题答案的翻译和重点词组**比对原文和选项，细看有没有不懂或当时误解的词和句子，直接标注在试卷上，之后常拿出来复习；但**没必要把每句话意思都抄一遍，尽量精简**。读完总结文章整体架构和段落关系（如某段是现象、某段是作者评价看法），考研阅读架构大部分差不多。
- 做错的题分两种：**看不懂的错** 和 **看懂了还是错的错**。前者反思为什么会看错误解（是单词不懂还是英文语句思维和中文不一样）；后者要**站在出题人的角度**思考，复盘当时的自己为什么会选错。先看黄皮书等解析，若不能说服自己（有些解析纯为凑答案），就上小红书搜这篇text看大家讨论、找大佬的理解来"洗脑"自己，反思自己的关注点和正确理解的差异（是依据找错还是解读有误），直到成为出题人"肚子里的蛔虫"。

## 四、小三门（完型 / 新题型 / 翻译）：核心都是"读懂文章"

作者自述没认真对待小三门、没做规划，约九月末开始一天一篇完型或新题型（简单做得快会写两篇），翻译甚至考前几天才全真模拟速成——**非常不建议模仿**，只分享做题思路。**小三门核心思路都是读懂文章。**

- **完型**：先通读一遍知道意思，第二遍边读边选，选不出先空着回头比对选项，把不确定的选项带入看通不通顺。
- **新题型**：技巧性最强，但**不建议一上来就开技巧**；有时间至少把文章和选项全部认真读一遍，尤其排序。七选五和小标题更侧重**文章信息的提炼**，读时标出关键信息；排序侧重**架构和逻辑连贯性**，思考每个选项主要内容、排时思考段与段之间"内容与逻辑"的衔接（看连词、看有没有词和上一段呼应），关键找过渡句、总起句。可看技巧作辅助，但绝不能为了技巧而技巧（作者觉得今年排序还是有难度）。
- **翻译**：作者考前才学，自认失误。方法可参考**高中文言文翻译**——翻译前先看这句话有没有**疑似得分点的词和句式**，重点关注熟词生义、各种格式的从句、该语背景下不同用法的衍生义，写时重点翻译这些；**写完可以让AI改一下、看得分情况、总结得分点特征**。

## 五、作文：抄范文 + 豆包逐句批改 + 分题型/主题整理模板

作者约十一月中下旬才开作文（自认开晚了，中间有"大空缺期"）。**大空缺期不利于阅读语感保持**，可通过二刷真题、写英二、看黄皮书阅读来保持手感（作者感觉英二阅读比英一略简单、选项设置简单很多；黄皮书阅读难度和题目设置都偏大，有些解析不认同也不用深究，当保持手感）。

**作文具体做法**：
- 先找一些比较好的范文和模板**一边抄一边记（顺便练字）**，抄几篇有感觉了就套模板写，然后**交给豆包评分**：让它给出**评这个分的理由**、**逐字逐句地改**、找出语法错误/不地道表达/对应修改建议，再让它根据主题给一些好的表达，最后逐渐形成自己的模板。
- **小作文根据题型整理**（建议信、通知信等）；**大作文根据主题整理**（美德品质类、传统文化类等）。
- **小作文**是传递信息的作用，不是高级表达和长难句越多越好，相反要求**用地道连贯的表达和正确的格式写出具体、完整的内容**（如写比赛通知：主题、参赛要求、时间地点、评分机制、赛后奖励、报名方式都要写到，让人一目了然）。写时可问AI"这类活动可以从哪几个方面入手、怎么把内容写具体"。
- **大作文**要做到**图表和模板的衔接，千万别让老师看出是套模板**——要**通过题目给出的图表引出你模板的内容，而不是生硬套模板**（如写"某品质提升了能力"，就写这个品质在哪个具体情况下、通过什么途径提升了你哪方面能力）。

**AI批改实操（图5、图6，作者晒出的与AI对话）**：
- 让AI"告诉我具体是哪些部分扣的分并给出提高建议"。AI反馈扣分集中在**语法细节**和**搭配地道性**（考研英语作文对这两类细节要求较严）：
  - 语法错误（约扣2–3分）：动名词作主语错误（"broaden vision is of paramount significance" → 应为 "broadening one's vision"）；祈使句结构缺失（"integrate our major with knowledge…" 缺主语，应补 "we should"）；固定搭配介词错误。
  - 表达地道性（约扣1–2分）：短语搭配生硬（"make cross-discipline collaboration" → 更地道 "engage in cross-disciplinary collaboration"）；词汇形式不准确（"cross-discipline" 修饰 collaboration 应用形容词 "cross-disciplinary"）。
- 追问句式（作者原话，可复用）："怎么表达社会发展方面的好处呢，我感觉我表达得很平淡""有没有在社会中传递这种精神、形成良好循环的表达""关于论证部分有没有更好的表达，个人和社会方面，在原作基础上改""还可以从哪些方面阐述主题的重要性呢"。
- AI给出的**大作文提升方向**：① 图画描述强化细节与准确性——还原图中对话、人物动作，避免方向/逻辑混淆，写前梳理"对话/动作/场景"，用"**人物+动作+语言**"结构增强画面感；② 语法与词汇聚焦基础纠错与搭配——修固定搭配（resume doing、ability to do）、拼写（external）、语法结构（encourages sb. to do），词汇优化用 unwavering / amid / nurturing 替代 abundant / in / gaining；③ 论证逻辑强化"**主题+场景**"关联——例子紧扣主题词（如"坚持"），避免无关表述（"鼓励同事"可改为"带领团队克服挑战"），每个分论点补具体场景。

**全真模拟**：作者认为非常有必要。一般找一个和平常自习完全不一样的环境，**下午两点到五点**开始模拟，主要关注自己**做题的心态和时间的分配**，想想考场上遇到拿不准的题该怎么办。

## 七、可直接迁移到本网站的要点

1. **"资料做减法"清单**：不背单词app + 英一英二真题 + 黄皮书解析，三样打天下——可纠偏网站里"名师课/资料堆砌"倾向，突出"少而精 + 吃透真题"。
2. **滚动式背词法（每天50–100个 + 早/午/睡前多次瞟 + 阅读碰到再记）** → 补入「英语·单词」模块，替代"一遍背熟"的错误预期。
3. **易混词成对对比记（ingenious/ingenuous、command/commend 用 ma妈命令/me我夸奖）+ 熟词生义结合句子记** → 网站「易混词/熟词生义」专项素材。
4. **"做真题前先确保单词熟练、别浪费真题；考英一先用一两篇英二热身找感觉"** → 可作为「真题使用原则」置顶。
5. **阅读应试6步流程（看题干划关键信息不看选项 → 主旨意识 → 划中心句/连词逻辑 → 每题原文划依据 → 二选一比对用词侧重+靠主旨）** → 直接做成网站「阅读方法论」流程图。
6. **"错题分'看不懂的错'和'看懂还错的错'，后者要站出题人角度复盘、被大佬解析洗脑到成为出题人蛔虫"** → 网站「错题复盘」核心观点，区别于泛泛的"整理错题本"。
7. **小三门统一心法"先读懂文章、别一上来开技巧"；翻译参考高中文言文'先找疑似得分点词和句式'"** → 补入「完型/新题型/翻译」分节。
8. **作文"抄范文顺便练字 → 豆包评分并给扣分理由 → 逐字逐句改 → 形成自己模板"，小作文按题型、大作文按主题整理；大作文要'用图表引出模板'而非生硬套模板** → 网站「作文」模块的AI批改工作流，含具体扣分维度（语法细节/搭配地道性）和可替换词（unwavering/amid/nurturing 替 abundant/in/gaining）。
9. **AI批改实操prompt清单**（"告诉我哪部分扣分并给提高建议""怎么把平淡表达写具体""在原作基础上改论证部分"）→ 可作为网站「用AI改作文」的提问模板，独家且可落地。
10. **全真模拟安排：12月留22–24年真题、换环境、下午2–5点、练心态与时间分配** → 网站「冲刺模拟」时间线。
11. **与常见建议的冲突/差异点**：① 作者明确"不善于规划、方法重于时间表"，与多数按月份排死计划的经验贴取向不同；② 单词不推荐专门背词书、词组搭配"性价比不高"，与"词组也要系统背"的常见建议相左；③ 新题型"不建议一上来开技巧"，与技巧流课程相反；④ 全程几乎不点名名师课（无唐迟/田静等），靠真题+黄皮书+AI自学，属"自学派"，可作为网站里区别于"名师推荐"的另一条路线样本。
