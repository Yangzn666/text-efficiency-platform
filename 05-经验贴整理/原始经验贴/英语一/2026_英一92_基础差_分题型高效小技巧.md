## 一、单词：三个背词小技巧（图2–图5）

1. **在语境里背**：用APP背时有意识地看一眼例句，带上下文理解更生动；也看固定搭配——**动词跟着它的介词一起记词组**效率更高（带介词念起来更有节奏感），而且前期背好用法，对后期做完型很有帮助。
2. **A4记忆法**（英专同学教的，本贴最大新点，图4实拍+图5步骤）：
   - 用自带的"A4背单词法"格式纸打印，或普通白纸**折4折**：左列写英文、右列写中文，**写的过程本身就是第一遍记忆**。
   - 沿中间折痕对折遮住中文 → 看英文默写中文；再反过来 → 看中文默写英文拼写。
   - 写错或卡壳的地方旁边打标记，这些就是重点关注词；纸顶记当天日期，**标出第2、4、7、15天的复习节点**，按节点定期回来反复过筛。
   - 把自己反复点错的词单独收藏，攒够数量导出集中背；**周日只用A4法背自己不会的词，不用每个词都A4一遍**。
   - 实拍词例：previously / reciprocity / reciprocal / multiple / genuine / suggest / trial / release / trapped / resemble…（对折看英写中、翻折看中写英，脑内回想中文，不记得摊开看一眼）。
3. **记读音**：一个词不会读就只能一个字母一个字母死记、效率很低；所以打开单词软件的发音反复听，**背读音比背字母组合快很多**。

## 二、长难句：三步找主干（图6）

- **定位**：作者认为长难句是英一最难的地方。听完方法课后最重要的事情是**练习**——可做课程配套题、考研软件的长难句练习功能，或读外刊做划分（外刊句式与真题很接近）。老师不直接推荐，各人基础不同，建议试听一两节再定。
- **三步拆解法**（可通用）：
  1. 找出句子里**所有动词**；
  2. 给动词排列，**找到主要动词**；
  3. **支配主要动词的名词就是主语，围绕主要动词的就是主干**。

## 三、阅读：定位 · 比对 · 排除（图7、图9、图11、图8、图10）

- **英一≠英二**：英二更看重词汇量，**英一更看重逻辑和文章结构**。英一真题数量有限很珍贵，别在语法还没熟练时就浪费——**5到6月靠读外刊培养阅读习惯**。考研阅读文章主要来自**经济学人、卫报、纽约时报**，每周读两三篇、不求多、每篇读透，重点是适应复杂句式和学术化表达。
- **六字诀**：**定位、比对、排除**。拿到文章先看题目，圈出题干里的定位词（人名、地名、时间、专有名词，以及 **according to the author / it can be learned that** 这类提示信息位置的表述）；读文时重点盯**段落开头结尾、but/however 转折词、argue/believe 观点动词**——关键信息最爱藏在这里。
- **五种题型分类处理**（本贴重点新点）：
  - **词义题**：考的不是词本身有多少义，而是它在上下文里的具体含义；答案一定藏在上下句，往前/往后各看一句就能找到解释或举例。
  - **细节题**：用题干关键词回原文定位、精读该句（必要时前后多看一句）；干扰项常见套路=**偷换概念、范围扩大/缩小**。
  - **推理题**：正确项往往是原文某句话的**同义改写**；不要把"看着很有道理但原文没提"的内容选进去。
  - **例证题**：区分"例子本身"和"例子要证明的观点"——**例子是工具、观点才是答案**；答案在例子前面的观点句，或例子后面总结性的那句话。
  - **主旨题**：**建议放在最后做**（做完其他题对全文把握更清）；重点关注首段、尾段及每段首尾句；正确项覆盖范围要能概括全文，不能只涵某一段。
- **定位要准**：每道题都要在原文找到对应句，不凭感觉选；两选项纠结时用**排除法**——看谁在原文有依据、谁有明显错误，排掉明显错的剩下就是答案。"你觉得对的不一定是答案，**原文说了的才是**。"
- **考点标注版复盘**（图8实拍）：刷完一遍后，**下载对应篇幅的"考点标注版"对照考点复盘**；长难句和考纲词用不同颜色标注、重点词组加粗，很清晰。
- **外刊当真题做**（图10实拍）：选**考研同源期刊**（如 Boston Globe 等），像做真题一样整理段落关系、分析主旨、练习分句、积累长难句，提前适应英一语篇逻辑。

## 四、完型填空：抓逻辑线 + 盯"复现"（图11）

- **9月才开始**（与新题型、翻译同步启动）。
- 完形文章有**完整的逻辑线**：做题前先把**第一段通读一遍**，再把后面**每段第一句话**读一遍，搞清楚全文在讲什么。
- 做题不凭语感乱选，看空格前后有没有线索。**完形最喜欢考的是"复现"**——前面出现过的词后面又出现一次，或者用同义词的形式再出现一次。

## 五、新题型：只盯首尾句 + 代词/逻辑词（图11）

- 作者**没听课**。
- 七选五/排序题都**不必读懂每个单词**，只需盯着**每段开头第一句和结尾最后一句**，重点看里面的**代词和逻辑连接词**。
- 例：第二段开头说 **this theory** → 第一段结尾一定提到了某个具体的 theory。

## 六、作文：按话题类型自建写作框架（图13–图14）

- **推荐早点开始**：基础弱的同学作文上手更慢；很多人背十几篇范文上考场仍写不出，是因为**没学会作文逻辑、背的句子都不是自己的**，东施效颦反而弄巧成拙。
- **整理一套"属于自己的写作框架"，按话题类型自己归纳**：
  - **社会现象类**：① 描述图画内容 → ② 分析现象产生的原因 → ③ 提出解决办法。
  - **个人品质类**：① 引出这个品质 → ② 讲品质为什么重要 → ③ 讲怎么培养。
- **每个话题动手写一篇完整作文**，写完找几篇高分范文对照，看人家的句式能不能替换掉自己写的简单句。
- **大作文每一段第一句都应是该段中心意思**，后面的话都围绕它展开。
- **小作文**：格式写对就能拿到一半以上分数；把**建议信、感谢信、投诉信、邀请信**这几种类型各练一篇就够了。
- **卷面**：字可以不好看，但一定要写清楚工整（老师改一篇作文只有几十秒，字迹潦草很吃亏）；**不建议练衡水体**（很耗时），用粗一点的笔芯慢慢写就很好看。

## 七、翻译：先主谓宾再加修饰、按点给分（图12）

- **翻译是长难句的延伸考点**。核心：**不要逐字翻译**，那样翻出来的东西不像中国话。
- 步骤同长难句：**先把句子的主谓宾找出来、把"谁做了什么"翻出来，然后再往里加修饰成分**（说他在什么条件下、为了什么目的做了这件事）。
- **阅卷老师按点给分**：主谓宾翻对了就已经拿到**1分**，修饰成分再翻对一部分就能拿到**1.5分以上**。
- **一定要动笔写在纸上**——只在脑子里过一遍，会发现自己的语序乱得一塌糊涂。

## 结尾金句（图14）

> 考研英语的复习是一场需要耐心的长跑，一开始会磕磕绊绊，中间会想放弃。只要你每天都在背单词、每天都在拆句子、每天都在认真做每一道题，那些看起来不起眼的积累最后都会变成考场上的底气。

> 以下均为**相对《旱区基础不好版》及英一87/88/93帖的新点**，聚焦各题型"独门小技巧"。

1. **A4纸背单词记忆法（全网站尚无同款）**：白纸折4遮中文默写、纸顶标"第2/4/7/15天"复习节点、反复点错的词单独收藏周日集中背——旱区版只给"APP+红宝书+写手心"，此为可复制的纸质SOP，建议做成「英语一·单词」图文教程。
2. **背单词量化新口径**：课多50 / 课少100–200新词、"背读音比背字母组合快"、动词跟介词联合记词组——补齐旱区版"两秒反应核心义"之外的可操作细节。
3. **长难句三步找主干法**（找所有动词→排主要动词→支配主要动词的名词是主语）：给出一套通用"拆解算法"，比旱区版"每天一句跟解析"更可迁移，入「长难句·方法论」。
4. **阅读六字诀 + 五题型逐类处理**（词义/细节/推理/例证/主旨）：旱区版仅"定位+同义替换+细节服从主旨"，本篇拆得更细，尤其**例证题"例子是工具、观点才是答案"、主旨题放最后做**，可做成「阅读·题型速查表」。
5. **英一≠英二 + 语法没熟前用外刊养习惯不浪费真题**（经济学人/卫报/纽约时报每周2–3篇读透）：给出"启动顺序"策略，纠偏"一上来就刷真题"。
6. **"考点标注版"复盘法**：刷完一遍下载同篇考点标注版，长难句/考纲词双色+重点词组加粗对照复盘——网站「阅读·复盘」可推荐此工具用法。
7. **完形最高频考点=复现**（原词重现 / 同义重现）+ 先通读首段和各段首句抓逻辑线：比旱区版"however/therefore逻辑词"更进一步，点出完形命题规律。
8. **新题型省力原则**：不读懂全文，只盯每段首尾句 + 代词/逻辑连接词（this theory→上段末必提具体theory）——与旱区版"七选五圈逻辑词/排序代入法"互补，给更省时的定位法。
9. **翻译"按点给分"量化**（主谓宾对=1分、修饰对一部分=1.5+）+ 先主谓宾再加修饰 + 必须动笔写纸上：把旱区版"抓主干再加修饰"落到分数层面，可入「翻译·评分说明」。
10. **作文"按话题类型自建框架"**（社会现象/个人品质各给三段式骨架）+ 每话题写完整一篇再用高分范文替换句式 + 小作文四类各练一篇 + 不练衡水体改用粗笔芯——与旱区版"约10个功能句现场组合"互补，提供"话题框架+整篇练写法"；另**大作文老师记为王江涛+周思成**（旱区版记为黄皮书+英专模板），可更新教师推荐位。
