## 一、真题精读标注示范（图1：Text 2 · 美国报业）

同一篇文章，作者用红蓝笔做了一套"标注动作"，可作为精读时每篇照做的清单：

1. **问句作用按位置判断**（作者单列的三条规律）：
   - 文章**开头**出现问句 → 作用是**引出主题**；
   - 文章**中间**出现问句 → **设问（自问自答）**，或**反问以表达作者态度**；
   - 文章**结尾**出现问句 → **反问，表达作者态度**。
2. **开篇方式与中心思想挂钩**：本篇首句即问句（"Whatever happened to the death of newspapers?"），作者标注"开篇方式=问句开篇"，并据此提炼**中心思想=报业衰落的美国报纸业**。
3. **指代关系标注**：圈出 "The **tn**"（the + 名词）这类指代，回指前文，理清句子间衔接。
4. **词汇逐处标注词性 / 词义 / 搭配**（边读边补生词与熟词新义），示例：
   - `fled`→ flee to somewhere（逃离到某地）；`chronicle`→ n.纪事报 / v.记录（编年史）；
   - `threaten to do` 预示着将要做某事；`launch` A发起B；`charitable` 慈善的；`subsidize` 补贴；`out of date` 过时了；
   - `stayed afloat` 维持运转；`pushing journalists overboard` 把船员推下船→**裁员**；`had the nerve to do sth` 有胆量做某事；`desperate measures` 铤而走险的措施；`revenue` 收益 / `reliance` 依赖；`whirlwind` 旋风→报业大动荡；`distinctive` 明显不同的；`completeness` 完整性 / `virtue` 美德。
5. **逻辑关系标注**（判断句间/段间走向）：一语双关（讽刺）、**因果**、**对比**、**递进**（not only…but）、`but…not` 的转折取舍、**暗含今昔对比**。
6. **数字圈出并读出言外之意**：87%（美国报业广告依赖度）vs 35%（日本）——作者批注"依赖度不同→稳定性不同，日本报纸更稳定"，把数据当作论证线索而非孤立信息。
7. **长难句圈画**：圈出定语从句等修饰成分（如 "areas **where newspapers are least distinctive**"），先抓主干。
8. **段落功能与出题点预判**：在某段旁标注"P5 推理题""段：段落（逻辑关系重要的）"，即精读时就预判"这段会出什么题型、逻辑重点在哪"。

> 这块的价值不在具体单词，而在示范一套**"问句看位置、开篇定主旨、指代理衔接、逻辑标关系、数字读结论、段落预判题型"**的固定标注流程。

## 二、五大题型分步打法（图2–图4 备忘录正文）

### 1. 主旨大意题
- **题干标志词**：main idea / main topic / best title（问主要内容、中心思想或选最合适标题）。
- **①串联首尾句**：考研文多为"总-分""总-分-总"或"转折后出主旨"结构，首末句常含段落核心观点，串起来即可把握整体走向。
- **②锁定高频名词**：反复出现的高频名词/名词短语=文章核心论述对象，主旨必然围绕它展开（如多次出现 artificial intelligence → 主旨大概率与AI相关）。
- **③用主旨句验证并排除**：主旨句常在首段转折后、尾段总结处、各段首句的共性表述中；拿选项与主旨句比对，排除**以偏概全、过度拔高、偷换概念**。例：文章讲"AI在医疗领域的应用现状"，选项讲"AI的未来发展趋势"=过度拔高，可直接排除。

### 2. 细节题
- **题干标志词**：对人物/事件/时间/地点等具体细节提问，题干明确指向某细节，常含 according to。
- **①定位要全面准确**：尤其**空格前面的内容**必须找到，注意可能有同义替换，需仔细比对。
- **②"原词优先 + 名词回带 + 动词校验"三步**：定位准后，若定位句原词能与选项对上→优先选；对不上→把**选项里的名词带回定位段落**找；段落里没这个名词、或名词在但**前面的动词不对**→排除，剩下的即为答案。

### 3. 推理题
- **题干标志词**：infer / imply / suggest（据文推断隐含信息）。
- **原则**：避免过度联想和主观臆断；据题干关键词定位到相关段落/句子，答案往往**不是原文直接表述**，而要结合上下文逻辑推断。
- **错误选项三特征（附例）**：
  - **过度推断**：原文说"某方法有一定效果"，选项说"某方法是最佳方法"；
  - **绝对化表述**：must、never 等；
  - **无中生有**：原文说"新能源汽车销量近年有所增长"，选项说"将完全取代传统燃油车"。

### 4. 词义猜测题
- **题干特征**：要求猜某单词/短语/句子的意思，并明确给出该词在文中的位置。
- **①看前后逻辑连接词定方向**：
  - `that is` / `in other words` 等解释性词语 → 其后内容即对该词的解释；
  - `but` / `however` 等转折词 → 该词与转折后内容意思相反；
  - `for example` / `such as` 等举例词 → 通过例子推测词义。
- **②用构词法**：由熟悉词根词缀构成的词，可依词根词缀推义（如 `un-` 否定前缀）；但**避免望文生义**，不能只看表面意思，必须结合语境。

### 5. 态度题
- **题干标志词**：attitude / feel about（问作者或文中某人物对某事的态度）。
- **①标记情感词汇**（通读时圈出，直接体现倾向）：
  - 褒义 positive / supportive / optimistic；
  - 贬义 negative / critical / pessimistic；
  - 中性 objective / neutral / impartial。
- **②从行为描述反推态度**：用了大量积极事例或数据支持某观点→**支持**；指出某事物弊端或问题→**批判**；仅客观陈述事实、不掺个人情感→**中立**。
- **③区分"作者态度"与"文中人物态度"，并识别三类设误**：
  - **极端态度**多为错项（enthusiastic / disgusted）——考研作者态度通常温和客观；
  - **"无态度"多为错项**（indifferent / unconcerned）——作者既然讨论某话题，必然有态度；
  - **偷换态度**——把文中人物的态度当作作者的态度。

## 三、复盘方法（图4 · "关于复盘"）

作者的复盘不是只对答案，而是三件可积累的动作：

1. **梳理段落核心观点 + 段间逻辑关系**：给出一套固定范式——第一段提传统观点 → 第二段转折、反驳传统观点 → 第三段举例论证新观点 → 第四段总结新观点的意义。
2. **分析出题分布**：标记每道题对应的段落位置，总结**出题人偏好的出题区域**（首段尾段、观点句、转折处等）。
3. **干扰选项归纳**：把所有错题的干扰项按**无中生有 / 偷换概念 / 过度推断 / 反向干扰**等类型分类，统计各类出现频率，练出对陷阱项的敏感度，下次做题能快速排除。
