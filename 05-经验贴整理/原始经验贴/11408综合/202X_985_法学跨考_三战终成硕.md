# 11408考研三战终成硕985上岸经验贴(法学跨考)

## 📊 基本信息
- **作者背景**: 法学专业本科,三战考研
- **考试科目**: 11408(政治+英语一+数学一+408)
- **初试分数**: 未说明
- **目标院校**: 某985院校
- **备考时长**: 约3年(一战+二战+三战)
- **特点**: 三战考研,已过法考,最终上岸985

## 🎯 核心策略概览
三战考研需要极大的毅力和决心。成功的人生不可复制,失败的经验却可以借鉴。关键是分析前两次失败原因,针对性改进,坚持不懈。

## 📚 详细备考策略

### 1. 资料选择
- **数学**: 武忠祥/张宇+真题
- **英语**: 真题+唐迟
- **政治**: 肖秀荣系列
- **408**: 王道四本+真题

### 2. 时间规划

#### 一战
- **问题**: 可能准备不足或方法不当
- **结果**: 失败

#### 二战
- **调整**: 分析一战问题,改进方法
- **结果**: 仍然失败

#### 三战
- **反思**: 深入分析前两次失败原因
- **改进**: 针对性突破薄弱环节
- **结果**: 成功上岸985

### 3. 学习方法

#### 失败经验借鉴法
- **理念**: 成功的人生不可复制,失败的经验却可以借鉴
- **实施**: 
  - 分析一战失败原因
  - 分析二战失败原因
  - 找出共性问题
  - 针对性改进

#### 坚持到底法
- **现象**: 三战考研压力巨大,容易放弃
- **建议**: 
  - 坚定信念
  - 不被困难打倒
  - 坚持到底
- **结果**: 最终成功

#### 已过法考优势利用
- **背景**: 已通过法考
- **优势**: 
  - 学习能力强
  - 自律性好
  - 抗压能力强
- **应用**: 将这些优势应用到考研中

### 4. 考场策略
- **心态**: 经历过两次失败,心态更稳定
- **策略**: 正常发挥,不要紧张

## ⚠️ 避坑指南

### ❌ 常见误区
1. **盲目三战**: 不分析失败原因,盲目继续
2. **心理崩溃**: 压力太大,心理崩溃
3. **经济压力**: 没有经济支持,难以坚持
4. **社会压力**: 家人朋友不理解,压力大
5. **忽视复试**: 初试过了,复试放松

### ✅ 正确做法
1. **分析失败**: 深入分析前两次失败原因
2. **心理调适**: 寻求心理支持,保持良好心态
3. **经济规划**: 提前做好经济规划
4. **沟通理解**: 与家人朋友沟通,争取理解
5. **重视复试**: 初试过后,认真准备复试
