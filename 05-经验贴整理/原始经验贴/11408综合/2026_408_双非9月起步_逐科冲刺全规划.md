## 〇、一句话定调（先稳住心态）

> "如果你现在才真正进入备考状态，千万别先被别人动辄几轮复习、几百小时学习时长吓住。**九月之后拼的不是谁前面学得最久，而是谁能把剩下的时间用在真正能涨分的地方。**"

> "现在不是来不及，而是**不能再延用前几个月的学习方式了**。九月以前可以慢慢听课、整理笔记、搭框架；九月以后一定要逐渐进入**真题、背诵、刷题、输出、复盘**。"

> "焦虑本身不会让分数上涨。真正让你上岸的是今天把该刷的题刷完、把错题弄明白、把该背的内容背下来。别算别人学了多少，从今天开始把每天能拿到的分，一分一分拿回来。"

## 一、英语复习规划

**1. 单词：不要再把大量时间耗在新词上**
- 九月开始，重点从"认识生词"转到 **反复巩固高频词 + 解决真题里的熟词僻义**。
- 每天早上固定一段时间过单词，数量不用夸张，但**一定要连续**；新词快速过，重点放在前一天、前几天反复错的词。
- 真题里遇到不认识的词直接整理进自己的词汇本——这些词比单纯背单词书更值得记。
- 尤其注意**熟词僻义**：一个词你以为背过很多次，但放进真题句子里还是反应不过来，这种才是真正影响阅读的词。
- 时间线：9–10月以真题阅读里的词为重点，逐渐减少纯背新词；11月—考前主要复习错词、熟词僻义、真题高频词，保持每天接触英语，不让手感掉下去。
- 核心建议：**不追求一天背多少个，而追求今天背过的东西，下周还能不能认出来。**

**2. 阅读：真题一定要吃透**
- 不要陷入"刷题数量越多越好"的误区。
- 后期做阅读先自己完整做一遍，做完**不是只看答案，而是把每道错题对应回原文**，弄清到底错在哪：
  - 定位错了 → 没找到对应段落
  - 理解错了 → 长难句没拆明白
  - 选项错了 → 被偷换概念或过度推断带偏
  - 文章没读懂 → 核心句和逻辑关系没抓住
- 这样整理一段时间，你会发现自己错题其实非常固定。
- 真题按年份推进：**前面年份练方法和手感，近几年真题一定留出来做完整模拟**。不要一边刷新题一边把错题丢掉，真正拉开差距的是**二刷、复盘和总结**。
- 二刷不追求全对，而是看能不能快速说出：文章讲什么、每段作用是什么、题目考哪里、正确选项为什么对、其他选项为什么错。做到这一步，阅读才算真正吃进去。

**3. 小三门：九月就开始，别拖到后面**
- 新题型、翻译、完型建议九月陆续启动。
- 新题型重点训练**文章逻辑和段落衔接**，不要只靠语感；做完一定复盘"为什么这段该接在这里"，注意指代、重复词、逻辑词和上下文关系。
- 翻译不要只看答案，自己先动笔翻，再对照参考答案修改；长难句拆主干、找修饰成分，先保证意思准确再调整表达。
- 完型不用花大量时间研究偏词，重点是把真题做起来，训练上下文逻辑、固定搭配和词义辨析。
- **小三门的目标不是刷出漂亮的正确率，而是提前把做题感觉练出来**——等到十一、二月再从零开始，时间会很紧。

**4. 作文：不要等到十一月才第一次动笔**
- 十月开始准备比较合适。
- 不建议直接背整篇"万能作文"，而是**自己整理一个能根据题目变化的框架**：小作文整理不同类型格式、开头结尾、常用表达；大作文按图表/现象/观点等方向准备素材和句型。
- 十月每周写1–2篇，不必每天写，但一定要真正动笔；写完丢到 App 里检查：句型有没有错误、时态有没有问题、逻辑是否连贯、表达有没有重复。
- 十一月提高频率，后期直接用历年真题练完整作文。**真正要训练的是限时状态下把自己会的东西写出来**，别到了考场才第一次完整写。

## 二、政治复习规划

> 政治后期不要追求把所有课程重新听一遍，核心任务是：**选择题刷题 → 错题回顾 → 知识点补漏洞 → 后期大题背诵。**

**9–10月：基础 + 选择题**
- 基础薄弱就先过一遍核心知识框架；不用边看课一边抄特别厚的笔记，而是边听边理解，遇到容易混淆的地方直接在资料上标出来。
- 选择题一定要及时跟上。做完一套题**不要只看分数，要把错题分类**：知识点根本不会 / 概念混淆 / 题干没看懂 / 选项陷阱没识别——不同原因后面处理方法完全不一样。只把错题答案抄一遍，下次还是会错。

**10–11月：提速，集中处理高频考点**
- 这个阶段政治不能再慢慢磨。前面听过的内容不要反复从头听，**直接通过刷题暴露问题**。
- 反复错的知识点单独整理，尤其是容易混淆的时间、会议、人物、理论表述。
- 给错题做标记：**第一次错 → 看懂；第二次错 → 重点标记；第三次还错 → 单独整理。** 真正要反复看的不是整本题，而是这些你一直记不住的地方。

**11月—考前：选择题 + 大题同步推进**
- 十一月之后重点越来越明确：选择题继续保持手感，大题开始系统背诵。
- 不要再纠结"到底哪套资料最全"，**选定一套主资料之后一直跟到底**——政治最怕资料换来换去，最后每本都只看了一半。
- 大题背诵也别只追求逐字逐句背下来，**先把答案结构记住**，知道每道题可以从哪些角度展开。
- 后期每天留固定时间背政治，持续到考前。

## 三、数学复习规划

> 考数学的话，九月以后数学占比非常大。这个阶段最重要的不是继续无止境地听新课，而是**把已经学过的内容转化成做题能力**。

**9–10月：真题 + 专题补漏洞**
- 基础还没完全过完，九月先把基础收尾，不要为了追进度直接跳过去；基础已经扎实的，可以大量进入真题和专题训练。
- 做题一定要**限时**，不能一道题想半小时然后觉得"终于做出来了"。考研数学最后拼的是**规定时间里拿到该拿的分**。
- 每做完一套题，重点看三类：**完全不会的题 / 会但做错的题 / 方法知道但计算出错的题**。第三种特别容易被忽略，但考试时非常吃亏。

**10–11月：强化计算 + 错题二刷**
- 十月以后不要沉迷追求新题，**真正值得反复做的是自己做错过的那道题**。
- 错题不要只看答案，最好重新独立做一遍；能完整写出来，再去总结：这道题考的是哪个知识点、为什么当时没想到、下次看到什么特征应该联想到这个方法。
- 数学错题本不要做成一本漂亮的作品，**只记自己真的会忘、真的容易错的东西**（某公式容易混、某类题总漏条件、某种计算特别容易出错），这些才值得留下。

**11月—考前：模拟 + 真题保持手感**
- 逐渐加入整套模拟，**按考试时间训练，尤其是上午的数学时段**，提前适应连续几个小时高强度计算。
- 模拟之后不要只看考了多少分，一定要复盘：时间花在哪里了、哪部分最慢、哪些题本来可以拿分却丢了、计算错误占多少。
- 如果一套卷子最后只剩下不会的难题，说明基础分拿得不错；如果大量时间浪费在基础题上，就要赶紧调整。
- **冲刺阶段最重要的不是把自己训练成难题机器，而是先保证基础题和中档题的稳定得分。**

## 四、专业课复习规划

> 专业课是后期最容易拉开差距的一科。九月之前如果只是把书看了一遍，不用焦虑；但**从九月开始一定要逐渐进入"背诵 + 输出"模式**。

**9–10月：第一轮完整背诵**
- 第一轮不要要求自己一字不差。方法是先把每一章的框架搭出来，知道：这一章讲什么 → 有哪些核心知识点 → 每个知识点下面有哪些关键词。
- 背完合上书尝试复述。**如果只能看着书觉得自己会、一合书就完全说不出来，那其实还没真正掌握。**

**10–11月：二轮三轮反复滚动**
- 背诵速度要提起来。不要每天从第一章背到最后一章，而是**根据自己的遗忘情况滚动复习**，把知识点分成：熟练 → 正常复习；模糊 → 高频复习；完全记不住 → 单独突破。这样比平均用力效率高很多。
- 同时开始结合历年真题，看目标院校到底喜欢怎么考。有些知识点看着很偏，但目标院校年年换着方式考；有些书上写了一大段，实际几年都没出现过——**专业课一定要研究真题**。

**11月—考前：从背诵转向输出**
- 十一月以后不能一直停留在"背"，开始给自己设限时任务：看到一个名词能不能马上写出定义、看到简答题能不能迅速列出框架、看到论述题能不能在规定时间内组织完整答案。**尤其是大题，一定要练落笔速度。**
- 后期把经常忘记的知识点集中整理成一份**高频清单**，最后阶段主要反复看这份东西。
- 最后一个月不要再追求把所有资料看完，而是**把自己最容易丢分的地方补起来**。

## 五、最后110天的时间分配（按任务量，不按小时数）

> 如果你现在才真正开始，更建议**按照任务量安排，而不是死磕每天必须学多少小时**。

- **早上：数学 / 英语** —— 头脑清醒，安排数学计算、英语单词和阅读。别一坐下就刷手机，坐到自习室直接开始第一项任务。
- **下午：专业课 + 数学** —— 重点放专业课背诵和数学刷题。专业课背完一定要合书复述，不然很容易出现"看了很多遍但真正答不出来"。
- **晚上：政治 + 专业课复盘** —— 不适合再排特别难的新内容；做政治选择题、整理当天错题，再把专业课当天背过的内容快速过一遍。
- **每天结束前留二三十分钟复盘三问**：今天真正完成了什么？哪些任务拖延了？明天最重要的三件事是什么？——这样第二天不会坐在自习室里才开始想自己该干什么。
