## 二、数学一（145+）：基础靠30讲，提分靠强化期，笔记是给未来的自己存档（图2–4）

### 2.1 基础阶段（蓝开，跟张宇）

- 高数、线代、概率论基础全部跟**张宇**；**"三十讲确实是真神，里面基本上把强化的知识也讲了"**——微分算子法之类"我自己用着还是挺方便的，不过记不住跳过也没关系"。
- 习题只写 **1000题基础部分**。前期进度快、直接看书，到微分方程章节才开始看网课；**看完一章写一章的1000题**。
- 节奏：4月中旬结束高数部分 → 线代2周半 → 概率论2周半，一轮结束。

### 2.2 强化阶段（重中之重是高数强化）

- lz强化用 **🖐讲义**（品牌名被作者用手形emoji打码遮蔽）："🖐的高数讲义上面的题目质量是比较高的，网课可以只看知识点复习阶段，例题完成后看答案。"
- **严选题只推荐写微分积分证明题**。
- **强化全程习题用880**；级数强化看**方浩**，曲面积分强化看**李艳芳或张宇**；"时间不够只写880也行。"
- 线代强化"看没咋了"，概率论强化看方浩，习题还是880。
- **保持高数手感的方法**：强化线代/概率论期间，每天写1小时**李艳芳900题高数部分的ab组选填**。"900题大题部分纯纯逆天，浪费了我半个月。不过它选填部分质量还是很高的，做完感觉对高数的理解有很大的飞跃。"

### 2.3 笔记哲学（作者反复强调）

- "记笔记这个好习惯功不可没。"数一内容与技巧多。
- **一轮笔记不重要**（可直接补充到30讲上，"我自己1轮的笔记中后期再没翻过"）；**强化期间的笔记很关键**：880、🖐讲义、900刷题量上来后，整理**做题技巧 + 当前章节的奇思妙想、小结论、易错点**（例：高数微分积分证明题套路有限，总结一下）。
- 笔记的作用在后期："复习时翻一下，可以很快进入状态。记笔记就是给自己存个档。"
- 执行细节：笔记可以潦草，自己能看懂就行；**每天刷完题把错题和思路记录一下，时间控制在半小时左右**。

### 2.4 真题、模拟卷与"翻车"教训

- 数学强化时间比较长，加上班级期末玩两周、暑假玩一周、**误刷900大题和严选题**，"导致进度有点翻车，**十月中旬才开真题**"。
- 纠偏建议："如果强化时间紧张，**刷个880其实就够了**。"
- 真题**强烈推荐李艳芳**版："参考答案有多种解法，讲解也详细，对答案时可以复习地很全面。"
- 模拟题只写了 **26超越卷**："计算量是真的大，几乎没有什么送分题，每道题都得思考一下。"
- 核心认知：**"提升水平还是在强化阶段刷880和900，这两个我的正确率都能达90%以上。真题和模拟卷更多还是查漏补缺和维持手感。"** 考研真题不会太难，考高分最重要的还是**提升正确率和计算能力**；"刷900和模拟卷时不要道心破碎了。"

## 三、408备考（约130+）：王道打底 + 咸鱼/湖科大分科强化（图4–6）

### 3.1 一轮总法

- **先完整看完王道单一大节网课，再快速浏览王道对应教材章节，紧接着刷完该部分选择题巩固基础**。
- **一轮阶段不用刻意整理笔记**，重心放在听懂、看懂、练熟基础题；系统梳理笔记、深挖重难点**统一留到强化阶段集中完成**。
- 一轮顺序：**数据结构 → 计组 → 操作系统 → 计网**。
- 教材选择：lz**计网一轮和强化都用湖科大教材**，其他用王道。
- "一轮时不要太钻牛角尖，把问题留到强化阶段再解答。"

### 3.2 数据结构强化

- **"不要看咸鱼的强化课。"** 强化时根据**王道咸鱼的打卡表和选择题**严格过一遍，做题有不懂的再看**咸鱼单独的讲解视频**（即：按打卡表刷题+按需看单集，不整套刷强化课）。

### 3.3 计组 + 操作系统强化

- **这两个强化课程咸鱼讲得很好**，"把各个部分的工作流程理得很清楚，建议保存课件上的流程图"。
- 听课前置动作：**开始一章网课前先快速浏览一遍书本再听课**，"不然知识点遗忘的还是挺严重的"；然后**二刷选择题，写大题**——**"写大题是提升理解的最有效的方式。"**
- "408真题考得很细，出题人也经常挑易错点来考，xdx们一定要勤记笔记，作用和高数笔记一样。"

### 3.4 计网强化（湖科大）

- 用**湖科大强化书**（湖科大基础和强化是两本书），"它的强化书讲得相当详细，阅读起来还是挺累的"（当时作者课程视频还没更完，lz是自己看书的）。
- 没时间的话**单看它基础阶段的书也行**。
- 湖科大强化习题册分**填空题、选择题、大题**：lz**填空题直接拿来抄写复习**，**大题只写了真题部分**。

### 3.5 进度与真题

- "我专业课八月中旬才开强化，十一月才开真题，考前把真题刷了一遍就上考场了。"
- **"真题质量非常高，能挖出很多易混淆点，一定要把不会的弄清楚，记录错题打标记。"**
- 考高分 = 对知识体系的理解（**尤其是机组和操作系统，一定要把工作流程各个细节搞清楚**）+ 细心。
- "408题目又臭又长，出题人又老是挖坑，我也经常犯许多rz的错误。xdx们不要焦虑，要相信熟能生巧。"
- **"408和高数在强化阶段一定要勤记笔记。刷过的题不要白刷，每错一道题都要有收获。"**
- 规律判断："11408考了20年，其实出题人把能出的题都出过了。"今年408**选择题比较难、大题比较简单**；考试时**不要死磕，要注意时间**。

## 四、英语一备考（80+）：单词两轮 + 阅读学技巧 + 作文模板限时（图6–7）

- **单词是英语一的重中之重**：从二月到九月初背了**两轮**；用**不背单词APP**（充了VIP），单词本选**红宝书**。
- 红宝书包含**真题阅读的中心词**："我背之前看阅读文章基本上看不懂，背完这些中心词之后，大概能猜懂文章意思，不用死磕长难句也能应付。"
- 阅读看**唐迟**视频课，**主要学解题技巧**："不用逐字逐句翻译，抓住中心词和文章逻辑就够了。"
- 作文"性价比很低、很难提分"，直接背模板，用的**不易学长**的。
- 考场时间分配：**大小作文一共40分钟**，剩下**一个半小时留给完型、七选五和翻译**——"做题不慌，正确率也能保证。"

## 六、对「浙大目标 + 408强化期」的可迁移做法

1. **408强化期分科策略明确**：数构"不整套看咸鱼强化课，按王道打卡表+选择题严格过一遍、不懂才看单集讲解"；计组/OS"咸鱼强化课值得完整看+保存课件流程图"；计网"湖科大强化书详细但累，时间不够只看基础书也行"——强化期四科投入方式完全不同，可作408强化期分科执行清单。
2. **强化期"先翻书再听课+二刷选择+写大题"**：每章开课前快速浏览书本对抗遗忘；"写大题是提升理解的最有效的方式"——直接可用于当前408强化阶段。
3. **强化期勤记笔记（数学+408同规格）**：一轮笔记可潦草、强化笔记才关键；每天记录错题与思路控制在半小时；408出题爱挑易错点、考得很细，笔记作用等同高数。
4. **数学提分在强化不在真题**：880+900选填正确率刷到90%以上才是水平来源，真题/模拟卷只是查漏补缺与维持手感；时间紧"只刷880就够"，900大题和严选题（除微积证明题）是低性价比坑。
5. **进度红线**：作者因期末/暑假放松+误刷难题导致**10月中旬才开数学真题、11月才开408真题**，自认"翻车"——浙大11408目标应把数学真题底线定在9月底~10月初、408真题不晚于10月。
6. **判分区现实**：浙区政治60+（写得满满当当也没上70）说明浙江主观题压分，公共课分数要往保守估，总分缺口靠数学+408扛。
