# 26考研京区22408初试441经验贴（检查为王·真题至上）

## 📊 基本信息
- **来源**: 知乎《26考研 京区22408 初试441 经验帖简易版》（作者 CPearl，北大信科强基，上岸中科院计算所）
- **考试科目**: 22408（数二+408）
- **特点**: 本科科班、5月启动、方法"非主流"但分数验证有效；对"真题 vs 模拟卷""检查环节"有独到结论

## 🎯 核心策略概览
5月起步先攻408，8-9月补其他。判断力强、不盲从题海：模拟卷非必须，真题一定吃透；数学高分的关键变量是"检查"。

## 📚 详细备考策略

### 1. 数学：检查是高分的必要环节
- 本科认真学过，未系统复习，只做卷：06-25真题 + 欧几里得8-11月模考 + 超越1-4 + 李四1/2/4。
- **考数二一定要练检查**：若今后难度接近26年，检查将是你保住高分的必要环节。作者平时就按3小时计时、用剩余时间检查，**考场上检查出约20分错误并全部改正**。
- 迁移到数一：计算量大，"会做但算错"极多，检查/草稿规范是稳分数的手段。

### 2. 408：一轮搭主干，真题为王
- 复习顺序（有基础者）：计组 → 操作系统 → 计网 → 数据结构；零基础须先从C语言+数据结构起。
- 每门课配合王道书：学一节/一章 → 看对应王道书 → 做书上选择题（大题不单独练，直接在真题里练）。
- 一轮耗时长（5月到9月），学完主干知识网络建立、无大漏洞。
- **真题核心法**：隔几天刷一张真题；早年408真题考查核心可直接做 → 做完把四本王道再过一遍清死角 → 再做近年真题。
- **金句结论**：掌握王道书上所有知识点和题型（不计低级错误和争议题），知识层面可到135+；"只看王道够不够"取决于能否真正"掌握所有"。
- **模拟卷非必须**：作者考前3天才刷完真题、没时间做模拟卷也高分 → 说明真题一定吃透，模拟卷非必要。

### 3. 英语：吃老本 + 核心词
- 不背红宝书6000词，背约**2000考研核心词汇**（自认不擅记忆，抓最高频）。
- 看往年真题（英一英二都看几年）感受风格；作文没准备模板直接写，体感考研英语作文比新高考简单。

### 4. 政治：小程序 + 临门资料
- 只听徐涛马原课（讲得清楚），其余没正经学。平时用小程序刷选择题。
- 临考看 PLDY大观、临门一脚、大牙"抄材料"教程。客观43、主观22（京区平均）。

## 💡 独特见解
1. 数学分数上限常常不取决于"会不会"，而取决于"能不能把会做的算对+查出来"。
2. 408与其堆模拟卷，不如把真题+王道反复吃透到无死角。
3. 信息差本身是分：考某研究所/院校要加对群，避免因招生政策变化踩坑。

## ⚠️ 避坑指南
- ❌ 盲目做完模拟卷才敢做真题 → ✅ 真题优先，模拟卷可放弃。
- ❌ 平时不限时、不练检查 → ✅ 全程3小时计时+留检查时间。
- ❌ 单词一上来啃6000 → ✅ 先吃透约2000核心词，抓高频。
