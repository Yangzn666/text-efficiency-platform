# 考研数学一139分高分经验贴(武忠祥体系)

## 📊 基本信息
- **作者背景**: 本科普通院校,有一定数学基础
- **考试科目**: 数学一
- **初试分数**: 139分
- **备考时长**: 约10个月
- **特点**: 全程跟随武忠祥老师,注重基础和方法论

## 🎯 核心策略概览
全程跟随武忠祥老师体系,基础阶段听武忠祥基础课+做660题,强化阶段听武忠祥强化课+刷严选题和880题,冲刺阶段真题+模拟卷。强调"在考场哪怕忘了,我们也能自己推出来"的理念。

## 📚 详细备考策略

### 1. 资料选择

#### 高数部分
- **基础阶段**:
  - 武忠祥《高等数学基础篇》讲义
  - 武忠祥660题
  - 武忠祥公众号每日一题
  
- **强化阶段**:
  - 武忠祥《高等数学辅导讲义》
  - 武忠祥严选题
  - 李林880题(综合篇+提高篇)
  
- **冲刺阶段**:
  - 历年真题(近15年,至少2遍)
  - 李林6+4套卷
  - 张宇8+4套卷
  - 超越5+5套卷

#### 线代部分
- **基础阶段**:
  - 张宇《基础30讲》线代分册 或 B站"没咋了"
  - 李林880题(基础篇)
  
- **强化阶段**:
  - 李永乐线性代数辅导讲义
  - 李林880题(综合篇+提高篇)

#### 概率论部分
- **基础阶段**:
  - 方浩概率论基础课
  
- **强化阶段**:
  - 方浩概率论强化课(强烈推荐)
  - 李林880题概率部分

### 2. 时间规划

#### 基础阶段(3月-6月)
- **每日时长**: 4-5小时
- **核心任务**:
  - 听武忠祥基础课
  - 做配套的高数基础篇的题
  - 跟武忠祥公众号每日一题
- **学习方法**:
  - 第一遍听了课不太会做题很正常,要仔细听,跟着老师的思路
  - 每一章听完课都要重新独立地做一遍题
  - 不会的和做错的题标记下来方便下次再做
  - 一定要自己先做再看老师的讲解视频
- **进度要求**:
  - 评估题目掌握情况:
    - 如果错的题比较多,就再刷一遍高数基础篇的题目
    - 如果掌握得比较好,建议刷张宇30讲的题目和配套300题
  - 660题正确率需达85%以上,否则补做汤家凤1800基础题

#### 衔接巩固阶段(7月)
- **特殊安排**: 
  - 不直接启动强化课
  - 花1个月复盘巩固基础知识
  - 重做基础阶段错题
  - 回顾武忠祥基础讲义与660题
- **原因**: 学完概率后,高数、线代遗忘较多,需要平稳过渡

#### 强化阶段(8月-9月)
- **每日时长**: 5-6小时
- **核心任务**:
  - 继续跟武忠祥老师的强化课
  - 做配套的高数辅导讲义
  - 听完课开始做660和武忠祥严选题
  - 做完这两本题后,开始做880并二刷
- **学习方法**:
  - 讲义上的题每道都很经典,建议2-3刷
  - 严选题难度大一些,第一遍不会没关系,好好复盘
  - 这两本建议至少二刷,第三遍只刷错题
  - 错题用A4纸整理,杜绝形式主义,反复消化错题

#### 冲刺阶段(10月-12月)
- **每日时长**: 4-5小时(上午8:30-11:30限时训练)
- **核心任务**:
  - 做真题(从2010年到最新,至少2遍)
  - 做模拟卷(李林6+4/张宇8+4/超越5+5)
  - 回顾错题,总结易错点
  - 严格按照考研时间模拟
- **进度要求**:
  - 10月: 完成真题一轮
  - 11月: 真题二轮 + 模拟卷
  - 12月: 查漏补缺,保持手感

### 3. 学习方法

#### 武忠祥体系特点

**核心理念**: "在考场哪怕忘了,我们也能自己推出来"
- **优势**: 
  - 侧重原理,提倡理解而非死记
  - 上课满满的全是干货,没有一句话是废话
  - 讲题能力很强,上课的体系很强
  - 每个题目都会有一些基础解法和简易解法
  
- **缺点**:
  - 课会默认你有一些基础,不然很难去体会他课上的一些思维
  - 有些同学反馈,武老师的课跟着容易困(建议配黑咖啡)
  - 数一专项部分内容不太全面,可以补上李正元全书或张宇老师的内容

**复习节奏**: "三天两节课"
- 三天的时间大概一共学12-15小时
- 其中4-6小时用来听课消化
- 剩下的时间先把上课的东西学好,然后再去做习题册

#### 660题使用方法

**定位**: "基础不基础,强化不强化"
- **适用人群**:
  - 第一种: 基础比较不错的同学,可以搭配本书+一本别的习题册
  - 第二种: 基础阶段刚刚结束,想要检测自己对概念和定理理解深度的同学
  
- **注意**: 
  - 这本书没有大题部分
  - 如果是刚学完基础阶段就直接尝试去做,可能会错的非常多
  - 级数那一部分,整整两页题,只对了一两个很正常

#### 每日一题的重要性

**武忠祥每日一题**:
- **特点**: 和武老师的性子很合适,细水长流,每天都会有讲解
- **内容**: 里面的题都很经典
- **建议**: 尝试着每天去跟一下
- **顺序**: 大概也是最近要复习到的地方
- **方法**: 整理到一个本子上,一定要自己先做再看老师的讲解视频

### 4. 名师选择建议

#### 为什么选择武忠祥?

**优点**:
1. **学院派讲解**: 能够把大多数基础概念和理解给你讲透彻
2. **讲义难度低**: 基础讲义里面的题目难度远低于张宇老师基础讲义的题目,对初学者友好
3. **思维清晰**: 提倡"在考场哪怕忘了,我们也能自己推出来"
4. **每日一题**: 细水长流,每天巩固

**缺点**:
1. **不够全面**: 这是没有推荐武忠祥老师作为唯一选择的原因
2. **数一专项内容少**: 可以补上李正元全书或张宇老师的内容
3. **容易困**: 有些同学反馈跟着容易困

**适用人群**:
- 基础一般,求稳的考生
- 喜欢系统性学习的考生
- 能够坚持跟每日一题的考生

#### 武忠祥vs张宇对比

| 维度 | 武忠祥 | 张宇 |
|------|--------|------|
| **教学思维** | 基础阶段讲基础概念和简单题目,强化阶段讲困难题目和方法 | 基础阶段就把知识全讲给大家,强化阶段核心是训练题目 |
| **课程难度** | 基础讲义难度低,对初学者友好 | 基础讲义难度较高,适合基础较好的 |
| **全面性** | 不够全面,数一专项内容少 | 知识点讲解非常全面 |
| **习题量** | 讲义例题题量不够,需补充 | 课后习题有视频讲解,优势明显 |
| **适合人群** | 基础一般,求稳 | 基础较好,想冲高分 |

**推荐方案**:
- **基础阶段**: 武忠祥(友好)或张宇(全面)
- **强化阶段**: 武忠祥(主流推荐)
- **补充**: 武忠祥后三章(无穷级数、三重积分、曲线曲面积分)质量已提升,但仍需补充张宇23版题目

## 💡 独特见解与建议

### 1. **武忠祥十七堂课**(强烈推荐)
- **价值**: 收留了很多"18讲心碎考研人"
- **特点**: 最强调的部分是训练,自己动手做做才知道自己哪里学的不好
- **使用方法**: 
  - 每个部分不需要都听
  - 效果最好的方式是先去做讲义
  - 等到自己实在是写不好了,再去看对应的课程

### 2. **思维导图非常重要**
- **认知**: 正确的使用思维导图和记录自己的思考总结是非常非常重要的
- **方法**: 
  - 看着每一讲的思维导图的框架
  - 自行脑补出这些具体的内容
  - 甚至能回忆起一些当时做过的题目
- **效果**: 如果能做到这一点,基础阶段的学习已经完全没问题

### 3. **循序渐进,一环扣一环**
- **理念**: 数学学习的过程是一环扣一环,循序渐进的
- **警告**: 
  - 你对上一个环节的理解和思考会不同程度上影响到下一个环节
  - 在任何一个环节都必须拼尽全力,不能囫囵吞枣,更不能贪多求快
  - 必须深刻理解掌握,否则你越往后走越会感觉到困难

### 4. **基础阶段培养良好学习习惯**
- **方法**: 
  - 多下点功夫对每一个知识点深入思考总结
  - 把一整章的内容合理的串联起来
  - 搞明白关系,捋清楚逻辑
- **效果**: 
  - 看似要花更多时间
  - 但实际上这为你后面的整个数学学习过程打下了非常扎实的基础
  - 越往后学你的优势越大

### 5. **计算能力至关重要**
- **原则**: 每道题都要算到底,锻炼计算能力
- **警告**: 一定不要眼高手低
- **方法**: 听完课一定要把例题再写一遍,查漏补缺

## ⚠️ 避坑指南

### ❌ 常见误区
1. **只看不练**: 视频看了很多,题做得很少,眼高手低
2. **过早放弃**: 第一遍不会就放弃,不相信"量变引起质变"
3. **忽视660题**: 觉得660题简单就不认真做
4. **不做每日一题**: 浪费了这个宝贵的资源
5. **不整理思维导图**: 知识点零散,无法形成体系

### ✅ 正确做法
1. **勤于动笔**: 每道题都要算到底
2. **坚持每日一题**: 细水长流,每天巩固
3. **重视660题**: 检测概念理解深度
4. **制作思维导图**: 串联知识点,形成体系
5. **反复刷错题**: 至少二刷,第三遍只刷错题

## 🎯 适用人群分析

- **特别提示**: 
  - 武忠祥体系适合大多数考生
