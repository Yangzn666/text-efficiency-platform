# 2025考研北大软微11408一战383分经验贴

## 📊 基本信息
- **作者背景**: 本科苏州大学人工智能专业,保研边缘但选择弃保考研
- **考试科目**: 11408(数学一/英语一/政治/408)
- **初试总分**: 383分(政治70 + 英语75 + 数学120 + 408 118)
- **备考时长**: 约9个月(2024年2月底-2024年12月)
- **开始时间**: 2024年2月底

## 🎯 核心策略概览
弃保后专注度大幅提升,采用"基础扎实+强化刷题+套卷模拟"三阶段策略。数学参考张宇+武忠祥体系,408以王道为主但更喜欢自己啃书而非看课。注重真题复盘和错题总结,考前一个月进入高强度套卷训练模式。

## 📚 各科详细策略

### 数学一(120分)
#### 1. 资料选择
- **基础阶段**: 张宇基础30讲 + 1000题A组 + 三大计算(高数版)
- **强化阶段**: 武忠祥强化课程 + 880题 + 900题(李艳芳)
- **冲刺阶段**: 张宇8+4套卷、李艳芳3套卷、超越5+5套卷、历年真题

#### 2. 时间规划
- **3月-6月**(基础阶段): 
  - 3月底完成高数基础
  - 4月底完成线代和概率论基础
  - 期间做660题和三大计算
- **7月-9月**(强化阶段):
  - 7月开始听强化课
  - 刷1800强化部分和1000题
  - 9月结束强化,做难度较高的900题
- **10月-12月**(冲刺阶段):
  - 先做21-24年真题
  - 完成900题剩余部分
  - 做模拟卷并回顾错题(重点看660和模拟卷错题)

#### 3. 学习方法
- 每天上午固定时间给数学,保证连续性
- 强化期间除了听课还做高难度题目用于冲刺高分
- 做套卷时暴露问题不要焦虑,及时总结改进是关键
- 把觉得好的题目做笔记mark,共性题目一起记录复盘
- 在卷子上标注错误原因(计算失误/知识不会/题型没见过等)

#### 4. 避坑建议
- 不要死磕大题导致没时间做前面跳过的题
- 考场上预留时间给之前跳过的小题
- 保持做题手感比单纯刷题更重要
- 哪一项弱就多练哪一项(如求积分)

### 408专业课(118分)
#### 1. 资料选择
- **主要资料**: 王道四本教材 + 王道视频(选择性观看)
- **辅助资料**: 湖科大计网视频
- **真题**: 历年408统考真题

#### 2. 时间规划
- **3月-6月**: 数据结构几乎没看课(有算法基础),计组和操作系统少量看课
- **7月-9月**: 完成408二轮复习,9月底完成强化
- **10月-12月**: 每天下午一张408套卷,晚上复盘

#### 3. 学习方法
- 相比数学,更喜欢自己啃书而非看课
- 看到难以理解的知识点或答案解析后,再去B站搜相关讲解
- DS因有算法竞赛基础,往年真题算法题基本能全对
- 计网看湖科大视频,其他都是王道

#### 4. 避坑建议
- 有算法基础的同学DS可以少看课,多自己理解
- 算法题在考场容易犯浑,平时要多练习手写代码
- 计组和计网细节较多,需要反复记忆

### 英语一(75分)
#### 1. 资料选择
- **单词**: 每日背单词APP
- **阅读**: 从05年真题开始,每天2篇阅读
- **作文**: 新东方版本模板 + AI润色
- **翻译**: 唐静老师课程(看了两三堂)

#### 2. 时间规划
- **前期**: 每日背单词,从05年真题每天2篇阅读
- **11月中旬**: 开始准备作文和翻译(较晚)
- **后期**: 较多时间花在政英上

#### 3. 学习方法
- 作文采用背模板方式,但不是死背
- 参考心海哥帖子,用AI将中文转化成符合考研大纲的英文表达
- 字丑的同学可以买字帖,10-11月每天练一练
- 好的卷面对作文很重要

#### 4. 避坑建议
- 作文和翻译不要拖到太晚开始
- 如果时间允许,唐静的翻译课应该全部看完
- 不同平台答案可能不一样,不要过度纠结

### 政治(70分)
#### 1. 资料选择
- **课程**: 徐涛马原强化班
- **刷题**: 肖秀荣1000题 + 小程序刷题
- **背诵**: 肖四肖八 + 腿姐手册

#### 2. 时间规划
- **10月底**: 开始政治复习
- **11月**: 做选择题,看肖四肖八带背视频
- **12月**: 突击肖四主观题和部分选择题

#### 3. 学习方法
- 利用碎片化时间刷小程序选择题
- 肖四主观题考前一周突击背诵
- 从题目中学习知识和做题技巧

#### 4. 避坑建议
- 政治开始时间不宜过晚
- 肖四不一定能完全背完,优先背马原和新思想部分
- 考前焦虑硬背也背不下来,不如早点休息

## 💡 独特见解与建议
1. **弃保后的专注度提升**: 放弃保研资格后,心理负担减轻,能够全身心投入考研复习
2. **408学习偏好**: 相比看课,更喜欢自己啃书,遇到难点再针对性搜索讲解
3. **AI辅助作文**: 利用AI工具将中文表达转化为符合考研要求的英文,提高效率
4. **考场时间管理**: 数学考试中跳过的题要预留时间回头做,避免死磕导致整体崩盘
5. **算法竞赛基础的双刃剑**: 虽然有优势,但考场容易因自信而犯浑,需保持谨慎

## ⚠️ 适用人群分析
- **适合**: 有一定算法基础、自律性强、能够自主学习的考生
- **不适合**: 基础薄弱、需要大量视频引导、跨考零基础的考生
- **特别提示**: 弃保考研风险较大,需评估自身实力和心理承受能力
