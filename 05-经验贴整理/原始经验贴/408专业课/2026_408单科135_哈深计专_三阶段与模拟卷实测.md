## 🎯 核心策略概览
408的重点是**重复 + 理解**：把知识理解后刻进脑子才能减少大面积遗忘，可用自己做的思维导图辅助记忆、方便快速过一轮，但绝非死记硬背。真题为王、模拟卷其次，全程一个循环：**回顾王道书 → 回顾强化讲义 → 真题练习 → 模拟练习 → 真题/模拟卷复盘 → 笔记总结消化**。

## 📚 详细备考策略

### 择校
408择校本质是"信息与策略的博弈"，辛辛苦苦学半年不如报名时点两下鼠标。27考研还不用急，建议暑假结束后慢慢了解择校报考。

### 基础阶段
- 资料：**王道四本书 + B站王道基础课就够了**。
- 顺序：本人按 **ds → co → os → cn**（强化阶段同序）。**co和os有很多相似/交叉知识点，非常建议一起学**。
- 一遍过王道书：学习理解知识点 + 同步完成课后选择题，主要攻克选择题（课后选择有些问题不用细究，以真题为主）。
- 一遍目标不是完全掌握，而是**建立知识框架**、对各知识点理解到一定程度即可，注意理解每个学科的核心概念；选择题错误要回看前面对应知识点并在书上做笔记记录，之后及时回顾。

### 强化阶段
- 老师/资料（2026实测推荐）：**零壹的数据机构（数据结构）+ 王道计网（咸鱼学长亲授，值得一听，湖科大计网也挑一部分看）+ 零壹的计组 + 零壹的操作系统（遇见亲授，值得一听）**。
- 节奏：每听完一节强化课就完成对应讲义，并**隔天及时复习强化课PPT**；模糊的地方翻王道四本书过知识点。
- 二遍过王道书：每消化完一节强化课，把对应王道选择错题看一遍并完成课后大题，主要攻克大题（大题和选择一样不必细究，以真题为主，王道课后有不少野题）。
- **强化阶段需要笔记本**：每门课(ds/co/cn/os)各准备一个专门笔记本，只用来总结重要的、常忘的知识；后面写卷子也把知识点总结上来（**题目不用抄，浪费时间**）。

### 冲刺阶段
- 强化完成后开始写真题卷和模拟卷，**留够3小时写一整套**，别写一会儿去玩。
- 真题写**1.5遍足够**（要完整地写一整套卷子才算，之前王道课后题形式不算）：第1遍每一年都完整写，后0.5遍只写你写得差的年份；但分数还不错年份的错题和知识点也要回顾。
- 模拟卷优先级低于真题；想冲120+/130+再做。刚开始吃力可半套半套写（先选择后大题），模拟卷分数不必焦虑细究，学会知识点就行。
- 模拟卷实测：写过零壹、竟成、王道、ACE、天勤、研芝士等，**只推荐零壹和竟成的模拟卷**，王道有时间也可写。第1遍真题差不多完成后建议**真题和模拟题轮流做**（竟成26版第一套不必理会，零壹模拟卷都可以写）。

### 考研进度（真实时间线参考）
- **6月下旬**：完成基础阶段王道课后选择题，回顾消化所有错题、理解四本书知识点。
- **暑假**：上午一套早年份数学卷或李林880，下午408王道课后大题或听零壹强化课并消化，晚上整套英一阅读，其余空闲纠错/消化/复盘。
- **9月下旬**：完成零壹强化课学习消化并写完王道课后大题。
- **10月上旬**：复盘王道书+课后真题错题+零壹强化讲义，即可开始真题卷和模拟卷轮流写。哪块知识学得不好就去补充写 relax 的1000题或重学一遍资料即可，**1000题全写完全没必要**。之后直到考前就是循环过程。

## 💡 独特见解与建议（作者"我想说的"）
1. 408重点 = 重复 + 理解，思维导图辅助记忆、非死记硬背。
2. 408有很多犄角旮旯知识点，谁也不知道写一次会不会被考到，能做的就是尽人事。
3. 注意身体健康，周末下午约研友去操场跑步或健身，洗完澡吃个饭休息一下。
4. **不要被网上信息影响（尤其是那群"模拟哥""进度哥"），不要畏难**（报考时很多人居心叵测传播焦虑），带着情绪也要接着学，坚持就是胜利，考研人不怕困难。
5. 学会利用网络资源和前人经验贴少走弯路、把时间用在刀刃上，但最重要的是结合自身情况做微调、及时调整备考。
