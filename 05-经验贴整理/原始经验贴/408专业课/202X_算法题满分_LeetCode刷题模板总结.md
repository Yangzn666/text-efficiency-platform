### 2. 算法模板总结

#### 排序算法模板
```c
// 快速排序
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pivot = partition(arr, low, high);
        quickSort(arr, low, pivot - 1);
        quickSort(arr, pivot + 1, high);
    }
}
```

#### 二叉树遍历模板

// 前序遍历
void preOrder(TreeNode* root) {
    if (root == NULL) return;
    visit(root);

    preOrder(root->right);
}

### 3. 常见算法思想

#### 动态规划
- **特征**: 最优子结构、重叠子问题
- **步骤**: 
  1. 定义状态
  2. 状态转移方程
  3. 初始化
  4. 返回结果
- **典型题**: 最长公共子序列、背包问题

#### 贪心算法
- **特征**: 局部最优导致全局最优
- **步骤**: 
  1. 建立数学模型
  2. 分解为子问题
  3. 求解子问题
  4. 合并解
- **典型题**: 活动选择、哈夫曼编码

#### 回溯算法
- **特征**: 穷举所有可能,剪枝优化
- **步骤**: 
  1. 定义解空间
  2. 确定搜索顺序
  3. 剪枝条件
  4. 保存结果
- **典型题**: N皇后、数独

## ⚠️ 避坑指南

### ❌ 常见误区
1. **只看不练**: 只看题解,不自己写代码
2. **忽视模板**: 不总结模板,考场现想
3. **不分类**: 随机刷题,效率低
4. **不写注释**: 代码没有注释,扣分严重
5. **忽视边界**: 不考虑边界条件,容易出错

### ✅ 正确做法
1. **勤加练习**: LeetCode 1000题,自己动手写
2. **总结模板**: 熟记常见算法模板
3. **分类刷题**: 按题型分类,集中突破
4. **写好注释**: 说明算法思想和关键步骤
5. **考虑边界**: 测试边界条件,确保正确
