## 一、个人情况与总基调

- 双非二本，**暑假7月才起步**，前期没上心；**8月发现只剩4个月**，从此进入高强度。
- 全篇按"政治 / 英语 / 数学 / 408"四科，各给一条**逐月时间线**，方法具体到老师、用书、每天题量与复盘方式。
- 极限起步的核心思路：**每一轮都"抓重点 + 反复二刷 + 复盘错题"**，不追求面面俱到。

## 二、政治：10月才开，徐涛强化只看马原史纲 → 1000题 → 肖八 → 肖四

| 时间段 | 任务 |
|--------|------|
| **10.1–10.31** | **徐涛强化课（只看马原 + 史纲）** + **肖秀荣1000题只做选择**；**二刷1000题选择**，复盘错题 |
| **11.1–11.30** | 继续**二刷1000题**；刷**肖八选择（一天一套、计时）**；认真复盘 |
| **12.1–考前** | **背肖四大题** |

- 取舍要点：强化课**只看马原、史纲**（理解型科目），毛中特/思修/形策不花时间听课，直接靠刷题与肖四兜底。
- 全程只做**选择题**（1000题、肖八），大题集中到12月背肖四——典型的"选择题为王、大题靠最后一个月"打法。

## 三、英语：8月中起步，阅读三刷 + 真题翻译拆长难句 + 作文模板

| 时间段 | 任务 |
|--------|------|
| **8.15–9.30** | 背单词 + 刷阅读 + **精读真题**；每天**2–3句真题翻译、拆解长难句**；每周1–2篇新题型 |
| **10.1–10.31** | **二刷阅读**；开始整理**作文模板**（小作文重点**书信**、大作文重点**图表**）；翻译每天2句；每周2篇新题型 + 2篇完型 |
| **11.1–考前** | 阅读**三刷**、总结各题型做题方法；**背作文**；**考前半个月刷套卷**，找适合自己的做题顺序 |

- 单词贯穿全程；阅读走"精读→二刷→三刷"三轮，每轮配合真题翻译与长难句拆解。
- 作文模板分型整理：**小作文主打书信、大作文主打图表**，11月起背诵。
- 考前半个月用套卷模拟，**确定个人做题顺序**。

## 四、数学：8月中加速一轮 → 强化刷题 → 真题+模拟（武忠祥/李永乐 + 1000/880 + 李林6+4）

| 时间段 | 任务 |
|--------|------|
| **8.15–9.20** | **加速把一轮学完**：高数**武忠祥**、线代**李永乐**；重点抓**极限计算、导数/微分中值定理、积分计算、二重积分、矩阵、向量组、特征值**等；刷**1000题 + 880** |
| **9.21–10.20** | **强化直接刷1000题和880**，哪里不行针对性回补 |
| **10.21–考前** | 刷**真题（两遍）**和模拟题；**回归教材公式考点**；模拟题**只刷李林6+4**；后面**模拟近3年真题**；反复做错题、背公式 |

- 老师分工明确：**高数武忠祥、线代李永乐**；题册以**1000题 + 880**为主力。
- 模拟卷只认**李林6+4**（不贪多）；冲刺阶段"真题两遍 + 近3年真题模拟 + 回归教材背公式"。

## 五、408：三阶段（基础→强化抓大题→真题）· 独家老师"沈悦"

| 时间段 | 任务 |
|--------|------|
| **8.15–9.20** | 按自己节奏**过完一轮基础**，抓考点重点学，把**重难点 + 高频考点**吃透：**树、图、排序、Cache计算、流水线、PV操作、文件索引、TCP**等（**沈悦会举例子、用图示讲解清楚**） |
| **9.21–10.31** | **二轮抓大题**：先跟**沈悦强化**梳理一遍重难点，老师**串联考点 + 讲对应题型和做题思路步骤**；很多大题有套路（**算法、Cache计算、PV操作**等沈悦会梳理**做题思路和模板**）；**弄懂再刷题** |
| **11.1–考前** | **刷真题**：一刷**按题型**、二刷**按套卷（一天一套、掐表做）**、当日复盘；错题和高频考点整理出来重点看；**考前梳理知识体系 + 高频考点 + 大题模板** |

- 用书：**王道408全套复习指导**；视频/强化跟**沈悦**。
- **沈悦三大特色（本篇最大独家）**：① 重难点**举例 + 图示**讲透（树/图/Cache/PV/TCP等）；② 强化阶段**串联考点**并配套**题型 + 做题思路步骤**；③ 把**算法、Cache计算、PV操作等大题**归纳成**套路与模板**。
- 408三轮节奏 = "一轮吃透重难点 → 二轮抓大题套路（先弄懂再刷）→ 三轮真题（按题型一刷、按套卷掐表二刷）"，与站内408"N轮学习法/双非9月起步"帖高度一致，但**多了一个"沈悦"老师选项**。
