## ⚠️ 使用建议

1. **不要只看一篇**: 建议至少阅读3-5篇不同背景的经验贴,找到适合自己的策略
2. **结合自身情况**: 每个人的基础、时间、目标都不同,不要生搬硬套
3. **重点关注共性**: 多篇经验贴都提到的方法和资料,通常更可靠
4. **注意时效性**: 优先参考近2-3年的经验贴,考研政策和题型可能有变化
5. **避坑指南很重要**: 特别关注作者提到的"血泪教训",避免重蹈覆辙
