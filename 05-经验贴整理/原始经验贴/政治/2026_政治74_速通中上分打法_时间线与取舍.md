## 二、常规路线的四科时间线（图3—图4，作者实际走过的）

作者自陈"政治是按常规路线走的，其中一些资料的有用程度仅高于玩手机，学不下去数学专业课的时候可以用用"；时间线按所用资料列出、**部分重叠**：

| 时间段 | 资料 / 老师 | 作者复盘评价（要点） |
|--------|-------------|----------------------|
| **8.1—11.10** | 徐涛马原·史纲课 + 肖1000 | 跨度长但没怎么学，**三倍速放完课**；马原课便于理解、没时间看也不影响做题；**觉得肖1000意义不大、全写很耗时，只写了不到一半** |
| **10.19—11.16** | 肖秀荣背诵手册带背 | 跟了一个月带背，**记住了0个知识点**，后悔"有这时间多做点数学错题不行吗" |
| **11.11—11.13** | 帕拉迪宇选择技巧 | 客观题分单选 / 多选，**多选全对才得分**、很多选项描述模糊，可用技巧判断该不该选，"推荐看看奇技淫巧" |
| **11.14—12.20** | 背帕拉迪宇一页纸 | **强烈推荐**；把背诵要点精简为一页纸，用**墨墨记忆卡**按记忆曲线反复背；与背单词并列为**日常任务**，不花很多时间但要坚持 |
| **11.17—12.7** | 肖八 + 苍盾模拟卷 | **一天做肖八选择题、一天看大牙解析做笔记记忆**；做完肖八用苍盾刷了十套，**可刷可不刷——不同老师出题角度有差异，刷太多反而影响做题思路** |
| **12.8—12.20** | 肖四 + 真题 + 大牙 | 每天一套肖四选择题，再**按题型背**（如马原分析题）；肖四也跟大牙、背整理后的大纲；写完成肖四做真题熟悉风格、复盘肖八错题笔记；**考前一晚看"考研春晚"——大牙抄材料教程**，考场上活用抄材料技巧 + 一页纸 / 肖四内容，**把答题卡填满就是胜利** |

## 三、选择题 / 分析题分别怎么练

**选择题（客观题，本篇主战场）**

- 抓评分规则：**多选题"全对才得分"**，所以重点是排除模糊干扰项，可学"奇技淫巧"式的判断技巧（帕拉迪宇选择技巧）。
- 练题载体：**肖八选择题 + 肖四选择题 + 真题选择题**为主干；模拟卷（苍盾）**适度即可**，作者明确"刷太多会影响做题思路"。
- 节奏：**一天做题、一天看大牙解析做笔记并记忆**，错题（尤其肖八）反复复盘。

**分析题（主观题）**

- **按题型背**（如马原分析题），跟**大牙**背其整理后的大纲，而非整段死背。
- 兜底策略：靠**一页纸 + 肖四内容**，考前学**大牙"抄材料"技巧**，考场上把**答题卡填满**即为胜利。

## 四、资料与老师阵容（本篇特有）

- **徐涛**：马原 / 史纲课，可三倍速、甚至不看也不影响做题（前期投入被作者自评偏低）。
- **肖秀荣**：1000题、背诵手册、肖八、肖四——全套照用，但作者对1000题与"带背"评价负面。
- **帕拉迪宇（牢宇）**：**一页纸 + 选择技巧**，本篇最核心的推荐位。
- **大牙**：肖八 / 肖四讲解 + **"考研春晚"抄材料教程**，主观题与解析的主力老师。
- **苍盾**：模拟卷小程序，作者评"可刷可不刷"。
- **墨墨记忆卡**：承载一页纸、按记忆曲线复习的工具。

## 五、旱区 vs 普通区：开政治时间的差异（作者立场）

- **普通区 / 追求速通**：可以**11—12月才开政治**，开太早只是混时长，考点到后期容易忘光。
- **旱区（判分紧、压分严重的地区）**：**开太晚有被"斩杀"（主观题被压到低分）的风险**，需要更早启动、把背诵与答题练得更扎实。
- **决策口径**：开分时间不是越晚越好，要按**目标分数 + 所在地区判分松紧**自行权衡。
