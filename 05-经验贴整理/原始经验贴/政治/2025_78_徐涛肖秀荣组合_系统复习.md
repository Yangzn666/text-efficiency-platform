# 考研政治78分系统复习经验(徐涛+肖秀荣组合,2025考研)

## 📊 基本信息
- **作者背景**: 基础一般或较好均可
- **考试科目**: 政治
- **初试分数**: 78分
- **备考时长**: 约5-6个月(6月底/8月中旬-12月)
- **特点**: 徐涛强化课+肖秀荣习题,分阶段系统复习

## 🎯 核心策略概览
考研政治取得78分,关键在于分阶段系统复习、针对性强化薄弱环节并注重时政积累。基础一般者6月底启动,基础较好者8月中旬开始。

## 📚 详细备考策略

### 1. 资料选择

#### 基础阶段
- **教材**: 肖秀荣《精讲精练》
- **视频**: 徐涛强化班
- **习题**: 肖秀荣《1000题》

#### 强化阶段
- **背诵**: 徐涛《冲刺背诵笔记》(小黄书)
- **真题**: 肖秀荣《讲真题》
- **时政**: 徐涛时政班 + 肖秀荣《时事政治》

#### 冲刺阶段
- **模拟卷**: 
  - 肖秀荣《肖八》
  - 肖秀荣《肖四》
  - 徐涛8套卷
  - 腿姐4套卷
- **直播课**: 肖秀荣考前直播课(资源易获取)

### 2. 时间规划

#### 基础搭建阶段(7-8月)
- **适用人群**: 基础一般者6月底启动,基础较好者8月中旬开始
- **核心任务**: 构建知识框架,重点攻克马原难点
- **具体操作**:
  - 教材与视频结合: 使用《肖秀荣精讲精练》搭配徐涛强化班视频
  - 逐章梳理知识点
  - 马原部分需反复理解,避免后期堆积问题
  
- **文科生优势**: 若具备政治基础,可适当压缩基础复习时间,但需确保选择题正确率

#### 强化巩固阶段(9-10月)
- **任务**:
  - 完成1000题第一遍
  - 看徐涛《冲刺背诵笔记》
  - 刷1000题第二遍
  
- **方法**:
  - 看完一科就开始刷那一科的1000题
  - 有些地方自己觉得不太清楚的就配合翻翻肖秀荣的精讲精练
  - 10月份开始看《风中劲草》(可选,重点太多,可换徐涛冲刺背诵笔记)

#### 冲刺突破阶段(11月)
- **任务**:
  - 背完一遍徐涛冲刺背诵笔记
  - 刷一遍1000题(第三遍)
  - 开始做模拟题
  
- **模拟卷选择**:
  - 买了一大堆,最后也只是做了:
    - 徐涛8套卷
    - 腿姐4套卷
    - 肖秀荣8套卷
    - 任汝芬4套卷
  - 都只需要做选择题
  
- **原则**: 模拟卷不在多,市面上的题筛选一下质量高的做个30套左右就足够了

#### 最后冲刺阶段(12月)
- **背诵**:
  - 11月底开始背诵
  - 主要有:
    - 知识点提要的框架
    - 肖秀荣四套卷的大题部分
    - 徐涛必背押题20题
    
- **直播课**: 12月份各个老师也会出热点直播课

- **肖四肖八**:
  - 肖秀荣的八套卷四套卷是最重要的
  - 很可能你背的就是原题

### 3. 学习方法

#### 分题型突破策略

**选择题(50分)**:
- **核心原则**: "得选择题者得高分",需重点突破
- **方法**:
  - 1000题反复刷(2-3遍)
  - 模拟卷选择题认真做
  - 搞清楚里面的知识点
  - 大部分题都是原则性错误,弄明白知识点就能做对
  - 熟悉出题套路(因果倒置、问题和选项对应等)

**分析题(50分)**:
- **核心原则**: 肖四分析题必背
- **方法**:
  - 11月底开始背诵
  - 肖四分析题全背
  - 徐涛必背押题20题辅助
  - 分点写,思维清晰

#### 马原难点攻克法

**问题**: 马原是政治中最难的部分,容易堆积问题

**解决**:
1. **早期攻克**: 7-8月基础阶段重点攻克马原难点
2. **反复理解**: 马原部分需反复理解,不能死记硬背
3. **视频辅助**: 配合徐涛强化班视频,帮助理解
4. **避免堆积**: 不要在后期才看马原,会来不及

#### 时政积累法

**重要性**: 时政是政治考试的重要组成部分

**方法**:
1. **徐涛时政班**: 系统学习时政知识点
2. **肖秀荣《时事政治》**: 补充时政资料
3. **12月热点直播课**: 各个老师出的热点直播课
4. **日常积累**: 平时关注新闻,了解热点事件

### 4. 考场策略

#### 时间分配
- **选择题**: 控制在40-50分钟内完成
- **分析题**: 每道题20-25分钟
- **检查**: 留出时间检查

#### 答题技巧
- **选择题**: 
  - 仔细审题
  - 排除明显错误选项
  - 注意因果倒置等陷阱
  
- **分析题**:
  - 分点作答
  - 思维清晰
  - 字迹工整
  - 把自己知道的点都写上去

## 💡 独特见解与建议

### 1. **分阶段系统复习**(重要认知)
- **理念**: 政治复习需要分阶段进行,每个阶段有不同重点
- **实施**: 
  - 基础阶段: 构建知识框架
  - 强化阶段: 刷题巩固
  - 冲刺阶段: 背诵+模拟
- **效果**: 系统性复习,避免遗漏

### 2. **徐涛+肖秀荣组合**
- **优势**: 
  - 徐涛强化课讲解生动,易于理解
  - 肖秀荣习题权威,贴近考试
  - 两者结合,优势互补
- **实施**: 
  - 看徐涛视频
  - 做肖秀荣习题
  - 背徐涛笔记
  - 背肖四分析题

### 3. **模拟卷不在多,在于精**
- **原则**: 市面上的题筛选一下质量高的做个30套左右就足够了
- **关键**: 要认真搞清楚里面的知识点
- **现象**: 大部分题都是原则性错误,只要弄明白知识点就能做对

### 4. **马原需早期攻克**
- **问题**: 马原是政治中最难的部分,容易堆积问题
- **解决**: 
  - 7-8月基础阶段重点攻克
  - 反复理解,配合视频
  - 避免后期堆积

### 5. **时政积累不可忽视**
- **重要性**: 时政是政治考试的重要组成部分
- **方法**: 
  - 徐涛时政班
  - 肖秀荣《时事政治》
  - 12月热点直播课
  - 日常关注新闻

## ⚠️ 避坑指南

### ❌ 常见误区
1. **起步太晚**: 基础一般者11月才开始,时间不够
2. **忽视马原**: 马原难点堆积到后期,来不及攻克
3. **贪多求全**: 买太多模拟卷,做不完
4. **只看视频**: 只看视频不做题,效果差
5. **不背肖四**: 觉得肖四不重要,不背分析题

### ✅ 正确做法
1. **适时启动**: 基础一般者6月底,基础较好者8月中旬
2. **早期攻克马原**: 7-8月重点攻克马原难点
3. **精选模拟卷**: 质量高的30套左右足矣
4. **视频+做题**: 看视频的同时要做题巩固
5. **肖四必背**: 分析题全背,反复背
